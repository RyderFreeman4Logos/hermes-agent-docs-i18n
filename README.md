# Hermes Agent Docs i18n

This repository publishes a bilingual mdBook mirror of the local Hermes Agent
documentation. It keeps the English source documents from
`/home/obj/.hermes/hermes-agent`, translates changed files to Simplified Chinese
with `hymt`, and publishes the result through GitHub Pages.

Published site:

<https://ryderfreeman4logos.github.io/hermes-agent-docs-i18n/>

## Translation Backend

The Chinese translation is produced locally by
[`hymt`](https://github.com/RyderFreeman4Logos/hymt), another open-source
project developed by RyderFreeman4Logos. It is backed by a 6-bit quantized HY
translation model currently running on this host:

- Model file: `/ssd/mirror-rootfs/home/obj/models/hy-mt2/Hy-MT2-7B.i1-Q6_K.gguf`
- Quantization: `Q6_K` GGUF, 6-bit class quantization
- Runtime: `llama-server`
- GPU: NVIDIA GeForce RTX 3070 Laptop GPU, 8 GiB VRAM
- Observed GPU memory use: about 7.9 GiB for the translation server
- Server endpoint: `http://100.78.159.38:8401/v1`
- Context: `-c 24576`, `--parallel 3`
- KV cache: `-ctk q8_0 -ctv q8_0`
- Inference parameters: `--temp 0.7 --top-k 20 --top-p 0.6 --repeat-penalty 1.05`

`hymt` caches completed translations. This repository also records source file
hashes in `state/translation-hashes.tsv`, so normal sync runs only translate
files whose source content changed. If an English source file disappears, the
corresponding Chinese file is removed on the next sync.

## Layout

- `src/en/` mirrors the selected English Markdown/MDX documentation.
- `src/zh/` contains the Chinese translations generated by `hymt`.
- `src/SUMMARY.md` is generated for mdBook and includes both language sections.
- `theme/language-toggle.js` adds a language switch link to book pages.
- `config/sync.toml` controls translation concurrency for manual and timer
  runs.
- `scripts/sync_docs.py` performs source sync, translation, mdBook summary
  generation, optional commit, and optional push.
- `systemd/` contains user service/timer units for unattended syncs.

## Manual Sync

```bash
python3 scripts/sync_docs.py --commit --push
```

For a dry metadata refresh without translating:

```bash
python3 scripts/sync_docs.py --skip-translation
```

For a bounded first run:

```bash
python3 scripts/sync_docs.py --max-files 20 --commit --push
```

## Translation Concurrency

Edit `config/sync.toml` to change how many `hymt translate-doc` jobs are active:

```toml
[translation]
workers = 1
worker_ceiling = 10
hot_reload_interval_seconds = 10
```

The sync process hot-reloads `workers` while it is running. Lowering the value
does not terminate already-started `hymt` jobs; it stops queueing new work until
the active job count falls under the new limit. Raising `workers` takes effect
up to `worker_ceiling` without restarting the process.

## Timer Install

```bash
scripts/install-systemd-user-timer.sh
```

The timer runs as the `obj` user after the normal Hermes update window. It tries
to fast-forward the Hermes Agent source checkout when that checkout is clean,
skips source updates when local changes are present, translates only changed
files, commits each completed translation as its own Git commit, and pushes each
commit to GitHub immediately. This keeps long translation runs recoverable if
the process is interrupted.

## GitHub Pages

GitHub Actions builds the mdBook on every push to `master` and deploys it using
GitHub Pages.
