# CLI 符号词汇表

Hermes 终端界面使用一种简洁的视觉语言：点、箭头、盲文旋转图标以及状态符号。本页面便是这种视觉语言的“解码器”，介绍了 [TUI](../user-guide/tui.md)（这些符号大多在此显示）的相关内容，并说明了与 [Classic CLI](../user-guide/cli.md) 共用的部分。

:::note 外观主题可重新设计部分符号
下方标有 *themeable* 的符号为品牌默认样式——[外观主题](../user-guide/features/skins.md) 可以对其进行覆盖（例如 `tool_prefix` 和提示符符号）。其余所有符号的显示方式在渲染器中是固定的。
:::

## 对话流中的符号

Agent 运行时在对话流程中显示的符号。

| 符号 | 含义 |
|------|------|
| `❯` | 输入提示符——即用户输入文字的位置。该符号支持主题定制（不同皮肤可设置自定义提示符符号）。 |
| `●` | 工具调用。此符号位于工具名称及其参数之前。 |
| `┊` | 工具操作栏，由多条工具线组成。该部分同样支持主题定制（可通过 `tool_prefix` 参数调整）。 |
| `✓` / `✗` | 工具执行结果：成功/失败。会显示在已完成工具行的末尾。 |
| `▸` / `▾` | 切换折叠/展开的箭头符号（用于切换思考过程、工具、子智能体及横幅区域等内容）。点击即可切换状态。 |
| `▍` | 流式光标——在模型仍在输出文本时会闪烁。 |
| `│` `├─` `└─` | 树状结构栏——用于连接父节点（如委托任务、处理流程）与其子项；`└─` 表示最后一个子项。 |
| `◈` | 仅用于显示的时间线事件（如会话通知会以内联形式呈现，而非用户消息）。 |
| `◇` | 注入的参考块，例如 `◇ 参考1/2 — <标签>`。 |
| `↳` | 固定提示符——会显示智能体当前正在处理的用户输入内容。 |
| `☐` / `☑` / `•` | Markdown任务列表项（待办/已完成状态）以及普通列表项目符号。 |
| `▶` | 在渲染的Markdown内容中用于表示已折叠的 `<details>` 区块标题。 |

## 状态栏符号

位于TUI底部的单行界面。相关内容仅会在必要时显示，且在终端宽度较窄时这些元素会优先隐藏。

| 符号 | 含义 |
|------|------|
| `⠋⠙⠹…`（盲文图案） | 正在处理中的旋转动画。思考阶段与工具使用阶段会采用不同的盲文动画效果。 |
| `⚕ 🌀 🤔 ✨ 🍵 🔮` | `emoji`型忙碌指示器风格的帧（格式为`/indicator emoji`）。默认风格则会循环显示各类表情符号。 |
| <code>&#124; / - &#92;</code> | `ascii`型忙碌指示器风格的帧。 |
| `⏱` | 单次响应过程中的耗时，例如`⏱ 12s/3m 45s`表示响应时间/会话总时长。 |
| `⏲` | 同上，用于显示单次响应结束后暂停的计时器。 |
| `cmp N` | 该会话已自动压缩过N次。 |
| `▶ N` | 当前有N个`/bg`任务正在运行中。 |
| `⚠ YOLO` | 已开启YOLO模式（自动批准）。此提示也会显示在启动横幅上。 |
| `⛓ N` | 当前有N个子代理处于活跃状态。 |
| `↩ resumes when subagent finishes` | 当子代理处理完毕时会显示的提示，用于在您处于空闲状态但任务仍在处理时给予安抚——结果会自动返回。 |
| `● REC` | 语音模式正在录音。 |
| `◉ STT` | 语音录音已停止，当前正在进行语音转文字处理。 |
| `◉ focus` | 已进入聚焦视图（输出内容减少）。该视图会被固定，确保不会在宽度较小的终端中消失。 |
| `♥` | 情感闪光提示——Hermes检测到您对它很友善。 |
| `⚡` / `🔋` | 电池状态指示器（需手动开启）：显示是否正在充电/使用电池，同时附带电量百分比。 |
| `N bg` | 本次会话中正在跟踪的背景终端进程数量为N个。 |
| `N live sessions` | 该进程中已打开的TUI会话数量——点击即可打开会话切换器。 |

## 注意事项

短暂显示在状态栏中的通知会带有根据严重程度设定的专属符号：

| 符号 | 含义 |
|------|------|
| `✓` | 成功通知。 |
| `•` | 信息性通知。 |
| `⚠` | 警告（也用于信用警告）。 |
| `✕` | 错误通知。 |

## 审批与确认提示

| 符号 | 含义 |
|------|------|
| `⚠ approval required` | 某工具需要执行某项操作，必须获得您的明确同意（带命令预览的边框面板）。 |
| `⚠` / `?` | 确认对话框标题：危险操作 / 普通问题。 |
| `🔐` | 需输入超级用户密码的提示（输入内容会被隐藏）。 |
| `🔑` | 需输入凭证/密钥的提示（输入内容会被隐藏）。 |

## 子代理状态显示（`/agents`）

| 符号 | 含义 |
|------|------|
| `●` | 子代理正在运行。 |
| `○` | 处于队列中。 |
| `✓` | 已完成。 |
| `■` | 被中断。 |
| `✗` | 失败。 |
| `⌛` | 超时。 |
| `⚠` | 出现错误。 |
| `⚡N` | 汇总行中当前活跃的代理数量为 N。 |
| `▁▂▃▄▅▆▇█` | 活动状况缩略图——各分支近期的操作频率。 |

## 会话切换器（`Ctrl+X`）

| 符号 | 含义 |
|------|------|
| `✓` | 会话处于空闲状态。 |
| `…` | 正在启动。 |
| `?` | 正在等待输入。 |
| `▶` | 正在运行中。 |
| `✎ draft` | 该会话中的编辑器有未发送的草稿。 |

## 选择器与中心控件

| 符号 | 含义 |
|--------|---------|
| `▸` | 当前选中行（模型选择器及好友列表）。 |
| `*` | 当前正在使用的模型/服务提供商。 |
| `●` / `○` | 服务提供商已认证/未认证（模型选择器）；插件状态备用指示（插件中心）。 |
| `✓` / `✗` | 插件已启用/已禁用（插件中心）。 |
| `↑ N more` / `↓ N more` | 列表可视区域上方/下方的更多行。 |
| `┃` | 可滚动界面上的滚动条滑块。 |

## 目标

目标生命周期状态提示（来自 [goals](../user-guide/features/goals.md)）会首先显示目标状态：

| 符号 | 含义 |
|--------|---------|
| `✓` | 目标已完成。 |
| `↻` | 目标仍在执行中——已安排下一次迭代。 |
| `⏸` | 目标已暂停。 |
