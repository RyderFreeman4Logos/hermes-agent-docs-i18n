# Impeccable（上游维护）

> **目录条目占位符。** 此项由上游项目
> [pbakaus/impeccable](https://github.com/pbakaus/impeccable) 维护：该项目会在 `.hermes/skills/` 目录下发布并验证符合 Hermes 标准的技能包。通过 `hermes skills install impeccable` 命令即可从该仓库获取最新版本的技能包（与通过 hub 安装的方式一样，会经过隔离和扫描处理）——该目录仅存放目录元数据，因此所使用的版本永远不会过时。
Impeccable 是一种专为 AI 编码智能体设计的语言：它通过一个技能即可提供 23 个子命令（如 `/impeccable init`、`craft`、`shape`、`critique`、`audit`、`polish`、`bolder`、`quieter`、`distill`、`harden`、`onboard`、`animate`、`colorize`、`typeset`、`layout`、`delight`、`overdrive`、`clarify`、`adapt`、`optimize`、`extract`、`document`、`live`），同时提供明确的反模式指导（如过度使用的字体、紫色渐变、嵌套卡片以及不自然的弹性动画效果），还配有基于 61 条规则的确定性检测命令行工具（`npx impeccable detect`），且无需依赖 LLM 或 API 密钥。安装完成后，可先从以下操作开始使用：

```
/impeccable init
```
