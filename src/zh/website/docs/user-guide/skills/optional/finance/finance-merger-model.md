# 合并模型

用于为并购交易构建价值增值/稀释分析。可模拟备考盈亏平衡值的影响、协同效应的敏感性变化，以及收购价格的分配方式。适用于评估潜在收购项目、为推介材料准备合并后果分析，或为交易条款提供咨询。

## 工作流程

### 步骤 1：收集输入数据

**收购方：**
- 公司名称、当前股价、流通股数量
- 近期及当前会计年度的每股收益（GAAP 标准及调整后）
- 市盈率
- 税前债务成本、税率
- 资产负债表中的现金余额、现有债务规模

**目标公司：**
- 公司名称、当前股价、流通股数量（如为上市公司）
- 近期及当前会计年度的每股收益或净收入
- 企业价值或股权价值

**交易条款：**
- 每股要约价格（或较当前价格的溢价比例）
- 对价构成：现金支付占比与股票支付占比
- 为支付现金部分而新发行的债务规模

## 重要注意事项

- 在适用情况下，务必同时展示GAAP标准每股收益及调整后的（现金）每股收益数值
- 股权收购类交易：计算换股比率时应采用收购方的当前股价，并注明新增股份带来的稀释效应
- 需明确列示收购价格分配情况——商誉及无形资产摊销会对GAAP标准下的每股收益产生重要影响
- 协同效应的释放节奏至关重要——通常首年实现的协同效应仅相当于全周期总效应的25%至50%
- 切勿忽略因资金占用而错过的利息收入，以及新增债务所带来的利息支出
- 协同效应相关的税率及利息调整数值，应与收购方的边际税率保持一致

## 数据来源——优先使用MCP，无法获取时再启用网络搜索

下文多处提及“使用S&P Kensho MCP / Daloopa MCP / FactSet MCP”这类商业金融数据接口。这些接口源自原有的Cowork插件环境。在Hermes系统中：

- **若已配置任何结构化金融数据MCP**（Hermes支持MCP功能，详见`native-mcp`技能），应优先使用它们来获取特定时间点的对比数据、历史同类交易案例及官方披露文件
- **若未配置此类接口**，则可采取以下替代方案：
  - 对于美国市场的披露文件，可通过SEC EDGAR网站（`https://www.sec.gov/cgi-bin/browse-edgar`）使用`web_search`/`web_extract`功能进行检索
  - 新闻稿和业绩演示材料可从公司的投资者关系页面获取
  - 需要访问交互式数据平台时，可使用`browser_navigate`功能
  - 若现有信息不足，可明确要求用户提供相关数据
- **严禁编造数据**。若无法找到合适的估值倍数、历史案例或文件编号，应将该单元格标记为`[UNSOURCED]`，并向用户说明情况。
