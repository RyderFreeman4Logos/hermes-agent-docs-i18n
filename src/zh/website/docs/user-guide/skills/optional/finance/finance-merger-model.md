# 合并模型

为并购交易构建权益增值/稀释分析功能。该工具可模拟预测合并后的每股收益变动、协同效应的敏感度以及收购价格的分摊方式。适用于评估潜在收购项目、为投资推介准备并购影响分析，或为交易条款提供咨询。

## 工作流程

### 第1步：收集输入数据

**收购方：**
- 公司名称、当前股价、流通股数量
- 近期及当前季度的每股收益（按GAAP标准及调整后数据）
- 市盈率
- 税前债务成本、税率
- 资产负债表中的现金余额、现有债务规模

**目标公司：**
- 公司名称、当前股价、流通股数量（如为上市公司）
- 近期及当前季度的每股收益或净利润
- 企业价值或股权价值

**交易条款：**
- 每股要约价格（或较当前价格的溢价幅度）
- 对价构成：现金支付比例与股票支付比例
- 为现金支付部分筹集的新债务规模
- 预期产生的协同效应（收入与成本方面）及逐步实现的时间表
- 交易费用及融资成本
- 预计完成交易日期

## 重要说明

- 在适用情况下，始终同时展示按通用会计准则计算的每股收益及调整后的（现金）每股收益。  
- 股权收购交易：在计算换股比率时应使用收购方的当前股价，并注明新增股份带来的稀释效应。  
- 需明确列示收购价格的分摊情况——商誉及无形资产摊销对按通用会计准则计算的每股收益具有重要影响。  
- 协同效应的释放需逐步体现——通常第一年的协同效应仅能达到预期总效应的25%至50%。  
- 切勿忽略因使用现金而错失的利息收入，以及因举债新增的利息支出。  
- 协同效应相关的税率及利息调整项，应与收购方的边际税率保持一致。  

## 数据来源——优先使用MCP，无法获取时再启用网页检索

下文多处提到“使用S&P Kensho MCP / Daloopa MCP / FactSet MCP”。这些均源自原有Cowork插件环境中的商业金融数据MCP服务。在Hermes系统中：  
- **若已配置任何结构化的金融数据MCP**（Hermes支持MCP功能，详见`native-mcp`技能），则优先使用它们来获取特定时间点的对比数据、历史交易案例及监管文件信息。  
- **否则**，可依次采用以下方式：  
  - 对于美国公司的监管文件，可通过SEC EDGAR网站（`https://www.sec.gov/cgi-bin/browse-edgar`）使用`web_search`/`web_extract`功能进行检索；  
  - 从公司官网的投资者关系页面获取新闻稿及业绩展示材料；  
  - 使用`browser_navigate`功能访问交互式数据平台；  
  - 接收用户提供的数据（当上下文信息不足时需主动询问用户）。  
- **绝不可编造数据**。若无法找到相应的倍数、历史案例或文件编号，应将该数据单元标记为`[UNSOURCED]`，并向用户说明情况。
