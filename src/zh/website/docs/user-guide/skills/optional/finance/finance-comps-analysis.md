# 对标公司估值分析

## ⚠️ 重要提示：数据源优先级（请首先阅读）

**务必遵循以下数据源层级顺序：**

1. **首要步骤：检查MCP数据源**——若可用S&P Kensho MCP、FactSet MCP或Daloopa MCP，应优先使用这些数据源获取金融与交易相关信息。

**为何如此重要？** MCP数据源能够提供经过验证的机构级数据，并附带规范的引用信息。而网络搜索结果往往过时、不准确，或无法满足金融分析的需求。

## 概述
该技能旨在指导智能体构建机构级的可比公司分析报告，通过整合运营指标、估值倍数及统计基准数据，帮助用户通过同行对比做出更明智的投资决策。分析结果将以结构化的Excel/电子表格形式呈现，便于用户进行深入分析。

- 掌握撰写原则（清晰的标题、透明的公式表达、可追溯的记录路径）

**务必首先自问：**

3. **“核心问题是什么？”**（估值分析、增长潜力评估、市场竞争地位分析、效率优化）  
4. **“背景情况如何？”**（并购评估、投资决策、行业对标、绩效审查）  

**需根据具体情况灵活调整：**  
- **行业特性**：大型科技巨头与新兴SaaS初创企业所需的指标各不相同  
- **行业特定需求**：应提前加入相关指标（例如科技行业需关注云服务年度经常性收入、企业客户数量及开发者生态状况）  
- **公司熟悉度**：知名企业可能无需过多背景介绍，而应侧重于变化趋势分析  
- **决策类型**：并购评估与日常投资组合监控在侧重点上存在差异  

**核心原则：** 严格遵循模板设计原则（清晰的结构、严谨的统计分析、透明的公式表达），但需根据具体情境调整呈现方式。目标在于产出具备机构级专业水准的分析报告，而非仅仅追求类似机构文档的格式外观。

用户提供的示例及明确指定的偏好设置始终优先于默认值。

## 核心理念
**“先构建合理的结构，再让数据讲述故事。”**

首先通过标题引导人们思考关键要素，输入干净的数据，建立透明的公式，让统计结果自动生成。一份优秀的对比分析报告应能让未参与制作的人也能立即理解。

---

## ⚠️ 重要提示：使用公式而非硬编码 + 分步验证

**必须使用公式，而非硬编码：**
- 所有衍生数值（利润率、倍数、统计指标等）都必须是引用输入单元格的 Excel 公式——绝不能直接粘贴预先计算好的数字
- 使用 Python/openpyxl 构建表格时，应写入 `cell.value = "=E7/C7"`（公式字符串），而非 `cell.value = 0.687`（计算结果）
- 唯一可进行硬编码的值应是原始输入数据（如营收、EBITDA、股价等）——并且每个数据都应在对应单元格中添加说明其来源的注释
- 原因：当输入数据发生变化时，模型必须能自动更新。硬编码的利润率其实是一个随时可能引发问题的隐患。

**需与用户一起分步进行验证：**
- 设置好结构后 → 在填充数据之前向用户展示表头布局  
- 输入原始数据后 → 在构建公式之前向用户显示输入区域，并确认数据来源与时间范围  
- 构建运营指标公式后 → 在进入估值环节之前，向用户展示计算出的利润率结果并进行合理性检查  
- 确定估值倍数后 → 在添加统计信息之前，先展示这些倍数并确认其数值合理  
- 不要一次性完成整个表格的构建后再呈现结果——应通过逐项确认来尽早发现错误

## 第1节：文档结构与设置

### 表头区域（第1至3行）
```
Row 1: [ANALYSIS TITLE] - COMPARABLE COMPANY ANALYSIS
Row 2: [List of Companies with Tickers] • [Company 1 (TICK1)] • [Company 2 (TICK2)] • [Company 3 (TICK3)]
Row 3: As of [Period] | All figures in [USD Millions/Billions] except per-share amounts and ratios
```

**为何如此重要：** 能立即明确背景信息。任何打开此文件的人都能立刻了解其内容、创建时间以及如何解读其中的数值。

### 视觉规范标准（可选——用户的偏好设置及上传的模板始终具有优先权）

**重要提示：** 以下仅为建议的默认设置。请始终以以下顺序为优先级：
1. 用户明确指定的格式偏好
2. 任何上传的模板文件中的格式设置
3. 公司/团队的风格指南
4. 才是这些默认设置（仅在其他指导信息均不存在时适用）

**推荐的字体与排版：**
- **字体系列**：Times New Roman（专业、易读，为行业标准）
- **字体大小**：数据单元格为11磅，标题为12磅
- **加粗文本**：章节标题、公司名称、统计指标标签

**默认颜色与阴影——专业蓝灰配色方案（简洁为佳）：**
- **色彩控制**：仅限蓝色与灰色，严禁使用绿色、橙色、红色或其他辅助色调。一份整洁的报表最多应使用3至4种颜色。
- **章节标题**（例如“运营统计数据与财务指标”）：
  - 背景色为深蓝色（`#1F4E79`或`#17365D`深蓝色）
  - 正文为白色粗体字
  - 所有列均需填充完整行阴影
- **列标题**（例如“公司名称”、“营收”、“利润率”）：
  - 背景色为浅蓝色（`#D9E1F2`或类似浅蓝色）
  - 正文为黑色粗体字
  - 文本居中显示
- **数据行**：
  - 公司相关数据背景为白色
  - 公式内容用黑色字体显示；固定值则用蓝色字体显示
- **统计行**（最高值、第75百分位数等）：
  - 背景色为浅灰色（`#F2F2F2`）
  - 文本为黑色，标签左对齐
- **完整配色方案**：深蓝色 + 浅蓝色 + 浅灰色 + 白色。除非用户模板另有规定，否则不得使用其他颜色。

**推荐的格式规范：**
- **小数精度**：
  - 百分比：保留1位小数（12.3%）
  - 数值倍数：保留1位小数（13.5x）
  - 美元金额：不显示小数，使用千位分隔符（69,632）
  - 以百分比表示的利润率：保留1位小数（68.7%）
- **边框**：无需添加边框，以保持简洁风格
- **对齐方式**：所有指标均居中对齐，以确保视觉统一性
- **单元格尺寸**：所有列宽应保持一致，所有行高也应相同，从而形成整洁专业的表格结构

**注意**：若用户提供了模板文件或指定了其他格式要求，请优先遵循这些规定。

## 第2节：运营统计数据与财务指标

### 核心列（优先展示这些）
1. **公司名称**——需采用统一格式
2. **营收**——规模类指标（根据具体语境可为过去12个月、季度或年度数据）
3. **营收增长率**——同比百分比变化
4. **毛利润**——营收减去销售成本
5. **毛利率**——毛利润/营收（反映基本盈利能力）
6. **EBITDA**——息税折旧摊销前利润
7. **EBITDA利润率**——EBITDA/营收（体现运营效率）

### 可选补充项（根据行业或分析目的选择）
- **季度数据与过去12个月数据**——若存在季节性差异，需同时列出
- **自由现金流**——适用于资本密集型或SaaS企业
- **FCF利润率**——自由现金流/营收（反映现金生成效率）
- **净收入**——适用于已成熟且盈利良好的企业
- **营业利润**——适用于折旧摊销金额不固定的企业
- **资本支出相关指标**——适用于资产密集型行业
- **40法则**——专为SaaS行业设计（增长率百分比 + 毛利率百分比）
- **FCF转化率**——用于分析盈利质量（高级用法）

### 公式示例（以第7列为例）
```excel
// Core ratios - these are always calculated
Gross Margin (F7): =E7/C7
EBITDA Margin (H7): =G7/C7

// Optional ratios - include if relevant
FCF Margin: =[FCF]/[Revenue]
Net Margin: =[Net Income]/[Revenue]
Rule of 40: =[Growth %]+[FCF Margin %]
```

**黄金法则：** 所有的比率都应采用 [某数值] / [营收]，或是 [某数值] / [本表格中的某数值] 的形式。保持简洁为佳。

### 统计数据模块（公司数据之后）

**非常重要：** 必须为所有可对比的指标（比率、利润率、增长率、倍数等）添加相应的统计公式。

```
[Leave one blank row for visual separation]
- Maximum: =MAX(B7:B9)
- 75th Percentile: =QUARTILE(B7:B9,3)
- Median: =MEDIAN(B7:B9)
- 25th Percentile: =QUARTILE(B7:B9,1)
- Minimum: =MIN(B7:B9)
```

**需要统计指标的列（可对比的财务指标）：**
- 营收增长率%、毛利率%、EBITDA利润率%、每股收益
- EV/营收倍数、EV/EBITDA倍数、市盈率、股息收益率%、贝塔值

**无需统计指标的列（规模相关指标）：**
- 营收、EBITDA、净利润（具体数值会因公司规模而异）
- 市值、企业价值（不同规模的公司之间不具备可比性）

**注意：** 为便于区分，应在公司数据行与统计指标行之间插入一行空白行。请勿添加“行业统计”或“估值统计”之类的标题行。

**为何四分位数如此重要：** 它们反映的是数据的分布情况，而不仅仅是平均值。75百分位倍数能帮助您了解企业的估值是否处于较高水平。

## 第3节：估值倍数与投资指标

### 核心估值指标列（请从这些开始）
1. **公司名称** - 顺序与运营数据部分相同
2. **市值** - 当前市场估值
3. **企业价值** - 市值 ± 净债务/现金
4. **EV/营收倍数** - 市场为每美元营收所支付的金额
5. **EV/EBITDA倍数** - 市场为每美元盈利所支付的金额
6. **市盈率** - 股价与净收益的比率

### 可选估值指标（根据实际情况选择）
- **自由现金流收益率**——自由现金流/市值（适用于以现金流为分析重点的情况）  
- **PEG比率**——市盈率/增长率（适用于处于成长阶段的企业）  
- **市净率**——市场价值与账面价值的比值（适用于资产密集型企业）  
- **净资产收益率/总资产收益率**——收益指标（用于盈利能力对比）  
- **营收/EBITDA复合增长率**——历史增长速度（用于趋势分析）  
- **资产周转率**——营收/资产总额（用于衡量运营效率）  
- **负债率**——杠杆水平（用于分析资本结构）  

**核心原则：** 仅选择与所处行业相关的3-5个关键估值指标，切勿因可选指标众多而全部纳入。  

### 公式示例
```excel
// Core multiples - always include these
EV/Revenue: =[Enterprise Value]/[LTM Revenue]
EV/EBITDA: =[Enterprise Value]/[LTM EBITDA]
P/E Ratio: =[Market Cap]/[Net Income]

// Optional multiples - include if data available
FCF Yield: =[LTM FCF]/[Market Cap]
PEG Ratio: =[P/E]/[Growth Rate %]
```

### 交叉引用规则
**至关重要：** 估值倍数必须引用“运营指标”部分。严禁重复输入相同的基础数据。如果营收数据位于C7单元格，则EV/Revenue计算公式也应引用C7单元格中的数据。

### 统计数据区块
结构与运营指标部分相同：每项指标均需列出最大值、第75百分位值、中位数、第25百分位值及最小值。在公司数据与统计结果之间添加一行空白行以便区分。**不得**添加“估值统计数据”这一标题行。

## 第4节：备注与方法论说明文档

### 必需组成部分

**数据来源与质量：**
- 数据来自何处？（S&P Kensho MCP、FactSet MCP、Daloopa MCP、彭博社、美国证券交易委员会备案文件）
- 数据覆盖的时间范围是什么？（2024年第四季度，经审计的财务数据）
- 数据是如何核实的？（通过与10-K/10-Q文件进行交叉验证）
- 备注：如有可能，请优先使用MCP数据源（S&P Kensho、FactSet、Daloopa），以提高数据的准确性和可追溯性。

**关键定义：**
- EBITDA的计算方法（毛利润 + 折旧与摊销，或营业利润 + 折旧与摊销）
- 自由现金流的计算公式（营业现金流 - 资本支出）
- 特殊指标的说明（40法则、自由现金流转换率）
- 时间周期的定义（最近12个月、复合年增长率的计算周期）

**估值方法论：**
- 企业价值的计算方式是什么？（市值 + 净负债）
- 使用了哪些增长率？（历史复合年增长率、未来预测值）
- 是否进行了任何调整？（剔除一次性项目、标准化利润率等）

**分析框架：**
- 投资逻辑是什么？（云服务/软件即服务的效率）
- 哪些指标最为重要？（现金流生成能力、资本使用效率）
- 阅读者应如何解读这些数据？（分位数有助于提供参考背景）

## 第5节：选择合适的指标（决策框架）

### 先明确“我要回答什么问题？”

**“哪家公司被低估了？”**
→ 重点关注：企业价值/营收比率、企业价值/EBITDA比率、市盈率、市值
→ 可忽略：运营细节、增长指标

**“哪家公司的效率最高？”**
→ 重点关注：毛利率、EBITDA利润率、自由现金流利润率、资产周转率
→ 可忽略：规模指标、绝对金额数值

**“哪家公司的增长速度最快？”**
→ 重点关注：营收增长率、EBITDA复合年增长率、用户/客户数量增长情况
→ 可忽略：利润率指标、杠杆比率

**“哪家公司的现金流生成能力最强？”**
→ 重点关注：自由现金流、自由现金流利润率、自由现金流转化率、资本支出强度
→ 可忽略：EBITDA、市盈率

### 不同行业的指标选择策略

**软件/软件即服务行业：**
必须关注的指标：营收增长率、毛利率、40法则指标
可选指标：年度经常性收入、净留存价值、客户获取成本回收期
可忽略的指标：资产周转率、库存相关指标

**制造业/工业行业：**
必须关注的指标：EBITDA利润率、资产周转率、资本支出/营收比率
可选指标：净资产收益率、库存周转率、未完成订单量
可忽略的指标：40法则指标、软件即服务行业指标

**金融服务行业：**
必须关注的指标：净资产收益率、总资产收益率、效率比率、市盈率
可选指标：净利息利润率、贷款损失准备金
可忽略的指标：毛利率、EBITDA（对银行行业而言意义不大）

**零售/电子商务领域：**
必选指标：营收增长、毛利率、库存周转率
可选指标：同店销售额、客户获取成本
可跳过指标：涉及大量研发支出或资本支出的指标

### “5-10法则”

**5项运营指标**——营收、增长速度，以及2-3项利润率/效率指标
**5项估值指标**——市值、企业价值，以及3种估值倍数
**总计10列数据**——既能完整呈现分析内容，又不会因信息过多而显得杂乱无章

如果指标数量超过15项，很可能其中包含无关信息。请果断进行筛选。

## 第6节：最佳实践与质量检查

### 开始之前
1. **明确对标群体**——所选公司必须在业务模式、规模及地域分布等方面具有真正可比性
2. **选择合适的时间周期**——长期数据可平滑季节性波动，而季度数据则更便于观察趋势
3. **提前统一数据单位**——是使用百万还是十亿作为单位，这一决定会影响到所有后续分析
4. **明确数据来源**——需清楚每项数据的出处

### 在构建过程中
1. **先输入所有原始数据**——在编写公式之前，需先填完蓝色标注的内容。  
2. **为所有硬编码的输入添加单元格注释**——右键点击单元格 → 插入注释 → 注明数据来源或假设依据。  

   **对于引用自外部的数据，需明确标注其来源：**  
   - 例如：“彭博终端——微软股票预期收益率，数据获取日期为2024年10月2日”  
   - 例如：“2024年第四季度10-K季度报告，第42页，‘总收入’项目”  
   - 例如：“截至2024年10月2日的FactSet共识预期值”  
   - **尽可能添加超链接**：右键点击单元格 → 添加链接 → 粘贴SEC文件、数据源或报告的网址。  

   **对于假设条件，需说明其推理逻辑：**  
   - 例如：“由于该公司未公开相关数据，故按行业平均水平15%的EBITDA利润率进行估算”  
   - 例如：“企业价值估算值为市值加上5000万美元的净负债（数据来自第三季度资产负债表，第四季度数据暂未公布）”  
   - 例如：“前瞻性市盈率基于市场共识预测的每股收益3.45美元计算（该数值为12位分析师预测值的平均值）”  

   **为何如此重要？**这有助于建立审计追踪机制、验证数据准确性、提高假设透明度，并便于后续更新。  
3. **逐行构建公式**——在继续下一步之前，需先测试每项计算结果。  
4. **标题行请使用绝对引用**——例如使用 $C$$6 即可锁定标题行。  
5. **保持格式一致**——百分比应直接以百分比形式显示，而非小数。  
6. **添加条件格式**——自动标出异常值。  

### 合理性检查
- **利润率测试**：毛利率 > EBITDA利润率 > 净利润率（按定义始终成立）  
- **估值倍数合理性**：  
  - EV/营收：通常为0.5–20倍（不同行业差异较大）  
  - EV/EBITDA：通常为8–25倍（各行业间相对稳定）  
  - P/E比率：通常为10–50倍（取决于企业成长速度）  
- **成长性与估值倍数的关联**：企业成长速度越快，其估值倍数通常越高  
- **规模效率权衡**：规模较大的企业往往拥有更高的利润率（得益于规模优势）  

### 需避免的常见错误  
❌ 在公式中混用市值与企业价值  
❌ 分子与分母使用不同的时间周期（如使用全期数据与季度数据）  
❌ 直接在公式中输入固定数值，而非使用单元格引用  
❌ **直接硬编码数值，却未添加说明来源的单元格注释或解释相关假设**  
❌ 若有相关资料，未添加指向SEC备案文件或数据源的超链接  
❌ 无明确目的地纳入过多指标  
❌ 包含业务模式不同的不可比企业  
❌ 使用过时数据且未予以说明  
❌ 错误地计算百分比的平均值（应使用中位数）

## 第7节：工作流程与实用技巧

### 分步操作流程
1. **搭建结构**（30分钟）
   - 创建所有标题行
   - 设置单元格格式（输入数据用蓝色，公式用黑色）
   - 固定单位与日期引用格式

2. **收集数据**（60-90分钟）
   - 从原始数据源获取数据（若有S&P Kensho MCP、FactSet MCP、Daloopa MCP则优先使用；否则可使用Bloomberg或SEC数据）
   - 将所有原始数值以蓝色填入
   - 在备注栏中记录数据来源

3. **构建公式**（30分钟）
   - 从简单比率（如利润率）开始
   - 逐步过渡到倍数指标（如企业价值/营收比）
   - 添加交叉验证步骤（确认利润率数值合理）

4. **添加统计分析**（15分钟）
   - 复制所有列的公式结构
   - 核对数据范围是否正确（例如应为B7:B9，而非B7:B10）
   - 检查分位数计算逻辑

5. **质量管控**（30分钟）
   - 执行合理性检查
   - 验证公式引用是否正确
   - 检查是否存在#DIV/0!或#REF!错误
   - 与已知基准数据进行对比

6. **文档编写**（15分钟）
   - 完成备注栏内容
   - 注明数据来源
   - 明确说明计算方法
   - 为分析结果标注日期

### 专业建议
- **保存模板**：一次构建，多次复用
- **对异常值进行颜色标记**：对偏离均值2个标准差以上的数值应用条件格式
- **链接到原始文件**：通过超链接关联Bloomberg截图或SEC备案文件
- **版本控制**：采用“Comps_v1_2024-12-15”等包含明确日期的命名方式保存文件
- **协作审核**：请他人帮忙检查公式正确性

## 第10节：风险信号与警示标志

### 数据质量问题
🚩 时间周期不一致（同时出现季度数据和年度数据）  
🚩 未作说明即缺失数据  
🚩 不同数据源之间的差异过大（差异超过10%）

### 估值方面的风险信号
🚩 对EBITDA为负的公司仍采用EBITDA倍数进行估值（应改用营收倍数）  
🚩 无高速成长支撑却拥有超过100倍的市盈率  
🚩 利润率低于该行业常规水平

### 可比性存在的问题
🚩 财年结算日不同（会导致时间差异问题）  
🚩 将纯行业公司与综合型企业混为一谈  
🚩 将业务模式存在显著差异的公司错误地列为可比对象

**如有疑问，最好直接排除该公司。** 三个完美的对比案例总比六个存疑的要好。

## 核心原则总结

1. **结构决定洞察力**——恰当的标题能引导正确的思考方向  
2. **少即是多**——5-10个关键指标远胜于20个无关指标  
3. **根据问题选择指标**——估值分析≠效率分析  
4. **数据揭示规律**——中位数/分位数比平均值更能反映真实情况  
5. **透明优于复杂**——简单易懂的公式更佳  
6. **可比性至上**——宁可排除某些公司，也不要强行进行不当对比  
7. **记录决策依据**——在备注部分说明所选指标及其原因

## 数据来源——优先使用MCP，再考虑网页检索

下文多处提到“使用S&P Kensho MCP / Daloopa MCP / FactSet MCP”。这些均为源自原有Cowork插件环境的商业金融数据MCP工具。在Hermes中：

- **如果您已配置了任何结构化的金融数据MCP**（Hermes支持MCP功能，详见`native-mcp`技能），则优先使用它们来获取特定时间点的同业对比数据、历史交易案例及监管文件信息。
- **否则**，可采取以下替代方案：
  - 对于美国公司的监管文件，可使用`web_search`/`web_extract`功能检索SEC EDGAR网站（`https://www.sec.gov/cgi-bin/browse-edgar`）上的内容；
  - 从公司官网的投资者关系页面获取新闻稿和业绩演示文稿；
  - 使用`browser_navigate`功能访问交互式数据平台；
  - 采用用户提供的数据（当上下文中没有相关数据时，请主动向用户询问）。
- **绝不可编造数据**。如果无法找到倍数对比、历史案例或监管文件编号，应将该数据单元标记为`[UNSOURCED]`，并向用户显示。
