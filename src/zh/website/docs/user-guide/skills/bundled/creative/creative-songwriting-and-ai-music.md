# 歌曲创作与 AI 音乐生成

此处所有内容均为指导原则，并非硬性规则。艺术创作本就旨在打破常规。
选用对歌曲有帮助的方法，忽略那些无用的内容。

---

## 1. 歌曲结构（选择一种或自行设计）

常见框架——可根据需求进行组合、修改或舍弃：

```
ABABCB  Verse/Chorus/Verse/Chorus/Bridge/Chorus    (most pop/rock)
AABA    Verse/Verse/Bridge/Verse (refrain-based)    (jazz standards, ballads)
ABAB    Verse/Chorus alternating                    (simple, direct)
AAA     Verse/Verse/Verse (strophic, no chorus)     (folk, storytelling)
```

**六个核心构成要素：**  
- **引子（Intro）**——奠定氛围，吸引听众的注意力  
- **主歌（Verse）**——讲述故事、呈现细节、构建世界观  
- **副歌前段（Pre-Chorus）**——在高潮来临前可选地逐步增强紧张感  
- **副歌（Chorus）**——情感的核心，也是人们最容易记住的部分  
- **桥段（Bridge）**——路径的转变，视角或调性的切换  
- **结尾（Outro）**——作为告别，可呼应前文内容或打破常规  

你并非必须使用所有这些元素。有些出色的歌曲仅由一个不断发展的段落构成。结构应服务于情感，而非相反。  

---

## 2. 押韵、节奏与音效  

**押韵类型（从严格到宽松）：**  
- **完全押韵**：lean/mean  
- **家族押韵**：crate/braid  
- **元音谐韵**：had/glass（元音相同，尾音不同）  
- **辅音谐韵**：scene/when（元音不同，尾音相似）  
- **近似押韵**：足以暗示关联但不够严格  

可将多种押韵方式混合使用。全用完全押韵的句子会显得像童谣；全用近似押韵的句子则可能显得拖沓。唯有巧妙结合才能达到最佳效果。  

**内部押韵**：指行内各词相互押韵，而不仅限于行尾。  
例如：“We pruned the lies from bleeding trees / Distilled the storm from entropy”——“lies/flies”与“trees/entropy”形成了行内的回响效果。  

**节奏**：由重读音节与非重读音节构成的韵律。  
- 平行诗句的音节数量相近更便于演唱  
- 重读音节的重要性高于总音节数  
- 大声朗读试试看，如果读起来卡顿，说明节奏需要调整  
- 有意打破常规节奏可以制造强调效果或惊喜感

## 3. 情感脉络与动态变化  

将歌曲视作一段旅程，而非平坦的道路。

**能量结构划分（仅作参考，非固定格式）：**  
引子：2–3小节 | 主歌：5–6小节 | 前副歌：7小节  
副歌：8–9小节 | 桥段：时长不定 | 最终副歌：9–10小节  

最有效的动态技巧在于**对比**。  
- 在爆发性高音之前先轻声低语，效果会比直接大喊更强烈；  
- 从稀疏到密集、从缓慢到快速、从低音到高音逐步推进；  
- 只有经过充分的铺垫，高潮部分才能产生震撼效果；  
- 沉默本身也是一种音乐元素。  

“从轻声到咆哮，再回到轻声”——以亲密感开头，逐渐积累力量，最终回归脆弱状态。这一手法适用于民谣、史诗曲目及赞歌。

## 4. 如何创作出出色的歌词  

**以行动展现，而非直接陈述（通常原则）：**  
- “我很难过” = 平淡无味  
- “你的连帽衫还挂在门边的钩子上” = 生动有力  
- 但有时直白地表达“我愿奉献一生”反而更具力量  

**记忆点——副歌核心句：**  
- 那句让人难以忘怀、会哼唱或反复吟诵的歌词；  
- 通常是歌曲标题或核心短语；  
- 当旋律、歌词与情感完美契合时，效果最佳；  
- 最佳位置通常在副歌的第一行或最后一行。  

**韵律搭配——歌词与音乐的相互呼应：**  
- 安稳的情绪（如释然、平静）适合节奏平稳的旋律、完美的押韵以及解决式的和弦；  
- 不稳定的情绪（如思念、疑虑）则适合起伏不定的旋律、近似押韵的措辞以及未解决的和弦；  
- 主歌的旋律通常较低，而副歌则逐渐升高；  
- 但若能服务于歌曲整体风格，也可打破这一常规。  

**应避免的情况（除非有意为之）：**
- 机械式套用陈词滥调（未经铺垫就使用“金子般的心”这类表述）  
- 强行调整语序以凑押韵（类似尤达式说话方式）  
- 各段落情绪表达千篇一律（缺乏动态变化）  
- 将初稿视为不可更改的圣物——修改其实也是一种创作

## 5. 拙劣模仿与改编  

在为现有歌曲填入新歌词时：  

**框架构建：** 先分析原曲的结构。  
- 统计每行的音节数  
- 标出押韵模式（ABAB、AABB等）  
- 确定哪些音节是重读音节  
- 记下长音出现的位置  

**匹配新歌词：**  
- 将重读音节对应到与原曲相同的节奏上  
- 总音节数可灵活调整1-2个非重读音节  
- 对于长音部分，尽量模仿原曲的元音发音  
  （若原曲以“oo”元音发长音“LOOOVE”，则“FOOOD”比“LIFE”更合适）  
- 在关键位置用单音节词替换，以保持节奏稳定  
  （如将“Crime”换成“Code”，“Snake”换成“Noose”）  
- 将新填的歌词对着原曲试唱——若有卡顿之处，及时修改  

**核心构思：**  
- 选择一个足以贯穿整首歌的强主题  
- 从标题或副歌入手逐步展开内容  
- 先大量收集素材（双关语、短语、意象等），  
  再将最合适的元素融入结构中  
- 若需要在某处加入特定句子，可逆向推导押韵模式来设计相应内容  

**保留部分原曲元素：** 保留少量原句或原结构，既能增强歌曲的辨识度，也能让听众感受到其与原作的关联。

## 6. Suno AI提示词工程  

### 风格/流派描述字段

公式（可根据需求调整）：
音乐类型 + 氛围 + 时代背景 + 乐器配置 + 声音风格 + 制作手法 + 力度控制

```
BAD:  "sad rock song"
GOOD: "Cinematic orchestral spy thriller, 1960s Cold War era, smoky
       sultry female vocalist, big band jazz, brass section with
       trumpets and french horns, sweeping strings, minor key,
       vintage analog warmth"
```

不仅要描述类型，更要描绘整个体验历程：
```
"Begins as a haunting whisper over sparse piano. Gradually layers
 in muted brass. Builds through the chorus with full orchestra.
 Second verse erupts with raw belting intensity. Outro strips back
 to a lone piano and a fragile whisper fading to silence."
```

提示：  
- V4.5及以上版本允许在“风格”字段中输入最多1,000个字符，建议充分利用此功能。  
- 禁止使用艺术家姓名或商标，应通过描述来体现音乐风格。例如，应写“1960年代冷战题材的间谍惊悚风格铜管乐”，而非“詹姆斯·邦德风格”；应写“90年代垃圾摇滚”，而非“涅槃乐队风格”。  
- 若有特定偏好，可明确标注节拍速度（BPM）和调性。  
- 如需排除某些风格，可使用“排除风格”字段。  
- 出人意料的风格组合往往能带来独特效果，比如“波萨诺瓦陷阱乐”、“阿巴拉契亚哥特风”或“芯片音效爵士乐”。  
- 建立有特色的人声形象，而不仅仅是指定性别。例如：“一位嗓音低沉沙哑、略带粗糙感的资深歌手，起初表现脆弱，随后逐渐释放出极具震撼力的演唱力”。  

### 元标签（请放在歌词字段中的[括号]内）  
结构：  
[引子] [主歌] [第一主歌] [前副歌] [副歌]  
[后副歌] [高潮段] [桥段] [间奏]  
[器乐部分] [器乐间奏] [吉他独奏]  
[情绪释放段] [渐强段落] [结尾] [静音] [结束]  

人声表现：  
[低语] [说唱] [强而有力的演唱] [假声] [充满力量]  
[富有情感] [沙哑] [气声] [流畅] [粗犷]  
[断奏] [连奏] [颤音] [花腔]  
[和声] [合唱] [和声副歌]  

动态变化：  
[高能量] [低能量] [逐渐增强] [爆发力强]  
[情感高潮] [逐步升温] [管弦乐式渐强]  
[安静的编曲] [紧张感减弱] [放慢节奏]  

性别：  
[女声] [男声]  

氛围：  
[忧郁] [欢快] [怀旧] [激进]  
[梦幻] [亲密] [黑暗氛围]  

音效：  
[黑胶唱片杂音] [雨声] [掌声] [静电声] [雷声]

为增强效果，请在“风格”字段和“歌词”字段中均添加标签。每个板块的标签数量最多控制在5-8个——标签过多会导致AI混淆。同时避免内容自相矛盾（同一板块内不得同时出现[Calm]与[Aggressive]等对立标签）。

### 自定义模式
- 进行重要创作时请始终使用自定义模式（分别填写风格与歌词部分）
- 歌词字段长度限制：约3,000字符（约40-60行）
- 务必添加结构化标签——若不添加，Suno会默认采用平铺式的主歌/副歌/主歌结构，且缺乏情感层次。

## 7. 面向AI歌手的发音技巧

AI歌手并非通过阅读来演唱，而是直接发音。可通过以下方法协助它们：

**拼写调整法**：
- 按单词的实际发音来拼写：“through”应拼作“thru”
- 专有名词的错误率最高——建议尽早测试
- “Nous”可拼作“Noose”，以此强制正确发音
- 通过连字符划分音节：如“Re-search”、“bio-engineering”

**演唱节奏控制法**：
- 全大写表示声音更响亮、情绪更强烈
- 元音拉长：如“lo-o-o-ove”可表现持续发音或花腔效果
- 省略号：如“I... need... you”可营造戏剧性的停顿感
- 连字符拉长：如“ne-e-ed”可表达情感上的延展

**通用注意事项**：
- 数字务必用文字书写：如“24/7”应写成“twenty four seven”
- 缩写词需加空格：如“AI”应写成“A I”或“A-I”
- 建议先在30秒的短片段中测试专有名词及生僻词汇
- 一旦内容生成，发音便已固定——务必提前在歌词中修正问题

## 8. 工作流程

1. 首先确定核心概念或主题——其情感内核是什么？  
2. 若需改编，需保留原作的结构（音节、押韵、重音）。  
3. 挖掘创作素材——在构建框架之前先自由发挥创意。  
4. 根据既定结构撰写歌词初稿。  
5. 朗读或试唱——发现卡顿之处并调整节奏。  
6. 编写适合Suno风格的描述——描绘音乐的动态发展过程。  
7. 为歌词添加元标签，以明确演绎方向。  
8. 至少生成3-5个不同版本——将其视同多次录制尝试。  
9. 选出最佳版本，再利用“扩展/续写”功能对有潜力的部分进行深化。  
10. 若偶然创作出出色片段，应直接保留。  

预期效果：每获得一个优质结果，大约需要3-5次生成迭代；修改是正常现象。在后续扩展时风格可能会出现偏移，此时需重新明确音乐类型与氛围。

## 9. 经验总结

- 在风格描述中清晰呈现歌曲的动态变化，远比单纯列出音乐类型更为重要。通过“从轻声细语到激昂高唱再到再度轻语”的描述，能为Suno提供完整的表演脉络。
- 在恶搞作品中保留部分原曲歌词，不仅能增强作品的辨识度，还能传递更深的情感共鸣——听众能感受到原作的影子。
- 歌曲的过渡段落正是转变意境的最佳时机。可将原曲中的具体意象替换为符合自身主题的隐喻，同时保持其情感功能（如反思、转折或揭示）。
- 在副歌或标签部分使用单音节词替换，是既能在保持节奏的同时又能改变含义的最简洁方法。
- 在风格描述中精心塑造鲜明的演唱形象，其效果远胜于任何单一的元标签。
- 不必过分拘泥于规则。即便某句歌词打破了节奏，但若能带来更强烈的感染力，就应当保留。重要的是情感表达，创作应服务于艺术，而非相反。

## 10. 本地/开源音乐生成

若希望在不使用Suno的情况下通过本地GPU进行音乐生成，有两种可选技能可满足需求（由于依赖性较强，因此不会默认安装）：

- **heartmula**——可根据歌词和标签生成带人声的完整歌曲（开源版Suno替代工具，需8-16GB显存）：
  `hermes skills install official/creative/heartmula`
- **audiocraft**——包含Meta开发的MusicGen（纯音乐文本转音乐功能）和AudioGen（音效生成功能）：
  `hermes skills install official/creative/audiocraft-audio-generation`
该技能中的歌词创作与提示词编写技巧同样适用于 HeartMula——其输入格式为带有括号结构标签以及逗号分隔的风格标签的歌词。
