# 任务列表截取功能异常

在从 `apps/desktop` 模块安装完工作区依赖项及 Playwright Chromium 后出现的问题：

```sh
npm run test:task-scroll
```

这两项测试会分别使用14条和20条模拟任务记录，来加载生产环境下的`ComposerStatusStack`（包括状态分组、板块折叠功能、任务行以及对应的生产级样式表）。真实的Chromium浏览器输入数据必须能够正确显示并检测到受限视口内的最后一行内容，且该位置需位于某个组合器边界之上。在执行折叠与展开操作时，页面的滚动状态必须保持不变。页面无法通过内联CSS处理或`scrollIntoView`方法来修复问题。该测试用例不依赖任何后端、模型、Electron原生桥接技术或用户会话数据；它属于渲染组件的回归测试，而非原生应用的全链路测试。

测试运行器仅监听回环端口18120，并会自动清理其使用的浏览器及Vite服务器。它的Vite缓存是私有的。如需将JSON格式的几何数据及截图保存到指定目录中，可设置`TASK_SCROLL_OUTPUT`环境变量；否则这些数据将存储在测试运行生成的临时目录中。在参与共享测试计划时，建议将该命令封装在对应测试计划的`flock tests.lock`文件中，并对`HOME`和`HERMES_HOME`环境变量进行隔离处理。
