# 问题分类体系

请使用此分类体系对在内部测试过程中发现的问题进行归类。

## 严重程度级别

### 极严重
该问题会导致核心功能完全无法使用或造成数据丢失。

**示例：**
- 应用程序崩溃或显示空白页面
- 表单提交时导致用户数据丢失且无任何提示
- 认证功能完全失效（无法登录）
- 支付流程失败，在未完成订单的情况下向用户扣款
- 安全漏洞（如 XSS 攻击、控制台泄露敏感信息）

### 严重
该问题会显著影响功能正常使用，但可能存在临时解决方案。

**示例：**
- 某关键按钮点击后无反应（但刷新页面后可恢复正常）
- 对于有效的搜索查询，系统无法返回任何结果
- 表单验证机制拒绝接受有效输入
- 页面虽能加载，但关键内容缺失或显示异常
- 导航链接指向 404 错误页或其他错误页面
- 核心页面的控制台出现未捕获的 JavaScript 异常

### 中等
该问题较为明显，会影响用户体验，但不会阻碍核心功能的正常使用。

**示例：**
- 某些屏幕区域中的布局错位或元素重叠
- 图片无法加载（显示损坏的图标）
- 性能较差（明显的加载延迟超过 3 秒）
- 表单字段缺乏有效的验证反馈（输入错误时无提示信息）
- 控制台出现提示功能已过时或配置错误的警告
- 相似页面之间的样式不一致

### 轻微
仅为一些不影响功能的细微优化问题。

**示例：**
- 文本内容中出现拼写错误或语法错误
- 稍微的间距或对齐问题
- 生产环境仍保留占位文本（如“Lorem ipsum”）
- 缺少图标文件
- 控制台出现本不应出现在生产环境中的信息或调试消息
- 颜色对比度略低，但尚未违反 WCAG 标准要求

## 问题类别

### 功能问题
功能无法按预期工作的问题。

- 按钮/链接无响应
- 表单无法提交或提交结果错误
- 用户操作流程中断（无法完成多步骤操作）
- 显示的数据不正确
- 部分功能可以正常工作

### 视觉问题
页面视觉呈现方面的问题。

- 布局问题（元素重叠、网格结构损坏）
- 图片损坏或媒体文件缺失
- 样式不一致
- 响应式设计失效
- Z-index 层级问题（元素被其他元素遮挡）
- 文本溢出或截断

### 无障碍访问问题
妨碍残障用户使用产品的问题。

- 有意义的图片缺少替代文本
- 颜色对比度不足（未达到 WCAG AA 标准）
- 元素无法通过键盘导航访问
- 表单缺少标签或 ARIA 属性
- 聚焦指示器缺失或不明显
- 不兼容屏幕阅读器的内容

### 控制台问题
通过 JavaScript 控制台输出检测到的问题。

- 未捕获的异常及未处理的 Promise 拒绝
- 网络请求失败（控制台中显示 4xx、5xx 错误）
- 功能过时警告
- CORS 错误
- 混合内容警告（HTTPS 页面上出现 HTTP 资源）
- 开发阶段留下的过多 console.log 输出

### 用户体验问题
功能虽能正常工作，但用户体验较差的问题。

- 导航结构或信息架构令人困惑
- 缺少加载指示器（用户无法知晓正在处理中）
- 用户操作后无任何反馈（如点击按钮后无任何可见变化）
- 交互模式不一致
- 执行破坏性操作时缺少确认对话框
- 错误提示信息无效，无法帮助用户解决问题

### 内容问题
页面上的文本、媒体或信息存在的问题。

- 拼写错误和语法错误
- 生产环境仍保留占位/虚拟内容
- 信息过时
- 内容缺失（某些区域为空）
- 外部资源链接失效
- 标签错误或具有误导性
