# 信息图内容分析框架

一种将教学设计原则应用于信息图制作的深度分析框架。

## 设计目的

在创建信息图之前，需对原始素材进行深入分析，以实现以下目标：
- 深入理解内容本质
- 明确设定受众的学习目标
- 对信息进行合理结构化处理，提升清晰度与记忆效果
- 选择最合适的布局与风格组合
- 原样保留所有原始数据

## 教学设计思维方式

以**世界级教学设计师**的标准来开展内容分析：

| 原则 | 应用方式 |
|------|----------|
| **深入理解** | 在分析任何部分之前，先通读完整文档 |
| **以学习者为中心** | 关注受众需要掌握的知识点 |
| **视觉叙事** | 运用视觉元素进行信息传递，而非单纯装饰 |
| **认知负荷管理** | 在不损失准确性的前提下简化复杂概念 |
| **数据完整性** | 绝不对原始事实进行修改、概括或改写 |

## 分析维度

### 1. 内容类型分类

| 类型 | 特点 | 最佳布局 | 最佳风格 |
|------|------|----------|----------|
| **时间线/历史** | 顺序发生的事件、日期、发展脉络 | 线性进展式 | 手工工艺风、复古学术风 |
| **流程/教程** | 分步指导、操作方法 | 线性进展式、蜿蜒路线图 | 宜家风格手册、技术示意图 |
| **对比分析** | A与B的对比、优缺点、前后变化 | 二元对比式、对比矩阵 | 企业极简风、大胆图形风 |
| **层级结构** | 不同层级、优先级、金字塔结构 | 层级式、树状分支 | 手工工艺风、企业极简风 |
| **关联关系** | 各要素之间的联系、重叠关系、影响机制 | 维恩图、中心辐射式、拼图式 | 手工工艺风、地铁线路图风格 |
| **数据/指标** | 统计数据、关键绩效指标、测量数值 | 仪表板式、元素周期表式 | 企业极简风、技术示意图 |
| **循环/循环过程** | 反复出现的流程、反馈循环 | 圆形流程图 | 手工工艺风、技术示意图 |
| **系统/结构** | 组成部件、架构、解剖结构 | 结构分解式、便当格布局 | 技术示意图、宜家风格手册 |
| **历程/叙事** | 故事情节、用户流程、重要里程碑 | 蜿蜒路线图、故事山峰式 | 故事书水彩风、连环画风格 |
| **概览/总结** | 多个主题、核心功能亮点 | 便当格布局、元素周期表式、密集模块式 | 黑板风格、大胆图形风 |
| **产品/选购指南** | 多维度对比、产品规格、常见误区 | 密集模块式 | 莫兰迪色调笔记风、流行实验室风、复古流行网格风 |

### 2. 学习目标确定

每张信息图都应设定1-3个明确的学习目标。

**优质的学习目标应具备以下特点**：
- 具体且可衡量
- 侧重于受众需要理解的内容，而不仅仅是视觉呈现内容
- 从受众的角度来表述

**格式示例**：“观看完此信息图后，受众将能够理解……”

| 内容方面 | 目标类型 |
|----------|----------|
| 核心概念 | “……[主题]是什么以及它为何重要” |
| 流程步骤 | “……如何[完成某项任务]” |
| 对比分析 | “……[A]与[B]之间的关键差异” |
| 关联关系 | “……[各要素]之间是如何相互关联的” |
| 数据信息 | “……[关键统计数据]的意义所在” |

### 3. 受众分析

| 分析因素 | 需要思考的问题 | 影响程度 |
|----------|----------------|----------|
| **知识水平** | 他们已掌握哪些知识？ | 决定内容的复杂程度 |
| **查看背景** | 他们为何查看此信息图？ | 决定需要强调的重点 |
| **预期目标** | 他们希望学到什么？ | 决定成功的评判标准 |
| **视觉偏好** | 偏好专业风格、趣味风格还是技术风格？ | 影响风格选择 |

### 4. 复杂度评估

| 等级 | 判定指标 | 布局建议 |
|------|----------|----------|
| **简单**（3-5分） | 主要概念较少，关联关系清晰 | 简洁布局，单一焦点 |
| **中等**（6-8分） | 包含多个概念，存在部分关联关系 | 平衡布局，分区明确 |
| **复杂**（9分及以上） | 概念众多，关联关系十分复杂 | 密集布局，多板块呈现 |

### 5. 视觉呈现机会识别

找出可以通过视觉方式展示而非文字描述的内容：

| 内容元素 | 视觉呈现方式 |
|----------|--------------|
| 数字/统计数据 | 大号、突出显示的数字 |
| 对比内容 | 并排展示、分屏呈现 |
| 流程步骤 | 箭头、编号步骤、流程线 |
| 层级结构 | 金字塔、分层设计、大小差异对比 |
| 关联关系 | 线条、连接点、重叠形状 |
| 分类内容 | 颜色编码、分组展示、分区呈现 |
| 时间线 | 水平/垂直进展式 |
| 引用内容 | 引用框、引号标注 |

### 6. 数据原样提取

**重要提示**：所有事实性信息必须与原始文本中的表述完全一致。

| 数据类型 | 处理规则 |
|----------|----------|
| **统计数据** | 原样复制，例如“73%”而非“约70%” |
| **引用内容** | 逐字复制，并标注出处 |
| **人名** | 保持原拼写不变 |
| **日期** | 保留原始格式 |
| **专业术语** | 不得简化或替换 |
| **列表内容** | 保持原有顺序和用词 |

**绝对禁止**：
- 四舍五入数值
- 改写引用内容
- 用更简单的词汇替代
- 添加隐含信息
- 删除会影响含义的上下文内容

## 分析检查清单

在开始生成结构化内容之前，请确认以下事项：

- [ ] 我已完整阅读源文档了吗？
- [ ] 能否用1-2句话概括其主要主题？
- [ ] 是否明确了1-3个清晰的学习目标？
- [ ] 我是否了解目标受众？
- [ ] 是否正确分类了内容类型？
- [ ] 是否已逐字提取所有数据信息？
- [ ] 是否发现了可用于呈现的可视化元素？
- [ ] 是否从用户输入中提取出了设计相关要求？
- [ ] 是否提出了3种布局与风格的组合方案？
