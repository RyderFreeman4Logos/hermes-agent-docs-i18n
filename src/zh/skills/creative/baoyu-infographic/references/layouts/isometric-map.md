# 等轴测地图

以3D风格展示空间中的位置、关联关系或路径走向。

## 结构要素

- 等轴测3D视角
- 以建筑物/地标表示位置
- 连接各位置的路径
- 可视化的空间关系
- 鸟瞰视角

## 适用场景

- 办公室/校园布局图
- 城市/生态系统地图
- 用户旅程地图
- 系统架构图
- 流程概览图

## 视觉元素

- 统一的30°等轴测角度
- 3D风格的建筑物或物体
- 路径与道路
- 漂浮在上的标签
- 各位置处的微型场景

## 文本标注位置

- 标题位于顶部角落
- 位置标签标注在物体上方
- 路径标签沿路线显示
- 符号说明图例
- 如有必要，可添加比例尺指示器

## 推荐搭配样式

- `isometric-3d`：简洁的技术类地图
- `pixel-art`：复古游戏风格的地图
- `lego-brick`：富有趣味性的位置地图
