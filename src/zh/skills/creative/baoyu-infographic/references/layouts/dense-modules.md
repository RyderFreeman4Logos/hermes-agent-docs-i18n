# 高密度模块

采用高密度模块化布局，整合6至7个包含具体数据的分类信息模块。

## 结构特点

- 每张图片包含6至7个独立模块，各自承担特定的信息展示功能
- 每个模块均包含具体数据：品牌名称、数字、百分比及参数值
- 极少留白——优先紧凑排布而非预留过多空隙
- 允许使用较小字体以进一步提升信息密度
- 每个模块通过坐标标签或章节标识进行区分（例如：MOD-1、SEC-A）

## 模块类型

| 模块类型 | 功能用途 | 内容要求 |
|----------|----------|----------|
| **品牌/选项矩阵** | 以网格形式展示选项并给出推荐 | 包含4至8项内容，配有图标、名称及简短描述；需突出显示“最佳选择” |
| **规格参数量表** | 用于展示质量或测量等级 | 设有3至5个等级，数值间隔精确，并搭配质量指示符号（表情符号或对勾） |
| **深度解析/细节展示** | 对关键产品进行技术拆解 | 包含放大视图、内部结构图、剖面图或分解图 |
| **场景对比** | 并列展示不同使用场景 | 提供3至6种场景，每种场景均附有具体推荐方案及相关数据 |
| **识别技巧** | 提供操作检查清单 | 包含3至5种识别方法，采用“观察/测试/检查/询问”等形式呈现 |
| **风险警示区** | 警示需避免的严重错误 | 列出3至5种可能带来的后果严重的错误，同时给出1至2种正确处理方式；该区域需有高对比度设计 |
| **快速参考** | 提供简洁概要 | 采用密集表格、单行总结、决策流程图或核心要点形式呈现 |

## 不同布局变体

| 变体类型 | 设计重点 | 视觉风格 |
|----------|----------|----------|
| **坐标标注型** | 强调精确性与系统性 | 每个模块配有字母数字组合的坐标标识（如A-01、B-05、C-12），并搭配尺子或坐标轴标记 |
| **网格单元型** | 突出秩序与结构感 | 模块被严格限制在矩形单元格内，由粗线分隔，具有瑞士式网格的规整感 |
| **自由流动型** | 体现自然紧凑感 | 采用类似杂志的排版风格，使用虚线框架，模块大小不一，并通过箭头相互连接 |

## 适用场景

- 产品选择指南与购买指南
- 多维度对比内容
- 富含数据的教育类材料
- “规避风险”/“完整指南”类内容
- 面向小红书等对视觉密度要求较高的平台的文案设计

## 视觉元素

- 模块边界标识（粗线、虚线框架或坐标网格）
- 每个模块对应的品质指示符号（表情符号、对勾、叉号、皇冠图标）
- 带有高亮数字的数据标注框
- 对比用箭头及进度指示器
- 风险警示模块的警告/提醒视觉标识
- 角落处的元数据（页码、时间戳、小型条形码）

## 文本排版方式

- 顶部放置醒目且富有冲击力的主标题
- 添加副标题说明模块数量（例如：“X大维度全面解析...”）
- 模块标题置于彩色徽章或带标签的框架内
- 正文内容紧凑排列，模块内可设置多列文字
- 数字需用特殊颜色高亮显示，字号略大于正文文字

## 信息密度准则

- 每个角落都应包含有用信息或元数据
- 不得存在仅用于装饰的空白区域
- 可适当缩小字体大小以容纳更多内容——信息优先于字体尺寸
- 每个模块都必须包含具体数据点，而非泛泛描述
- 需在密度与可读性之间取得平衡：内容密集但结构清晰

## 推荐搭配方案

- `pop-laboratory`：结合坐标标记与蓝图网格，体现技术精确性
- `morandi-journal`：通过手绘风格插图与自然风格框架，营造温暖感
- `retro-pop-grid`：采用1970年代流行艺术风格，搭配规整网格与强烈对比色
- `corporate-memphis`：为产品对比提供简洁的商务风格设计
- `technical-schematic`：适用于技术型产品指南，具备工程领域的精确感
