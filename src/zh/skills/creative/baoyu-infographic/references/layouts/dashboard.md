# 数据看板

通过图表、数字及关键绩效指标，实现多维度数据展示。

## 结构设计

- 多个数据组件
- 图表、曲线图与数值显示
- 网格式或模块化布局
- 核心指标突出展示
- 状态指示器

## 适用场景

- 关键绩效指标汇总
- 性能指标分析
- 数据概览展示
- 状态报告生成
- 数据快照呈现

## 视觉元素

- 图表类型（柱状图、折线图、饼图、仪表盘）
- 关键绩效指标的大号数值显示
- 趋势方向箭头（上升/下降）
- 颜色编码的状态指示（绿色/红色)
- 清晰直观的数据可视化效果

## 文本排版

- 顶部放置标题
- 每个区域上方标注组件名称
- 显示指标标签与数值
- 清晰标注单位
-标明时间周期

## 推荐搭配主题

- `corporate-memphis`：企业风格数据看板
- `ui-wireframe`：技术型数据看板
- `cyberpunk-neon`：未来感风格展示界面
