# 二元对比

用于对两个项目、状态或概念进行并排对比。

## 结构

- 垂直分隔线将图像一分为二
- 左侧：项目A / 之前 / 优势
- 右侧：项目B / 之后 / 劣势
- 镜像布局便于对比
- 两侧有清晰的视觉区分

## 变体类型

| 变体类型 | 核心焦点 | 视觉强调点 |
|---------|-------|--------------|
| **前后对比** | 随时间发生的转变 | 时间变化、改进效果 |
| **A与B对比** | 功能特性对比 | 直接对比、差异展示 |
| **优缺点分析** | 优势与劣势 | 公平的评估视角 |

## 适用场景

- 事物前后状态的转变展示
- 产品或选项的对比
- 优缺点分析
- 旧版本与新版本的对比
- 对同一主题的两种不同观点阐述

## 视觉元素

- 突出的垂直分隔线或渐变效果
- 两侧使用对比色
- 对应元素位置保持一致以便对比
- “VS”符号或分隔线装饰
- 用于前后对比的转换箭头

## 文本排版

- 主标题居中显示在顶部
- 侧边标签（A/B、之前/之后）
- 相关内容水平对齐
- 如有需要，可在底部添加总结

## 推荐搭配主题

- `corporate-memphis`：适用于商业类对比
- `bold-graphic`：适合高对比度的强烈视觉对比
- `craft-handmade`：适合轻松易懂的说明风格
