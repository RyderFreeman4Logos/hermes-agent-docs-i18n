# 元素周期表

采用统一单元格格式的元素分类网格。

## 结构

- 矩形网格
- 每个单元格代表一种元素
- 颜色编码的分类标识
- 统一的单元格样式
- 可选的分组间隔

## 适用场景

- 分类集合展示
- 工具/资源目录
- 能力矩阵
- 元素集合展示
- 参考指南

## 视觉元素

- 均一的单元格尺寸
- 分类颜色标识
- 突出的元素符号/缩写
- 每个单元格附带小图标
- 分类图例

## 文本排版

- 标题位于顶部
- 单元格内容：符号、名称及简要说明
- 分类名称显示在图例中
- 可选行/列标题
- 特殊情况标注脚注

## 推荐搭配风格

- `pop-art`：色彩鲜明的元素网格
- `pixel-art`：复古风格的集合展示
- `corporate-memphis`：企业工具目录设计
