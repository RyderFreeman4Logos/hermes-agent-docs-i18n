# 概念图原型

适用于教育类及非软件领域的可视化场景——物理、化学、数学、生物学、实物对象、解剖结构、平面图、生命周期、横截面以及中心辐射式系统。采用扁平化设计，极简风格，并考虑明暗模式适配。（该规范继承自之前的 `concept-diagrams` 技能。）

如需了解箭头标记、节点分组及坐标系统的相关内容，请先阅读 `svg-diagrams.md`。本文档在基础流程图的基础上，增加了教育类配色方案以及更多原型模板。

## 设计理念

- **扁平化**：不使用渐变、阴影、模糊效果、发光效果或霓虹色彩。
- **极简主义**：仅展示核心内容，框内不添加装饰性图标。
- **始终使用小写**：禁止使用首字母大写，也禁止全大写。
- **仅两种字体大小**：标题使用 `th` 字体，大小为 14px/500；副标题与标签使用 `ts` 字体，大小为 12px/400。
- 节点边框的线宽为 **0.5px**，所有连接线的填充属性均为 `fill="none"`。

## 9级渐变的教育类配色系统

颜色用于表示**类别/含义**，而非顺序。每张图表建议使用2–3种渐变层次。将类别信息置于 `<g>` 元素或特定形状中，模板CSS会自动适配明暗模式下的颜色停靠点（明亮模式：填充值50、线宽600、标题值800；暗黑模式：填充值800、线宽200、标题值100）。

|---|---|---|---|---|---|
| `c-purple` | #EEEDFE | #AFA9EC | #7F77DD | #534AB7 | #3C3489 |
| `c-teal`   | #E1F5EE | #5DCAA5 | #1D9E75 | #0F6E56 | #085041 |
| `c-coral`  | #FAECE7 | #F0997B | #D85A30 | #993C1D | #712B13 |
| `c-pink`   | #FBEAF0 | #ED93B1 | #D4537E | #993556 | #72243E |
| `c-gray`   | #F1EFE8 | #B4B2A9 | #888780 | #5F5E5A | #444441 |
| `c-blue`   | #E6F1FB | #85B7EB | #378ADD | #185FA5 | #0C447C |
| `c-green`  | #EAF3DE | #97C459 | #639922 | #3B6D11 | #27500A |

配色规则：按类别对节点进行分组（相同类型的节点使用相同颜色）；中性或结构类元素（起点、终点、通用步骤、用户等）使用 `c-gray` 颜色；语义信息、成功状态、警告及错误状态则分别预留 `c-blue`/`c-green`/`c-amber`/`c-red` 颜色。完整的模板文件（包含7级渐变及明暗模式CSS）位于 `templates/diagram.html`。

## 布局常量

- 视口范围为 `0 0 680 H`（H = 内容区域宽度 + 40px边距）；安全区域宽度为40→640像素。
- 单行框的高度为44像素，双行框为56像素，框与框之间的间距至少为60像素。
- 内部填充：水平方向24像素，垂直方向12像素。容器圆角半径为16–20像素，节点圆角半径为8像素。
- 最大嵌套层级为2–3层（在680像素的宽度下，更深层的嵌套将难以辨识）。

## 原型模板库

根据主题选择合适的图形形状。所有模板均为使用上述配色方案手动绘制的SVG图形。

**流程图/过程图**——起点和终点使用 `c-gray` 颜色，各步骤使用对应类别的颜色，错误分支使用 `c-red` 颜色。决策菱形用于控制流程走向（详情见 `svg-diagrams.md`）。

**管道/数据流图**（从左到右）——数据源使用 `c-gray` 颜色，处理阶段使用对应类别的颜色，数据接收端使用 `c-teal` 颜色。所有元素呈单行水平排列。

**分层堆叠图/分解视图**——由全宽的 `<rect>` 元素垂直堆叠而成，越往下颜色越深，一层对应一个渐变停靠点，标签位于元素侧面并配有指引线。适用于展示“X的多个层级”或“Y的N个层次”的场景。

**树形图/层级结构图**——根节点位于顶部中央，子节点向四周展开；连接边为 `<line>` 元素或简化的贝塞尔曲线，同一层级使用相同颜色。

**象限图/2×2矩阵图**——包含两条交叉的轴线及箭头，形成四个带标签的单元格，轴线标签使用 `ts` 字体。适用于展示不同选项的对比关系。

**前后对比图**——两个并排的面板共享相同的列网格；“问题状态”部分使用 `c-red`/`rust` 颜色作为强调色，“改进后状态”部分则使用 `c-green`/`olive` 颜色。中间可通过分隔线或箭头示意变化过程。

**时间轴/序列图**——包含水平或垂直的轨道，轨道上标注有日期或序号的节点；对于类似UML的序列图，可采用垂直的生命线搭配水平的信息箭头，箭头标签使用 `ts` 字体。

**中心辐射式图/系统集成图**——以中心节点为起点，向外延伸出连接各个子系统的线条；不同类型的子系统（如智慧城市、物联网、电网等）可使用不同的线条样式。

**横截面图/实物对象图/解剖结构图**——使用 `<path>` 元素绘制物体的轮廓（多边形、椭圆或贝塞尔曲线），用对应类别的颜色填充区域，再用 `ts` 字体标注各部分名称并配有指引线。适用于展示飞机、涡轮机、电池单元等物体。

**定量图表**——以基线为基准，用 `<rect>` 元素绘制分组条形图，轴上标注刻度；每个数据系列对应一个渐变层次，数值显示在条形上方的 `ts` 字体中。保持设计扁平化，避免使用3D效果或渐变。

## 何时选择此方案而非暗黑科技风格

适用于教育、科学或物理相关主题时，推荐使用此明亮型、9级渐变的方案。对于云服务、基础设施或软件系统架构类场景，则建议采用 `dark-tech.md` 中的暗黑风格方案。如果上述两种风格均不合适，这种教育类视觉风格则是安全且通用的默认选择。
