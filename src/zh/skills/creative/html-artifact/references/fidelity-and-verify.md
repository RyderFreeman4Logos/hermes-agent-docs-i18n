# 精度控制与验证

有两个贯穿始终的关键问题：如何调整输出成果的精细程度（即“精度滑块”，该概念源自之前的 `sketch` 功能），以及如何在标记任务完成之前发现错误输出（即“浏览器视觉检测循环”——对于图表而言这是必需的）。

## 精度滑块

根据需求投入相应精力。对快速比较的内容过度美化只会浪费时间；而提交粗糙的报告则完全违背了使用 HTML 的初衷。

**临时/草图精度**——快速生成、流程简单，旨在供人快速查看后丢弃。适用于用户要求“草图版”、“粗略版本”、“展示 X 可能的样子”、“快速预览”、“对比 A 和 B”、“在我正式开发前先做个模拟”。其特点包括：
- 提供逼真的*虚拟*内容（无需让用户凭空想象——直接填充内容即可）。
- 使用系统字体和品牌统一标识，自定义 CSS 最少化。仅支持一两种交互状态，而非完整应用。
- 在同一页面上展示多个版本（见下文说明）。
- 明确为临时用途：值得保留的草图应升级为正式项目代码，而非作为最终交付物保存。

**正式展示精度**——用于实际交付、供他人从头到尾阅读并分享的内容，如说明文档、计划书、报告、Pull Request 说明或文档中的图表。需采用完整的品牌风格、精心设计的排版、经过验证的图表，并确保在低性能环境下仍能正常显示。

当不确定时应直接提问（“是快速草图还是正式交付物？”），而非凭猜测决定——两者所需的精力投入差异极大。

## 多版本对比

当用户希望*选定一个方向*时，应生成 3–6 个不同的版本，并将它们放在**同一个**HTML文件中并列展示。目前有三种经过验证的布局方式：

- **静态权衡列**——各列权重相等，每列包含对应方案、代码或视觉示例、简短的权衡表以及统一的指标标签（如“包大小：+0.2kb”，“复用率：高”）。最后给出一个明确的**推荐意见**。最适合用于对比*代码实现方案*或策略。

- **可切换背景的动态画布板**——采用 2×N 的网格布局，每个 `.artboard` 卡片展示一个实际版本，同时提供深色/浅色切换功能，确保所有版本在两种背景下都能正常显示。最适合用于*视觉设计*方向的对比。可通过作用域限定符实现不同阶段的主题风格。
  ```css
  .stage      { --fg: var(--slate); --panel: var(--white); --line: var(--gray-300); }
  .stage.dark { --fg: #F0EEE6; --panel: #1F1E1B; --line: #3D3D3A; }
  ```
各变体仅能引用 `var(--fg/--panel/--line)` 这些参数，因此切换为 `.dark` 模式会同时重置所有主题。
- **实时令牌矩阵**——这是一组由滑块、分段控件及复选框构成的工具栏，它们会向 `:root` 写入自定义属性，从而实现所有变体单元的同步更新。该功能特别适用于在参数空间（密度×边框宽度×阴影效果）内探索不同组合的*组件*。

在设计时务必对布局、色调和密度进行有实质意义的调整（而非仅做表面修饰），为每个变体标注其所做出的权衡，并明确说明最终选择。

## 浏览器视觉验证循环（图表制作时的必经步骤）

手动设置的 SVG 坐标容易出现偏差：箭头可能出现在空白区域，矩形框会相互重叠，文本会超出其边界，图例也可能与图表边缘发生冲突。仅通过静态标记审查无法发现这些问题——必须查看实际渲染后的像素效果。

1. 使用 `write_file` 函数保存文件。
2. 用浏览器打开该文件：`browser_navigate(url="file:///absolute/path/to/artifact.html")`。
3. 进行视觉检查：`browser_vision(question="是否有箭头指向空白区域？是否存在重叠的矩形框或超出容器的文本？图例是否与图表保持清晰距离？是否有任何内容被截断？")`。（也可使用 `browser_screenshot` 拍照后再进行查看。）
4. 根据截图发现的问题进行修正——重新计算有问题的坐标，扩大矩形框以容纳文本，提高 viewBox 的高度，调整图例位置。
5. 重复渲染与检查，直至图表完全正常。

对于非图表类文档（如报告、规划方案、说明文档），只需截取一次图片即可检测出布局问题——包括内容溢出、网格错乱、对比度不足或内容被裁剪等。在告知用户任务已完成之前，务必至少进行一次视觉检查；“这是有效的 HTML”并不等同于“它的渲染效果正确”。

## 降级兼容性检查

如果该文档包含 JavaScript，还需确认在禁用 JS 的情况下页面仍能正常展示内容：真正的文本内容应存在于 HTML 中（而不仅仅是在 `render()` 函数内部），可折叠区域应使用原生的 `<details>` 标签，标签页默认处于展开状态，交互式图表则需设置默认激活的节点。在没有 JavaScript 的情况下，文档绝不能呈现为空白页面。
