## 1. 视觉主题与氛围

Apple 的网站堪称“可控戏剧感”的典范——大面积的纯黑与近乎纯白背景为产品提供了如电影画布般的展示空间，产品照片的拍摄方式则如同美术馆中的雕塑。其设计理念高度简化：每一个像素都服务于产品本身，而界面本身则尽可能隐退，直至几乎不可见。这并非出于审美偏好而追求极简，而是出于对产品的尊重而采用的极简风格。

排版是整个设计的基石。San Francisco 字体系列（大号字体使用 SF Pro Display，正文使用 SF Pro Text）是 Apple 的专有字体，它采用了“光学尺寸调整”技术，能根据字体大小自动调整字母形态。在标题尺寸（56px）下，600 号字体搭配 1.07 的紧密行高以及 -0.28px 的微负字距，使得标题看起来更像经过精密加工而非简单排版而成——精准、自信，且毫不含糊地传达信息。在正文尺寸（17px）下，字距会略微增加（-0.374px），行高则提升至 1.47，从而形成一种既舒适又不显松散的阅读节奏。

色彩运用则极为二元化。产品页面在纯黑背景（`#000000`）配白色文字，与浅灰背景（`#f5f5f7`）配近乎纯黑的文字（`#1d1d1f`）之间交替出现。这种设计营造出强烈的视觉节奏——深色区域给人沉浸式、高端的感觉，而浅色区域则显得开放且富有信息量。唯一的色彩点缀是 Apple 蓝色（`#0071e3`），它专门用于交互元素：链接、按钮以及处于焦点状态时的元素。在这片中性色的海洋中，这一独特的强调色让每一个可点击元素都格外醒目。

**核心特征：**
- SF Pro Display/Text 字体搭配光学尺寸调整技术——字母形态会随字体大小自动变化
- 二元化的深色/浅色区域节奏：纯黑（`#000000`）与浅灰（`#f5f5f7`）交替使用
- 唯一的强调色：Apple 蓝色（`#0071e3`），专门用于交互元素
- 产品图片置于纯色背景上展示——无渐变、无纹理、无任何干扰元素
- 极为紧密的标题行高（1.07–1.14），营造出类似广告牌般的强烈视觉冲击力
- 全宽布局，内容居中——整个视口即为设计画布
- 圆形按钮式 CTA（半径为 980px），打造出柔和且易于点击的操作按钮
- 各区域之间留有充足空白，让每款产品的展示都有足够空间

## 2. 色彩方案与用途

### 主要色彩
- **纯黑**（`#000000`）：用于主视觉区域背景及沉浸式产品展示。为最亮丽的产品提供最深沉的背景。
- **浅灰**（`#f5f5f7`）：用于其他区域背景及信息展示区。并非纯白——其中略带蓝灰色调，避免了视觉上的单调感。
- **近乎纯黑**（`#1d1d1f`）：用于浅色背景上的主要文字，以及深色按钮的填充色。其色调比纯黑稍暖，更便于阅读。

### 交互色彩
- **Apple 蓝色**（`#0071e3`）：用于 `--sk-focus-color`、主要 CTA 背景及焦点环。这是界面中唯一的彩色元素。
- **链接蓝色**（`#0066cc`）：用于 `--sk-body-link-color`，即行内文本链接。其色调比 Apple 蓝色稍深，更利于文本阅读。
- **亮蓝色**（`#2997ff`）：用于深色背景上的链接。较高的亮度有助于在黑色背景下形成鲜明对比。

### 文本色彩
- **白色**（`#ffffff`）：用于深色背景上的文字，以及蓝色/深色 CTA 按钮上的文字。
- **近乎纯黑**（`#1d1d1f`）：用于浅色背景上的主要正文文字。
- **80% 黑色**（`rgba(0, 0, 0, 0.8)`）：用于次要文字及浅色背景上的导航项。色调稍显柔和。
- **48% 黑色**（`rgba(0, 0, 0, 0.48)`）：用于三级文字、禁用状态及轮播控件。

### 表面样式与深色变体
- **深色表面 1**（`#272729`）：用于深色区域中的卡片背景。
- **深色表面 2**（`#262628`）：在深色环境中提供的细微表面变化。
- **深色表面 3**（`#28282a`）：用于深色背景上的突出显示卡片。
- **深色表面 4**（`#2a2a2d`）：深色表面中色调最深的版本。
- **深色表面 5**（`#242426`）：深色表面中色调最浅的版本。

### 按钮状态
- **按钮激活状态**（`#ededf2`）：浅色按钮的激活/按下状态。
- **按钮默认浅色状态**（`#fafafc`）：搜索/筛选按钮的背景色。
- **覆盖层**（`rgba(210, 210, 215, 0.64)`）：用于媒体控制遮罩层。
- **32% 白色**（`rgba(255, 255, 255, 0.32)`）：深色模态框关闭按钮的悬停状态。

### 阴影效果
- **卡片阴影**（`rgba(0, 0, 0, 0.22) 3px 5px 30px 0px`）：为产品卡片添加柔和、扩散式的凸起效果。偏移量与较大的模糊度共同营造出自然的摄影风格阴影。

## 3. 排版规则

### 字体系列
- **显示字体**：`SF Pro Display`，备用字体为 `SF Pro Icons, Helvetica Neue, Helvetica, Arial, sans-serif`
- **正文字体**：`SF Pro Text`，备用字体同上
- SF Pro Display 适用于 20px 及以上的字体大小；SF Pro Text 则针对 19px 及以下的字体大小进行了优化。

### 设计原则
- **以光学尺寸调整为核心理念**：SF Pro 字体会根据上下文在显示字体与正文字体之间自动切换。显示版本具有更宽的字距和更细的笔画，专为大字体大小优化；而正文版本则更为紧凑结实，适合小字体大小。这意味着该字体实际上会根据使用场景“改变其特性”。
- **控制字重使用**：字体字重范围从 300（轻）到 700（粗），但大多数文字实际使用的是 400（普通）和 600（半粗）字重。300 字重仅用于大型装饰性文字，而 700 字重则极为罕见，仅用于加粗的卡片标题。
- **所有字体大小均应用负字距**：与大多数仅对标题应用负字距的系统不同，Apple 即使在正文尺寸下也会应用微小的负字距（17px 时为 -0.374px，14px 时为 -0.224px，12px 时为 -0.12px）。这使得所有文字都具有统一且紧凑的视觉效果。
- **极端的行高范围**：标题的行高可低至 1.07，而正文行高则可高至 1.47，某些按钮区域的行高甚至可达 2.41。如此大的差异仅通过节奏感就能形成清晰的视觉层次。

## 4. 组件样式

### 按钮

**主要蓝色 CTA 按钮**
- 背景色：`#0071e3`（Apple 蓝色）
- 文字颜色：`#ffffff`
- 内边距：8px × 15px
- 半径：8px
- 边框：1px 宽的透明边框
- 字体：SF Pro Text，17px，字重 400
- 悬停状态：背景色略微变亮
- 激活状态：背景色变为 `#ededf2`
- 焦点状态：2px 宽的 `var(--sk-focus-color, #0071E3)` 轮廓线
- 用途：主要行动号召按钮，如“购买”或“选购 iPhone”

**深色主题主要按钮**
- 背景色：`#1d1d1f`
- 文字颜色：`#ffffff`
- 内边距：8px × 15px
- 半径：8px
- 字体：SF Pro Text，17px，字重 400
- 用途：次要 CTA 按钮，深色主题版本

**圆形链接按钮（“了解更多”/“购买”）**
- 背景色：透明
- 文字颜色：浅色背景为 `#0066cc`，深色背景为 `#2997ff`
- 半径：980px（完整圆形）
- 边框：1px 宽的 `#0066cc` 边框
- 字体：SF Pro Text，14px–17px
- 悬停状态：添加下划线装饰
- 用途：用于“了解更多”及“购买”链接——这是 Apple 独特的行内 CTA 样式

**筛选/搜索按钮**
- 背景色：`#fafafc`
- 文字颜色：`rgba(0, 0, 0, 0.8)`
- 内边距：0px × 14px
- 半径：11px
- 边框：3px 宽的 `rgba(0, 0, 0, 0.04)` 边框
- 焦点状态：2px 宽的 `var(--sk-focus-color, #0071E3)` 轮廓线
- 用途：搜索栏及筛选控件

**媒体控制按钮**
- 背景色：`rgba(210, 210, 215, 0.64)`
- 文字颜色：`rgba(0, 0, 0, 0.48)`
- 半径：50%（圆形）
- 激活状态：缩小至 0.9 倍大小，背景色发生变化
- 焦点状态：2px 宽的 `var(--sk-focus-color, #0071E3)` 轮廓线，背景色为白色，文字颜色为黑色
- 用途：播放/暂停按钮及轮播箭头

### 卡片与容器
- 背景色：`#f5f5f7`（浅色）或 `#272729`–`#2a2a2d`（深色）
- 边框：无边框（Apple 的设计中几乎不用边框）
- 半径：5px–8px
- 阴影效果：用于突出显示的产品卡片，阴影为 `rgba(0, 0, 0, 0.22) 3px 5px 30px 0px`
- 内容：居中显示，留有充足内边距
- 悬停状态：无标准悬停效果——卡片本身保持不变，仅其中的链接可交互

### 导航栏
- 背景色：`rgba(0, 0, 0, 0.8)`（半透明深色），并应用 `backdrop-filter: saturate(180%) blur(20px)` 效果
- 高度：48px（紧凑设计）
- 文字颜色：`#ffffff`，字号 12px，字重 400
- 激活状态：悬停时显示下划线
- 图标：Apple 徽标（SVG 格式），居中或左对齐，适配 17×48px 的视口尺寸
- 移动端：折叠为汉堡菜单，并伴随全屏覆盖式菜单
- 无论页面背景如何，导航栏始终悬浮在内容上方，保持其半透明深色玻璃态效果

### 图片处理方式- 以纯色背景（黑色或白色）呈现的产品图片——无背景、无上下文，仅展示产品本身  
- 覆盖整个视口宽度的满幅区域图像  
- 分辨率极高且带有柔和阴影的产品摄影图  
- 放置在圆角容器（半径≥12px）中的生活化场景图片  

### 核心组件设计  

**产品主视觉模块**  
- 全视口宽度、纯色背景（黑色或`#f5f5f7`）的区域  
- 产品名称作为主标题，使用SF Pro Display字体，大小为56px，字重为600  
- 下方为一行较浅字重的描述文字  
- 两侧并排放置两个圆形按钮式CTA：“了解更多”（轮廓样式）和“购买”/“选购”（实心样式）  

**产品网格卡片**  
- 放置在对比色背景上的正方形或近似正方形的卡片  
- 产品图片占据卡片的60-70%面积  
- 下方为产品名称加一行描述文字  
- 底部为“了解更多”与“选购”两个链接  

**功能对比栏**  
- 水平滚动展示不同版本的产品  
- 每个版本以垂直卡片形式呈现，包含图片、名称及核心参数  
- 极简边框设计——让产品本身成为焦点  

## 5. 布局原则  

### 空间系统  
- 基本单位：8px  
- 缩放比例：2px、4px、5px、6px、7px、8px、9px、10px、11px、14px、15px、17px、20px、24px  
- 特点：在较小尺寸（2-11px）时，缩放步长为1px，十分精细；较大尺寸时则步长加大。这便于对字体和图标位置进行精准微调。  

### 网格与容器  
- 内容最大宽度：约980px（圆形按钮中反复出现的“980px半径”即参照此数值）  
- 主视觉区域：全视口宽度，内容居中显示  
- 产品网格：在居中容器内采用2列或3列布局  
- 主视觉区域采用单列设计——仅展示一个产品、一条信息，让用户全神贯注  
- 不显示网格线或间隙——通过合理间距营造结构感  

### 空白设计理念  
- **电影般的留白**：每个产品区域占据接近整个视口高度。产品之间的空白并非真正的空无，而是如同电影场景切换间的停顿。  
- **通过颜色块构建垂直节奏**：苹果公司不单纯依靠间距来分隔区域，而是通过交替使用黑色、`#f5f5f7`和白色等背景色。每次颜色变化都象征着一个新“场景”的开始。  
- **内部紧凑，外部开阔**：文字块采用紧密排版（负字距、较短的行高），而其周围空间则极为宽敞。这种设计在密集感与开阔感之间形成张力。  

### 圆角半径标准  
- 微型（5px）：小型容器、链接标签  
- 标准型（8px）：按钮、产品卡片、图片容器  
- 舒适型（11px）：搜索输入框、筛选按钮  
- 大型（12px）：功能面板、生活化场景图片容器  
- 完整圆形（980px）：CTA链接（“了解更多”、“选购”）及导航按钮  
- 圆形（50%）：媒体控制按钮（播放/暂停、箭头键）  

## 6. 深度与层次感  

| 层级 | 处理方式 | 适用场景 |
|------|-----------|----------|
| 平面层（第0层） | 无阴影，纯色背景 | 标准内容区域、文字块 |
| 玻璃态导航栏 | 使用`backdrop-filter: saturate(180%) blur(20px)`效果，背景为`rgba(0,0,0,0.8)` | 固定定位的导航栏，具有玻璃质感 |
| 轻微凸起层（第1层） | 阴影为`rgba(0, 0, 0, 0.22) 3px 5px 30px 0px` | 产品卡片、浮动元素 |
| 媒体控制元素 | 背景为`rgba(210, 210, 215, 0.64)`，并带有缩放变换效果 | 播放/暂停按钮、轮播控件 |
| 可访问性焦点状态 | 显示`2px solid #0071e3`的轮廓线 | 键盘操作时的焦点指示 |

**阴影设计理念**：苹果公司极少使用阴影。主要的阴影效果为`3px 5px 30px`，透明度为0.22，属于柔和、宽阔且偏移的类型——模拟真实摄影棚中光线在物体下方投下的自然阴影。这一设计进一步强化了“产品如同实体雕塑”的比喻。大多数元素根本不使用阴影；层次感主要通过背景色对比来实现（深色卡片置于深色背景上，或浅色卡片置于略带差异的灰色背景上）。  

### 装饰性深度表现  
- 玻璃态导航栏：半透明且带有模糊效果的导航栏是最具辨识度的深度表现元素，使界面仿佛悬浮在滚动内容之上。  
- 区域颜色交替：通过黑色与浅灰色区域之间的切换来暗示深度，而非依赖阴影。  
- 产品摄影中的阴影：产品图片本身已带有阴影，因此界面无需再添加人工生成的阴影。  

## 7. 正确做法与禁忌  

### 应该这样做  
- 使用SF Pro Display字体，标题字号≥20px，正文字体小于20px——遵循苹果规定的视觉尺寸规范。  
- 所有文字大小均应用负字距（不仅限于标题），因为苹果产品普遍采用紧密排版风格。  
- 仅将Apple Blue颜色`#0071e3`用于交互元素——它应是唯一的强调色。  
- 通过交替使用黑色与浅灰色`#f5f5f7`作为区域背景，营造电影般的节奏感。  
- CTA链接采用980px的圆形半径——这是苹果标志性的链接形状。  
- 确保产品图片置于纯色背景上，避免其他视觉元素干扰。  
- 为固定导航栏使用半透明深色玻璃效果（`rgba(0,0,0,0.8)`加模糊处理）。  
- 将标题行高设置为1.07–1.14——苹果的标题以紧密排版著称。  

### 不应该这样做  
- 不要添加额外的强调色——整个色彩体系仅围绕蓝色展开。  
- 不要使用厚重阴影或多层阴影——苹果的阴影系统只允许一种柔和的扩散式阴影，否则不予采用。  
- 不要在卡片或容器上使用边框——苹果几乎从不使用可见边框（特定按钮除外）。  
- 不要对SF Pro字体应用过大的字距——该字体设计初衷就是在各种尺寸下保持紧密排版。  
- 不要使用字重800或900——最大字重为700（粗体），即便如此也极为罕见。  
- 不要在背景上添加纹理、图案或渐变——仅允许纯色背景。  
- 不要让导航栏完全不透明——玻璃模糊效果是苹果界面风格的核心要素。  
- 不要对正文文本进行居中对齐——苹果的正文始终左对齐，仅有标题会居中。  
- 不要在矩形元素上使用大于12px的圆角——980px的半径仅适用于圆形按钮。  

## 8. 响应式设计行为  

### 分界点  
| 名称 | 宽度 | 主要变化 |
|------|------|----------|
| 小型手机端 | <360px | 最低支持宽度，单列布局 |
| 手机端 | 360–480px | 标准手机布局 |
| 大型手机端 | 480–640px | 更宽的单列布局，图片尺寸更大 |
| 小型平板端 | 640–834px | 开始出现2列产品网格 |
| 平板端 | 834–1024px | 完整的平板布局，导航栏扩展 |
| 小型桌面端 | 1024–1070px | 标准桌面布局开始应用 |
| 桌面端 | 1070–1440px | 完整布局，内容最大宽度达到极限 |
| 大型桌面端 | >1440px | 元素居中显示，周围留有充足边距 |

### 触控目标区域尺寸  
- 主要CTA按钮：内边距为8px×15px，实际触控高度约为44px  
- 导航链接：高度为48px，且周围有足够间距  
- 媒体控制按钮：圆形按钮半径为50%，最小尺寸为44×44px  
- “了解更多”圆形按钮：预留充足内边距，便于舒适点击  

### 布局折叠策略  
- 主视觉标题：在手机端从56px缩小至40px，再降至28px，同时保持行高比例不变  
- 产品网格：从3列变为2列，最终折叠为单列堆叠布局  
- 导航栏：从水平导航栏变为紧凑的移动端汉堡菜单  
- 产品主视觉模块：在所有屏幕尺寸下均保持满幅设计，仅文字大小相应缩小  
- 区域背景：在所有分界点下均保持全宽度颜色块——电影般的节奏感不会中断  
- 图片尺寸：产品图片按比例缩放，绝不裁剪——产品的轮廓必须完整呈现  

### 图片处理方式  
- 产品摄影图在所有分界点下均保持原始宽高比  
- 主视觉产品图片会缩小，但始终居中显示  
- 满幅区域背景在所有屏幕尺寸下均保留  
- 生活化场景图片在手机端可能会被裁剪，但圆角仍会保持  
- 对超出可视区域的图片采用懒加载技术

### 组件提示词示例  
- “创建一个黑色背景的主视觉区域。标题使用SF Pro Display字体，大小56px，字重600，行高1.07，负字距-0.28px，文字颜色为白色。下方为一行描述文字，使用SF Pro Display字体，大小21px，字重400，行高1.19，文字颜色为白色。两侧各放置一个圆形按钮式CTA：‘了解更多’（背景透明，文字白色，1px白色实心边框，半径980px），以及‘购买’（背景为Apple Blue `#0071e3`，文字白色，半径8px，内边距8px×15px）。”  
- “设计一张产品卡片：背景为`#f5f5f7`，圆角半径8px，无边框且无阴影。产品图片位于卡片顶部的60%区域，背景为纯色。标题使用SF Pro Display字体，大小28px，字重400，负字距0.196px，行高1.14。描述文字使用SF Pro Text字体，大小14px，字重400，颜色为`rgba(0,0,0,0.8)`。‘了解更多’与‘选购’链接颜色为`#0066cc`，字体大小为14px。”  
- “构建苹果风格的导航栏：固定定位，高度48px，背景为`rgba(0,0,0,0.8)`，并应用`backdrop-filter: saturate(180%) blur(20px)`效果。链接文字使用SF Pro Text字体，大小12px，字重400，颜色为白色。苹果标志位于左侧，链接居中，搜索图标与购物袋图标位于右侧。”  
- “创建交替颜色的区域布局：第一个区域背景为黑色，文字和居中的产品图片为白色；第二个区域背景为`#f5f5f7`，文字为`#1d1d1f`。每个区域高度接近整个视口，包含56px大小的标题以及下方的两个圆形按钮式CTA。”  
- “设计一个‘了解更多’链接：文字颜色在浅色背景上为`#0066cc`，在深色背景上为`#2997ff`，字体使用SF Pro Text，大小14px，悬停时显示下划线。文字后方需添加一个向右的箭头字符（>`）。当该链接作为独立CTA使用时，需将其包裹在一个半径为980px的容器中，以呈现苹果标志性的圆形按钮形状。”  

### 优化迭代指南  
1. 所有交互元素均使用Apple Blue颜色`#0071e3`——不得使用其他强调色。  
2. 区域背景交替使用：黑色用于营造沉浸式体验，`#f5f5f7`用于传递信息类内容。  
3. 字体视觉尺寸规范：标题使用SF Pro Display字体，字号≥20px；正文使用SF Pro Text字体——严禁混用。  
4. 所有文字大小均应用负字距：56px时为-0.28px，17px时为-0.374px，14px时为-0.224px，12px时为-0.12px。  
5. 玻璃态导航栏效果（半透明深色背景加模糊处理）是不可或缺的——它定义了苹果网页体验的核心特征。  
6. 产品图片始终置于纯色背景上——在主视觉模块中，绝不能使用渐变、纹理或生活化场景背景。  
7. 阴影极为罕见，且始终为柔和类型：`3px 5px 30px 0.22`透明度，或干脆不使用阴影。  
8. CTA按钮采用980px的圆形半径——这一设计造就了苹果标志性的、类似胶囊形状的圆角矩形外观。
