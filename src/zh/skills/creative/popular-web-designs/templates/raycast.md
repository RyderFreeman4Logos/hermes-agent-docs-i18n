## 1. 视觉主题与氛围

Raycast 的营销网站给人一种精密仪器深邃内部的感受——宛如用黑曜石雕刻而成的瑞士手表表壳。其背景并非单纯的黑色，而是一种近乎黑色的蓝调色调（`#07080a`），这种色调让人感觉自己正身处 macOS 原生应用程序之中，而非普通网站。每一个表面、每一条边框、每一道阴影都经过精心设计，旨在营造出高性能桌面工具的体验：快速、极简且值得信赖。

该设计的亮点在于借鉴了 macOS 窗口边框设计的多层阴影系统：通过多层盒阴影搭配内嵌高光，模拟出物理层面的深度感，仿佛卡片和按钮其实是放置在深色桌面上的实心玻璃元素。再结合几乎仅用于主视觉区域标志性对角条纹的 Raycast 红色（`#FF6363`），这样的色彩搭配让该品牌呈现出“功能强大且富有个性”的形象。红色并非占据主导，而是起到点缀作用。

Inter 字体被广泛运用在各种元素上——标题、正文、按钮、字幕等——其丰富的 OpenType 特性（如 `calt`、`kern`、`liga`、`ss03`）确保了字体风格的一致性与可读性。正文文本采用了较大的字距（0.2px–0.4px），这在深色界面中实属罕见，为文字增添了一种轻盈感，有效平衡了密集的深色背景。代码部分则使用 GeistMono 字体，进一步强化了其作为开发者工具的身份。

**核心特征：**
- 几近黑色的蓝调背景（`#07080a`）——并非纯黑，带有微妙的蓝色偏调
- 借鉴 macOS 设计的多层内嵌高光阴影系统，模拟物理深度感
- Raycast 红色（`#FF6363`）作为点缀色——仅用于主视觉条纹，而非大面积使用
- 使用 Inter 字体并设置较大字距（0.2px），以实现轻盈且易读的深色模式体验
- 采用 Radix UI 组件作为交互层的基础
- 在深色背景上使用透明度为 0.06–0.1 的半透明白色边框作为边界界定
- 键盘快捷键按钮具有渐变键帽和厚重阴影效果

## 3. 字体规则

### 字体家族
- **正文字体**：`Inter`——一款人文主义风格的无衬线字体，应用于所有场景。备用字体：`Inter Fallback` 及系统默认无衬线字体
- **系统字体**：`SF Pro Text`——苹果系统的字体，用于部分 macOS 原生界面元素。备用字体：`SF Pro Icons`、`Inter`、`Inter Fallback`
- **等宽字体**：`GeistMono`——Vercel 提供的等宽字体，用于代码元素。备用字体：`ui-monospace`、`SFMono-Regular`、`Roboto Mono`、`Menlo`、`Monaco`
- **OpenType 特性**：全局启用 `calt`、`kern`、`liga`、`ss03`；显示文本启用 `ss02`、`ss08`；主视觉标题则禁用 `liga`（设置为 `"liga" 0`）

### 设计原则
- **深色背景使用正字距**：与大多数采用紧凑或中性字距的深色界面不同，Raycast 采用了 +0.2px 至 +0.4px 的正字距——这种设计为文字增添了轻盈感，提升了在深色背景下的可读性
- **以500字重作为基准**：大多数正文文本采用500字重而非400字重——略微增加的字体厚度有助于在深色背景下提高可读性
- **主视觉标题的克制设计**：主视觉标题的字号为64px，字重为600，既显得自信又不显得过大——Raycast避免过度追求视觉效果，更注重功能性的优雅
- **全面启用OpenType特性**：Inter字体全局启用 `ss03`（风格集3）特性，使得字体具有更为几何化、类似工具的视觉风格

## 4. 组件样式

### 按钮
- **主按钮**：透明背景，白色文字，圆角 pill形状（半径86px），带有多层内嵌阴影（`rgba(255, 255, 255, 0.1) 0px 1px 0px 0px inset`）。悬停时透明度变为0.6
- **次要按钮**：透明背景，白色文字，半径6px，带有 `1px solid rgba(255, 255, 255, 0.1)` 的边框，以及微弱的投影（`rgba(0, 0, 0, 0.03) 0px 7px 3px`）。悬停时透明度变为0.6
- **透明按钮**：无背景也无边框，灰色文字（`#6a6b6c`），半径86px，阴影与主按钮相同。悬停时透明度变为0.6，文字颜色变为白色
- **行动号召按钮（下载）**：半透明白色背景（`hsla(0, 0%, 100%, 0.815)`），深色文字（`#18191a`），pill形状。悬停时背景变为纯白色（`hsl(0, 0%, 100%)`）
- **过渡效果**：所有按钮均采用透明度过渡实现悬停效果，而非改变背景颜色——这是Raycast独特的交互风格

### 卡片与容器
- **标准卡片**：背景色为 `#101111`，边框宽度为1px，颜色为 `rgba(255, 255, 255, 0.06)`，圆角半径为12px–16px
- **凸起卡片**：外部带有 `rgb(27, 28, 30) 0px 0px 0px 1px` 的环状阴影，内部带有 `rgb(7, 8, 10) 0px 0px 0px 1px` 的内嵌阴影——形成双重环形边界效果
- **特色卡片**：圆角半径为16px–20px，重点元素背后带有微弱的温暖光晕（`rgba(215, 201, 175, 0.05) 0px 0px 20px 5px`）
- **悬停效果**：卡片会通过增加边框透明度或微调阴影来略微亮起

### 输入框与表单
- 输入字段为深色背景，颜色为 `#07080a`，边框宽度为1px，颜色为 `rgba(255, 255, 255, 0.08)`，圆角半径为8px
- 聚焦状态时：边框颜色变亮，并出现蓝色光晕（`hsla(202, 100%, 67%, 0.15)`）
- 输入文字颜色为 `#f9f9f9`，占位符颜色为 `#6a6b6c`
- 标签颜色为 `#9c9c9d`，字号为14px，字重为500

### 导航栏
- **顶部导航栏**：背景色与页面背景融为一体，白色文字链接，字号16px，字重500
- **导航链接**：默认为灰色文字（`#9c9c9d`），悬停时变为白色，并带有下划线装饰
- **行动号召按钮**：导航栏末尾为半透明白色pill形状按钮
- **移动端适配**：导航栏会折叠为汉堡菜单，但仍保持深色主题
- **固定导航**：导航栏固定在页面顶部，配有微妙的边框分隔线

### 图片处理方式
- **产品截图**：采用 macOS 窗口边框风格——圆角12px，深度阴影模拟悬浮窗口效果
- **全屏区域**：深色截图能与背景完美融合
- **主视觉插图**：使用Raycast红色呈现的对角条纹图案——抽象、几何化，是品牌的重要标识
- **应用界面嵌入**：直接展示Raycast的命令面板及扩展功能——将产品本身作为内容呈现

### 键盘快捷键按键样式
- **键帽样式**：具有从 `#121212` 到 `#0d0d0d` 的渐变背景，以及厚重的多层阴影（`rgba(0, 0, 0, 0.4) 0px 1.5px 0.5px 2.5px` 加上内嵌阴影），模拟出真实的物理按键外观
- 单个按键的圆角半径为4px–6px

### 徽章与标签
- **中性徽章**：背景色为 `#1b1c1e`，文字颜色为白色，半径6px，字体大小为14px，字重为500，内边距为 `0px 6px`
- 采用类似pill的紧凑设计，用于分类展示

## 5. 布局原则

### 空间系统- **基础单位**：8px  
- **缩放比例**：1px、2px、3px、4px、8px、10px、12px、16px、20px、24px、32px、40px

- **卡片内边距**：内部间距为16px–32px

### 网格与容器
- **最大宽度**：约1200px的容器（在1204px处断点），内容居中显示  
- **列布局模式**：单列的首页区域、2–3列的功能网格、全宽的产品展示区  
- **应用展示**：产品界面以居中的窗口框架呈现  

### 空白设计理念
- **强烈的负空间**：各板块仿佛悬浮在广阔的黑暗虚空中，从而在功能模块之间营造出如电影般的节奏感

- **垂直节奏感**：各板块内元素之间保持一致的24px–32px间隙  

### 圆角尺寸规范
- **2px–3px**：微小元素、代码片段、小型指示器  
- **4px–5px**：键盘按键、小型交互元素

- **8px**：输入框、内联组件  
- **9px–11px**：图片、中等尺寸容器  
- **12px**：标准卡片、产品截图  
- **16px**：大型卡片、功能板块  
- **20px**：首页卡片、突出显示的容器  
- **86px+**：药丸形按钮、导航号召按钮——呈现完整的药丸形状  

## 6. 深度与立体感

| 级别 | 处理方式 | 适用场景 |
|------|-----------|----------|
| 级别0（虚无） | 无阴影，表面颜色为`#07080a` | 页面背景 |
| 级别1（微妙效果） | `rgba(0, 0, 0, 0.28) 0px 1.189px 2.377px` | 轻微凸起效果，适用于内联元素 |
| 级别2（双环效果） | 外层阴影为`rgb(27, 28, 30) 0px 0px 0px 1px`，内层阴影为`rgb(7, 8, 10) 0px 0px 0px 1px` | 用于卡片包裹效果，采用双环设计 |
| 级别3（按钮效果） | 内陷上高光为`rgba(255, 255, 255, 0.05) 0px 1px 0px 0px inset`，中间层为`rgba(255, 255, 255, 0.25) 0px 0px 0px 1px`，内陷下阴影为`rgba(0, 0, 0, 0.2) 0px -1px 0px 0px inset` | 模拟macOS原生按钮的按压效果——顶部有白色高光，底部有深色内陷 |
| 级别4（键盘按键效果） | 五层阴影叠加，并带有内陷按压效果 | 键盘快捷键图标——呈现逼真的3D质感 |
| 级别5（悬浮效果） | `rgba(0, 0, 0, 0.5) 0px 0px 0px 2px` + `rgba(255, 255, 255, 0.19) 0px 0px 14px` + 内陷阴影 | 命令面板、悬浮面板——具有强烈深度感并带有光晕效果 |

### 阴影设计理念
Raycast的阴影系统是网络上最贴近macOS原生风格的。多层阴影的组合包括：  
- **外层环状阴影**：用于元素包裹，替代传统边框  
- **内陷上高光**（`rgba(255, 255, 255, 0.05–0.25)`）：模拟来自上方的光源  
- **内陷下阴影**（`rgba(0, 0, 0, 0.2)`）：模拟下方的阴影  
这种效果具有物理真实感：元素看起来像玻璃或拉丝金属，而非扁平的矩形  

### 装饰性深度效果
- **温暖光晕**：在特色元素背后使用`rgba(215, 201, 175, 0.05) 0px 0px 20px 5px`——在冷色调的黑暗背景上增添柔和的暖色氛围  
- **蓝色信息光晕**：使用`rgba(0, 153, 255, 0.15)`，用于强调交互状态  
- **红色危险光晕**：使用`rgba(255, 99, 99, 0.15)`，用于强调错误或破坏性状态  

## 7. 正确做法与禁忌

### 应该这样做
- 使用`#07080a`（而非纯黑色）作为背景——这种蓝调冷色调是Raycast风格的关键  
- 对正文文本应用正号字距（+0.2px）——这与大多数深色UI设计截然不同  
- 为交互元素使用带有内陷高光的多层阴影——这种macOS原生的深度感是其标志性特点  
- 仅将Raycast红色（`#FF6363`）用于关键强调点，而非大面积使用——应将其保留用于首页重点区域和错误状态  
- 使用`rgba(255, 255, 255, 0.06)`作为卡片边框颜色——几乎不可见，但具有结构上的必要性  
- 将正文文本的字体粗细设置为500——中等粗细有助于提升深色模式下的可读性  
- 将主要号召按钮设为药丸形状（圆角≥86px），次要操作按钮设为矩形形状（圆角6px–8px）  
- 为所有Inter字体启用OpenType特性`calt`、`kern`、`liga`、`ss03`  
- 对按钮交互使用透明度过渡效果（悬停时透明度变为0.6），而非颜色变化  

### 不应该这样做
- 使用纯黑色（`#000000`）作为背景——蓝色调是Raycast区别于普通深色主题的关键  
- 对正文文本应用负号字距——Raycast刻意使用正号字距以提高可读性  
- 将Raycast蓝色作为所有元素的主体强调色——蓝色用于交互/信息展示，红色才是品牌主色  
- 仅使用单层扁平阴影——多层内陷阴影系统是macOS原生风格的核心  
- 当有500粗细可选时仍使用400粗细的文字——更高的粗细可避免深色模式下的文字显得过细  
- 混合使用暖色调和冷色调边框——坚持使用冷灰色（`hsl(195, 5%, 15%)`）的边框配色方案  
- 仅使用厚重的外阴影而忽略内陷阴影——阴影始终应成对出现（外层+内陷层）  
- 使用装饰性元素、渐变或彩色背景——黑暗的虚空才是舞台，内容才是核心  

## 8. 响应式设计行为

### 断点设置
| 名称 | 宽度 | 主要变化 |
|------|------|----------|
| 移动端 | <600px | 单列布局、卡片堆叠、汉堡菜单、首页文字缩小至约40px |
| 小型平板 | 600px–768px | 开始使用2列网格，导航部分可见 |
| 平板 | 768px–1024px | 2–3列功能展示、导航栏扩展、截图尺寸自适应调整 |
| 桌面端 | 1024px–1200px | 完整布局，所有导航链接可见，首页显示区域宽度为64px |
| 大型桌面端 | >1200px | 容器居中显示最大宽度，两侧留有充足边距 |

### 触控目标区域
- 药丸形按钮：圆角86px，内边距20px——远高于44px的最低要求  
- 次要按钮：最小内边距为8px，但边框可扩展视觉目标区域  
- 导航链接：文字宽度为16px，并配有周围边距，以确保良好的触控体验  

### 布局折叠策略
- **导航栏**：桌面端为水平全宽导航，移动端变为汉堡菜单，点击后展开菜单  
- **首页区域**：在不同断点下显示宽度分别为64px、48px、36px  
- **功能网格**：从3列逐渐变为2列，最终变为单列堆叠  
- **产品截图**：在固定比例的容器内自适应缩放，同时保持macOS窗口边框的比例  
- **键盘快捷键显示**：在移动端简化或隐藏该功能，因为键盘快捷键在此场景下并无意义  

### 图片处理方式
- 产品截图在固定比例的容器内响应式缩放  
- 首页对角线条纹图案按比例同步缩放  
- 所有尺寸下均保持macOS窗口边框的圆角效果  
- 不使用懒加载技术——图片对传达产品信息至关重要

### 优化迭代指南
在使用该设计系统生成的现有界面进行优化时，请检查：  
1. 背景颜色是否为`#07080a`而非纯黑色——蓝色调至关重要  
2. 正文文本的字距是否为正号（+0.2px）——负号字距会破坏Raycast的设计风格  
3. 阴影是否同时包含外层和内陷层——单层阴影会使界面显得扁平且不符合设计要求  
4. Inter字体是否已启用OpenType特性`calt`、`kern`、`liga`、`ss03`  
5. 悬停状态是否使用透明度过渡效果（0.6）而非颜色替换——这是核心的交互模式
