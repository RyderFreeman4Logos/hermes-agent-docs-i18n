## 1. 视觉主题与氛围

Airbnb 的网站是一个充满温暖气息、以摄影为主的交易平台，让人感觉就像在翻阅一本旅游杂志，每一页都在吸引你预订行程。其设计以纯白色（`#ffffff`）为基底，以标志性的 Rausch 红色（`#ff385c`）——该颜色源自 Airbnb 的首个地址——作为唯一的品牌强调色。这样的设计营造出简洁明亮的视觉空间，其中房源照片、分类图标以及红色的操作按钮是仅有的色彩来源。

在字体选择上，Airbnb 使用了自定义的可变字体 Airbnb Cereal VF，这款字体风格温暖亲切，圆润的字体端点体现了该品牌“无处不属”的理念。字体的粗细范围较为集中：大多数界面元素使用 500（中等）号，需要强调的内容使用 600（半粗）号，而主要标题则使用 700（粗）号。标题的负字距为 -0.18px 至 -0.44px，这样的设计能带来舒适亲切的阅读体验，而非科技公司常见的紧凑高效风格。

Airbnb 的独特之处在于其基于调色板令牌的系统（`--palette-*`）以及多层阴影效果。卡片的主要阴影采用三层结构（`rgba(0,0,0,0.02) 0px 0px 0px 1px, rgba(0,0,0,0.04) 0px 2px 6px, rgba(0,0,0,0.1) 0px 4px 8px`），能营造出柔和温暖的凸起效果。再加上较大的圆角（8px–32px）、半径为 50% 的圆形导航控件，以及可水平滚动的分类标签栏，整个界面显得触感十足且极具亲和力——它更注重浏览体验，而非命令式操作。

**核心特点：**
- 以纯白色为基底，以 Rausch 红色（`#ff385c`）作为唯一品牌强调色
- 使用 Airbnb Cereal VF —— 拥有温暖圆润端点的自定义可变字体
- 基于调色板令牌的系统（`--palette-*`）实现系统化的颜色管理
- 三层卡片阴影：边框环 + 软模糊层 + 较强模糊层
- 宽大的圆角设计：按钮为 8px，徽章为 14px，卡片为 20px，大型元素为 32px
- 半径为 50% 的圆形导航控件
- 以摄影为主的房源卡片——图片是核心内容
- 接近黑色的文字颜色（`#222222`）——温暖而非冷峻
- 高级套餐使用 Luxe Purple（`#460479`）和 Plus Magenta（`#92174d`）作为配色

## 2. 色彩方案与用途

### 主品牌颜色
- **Rausch 红色**（`#ff385c`）：用于 `--palette-bg-primary-core`、主要操作按钮、品牌强调色以及处于激活状态的元素
- **深 Rausch 红色**（`#e00b41`）：用于 `--palette-bg-tertiary-core`，是品牌红色的深色变体
- **错误红色**（`#c13515`）：用于 `--palette-text-primary-error`，即浅色背景上的错误提示文字
- **深错误红色**（`#b32505`）：用于 `--palette-text-secondary-error-hover`，即悬停状态下的错误提示文字

### 高级套餐颜色
- **Luxe Purple**（`#460479`）：用于 `--palette-bg-primary-luxe`，作为 Airbnb Luxe 套餐的标识色
- **Plus Magenta**（`#92174d`）：用于 `--palette-bg-primary-plus`，作为 Airbnb Plus 套餐的标识色

### 文本颜色等级
- **接近黑色**（`#222222`）：用于 `--palette-text-primary`，即主要文本颜色——温暖而非冷峻
- **聚焦灰色**（`#3f3f3f`）：用于 `--palette-text-focused`，即处于聚焦状态的文本
- **次要灰色**（`#6a6a6a`）：用于次要文本及描述内容
- **禁用状态**（`rgba(0,0,0,0.24)`）：用于 `--palette-text-material-disabled`，表示禁用状态的文本
- **禁用链接**（`#929292`）：用于 `--palette-text-link-disabled`，表示禁用的链接文字

### 交互元素颜色
- **法律蓝色**（`#428bff`）：用于 `--palette-text-legal`，即法律相关链接及说明性文本
- **边框灰色**（`#c1c1c1`）：用于卡片和分隔线的边框颜色
- **浅背景色**（`#f2f2f2`）：用于圆形导航按钮及次要背景区域

### 背景与阴影颜色
- **纯白色**（`#ffffff`）：页面背景及卡片表面颜色
- **卡片阴影**（`rgba(0,0,0,0.02) 0px 0px 0px 1px, rgba(0,0,0,0.04) 0px 2px 6px, rgba(0,0,0,0.1) 0px 4px 8px`）：三层结构的柔和凸起效果
- **悬停阴影**（`rgba(0,0,0,0.08) 0px 4px 12px`）：按钮悬停时的凸起效果

### 设计原则
- **温暖的字体粗细范围**：以 500–700 号字体为主。标题不使用 300 或 400 号字体——Airbnb 的字体始终为中等或更粗的样式，从而营造出温暖且自信的视觉风格。
- **标题的负字距设计**：标题文字采用 -0.18px 至 -0.44px 的负字距，使得标题显得亲切舒适，而非冷峻紧凑。
- **"salt" OpenType 特性**：在特定的界面元素（如徽章、标题）上应用该特性，可产生细微的字形变化，为视觉设计增添趣味性。
- **可变字体的精确控制**：虽然 Cereal VF 支持连续的字体粗细过渡，但该设计系统仍采用 500、600 和 700 这三种离散的粗细级别。

## 4. 组件样式设计

### 按钮

**深色主按钮**
- 背景颜色：`#222222`（接近黑色，非纯黑）
- 文字颜色：`#ffffff`
- 内边距：0px 24px
- 圆角大小：8px
- 悬停状态：通过 `var(--accent-bg-error)` 变量过渡为错误色/品牌强调色
- 聚焦状态：显示 `0 0 0 2px var(--palette-grey1000)` 的光环效果，并伴有缩小动画（scale: 0.92）

**圆形导航按钮**
- 背景颜色：`#f2f2f2`
- 文字颜色：`#222222`
- 圆形半径：50%
- 悬停状态：添加 `rgba(0,0,0,0.08) 0px 4px 12px` 的阴影，并向右平移 50%
- 激活状态：添加 4px 宽的白色边框环以及聚焦阴影
- 聚焦状态：伴有缩小动画（scale: 0.92）

### 卡片与容器
- 背景颜色：`#ffffff`
- 圆角大小：徽章为 14px，卡片/按钮为 20px，大型元素为 32px
- 阴影效果：三层结构，即 `rgba(0,0,0,0.02) 0px 0px 0px 1px, rgba(0,0,0,0.04) 0px 2px 6px, rgba(0,0,0,0.1) 0px 4px 8px`
- 房源卡片：顶部为全宽照片，下方为详细信息
- 图片轮播控件：采用半径为 50% 的圆形按钮

### 输入框
- 搜索框：文字颜色为 `#222222`
- 聚焦状态：背景色变为 `var(--palette-bg-primary-error)`，并添加 `0 0 0 2px` 的光环效果
- 圆角大小：根据上下文而定（搜索栏采用类似药丸的圆角设计）

### 导航栏
- 白色固定顶部导航栏，搜索框居中显示
- Airbnb 徽标（Rausch 红色）位于左侧
- 分类筛选标签栏：位于搜索框下方的水平滚动区域
- 图片轮播的导航控件为圆形设计
- “成为房东”文字链接及头像/菜单位于右侧

### 图片处理方式
- 房源照片占据卡片顶部较大空间
- 图片轮播带有圆点指示器
- 图片上可叠加心形/收藏图标
- 被容器包裹的图片圆角大小为 8px–14px

## 5. 布局原则

### 空间系统
- 基础单位：8px
- 缩放比例：2px、3px、4px、6px、8px、10px、11px、12px、15px、16px、22px、24px、32px

### 网格与容器布局
- 全宽顶部导航栏，搜索框居中
- 分类标签栏：可水平滚动的行式布局
- 房源网格：响应式多列布局（桌面端为 3–5 列）
- 全宽底部页脚，包含多个链接栏目

### 空白设计理念
- **类似旅游杂志的间距**：各部分之间保留较大的垂直间距，营造出悠闲的浏览节奏——旨在让用户像翻阅杂志一样慢慢浏览。
- **适度的图片密度**：房源卡片排列相对紧密，但每张图片的尺寸都足够大，从而带来沉浸式的视觉体验。
- **突出的搜索栏**：搜索栏在顶部占据最大垂直空间——找到目的地是用户最核心的操作需求。

### 圆角大小分类
- 微妙圆角（4px）：小型链接元素
- 标准圆角（8px）：按钮、标签页、搜索元素
- 徽章圆角（14px）：状态徽章、标签文字
- 卡片圆角（20px）：功能卡片、大型按钮
- 大圆角（32px）：大型容器、核心展示元素
- 圆形圆角（50%）：导航控件、头像、图标

## 6. 深度与凸起效果

| 层级 | 处理方式 | 用途 |
|------|----------|-----|
| 平面层（层级 0） | 无阴影 | 页面背景、文本块 |
| 卡片层（层级 1） | `rgba(0,0,0,0.02) 0px 0px 0px 1px, rgba(0,0,0,0.04) 0px 2px 6px, rgba(0,0,0,0.1) 0px 4px 8px` | 房源卡片、搜索栏 |
| 悬停层（层级 2） | `rgba(0,0,0,0.08) 0px 4px 12px` | 按钮悬停效果及交互时的凸起感 |
| 激活/聚焦层（层级 3） | `rgb(255,255,255) 0px 0px 0px 4px` 加上聚焦光环 | 处于激活状态或被聚焦的元素 |

**阴影设计理念**：Airbnb 的三层阴影系统营造出温暖自然的凸起效果。第一层阴影（`0px 0px 0px 1px`，透明度为 0.02）实际上是一种极微妙的边框效果。第二层阴影（`0px 2px 6px`，透明度为 0.04）则形成柔和的背景阴影。第三层阴影（`0px 4px 8px`，透明度为 0.1）则构成主要的凸起效果。这种渐进式的设计使得阴影看起来更像自然光线而非单纯的 CSS 效果。

## 7. 正确做法与错误避免指南

### 应该做的- 文本颜色请使用 `#222222`（暖色调近黑色），切勿使用纯黑色 `#000000`
- 仅在核心操作按钮及品牌重点区域使用 Rausch 红色 (`#ff385c`)，它属于唯一的强调色
- 字体应选用 Airbnb Cereal VF，字体重量设定在 500–700 之间——选择这一暖色调范围是有意为之
- 所有突出显示的区域均需应用三层阴影效果
- 按钮的圆角半径设为 8px，卡片为 20px，控件则为 50%
- 照片应是主要视觉内容——所有房源展示均以图片优先
- 为增强亲昵感，标题可设置负字距（-0.18px 至 -0.44px）
- 卡片式轮播/导航控件应采用圆形设计（圆角 50%）

### 不推荐的做法
- 文本切勿使用纯黑色 `#000000`，始终请使用暖色调的 `#222222`
- 背景或大面积区域不可使用 Rausch 红色——它仅作为强调色使用
- 标题字体重量不可过轻（300、400），最低应设置为 500
- 阴影效果不宜过重（主层不透明度不可超过 0.1）——阴影应保持暖色调且呈渐变效果
- 卡片边缘不可过于锐利（圆角 0–4px）——较大的圆角（20px 以上）是设计核心要求
- 除 Rausch/Luxe/Plus 系列颜色外，不得使用其他品牌颜色
- 不可随意修改配色方案机制——请始终统一使用 `--palette-*` 变量

## 8. 响应式设计规则

### 分界点
| 名称 | 宽度范围 | 主要变化 |
|------|---------|---------|
| 小型移动端 | <375px | 单列布局，简化搜索功能 |
| 移动端 | 375–550px | 标准移动端房源网格布局 |
| 小型平板端 | 550–744px | 双列房源展示 |
| 平板端 | 744–950px | 搜索栏宽度增加 |
| 小型桌面端 | 950–1128px | 三列房源布局 |
| 桌面端 | 1128–1440px | 四列网格布局，完整头部区域 |
| 大型桌面端 | 1440–1920px | 五列网格布局 |
| 超宽屏 | >1920px | 最大网格宽度 |

*注：Airbnb 拥有 61 个分界点——这是目前观察到的最为精细的响应式系统之一，充分体现了他们对各种屏幕尺寸下布局设计的极致追求。*

### 触控区域大小
- 圆形导航按钮：圆角半径需达到 50%，确保易于触控
- 房源卡片：在移动端需设置整个卡片作为触控区域
- 搜索栏：尺寸需足够大，方便使用拇指操作
- 类别标签：具有水平滚动功能，且周围留有充足间距

### 布局折叠策略
- 房源网格：从 5 列逐渐变为 4 列、3 列、2 列，最终为 1 列
- 搜索栏：从扩展状态变为紧凑状态，最终变为覆盖式设计
- 类别标签：在所有屏幕尺寸下均支持水平滚动
- 导航栏：从完整头部布局变为移动端简化版
- 地图：从侧边面板显示变为覆盖式或可切换显示

### 图片处理规则
- 房源照片：在移动端以轮播形式展示，支持滑动操作
- 图片尺寸需根据屏幕比例自动调整
- 心形图标的位置在不同屏幕尺寸下保持一致
- 图片质量会根据视口大小进行相应调整

### 优化迭代指南
1. 先以白色作为基础色——照片本身已提供了足够的色彩元素
2. Rausch 红色 (`#ff385c`) 是唯一的强调色——仅限于关键操作按钮使用，切勿滥用
3. 文本请使用近黑色 (`#222222`)——暖色调能提升视觉舒适度
4. 三层阴影可营造自然且温暖的立体感——务必全部使用
5. 圆角半径要足够大：按钮为 8px，卡片为 20px，控件为 50%
6. 字体重量应选用 Airbnb Cereal VF 的 500–700 级别——任何标题均不可使用过轻的字体重量
7. 照片是核心视觉元素——所有房源卡片均应以图片为主导
