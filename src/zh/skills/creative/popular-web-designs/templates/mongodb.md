## 1. 视觉主题与氛围

MongoDB的网站呈现出“深林与终端的融合”风格——其设计系统以最深的青黑色（`#001e2b`）为基调，既呼应了数据库的密集感，又营造出森林树冠的深邃氛围。在近乎纯黑的背景上，醒目的霓虹绿（`#00ed64`）作为品牌标志性色彩闪烁着光芒——这种颜色明亮而富有活力，同时又充满自然气息。它并非赛博朋克风格中冷峻的霓虹灯，而是如同在黑暗中生长的生物所散发出的生物荧光绿。

其排版系统设计极为精巧：大号标题使用MongoDB Value Serif字体（字高96像素），展现出极具权威感的编辑风格——在数据库企业中使用衬线字体实属大胆之举，足以彰显“我们绝非普通科技公司”的定位。Euclid Circular A字体则承担了正文与界面文字的显示任务，拥有300–700共5个不同的粗细等级；而Source Code Pro字体则用于代码及标签显示，其大写字母具有独特的样式，字母间距可达1px–3px。这套三款字体的组合形成了清晰的层级关系：从优雅的编辑风格 → 几何感的专业风格 → 精确的工程风格依次递进。

MongoDB的独特之处在于其双模式设计：深色主题用于标题与功能介绍区域（背景为`#001e2b`，搭配霓虹绿点缀），而浅色主题则用于内容展示区（背景为白色，边框为青灰色`#b8c4c2`）。两种模式之间的切换形成了强烈的视觉对比。阴影效果采用带有青色色调的深色阴影（`rgba(0, 30, 43, 0.12)`），即便在浅色背景上也能保持森林般的深邃感。按钮采用药丸形设计（半径为100px–999px），边框为MongoDB绿颜色（`#00684a`），整个组件系统均遵循LeafyGreen设计系统。

**核心特征：**
- 深青黑色背景（`#001e2b`）——类似森林深处的颜色，而非太空般的纯黑
- 霓虹MongoDB绿（`#00ed64`）作为唯一品牌标识色——兼具电光感与自然气息
- 使用MongoDB Value Serif字体作为标题——在科技领域展现出权威的编辑风格
- Euclid Circular A字体的300号粗细版本作为正文专用，独具特色
- Source Code Pro字体的大写字母具有1px–3px的宽字母间距，用于技术标签显示
- 带有青色色调的阴影：`rgba(0, 30, 43, 0.12)`——阴影同样延续森林色调
- 双模式设计：深色青绿标题区 + 浅色白色内容区
- 药丸形按钮（半径100px），带有绿色边框（`#00684a`）
- 链接颜色为链接蓝（`#006cfa`），悬停时变为`#3860be`

## 2. 色彩方案与用途

### 主要品牌色
- **森林黑**（`#001e2b`）：主要深色背景色——最深的青黑色
- **MongoDB绿**（`#00ed64`）：核心品牌点缀色——用于高亮、下划线及渐变效果
- **深绿**（`#00684a`）：按钮边框及浅色背景上的链接文字颜色——柔和的绿色，用于功能性元素

### 交互元素色
- **动作蓝**（`#006cfa`）：次要点缀色——用于链接及交互高亮区域
- **悬停蓝**（`#3860be`）：所有链接悬停状态都会过渡到此蓝色
- **青绿激活态**（`#1eaedb`）：按钮悬停时的背景色——明亮的青绿色

### 中性色调系列
- **深青色**（`#1c2d38`）：按钮深色背景及次要深色表面颜色
- **青灰色**（`#3d4f58`）：深色表面上的深色边框颜色
- **深石板灰**（`#21313c`）：深色链接文字的另一种版本
- **冷灰色**（`#5c6c75`）：深色背景上的柔和文字颜色，以及次要按钮文字颜色
- **银青色**（`#b8c4c2`）：浅色表面上的边框及分隔线颜色
- **浅输入色**（`#e8edeb`）：深色背景上的输入框文字颜色
- **纯白色**（`#ffffff`）：浅色区域背景及深色背景上的按钮文字颜色
- **黑色**（`#000000`）：浅色背景上的文字颜色，以及最暗的元素颜色

### 阴影效果
- **森林阴影**（`rgba(0, 30, 43, 0.12) 0px 26px 44px, rgba(0, 0, 0, 0.13) 0px 7px 13px`）：主要卡片凸起效果——带有青色色调
- **标准阴影**（`rgba(0, 0, 0, 0.15) 0px 3px 20px`）：通用凸起效果
- **柔和阴影**（`rgba(0, 0, 0, 0.1) 0px 2px 4px`）：轻微的卡片凸起效果

## 3. 排版规则

### 字体家族
- **展示用衬线字体**：`MongoDB Value Serif`——用于标题等需要突出权威感的区域
- **正文/界面文字**：`Euclid Circular A`——几何感强的无衬线字体，适用性广泛
- **代码/标签**：`Source Code Pro`——等宽字体，大写字母有特殊样式
- **备用字体**：`Akzidenz-Grotesk Std`（支持中文时可用Noto Sans KR/SC/JP）、`Times`、`Arial`、`system-ui`

### 设计原则
- **衬线字体彰显权威**：在标题区域使用MongoDB Value Serif字体，这种风格在科技领域极为罕见，足以体现MongoDB是一家成熟企业而非初创公司。
- **正文默认使用300号粗细**：Euclid Circular A字体的300号版本用于正文，营造出轻盈的阅读体验，与深色背景形成鲜明对比。
- **宽字母间距的等宽字体标签**：Source Code Pro字体的大写字母具有1px–3px的宽字母间距，类似数据库字段标签，显得井然有序、结构清晰。
- **四级粗细范围**：从300（轻量级正文）→ 400（标准）→ 500（界面/导航）→ 700（加粗行动号召），相比大多数设计系统拥有更宽的粗细范围，便于实现更精细的层级控制。

## 4. 组件样式

### 按钮

**主绿色按钮（深色背景）**
- 背景色：`#00684a`（柔和的MongoDB绿）
- 文字颜色：`#000000`
- 半径：50%（圆形）或100px（药丸形）
- 边框：`1px solid #00684a`
- 阴影：`rgba(0,0,0,0.06) 0px 1px 6px`
- 悬停效果：放大1.1倍
- 激活状态：缩小0.85倍

**深青色按钮**
- 背景色：`#1c2d38`
- 文字颜色：`#5c6c75`
- 半径：100px（药丸形）
- 边框：`1px solid #3d4f58`
- 悬停效果：背景色变为`#1eaedb`，文字变为白色，并向右平移5px

**轮廓按钮（浅色背景）**
- 背景色：透明
- 文字颜色：`#001e2b`
- 边框：`1px solid #b8c4c2`
- 半径：4px–8px
- 悬停效果：背景色略带阴影

### 卡片与容器
- 浅色模式：白色背景，搭配`1px solid #b8c4c2`的边框
- 深色模式：背景色为`#001e2b`或`#1c2d38`，搭配`1px solid #3d4f58`的边框
- 半径：标准为16px，中等为24px，大型/标题用为48px
- 阴影：`rgba(0,30,43,0.12) 0px 26px 44px`（带有森林色调）
- 图片容器：半径为30px–32px

### 输入框与表单
- 文本区域：文字颜色为`#e8edeb`，内边距为12px 12px 12px 8px
- 边框：浅色模式下为`1px solid #b8c4c2`，深色模式下为`1px solid #3d4f58`
- 输入框半径：4px

### 导航栏
- 深色背景上搭配深色标题栏
- 导航链接使用Euclid Circular A字体，字号为16px，粗细为500
- MongoDB标志（树叶图标+品牌名）位于左侧对齐
- 绿色行动号召按钮位于右侧对齐
- 下拉菜单中展示产品分类

### 图片处理方式
- 控制台截图置于深色背景上
- 截图中的界面元素使用绿色作为点缀
- 图片容器半径为30px–32px
- 产品展示区域采用全宽深色背景

### 独特组件

**霓虹绿强调下划线**
- 样式：`0px 2px 2px 0px solid #00ed64`——在底部和右侧添加下划线作为强调效果
- 用于功能标题及需要突出显示的文字
- 还存在蓝色版本`#006cfa`

**Source Code Pro标签系统**
- 使用14px大小的Source Code Pro字体，大写字母，字母间距为1px–2px
- 用作标题上方的区域分类标记
- 营造出类似数据库字段标签的视觉效果

## 5. 布局原则

### 空间系统
- 基本单位：8px
- 常用比例值：1px、4px、7px、8px、10px、12px、14px、15px、16px、18px、20px、24px、32px

### 网格与容器布局
- 内容最大宽度居中显示
- 深色标题区域包含紧凑的内容
- 浅色内容区域位于下方
- 卡片网格：2–3列
- 深色全宽页脚

### 空白设计理念
- **强烈的模式过渡效果**：通过深青色区域与白色内容之间的对比，而非单纯依靠空间分隔，实现出色的视觉层次感。
- **充足的深色区域**：标题和功能介绍区域拥有较大的垂直内边距（80px以上），让森林般的深色背景有足够“呼吸”的空间。
- **紧凑的浅色区域**：白色内容区域更加密集，卡片网格更紧密，垂直间距更小。

### 边框半径比例
- 最小值（1px–2px）：用于小图标、徽章等元素
- 柔和值（4px）：用于输入框、小型按钮等
- 标准值（8px）：用于卡片、链接等
- 卡片值（16px）：标准卡片及容器
- 切换值（20px）：用于开关类元素
- 大值（24px）：用于大型面板
- 图片值（30px–32px）：用于图片容器
- 标题卡值（48px）：用于标题卡片
- 药丸形值（100px–999px）：用于按钮、导航药丸按钮
- 全宽值（9999px）：最大尺寸的药丸按钮

## 6. 深度与凸起效果| 级别 | 效果处理 | 适用场景 |
|-------|-----------|----------|
| 平面（0级） | 无阴影 | 默认表面元素 |
| 微妙（1级） | `rgba(0,0,0,0.1) 0px 2px 4px` | 轻微的卡片凸起效果 |
| 标准（2级） | `rgba(0,0,0,0.15) 0px 3px 9px` | 普通卡片 |
| 显著（3级） | `rgba(0,0,0,0.15) 0px 3px 20px` | 高突起的面板 |
| 森林色（4级） | `rgba(0,30,43,0.12) 0px 26px 44px, rgba(0,0,0,0.13) 0px 7px 13px` | 主要展示卡片——带有青绿色调 |

**阴影设计理念**：MongoDB的阴影系统独具特色，其主要的凸起阴影采用`rgba(0, 30, 43, 0.12)`——这种带有青绿色调的阴影将品牌特有的深森林色融入到深度层次设计中。因此，即便在白色背景上，这些阴影也仿佛属于MongoDB的色彩体系，而非普通的中性黑色。

## 7. 正确做法与禁忌

### 应该这样做
- 为深色区域使用`#001e2b`（森林黑）——而非纯黑色
- 适度使用MongoDB绿（`#00ed64`），以营造最强的视觉冲击力
- 仅将MongoDB Value Serif字体用于标题和重点展示内容，其他所有文字均使用Euclid Circular A字体
- 为技术标签使用Source Code Pro大写字体，并设置1px–3px的宽字距
- 为卡片的凸起效果使用带青绿色调的阴影（`rgba(0,30,43,0.12)`）
- 保持深色与浅色区域的鲜明对比
- 正文文字使用300号字体——这种轻量化字体更利于阅读
- 主要操作按钮设置100px的圆角半径

### 不应该这样做
- 不要在深色背景上使用纯黑色（`#000000`），务必使用青黑色（`#001e2b`）
- 不要在背景上使用MongoDB绿（`#00ed64`），该颜色仅用于文字、下划线及小型高亮元素
- 不要使用普通的灰色阴影，始终要使用带青绿色调的阴影（`rgba(0,30,43,...)`）
- 不要在正文文字上使用衬线字体——MongoDB Value Serif仅适用于标题区域
- 不要在Source Code Pro标签上使用过窄的字距——宽字距才是该字体的特色
- 不要在同一区域内混用深色与浅色的设计风格
- 不要使用暖色调——整个配色方案严格限定为冷色调（青色、绿色、蓝色）
- 切勿忘记使用绿色的装饰性下划线——它们是该设计风格的标志性元素

## 8. 响应式设计行为

### 分界点
| 名称 | 宽度范围 | 主要变化 |
|------|----------|----------|
| 小型手机端 | <425px | 单列紧凑布局 |
| 手机端 | 425–768px | 标准手机布局 |
| 平板端 | 768–1024px | 开始采用双列网格布局 |
| 桌面端 | 1024–1280px | 标准布局 |
| 大桌面端 | 1280–1440px | 扩展版布局 |
| 超宽屏 | >1440px | 最大宽度，更大边距 |

### 触控目标区域
- 按钮具有足够的填充空间
- 导航链接间距为16px，并有充足间隔
- 卡片整体区域均可作为触控目标

### 布局折叠策略
- 标题区域：MongoDB Value Serif字体，从96px缩小到64px，再进一步缩放
- 导航栏：水平巨型菜单 → 汉堡菜单
- 功能卡片：多列布局 → 叠加布局
- 深色/浅色区域在所有屏幕尺寸下均保持原有风格
- Source Code Pro标签始终保持大写格式

### 图片显示规则
- 仪表板截图按比例缩放
- 深色区域背景保持全宽
- 图片圆角在不同分界点下保持一致

### 优化迭代指南
1. 首先确定整体风格：标题和功能区域使用深色（#001e2b），内容区域使用浅色
2. MongoDB绿（#00ed64）具有强烈的视觉冲击力——每个区域最多使用一次，以获得最佳效果
3. 衬线字体（MongoDB Value Serif）能彰显内容的权威性——切勿用于正文
4. 正文文字使用300号字体，可营造轻松的阅读体验——不要默认使用400号字体
5. 技术标签使用Source Code Pro大写字体并设置宽字距，以体现数据库领域的专业风格
6. 带青绿色调的阴影能让所有元素都融入MongoDB的色彩体系中
