## 1. 视觉主题与氛围

Composio 的界面宛如一座夜间的指挥中心——在以开发者为中心的深色背景中，点缀着电光蓝与深钴蓝色的醒目元素。整个界面建立在近乎纯黑的背景色 `#0f0f0f` 上，内容元素则悬浮在几乎看不见的边界内，营造出高科技控制面板的质感，而非传统的营销页面。对于那些常在黑暗终端前工作的开发者而言，这个网站仿佛在无声地彰显其权威性。

其视觉风格深受代码编辑器与终端窗口的设计理念影响。`JetBrains Mono` 字体与 `abcDiatype` 的几何精准风格相得益彰，进一步凸显出这是一个由开发者为开发者打造的工具这一特点。装饰元素虽简洁却极具冲击力——卡片和板块会散发出微妙的青蓝色渐变光晕，犹如深水中的生物发出的生物荧光；同时，部分元素还带有明显的硬阴影（`4px 4px`），这种粗犷的设计风格避免了整体界面的单调感。

Composio 的独特之处在于它在极致极简主义与策略性色彩点缀之间的巧妙平衡。该网站从不喧哗——标题的行高极低（0.87），使得文字显得紧凑而富有权威感。颜色运用也如同管理稀有资源一般：主要内容使用白色文字，次要内容则采用半透明白色（`rgba(255,255,255,0.5-0.6)`），而品牌蓝 `#0007cd` 或电光蓝 `#00ffff` 则专门用于交互场景及强调效果。

**核心特点：**
- 几乎纯黑的背景，搭配透明度为 4-12% 的几乎看不见的白色边框
- 双字体设计：内容部分使用几何感强的无衬线字体 `abcDiatype`，技术内容则采用等宽字体 `JetBrains Mono` 以增强可信度
- 极低的标题行高（0.87-1.0），使文字块显得紧凑有力
- 生物荧光式强调效果——青蓝色调的光晕仿佛从元素内部透出
- 部分交互元素带有明显的硬阴影（`4px 4px`），呈现粗犷的极简主义风格
- 以单色为主，仅在关键位置使用色彩
- 融合了营销与文档风格的开发者终端式视觉设计

## 2. 色彩方案与用途

### 主色调
- **Composio Cobalt** (`#0007cd`)：核心品牌颜色——一种深沉且饱和度极高的蓝色，仅用于优先级较高的交互元素及品牌展示场景，以低调而强烈的方式确立品牌身份。

### 辅助色与强调色
- **电光蓝** (`#00ffff`)：用于吸引注意力的强调色——以低透明度（`rgba(0,255,255,0.12)`）应用于按钮背景和卡片高亮区域，使其发出微光。在全饱和状态下，则可作为深色背景的活力对比色。
- **信号蓝** (`#0089ff` / `rgb(0,137,255)`)：用于部分按钮边框及交互元素的焦点状态，起到连接钴蓝与电光蓝的作用。
- **海洋蓝** (`#0096ff` / `rgb(0,150,255)`)：用于号召性操作按钮的强调边框颜色，色调略暖于信号蓝。

### 背景与表面色
- **虚空黑** (`#0f0f0f`)：页面的主要背景色——并非纯黑，而是稍暖一些的颜色，可减少在深色显示屏上的视觉疲劳。
- **纯黑** (`#000000`)：用于卡片内部及深层嵌套的容器，与页面背景形成细微的深度差异。
- **炭灰** (`#2c2c2c` / `rgb(44,44,44)`)：用于深色背景上的次要按钮边框及分隔线。

### 中性色与文字色
- **纯白** (`#ffffff`)：深色背景上主要标题及需重点强调的文字颜色。
- **暗烟灰** (`#444444`)：用于非重点的正文、元数据及次要内容。
- **幽灵白** (`rgba(255,255,255,0.6)`)：用于次要正文及链接标签——可见但刻意保持柔和感。
- **低语白** (`rgba(255,255,255,0.5)`)：用于三级按钮文字及占位内容。
- **幻影白** (`rgba(255,255,255,0.2)`)：用于极微弱的按钮背景及深度隐藏的界面元素边框。

### 语义色与强调色
- **边界雾 12** (`rgba(255,255,255,0.12)`)：透明度最高的边框样式——用于突出显示的卡片边缘及内容分隔线。
- **边界雾 10** (`rgba(255,255,255,0.10)`)：深色背景上标准的容器边框。
- **边界雾 08** (`rgba(255,255,255,0.08)`)：用于细微的板块分隔线及次要卡片边缘。
- **边界雾 06** (`rgba(255,255,255,0.06)`)：用于背景分组区域的几乎看不见的边界。
- **边界雾 04** (`rgba(255,255,255,0.04)`)：最微弱的边框——仅用于营造氛围分隔效果。
- **浅色边框** (`#e0e0e0` / `rgb(224,224,224)`)：保留用于浅色背景场景（在该网站中较为罕见）。

### 渐变系统
- **青色光晕**：使用极低透明度的 `#00ffff` 创建径向渐变，为卡片和功能板块背后增添生物荧光般的光环。
- **蓝至黑渐变**：从 Composio Cobalt (`#0007cd`) 到虚空黑 (`#0f0f0f`) 的线性渐变，用于主视觉区域背景及板块过渡效果。
- **白色雾效**：页面底部的渐变，从深色逐渐过渡到柔和的灰白色，可在页脚附近营造出类似“地平线”的氛围效果。

## 3. 字体规范

### 字体家族
- **正文字体**：`abcDiatype`，备用字体包括：`abcDiatype Fallback, ui-sans-serif, system-ui, Apple Color Emoji, Segoe UI Emoji, Segoe UI Symbol, Noto Color Emoji`
- **等宽字体**：`JetBrains Mono`，备用字体包括：`JetBrains Mono Fallback, ui-monospace, SFMono-Regular, Menlo, Monaco, Consolas, Liberation Mono, Courier New`
- **系统默认等宽字体**（备用）：`Menlo` 或 `monospace`，用于最小的内联代码

### 设计原则
- **压缩带来权威感**：标题的行高极低（0.87-1.0），使得大号文字显得紧凑而富有力量，而非轻松美观。
- **双重风格定位**：`abcDiatype` 负责传递营销风格——几何感强、精准且友好；`JetBrains Mono` 则体现技术风格——可信、实用，深受开发者喜爱。
- **字重控制严格**：几乎所有文字都使用 400 号（常规）字重。500 号（中等）字重仅用于小型标签、徽章及部分卡片标题。700 号（粗体）则仅出现在极小的系统默认等宽字体场景中。
- **代码文字使用负字距**：`JetBrains Mono` 采用负字距（-0.28px 至 -0.98px），使代码块更加紧凑，仿佛来自真正的集成开发环境。
- **大写仅用于特定场景**：上划线加字距的格式仅用于极小的标签和技术术语——绝不会用于标题。

## 4. 组件样式

### 按钮

**主要号召性按钮（白色填充）**
- 背景：纯白 (`#ffffff`)
- 文字颜色：接近黑色 (`oklch(0.145 0 0)`)
- 内边距：适中（8px 24px）
- 无边框
- 圆角：略微圆润（根据字体比例约为 4px）
- 悬停效果：可能为透明度略微降低或颜色稍显灰暗

**青色强调号召性按钮**
- 背景：12% 透明度的电光蓝 (`rgba(0,255,255,0.12)`)
- 文字颜色：接近黑色 (`oklch(0.145 0 0)`)
- 内边距：适中（8px 24px）
- 边框：细实的海洋蓝边框 (`1px solid rgb(0,150,255)`)
- 圆角：略微圆润（4px）
- 在深色背景下可营造出“从内部发光”的效果

**幽灵/轮廓按钮（信号蓝）**
- 背景：透明
- 文字颜色：接近黑色 (`oklch(0.145 0 0)`)
- 内边距：适中（10px）
- 边框：细实的信号蓝边框 (`1px solid rgb(0,137,255)`)
- 悬停效果：可能为填充色或边框颜色变化

**幽灵/轮廓按钮（炭灰色）**
- 背景：透明
- 文字颜色：接近黑色 (`oklch(0.145 0 0)`)
- 内边距：适中（10px）
- 边框：细实的炭灰色边框 (`1px solid rgb(44,44,44)`)
- 用于深色背景上的次要或三级操作

**幻影按钮**
- 背景：幻影白 (`rgba(255,255,255,0.2)`)
- 文字颜色：低语白 (`rgba(255,255,255,0.5)`)
- 无可见边框
- 用于需要极度弱化视觉效果的操作

### 卡片与容器- 背景：纯黑色（`#000000`）或透明背景  
- 边框：根据重要性不同，采用低不透明度白色边框，范围从 Border Mist 04（`rgba(255,255,255,0.04)`）到 Border Mist 12（`rgba(255,255,255,0.12)`）  
- 圆角：几乎无圆角效果（内联元素为2px，内容卡片为4px）  
- 阴影：部分卡片采用硬偏移的粗犷风格阴影（`rgba(0,0,0,0.15) 4px 4px 0px 0px`）——这种独特的设计手法能增强视觉深度感  
- 浮起阴影：层级更深的容器则使用柔和的漫射阴影（`rgba(0,0,0,0.5) 0px 8px 32px`）  
- 悬停效果：通常为边框不透明度略微增加或出现微弱发光效果  

### 输入框与表单
- 未提取明确的输入字段数据——输入元素大概率遵循深色背景设计规范，具体如下：
  - 背景：透明或纯黑色
  - 边框：Border Mist 10（`rgba(255,255,255,0.10)`）
  - 聚焦状态：边框颜色变为信号蓝（`#0089ff`）或电光青色
  - 文本：纯白色，占位符为幽灵白

### 导航栏
- 深色/黑色背景上的固定顶部导航栏
- 左侧为白色SVG标识：Composio品牌字标
- 导航链接：纯白色（`#ffffff`），字体大小为标准值16px，使用abcDiatype字体
- 导航栏中的操作按钮：实心填充的主色调风格
- 移动端：折叠为汉堡菜单，采用单列布局
- 导航栏底部有细微的边框（Border Mist 06-08）

### 图片处理
- 以深色主题的产品截图和UI原型为主
- 图片置于与卡片系统一致的带边框容器中
- 功能图片的背景或下方有蓝/青色渐变光晕
- 图片本身除容器圆角（4px）外无可见圆角效果
- 图片在卡片容器内实现全填充显示

### 独特组件

**数据统计/指标展示**
- 使用大型等宽字体（JetBrains Mono），采用“10k+”风格显示数值
- 布局紧凑，下方配有简洁的标签文字

**代码块/终端预览**
- 深色容器，使用JetBrains Mono字体
- 内容带有语法高亮效果
- 容器边缘有细微边框（Border Mist 10）

**集成工具/合作伙伴标识网格**
- 在深色背景上以网格形式展示各类工具的标识
- 所有标识均置于带边框的卡片中
- 以此体现平台的生态多样性

**“COMPOSIO”品牌展示**
- 使用超大尺寸的字体——很可能是页面上最大的文字
- 用作章节分隔符或品牌声明元素
- 黑色背景上搭配纯白色字体，形成强烈对比

## 5. 布局原则

### 空间系统
- 基本单位：8px
- 缩放比例：1px、2px、4px、6px、8px、10px、12px、14px、16px、18px、20px、24px、30px、32px、40px
- 组件内边距：通常为10px（按钮）至24px（水平方向的操作按钮）
- 章节间距：各主要章节之间保留较大的垂直间距，约80-120px
- 卡片内部边距：大约为24-32px

### 网格与容器
- 容器最大宽度：约1200px，居中显示
- 内容区域根据功能卡片的数量采用单列或2-3列网格布局
- 主标题区域：居中的单列布局，以获得最佳视觉冲击力
- 功能展示区：采用非对称布局，结合文字块与产品截图

### 空白设计理念
- **章节间的充足间距**：较大的垂直间隙能让页面滚动时形成清晰的“章节”分隔
- **组件内部的紧凑布局**：卡片和文字块内部结构紧密（行高较小，内边距极简），从而形成聚焦的信息单元
- **通过对比实现区分**：Composio并非仅依赖空白来划分区域，而是通过边框不透明度的差异以及细微的背景色调变化来实现内容区域的区分

### 圆角尺度标准
- 几乎为直角（2px）：内联代码、小型标签、预格式化文本块——采用最锐利的边缘处理方式，凸显技术精准感
- 轻微圆角（4px）：内容卡片、图片、普通容器——最常用的圆角尺寸
- 圆形凸起效果（37px）：部分按钮和徽章——为关键操作按钮增添柔和、更易接近的视觉感受
- 完全圆形（9999px+）：圆形元素、类似头像的容器、装饰性圆点

## 6. 深度与层次感

| 层级 | 设计处理方式 | 适用场景 |
|------|--------------|----------|
| 平面层（层级0） | 无阴影，无边框 | 页面背景、内联文本 |
| 包含层（层级1） | Border Mist 04-08，无阴影 | 背景分组、次要章节区域 |
| 卡片层（层级2） | Border Mist 10-12，无阴影 | 标准内容卡片、代码块 |
| 粗犷层（层级3） | 硬偏移阴影（`4px 4px`，15%黑色浓度） | 特定交互式卡片、需要突出显示的特色功能 |
| 浮起层（层级4） | 柔和漫射阴影（`0px 8px 32px`，50%黑色浓度） | 弹窗、覆盖层、层级极高的内容 |

**阴影设计理念**：Composio谨慎使用阴影，并注重对比效果。硬偏移的粗犷风格阴影是其标志性设计——这种阴影打破了纯黑的简洁感，带来一种原始的、近乎复古计算机时代的视觉体验。柔和漫射阴影则仅用于真正需要浮起效果的元素。大多数层次感是通过边框不透明度的渐变来实现的，而非依赖阴影。

### 装饰性深度效果
- **青色光晕环**：在功能卡片和图片背后使用低不透明度的电光青色创建径向渐变光环，营造出“屏幕发光”的效果，仿佛UI元素正在散发光线。
- **蓝黑渐变背景**：使用从Composio Cobalt到Void Black的线性渐变作为章节背景，从而实现细微的颜色温度变化。
- **白色雾气底边**：在页面底部设置从深色逐渐过渡到柔和白灰色的渐变，为页脚之前营造出一种如“黎明”般的氛围效果。

## 7. 正确做法与禁忌

### 应该做的
- 将Void Black（`#0f0f0f`）作为页面的主背景色——切勿在主要区域使用纯白色
- 保持标题的行高极低（0.87-1.0），以实现紧凑且富有权威感的文字呈现
- 使用不透明度为4-12%的白色边框作为内容边界——相比阴影，边框在这里更为重要
- 仅将电光青色（`#00ffff`）用于需要强烈视觉强调的场景——如操作按钮、发光效果、交互式装饰元素
- 将abcDiatype字体与JetBrains Mono字体搭配使用，进一步强化开发工具的定位
- 有意在部分元素上应用硬偏移阴影（`4px 4px`），以塑造粗犷的设计风格
- 即使在最深的背景上，按钮文字也应保持深色（`oklch(0.145 0 0)`）——按钮本身具有独立的视觉表面
- 通过叠加不同不透明度的边框来营造细微的深度感，无需依赖阴影
- 仅在对非常小的上划线标签（12px或更小）使用大写字母加字距效果

### 不应该做的
- 不要在主要容器中使用明亮的背景或浅色表面
- 不要到处都使用厚重阴影——层次感应通过边框不透明度而非box-shadow来实现
- 不要将Composio Cobalt（`#0007cd`）用作文本颜色——在深色背景下它过暗，在浅色背景下则色彩过于饱和
- 不要将标题的行高提高到1.2以上——紧凑的视觉效果是该设计风格的核心特征
- 不要在正文或标题文本中使用700号粗体字体——400-500号字体为最佳选择
- 不要混用暖色调——整个设计配色严格遵循冷色调体系（蓝色、青色、白色、黑色）
- 不要在内容卡片上使用大于4px的圆角——近乎直角的精确设计是刻意为之
- 不要在大面积背景上使用全不透明度的电光青色——它仅作为装饰色，背景中使用时最大不透明度不超过12%
- 不要使用装饰性衬线字体或手写体——整个设计风格以几何感强的无衬线字体和等宽字体为主
- 不要在技术内容中省略等宽字体——JetBrains Mono并非用于装饰，而是传递专业可信度的象征

## 8. 响应式设计行为

### 分界点
| 名称 | 宽度 | 主要变化 |
|------|------|----------|
| 移动端 | <768px | 单列布局，汉堡菜单导航，全宽度卡片，章节间距缩小，主标题文字大小缩小至约28-40px |
| 平板端 | 768-1024px | 卡片采用2列网格布局，导航栏更紧凑，主标题文字尺寸略有缩小 |
| 桌面端 | 1024-1440px | 完整的多列布局，导航栏扩展，所有链接均可见，主标题字体大小达到64px |
| 大屏幕桌面端 | >1440px | 容器居中显示，水平边距更加宽敞 |

### 触控目标区域
- 所有交互元素的最小触控目标区域尺寸为44x44px
- 按钮需具备足够的填充空间（垂直方向至少8px，水平方向至少24px），以确保充足的触控区域
- 导航链接之间保留足够间距，便于用拇指操作

### 布局折叠策略
- **导航栏**：桌面端为完整水平导航栏，移动端则折叠为汉堡菜单
- **功能网格**：从3列布局逐步变为2列，最终在移动端变为单列堆叠
- **主标题文字**：从64px逐步缩小至40px，再降至28px
- **章节间距**：虽然也会按比例缩小，但仍保持较大的垂直节奏感
- **卡片**：在移动端垂直堆叠显示，且保持全宽度
- **代码块**：在较小屏幕上采用水平滚动方式，而非自动换行

### 图片行为
- 产品截图会在其容器内按比例缩放
- 深色主题的图片在所有尺寸下都能在深色背景上保持良好的对比度
- 渐变光晕效果会随容器大小同步变化
- 不同分界点之间不会出现明显的视觉风格变化——裁剪方式和比例缩放保持一致
