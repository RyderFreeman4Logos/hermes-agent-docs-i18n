## 1. 视觉主题与氛围

Framer 的网站呈现出一种电影般的风格，以工具为核心，采用深色背景，尽显由注重工艺的设计师打造的工具所拥有的自信气质。整个页面浸透在纯黑色之中——并非温暖的炭灰色或舒适的深灰色，而是纯粹的黑色（`#000000`），这让每一个元素、每一张截图、每一处排版细节都仿佛悬浮在浩瀚的太空中。这是一个将自身产品界面视为核心视觉元素的网站，它直接将高保真截图与交互式演示嵌入到内容叙事中。

其独特的排版风格尤为引人注目：使用 GT Walsheim 字体，并设置极小的字距负值（在 110px 的显示字体大小下可达 -5.5px），使得标题看起来仿佛被压缩、充满动感，犹如随时可能因压力而膨胀的弹簧。正文则平滑过渡到 Inter 字体，同时充分利用了 OpenType 的多种特性（`cv01`、`cv05`、`cv09`、`cv11`、`ss03`、`ss07`），即便在小字号文本上也能呈现出精致且独特的效果。Framer Blue（`#0099ff`）被谨慎而恰当地运用——作为链接颜色、边框点缀以及微妙的环形阴影，为纯黑背景增添了一抹冷峻而充满电感的色彩线条。

整体效果宛如专为网页设计师打造的夜店：环境幽暗、设计精准、富有诱惑力，且毫不掩饰地以产品为核心。每个板块的存在都是为了展示该工具的功能，而网站本身则充当了概念验证的载体。

**核心特征：**
- 纯黑色（`#000000`）背景——绝对的黑暗，无任何暖色或灰色调
- 使用 GT Walsheim 字体，具有极小的负字距（110px 时为 -5.5px）
- 仅使用 Framer Blue（`#0099ff`）作为强调色——冷峻、充满电感且精准
- 圆形按钮（半径为 40px–100px）——交互元素无尖锐边缘
- 将产品截图作为核心视觉元素——工具本身即是最好的营销素材
- 在深色背景上使用 `rgba(255, 255, 255, 0.1)` 创建磨砂玻璃效果的按钮变体
- Inter 字体广泛运用 OpenType 特性，以实现精细的微排版

## 2. 色彩方案与用途

### 主要色彩
- **纯黑色**（`#000000`）：主要背景色，构成了 Framer 以深色为基调的独特风格
- **纯白色**（`#ffffff`）：深色背景上的主文字颜色，以及强调色背景上的按钮文字颜色
- **Framer Blue**（`#0099ff`）：主要强调色——用于链接、边框、环形阴影及交互高亮效果

### 辅助与强调色彩
- **暗银色**（`#a6a6a6`）：深色背景上的辅助文字、柔和标签以及暗淡的描述文字
- **近黑色**（`#090909`）：用于打造更显层次感的深色背景，以及作为阴影环的颜色以实现微妙的深度分隔

### 表面与背景色
- **纯黑**（`#000000`）：页面背景，即主要的视觉画布
- **磨砂白色**（`rgba(255, 255, 255, 0.1)`）：半透明按钮背景，以及深色背景上的玻璃效果表面
- **淡白色**（`rgba(255, 255, 255, 0.5)`）：用于悬停状态，透明度略高的磨砂元素

### 中性色与文字颜色
- **纯白色**（`#ffffff`）：标题文字及需要重点突出的正文文字
- **暗银色**（`#a6a6a6`）：正文文字、描述内容以及次要信息
- **幽灵白**（`rgba(255, 255, 255, 0.6)`）：深色背景上的第三级文字及占位符

### 语义色彩与强调色彩
- **Framer Blue**（`#0099ff`）：链接、交互式边框以及焦点环
- **蓝色光晕**（`rgba(0, 153, 255, 0.15)`）：焦点环的阴影效果，为交互元素增添微妙的蓝色光环
- **默认链接蓝**（`#0000ee`）：标准的浏览器链接颜色（在内容区域中少量使用）

### 渐变系统
- 该网站几乎不使用明显的渐变效果——Framer 依靠纯平面的黑色背景，偶尔通过略带蓝色的光晕来营造深度感
- 在产品截图背后，会使用低透明度的 Framer Blue 创建微妙的径向光晕效果

- **正文/界面文字**：`Inter Variable` / `Inter`——具有丰富 OpenType 特性的可变字体。备用字体为 `Inter Placeholder`、`-apple-system`、`system-ui`
- **强调文字**：`Mona Sans`——GitHub 的开源字体，用于部分元素，字重为超轻级（100）
- **等宽字体**：`Azeret Mono`——用于代码及技术标签的配套等宽字体

### 设计原则
- **以压缩塑造个性**：GT Walsheim 字体极小的负字距（110px 时为 -5.5px）是其最具代表性的排版特点——标题看起来仿佛充满弹性、紧迫感，甚至带有一丝急促的气息
- **最大化 OpenType 特性**：Inter 字体同时运用了 6 种以上的 OpenType 特性（`cv01`、`cv05`、`cv09`、`cv11`、`ss03`、`ss07`），即便在正文字号下也能呈现出独特而精致的效果
- **标题字体字重控制**：所有 GT Walsheim 字体均使用 500 级字重（中等），既不粗也不细，从而营造出自信而不张扬的标题视觉效果
- **极低的行高设计**：标题级文本的行高仅为 0.85，意味着字母在垂直方向上几乎相互重叠——这种刻意设计的密集感旨在鼓励用户近距离阅读

## 4. 组件样式设计

### 按钮
- **磨砂圆形按钮**：背景色为 `rgba(255, 255, 255, 0.1)`，文字颜色为黑色（`#000000`），呈圆形形状（半径为 40px）。这种按钮呈现出现在深色背景上，具有半透明、柔和的玻璃效果
- **纯白色圆形按钮**：背景色为 `rgb(255, 255, 255)`，文字颜色为黑色（`#000000`），完整圆形形状（半径为 100px），内边距为 `10px 15px`。这是主要的行动号召按钮——在深色背景下对比鲜明、醒目易见
- **幽灵按钮**：无可见背景，仅显示白色文字，完全依赖文字样式来呈现效果。悬停时会出现微弱的磨砂背景
- **动画过渡效果**：基于缩放的动画效果（使用矩阵变换，缩放因子为 0.85），以及用于展示效果的透明度过渡

### 卡片与容器
- **深色背景卡片**：背景色为黑色或近黑色（`#090909`），边框为 `rgba(0, 153, 255, 0.15) 0px 0px 0px 1px` 形式的蓝色环形阴影，圆角半径为 10px–15px
- **浮起效果卡片**：具有多层阴影——包括 `rgba(255, 255, 255, 0.1) 0px 0.5px 0px 0.5px`（轻微的顶部高光）以及 `rgba(0, 0, 0, 0.25) 0px 10px 30px`（深色的环境阴影）
- **产品截图**：在深色容器中以全宽显示或添加内边距，软件界面预览的圆角半径为 8px–12px
- **悬停效果**：Framer Blue 环形阴影的亮度会略有增加，或磨砂表面会有明暗变化

### 输入框与表单
- 由于该网站属于营销性质，表单元素相对简洁
- 输入字段遵循深色主题设计：深色背景、细微边框、白色文字
- 聚焦状态时：边框变为 Framer Blue（`#0099ff`）颜色，宽度为 `1px solid #0099ff`
- 占位符文字颜色为 `rgba(255, 255, 255, 0.4)`

### 导航栏
- **深色浮动导航栏**：黑色背景搭配磨砂玻璃效果，链接文字为白色
- **导航链接**：使用 Inter 字体，字号 15px，字重 400，文字为白色，悬停时透明度会有轻微变化
- **行动号召按钮**：圆形设计，颜色为白色或磨砂色，位于导航栏右侧
- **移动端适配**：在移动设备上会折叠为汉堡菜单，但仍保持深色主题
- **固定定位**：滚动时导航栏会始终固定在页面顶部

### 图片处理
- **产品截图作为核心视觉元素**：以全宽方式嵌入 UI 截图，圆角半径为 8px–12px
- **深色背景上的布局**：截图放置在黑色背景上，并通过微弱的阴影来实现层次分隔
- **16:9 及自定义宽高比**：产品演示内容会填满对应容器
- **无装饰性图片**：所有图片都具有实用功能——用于展示工具、输出效果或工作流程

### 信任度与用户见证
- 客户LOGO及评价文字以暗灰色显示在深色背景上
- 极少使用装饰元素——产品截图本身即可作为建立信任的依据

## 5. 布局原则

### 空间系统
- **基础单位**：8px
- **倍数序列**：1px、2px、3px、4px、5px、6px、8px、10px、12px、15px、20px、30px、35px
- **分节间距**：各分节之间有较大的垂直间距（80px–120px）
- **卡片内边距**：卡片内部间距为 15px–30px
- **组件间隙**：相关元素之间的间距为 8px–20px

### 网格与容器布局
- **最大宽度**：容器宽度约为 1200px，居中显示
- **列布局模式**：首页为全宽展示区，功能介绍部分为双列布局，产品展示部分为单列布局
- **非对称布局**：功能介绍部分通常将文字内容（占 40%）与截图内容（占 60%）相结合

### 空白设计理念- **在黑暗中呼吸**：各内容区块之间保留充足的垂直间距——黑色背景使得空白区域呈现为深邃的虚无，从而在内容块之间营造出强烈的视觉停顿感  
- **内部紧凑，外部宽敞**：单个组件内部布局紧密（行高较小、文字密度较高），但整体悬浮在广阔的背景空间中  
- **以产品为核心的高密度设计**：截图区域可设计得信息密集且内容充实，与稀疏的营销文案形成鲜明对比  

### 边框圆角尺度
- **1px**：微小元素，边缘近乎方形且精度极高  
- **5px–7px**：小型UI元素、图片缩略图——边缘有轻微柔和处理  
- **8px**：标准组件圆角——代码块、按钮、交互式元素  
- **10px–12px**：卡片、产品截图——圆角较为舒适  
- **15px–20px**：大型容器、功能卡片——圆角更为夸张  
- **30px–40px**：导航按钮、分页控件——圆角极为明显  
- **100px**：完整的圆形按钮形状——主要行动号召按钮、标签元素  

## 6. 深度与立体感

| 级别 | 处理方式 | 适用场景 |
|------|-----------|----------|
| 级别0（平面） | 无阴影，纯黑色表面 | 页面背景、空白区域 |
| 级别1（环形） | `rgba(0, 153, 255, 0.15) 0px 0px 0px 1px` | 卡片边框、交互元素轮廓——具有Framer Blue风格的蓝色光环 |
| 级别2（包裹式） | `rgb(9, 9, 9) 0px 0px 0px 2px` | 在深色背景上形成近乎黑色的柔和包裹效果 |
| 级别3（悬浮式） | `rgba(255, 255, 255, 0.1) 0px 0.5px 0px 0.5px, rgba(0, 0, 0, 0.25) 0px 10px 30px` | 升起的卡片、悬浮元素——顶部有微弱的白色高光边缘，同时伴有深色的环境阴影 |

### 阴影设计理念
Framer的立体感系统与传统浅色主题设计相反。它并未在浅色背景上使用更深的阴影，而是采用以下方式：  
- **低透明度的蓝色环形阴影**（透明度为0.15），用于实现元素包裹效果——这一独特设计为每个带边框的元素增添了鲜明的品牌标识  
- **悬浮元素顶部的白色边缘高光**（厚度为0.5px），模拟光线照射在顶部表面的效果  
- **深度环境阴影**，用于真正具有悬浮效果的元素——使用`rgba(0, 0, 0, 0.25)`且阴影范围较广（30px）  

### 装饰性深度效果
- **蓝色光晕**：在关键交互区域背后添加微妙的Framer Blue（`#0099ff`）径向渐变  
- **无背景模糊/玻璃态效果**：尽管使用了磨砂按钮效果，但并未大量使用复杂的玻璃模糊技术——透明度是通过简单的rgba透明度实现的  

## 7. 正确做法与禁忌

### 应该这样做
- 使用纯黑色（`#000000`）作为主背景色——而非深灰色或炭黑色  
- 对GT Walsheim显示文本应用极大的负字距（-3px至-5.5px）  
- 所有按钮均保持圆形设计（圆角至少40px）——绝不能使用方形或略微圆角的按钮  
- 仅将Framer Blue（`#0099ff`）用于交互式强调元素——如链接、边框及焦点状态  
- 在深色背景上使用`rgba(255, 255, 255, 0.1)`来创建磨砂玻璃效果表面  
- 仅使用GT Walsheim的500号字体重量——正是这个中等重量体现了品牌风格  
- 对Inter字体启用丰富的OpenType特性（cv01、cv05、cv09、cv11、ss03、ss07）  
- 让产品截图成为视觉焦点——产品本身即是最好的展示素材  
- 为卡片添加蓝色环形阴影（`rgba(0, 153, 255, 0.15) 0px 0px 0px 1px`）以实现元素包裹效果  

### 不应该这样做
- 使用温暖的深色背景（避免使用`#1a1a1a`、`#2d2d2d`或带棕色的黑色）  
- 对GT Walsheim显示文本使用粗体（700号及以上）字体——仅限500号中等字体  
- 除Framer Blue之外再使用其他强调颜色——该设计体系仅允许一种强调色  
- 为非交互元素设置过大的圆角（卡片圆角为10px–15px，按钮才可使用40px及以上）  
- 添加装饰性图片、插图或图标——产品本身即是最好的视觉表达  
- 在标题上使用正字距——所有文本均需压缩，采用负字距设计  
- 使用过重的投影效果——深度感应通过微妙的环形阴影和极简的环境阴影来体现  
- 在内容区块背后放置浅色/白色背景——空白区域具有特殊意义  
- 使用衬线字体或显示字体——该设计体系仅使用几何风格的无衬线字体

| 移动端 | <809px | 单列布局，功能区块垂直堆叠，主标题文字缩小（62px→40px），出现汉堡菜单导航 |
| 平板端 | 809px–1199px | 开始采用双列布局展示功能项，导航链接部分可见，截图尺寸缩小 |
| 桌面端 | >1199px | 完整布局，导航栏扩展并显示所有链接及行动号召按钮，主标题高度为110px，功能区块并排显示 |

### 触控目标区域
- 圆形按钮：最小高度为40px，垂直内边距为10px——远超过WCAG规定的44px最低标准  
- 导航链接：文字高度为15px，并配有充足的内边距以确保触控便利性  
- 移动端行动号召按钮：在移动端采用全宽度圆形按钮，便于拇指操作  

### 收缩策略
- **导航栏**：桌面端为水平导航栏——在移动端断点处转换为汉堡菜单  
- **主标题文字**：在不同断点下分别从110px逐渐缩小至85px、62px，最终约为40px，同时保持极端的负字距比例  
- **功能区块**：桌面端为文本与截图并排显示——在移动端则垂直堆叠  
- **产品截图**：在容器内按比例响应式缩放，同时保持原有宽高比  
- **区块间距**：按比例缩小——桌面端为120px，移动端为60px  

### 图片处理方式
- 产品截图具有响应式特性，会在其容器边界内按比例缩放  
- 不会因屏幕尺寸变化而调整构图——所有断点下均保持相同的裁剪方式  
- 深色背景确保截图在任何尺寸下都能保持视觉冲击力  
- 图片会在用户滚动到可视区域时再加载

### 优化迭代指南
在使用该设计系统生成的现有界面进行优化时：  
1. 每次仅专注优化一个组件——深色背景让每个元素都显得尤为重要  
2. 始终检查GT Walsheim标题的字距设置——极端的负字距是必须遵循的原则  
3. 确保Framer Blue仅出现在交互式元素上——绝不能用作非链接元素的装饰性背景或文字颜色  
4. 所有按钮都必须保持圆形设计——任何方形角落都会破坏Framer的设计风格  
5. 通过检查磨砂表面是否恰好使用`rgba(255, 255, 255, 0.1)`来验证其效果——透明度过高会显得异常，过低则几乎不可见
