## 1. 视觉主题与氛围

OpenCode 的网站采用了原生终端风格、以单行字体为主的视觉设计，这正是其作为开源 AI 编码工具的体现。整个视觉系统以强烈的深色背景（`#201d1d`）与温暖的米白色文字（`#fdfcfc`）形成对比，营造出一种简洁而富有层次感的效果。这并非普通的深色主题——它是一种略带红棕色调的温暖深色，更像是高级终端模拟器，而非冷冰冰的集成开发环境。无论是深色还是浅色元素都带有温暖的色调（注意 `#201d1d` 中微妙的红色成分——rgb(32, 29, 29)），从而形成统一且自然的视觉风格。

该设计仅使用 Berkeley Mono 这一种字体，彻底凸显了单行字体的特性。从标题、正文、按钮到导航元素，所有内容都使用同一种字体，完美诠释了“一切皆代码”的理念。标题字体大小为 38px，加粗，行高为 1.50，既醒目又易于阅读；而正文字体大小为 16px，字重为 500，略高于常规字体重量，有助于提升屏幕上的可读性。单行字体网格自然地为整个布局带来了整齐的对齐感和节奏感。

色彩系统则力求简约。主要色调仅包含三种功能性颜色：略带红棕色调的温暖深色（`#201d1d`）、中等暖灰色（`#9a9898`）以及明亮的米白色（`#fdfcfc`）。语义化颜色则借鉴了 Apple HIG 色板——蓝色强调色（`#007aff`）、红色危险提示色（`#ff3b30`）、绿色成功提示色（`#30d158`）以及橙色警告色（`#ff9f0a`）——这些颜色让界面具备熟悉且值得信赖的视觉信号，同时不会增加品牌设计的复杂性。边框则采用略带温暖的半透明效果（`rgba(15, 0, 0, 0.12)`），与整个系统的温暖色调相呼应。

**核心特征：**
- 仅使用 Berkeley Mono 一种字体——所有元素均为单行字体，无衬线或仿衬线字体
- 主色调为略带红棕色调的温暖深色（`#201d1d`），并非纯黑色
- 文字颜色为带暖色调的米白色（`#fdfcfc`），并非纯白色
- 所有元素均采用 4px 的圆角半径——边缘线条简洁实用
- 基础间距系统为 8px，最大扩展至 96px
- 颜色选用受 Apple HIG 指南启发的语义化颜色（蓝、红、绿、橙）
- 边框采用半透明的温暖色调，颜色值为 `rgba(15, 0, 0, 0.12)`
- 邮箱输入框拥有 20px 的较大内边距和 6px 的圆角半径——是所有组件中圆角最大的
- 按钮仅有一种样式：深色背景、浅色文字，垂直内边距较小（4px × 20px）
- 链接默认采用下划线样式，进一步强化以文本为核心的设计理念

## 2. 色彩方案与用途

### 主要颜色
- **OpenCode 深色**（`#201d1d`）：用作背景、按钮填充色及链接文字。这是一种略带红棕色调的温暖深色——rgb(32, 29, 29)。
- **OpenCode 浅色**（`#fdfcfc`）：用于深色背景上的文字及按钮文字。这是一种略带暖意的米白色，避免了纯白色的冰冷感。
- **中间灰色**（`#9a9898`）：用作次要文字及暗淡链接的颜色。这是一种介于深色与浅色之间的中性暖灰色。

### 辅助颜色
- **深色背景**（`#302c2c`）：略比主深色稍亮，用于需要突出显示的区域或实现细微区分。
- **边框灰色**（`#646262`）：用于更明显的边框以及交互元素周围的轮廓线。
- **浅色背景**（`#f1eeee`）：用于浅色模式下的背景，带有轻微的色调变化。

### 强调色
- **强调蓝**（`#007aff`）：主要强调色，用于链接及交互元素的高亮显示。采用 Apple 系统蓝色。
- **强调蓝悬停态**（`#0056b3`）：悬停时使用的更深蓝色。
- **强调蓝激活态**（`#004085`）：被点击或处于激活状态时的最深蓝色。

### 语义化颜色
- **危险红**（`#ff3b30`）：用于错误状态及具有破坏性作用的操作。采用 Apple 系统红色。
- **危险红悬停态**（`#d70015`）：悬停在危险元素上时的更深红色。
- **危险红激活态**（`#a50011`）：危险状态被点击时的最深红色。
- **成功绿**（`#30d158`）：用于成功状态及正面反馈。采用 Apple 系统绿色。
- **警告橙**（`#ff9f0a`）：用于警告状态及提醒信息。采用 Apple 系统橙色。
- **警告橙悬停态**（`#cc7f08`）：悬停在警告元素上时的更深橙色。
- **警告橙激活态**（`#995f06`）：警告状态被点击时的最深橙色。

### 文本相关颜色
- **暗淡文本**（`#6e6e73`）：用于暗淡标签、禁用文本及占位符内容。
- **次要文本**（`#424245`）：用于浅色背景上的次要文字及图注。

### 边框相关颜色
- **温暖边框**（`rgba(15, 0, 0, 0.12)`）：主要边框颜色，为带红色色调的半透明暖黑色。
- **标签边框**（`#9a9898`）：用于标签下划线的 2px 实线边框。
- **轮廓边框**（`#646262`）：用于容器周围的 1px 实线轮廓边框。

## 3. 字体规则

### 字体系列
- **首选字体**：`Berkeley Mono`，备选字体包括：`IBM Plex Mono, ui-monospace, SFMono-Regular, Menlo, Monaco, Consolas, Liberation Mono, Courier New, monospace`

### 层级结构

| 元素类型 | 字体大小 | 字重 | 行高 | 备注 |
|----------|----------|------|------|------|
| 标题 1 | 38px（2.38rem） | 700 | 1.50 | 页面标题、主标题 |
| 标题 2 | 16px（1.00rem） | 700 | 1.50 | 分节标题、强调内容 |
| 正文 | 16px（1.00rem） | 400 | 1.50 | 普通正文、段落文字 |
| 中等正文 | 16px（1.00rem） | 500 | 1.50 | 链接文字、按钮文字、导航项 |
| 紧凑正文 | 16px（1.00rem） | 500 | 1.00（紧凑） | 紧凑型标签、选项卡项 |
| 图注 | 14px（0.88rem） | 400 | 2.00（宽松） | 脚注、元数据、小型标签 |

### 设计原则
- **统一字体，统一风格**：仅使用 Berkeley Mono 字体。无论是显示文本、正文还是代码，都采用同一种单行字体风格，通过字号和字重来体现层次差异。
- **以字重体现层级**：标题使用 700 字重，交互元素或中等强调内容使用 500 字重，正文则使用 400 字重。仅通过三种字重即可构建完整的层级结构。
- **合理的行高**：标准行高为 1.50，为单行字体内的文字提供了足够的显示空间。图注则采用更宽松的 2.00 行高，以实现清晰的视觉分隔。
- **交互元素采用紧凑行高**：选项卡、紧凑型标签等交互元素采用 1.00 的行高，从而形成密集且易于点击的界面元素。

- 背景颜色与页面背景一致

### 图片处理
- 以终端或代码截图作为页面主视觉元素
- 采用深色终端风格，字体为单行字体

- 使用全宽的深色终端窗口作为主视觉元素

**功能列表**
- 以项目符号形式展示功能项，所有文字均使用 Berkeley Mono 字体
- 功能名称字重为 500，描述文字字重为 400
- 各功能项之间垂直间距较小
- 无卡片或边框设计——纯粹的文本布局

**邮箱收集表单**
- 输入框背景为浅色（`#f8f7f7`），与深色页面形成对比

- 圆角半径为 6px——是整个系统中圆角最大的元素
- 采用新闻订阅或等候列表的表单样式

## 5. 布局原则

### 间距系统
- 基础单位：8px
- 细微调整尺度：1px、2px、4px（用于边框及微调）
- 标准尺度：8px、12px、16px、20px、24px
- 扩展尺度：32px、40px、48px、64px、80px、96px
- 该系统遵循简洁的 4/8px 网格结构，且所有数值均为两倍关系

### 网格与容器
- 内容最大宽度：约 800-900px（较窄，便于阅读）
- 以单列布局为主
- 内容居中显示，两侧留有充足的水平间距
- 主视觉区域：全宽的深色终端元素
- 功能展示区域：单列文本块
- 页脚：多列链接网格

### 空白设计理念
- **单行字体的节奏感**：Berkeley Mono 的固定宽度特性形成了自然的垂直网格结构。1.50 和 2.00 的行高则保持了统一的节奏感。
- **紧凑且专注的布局**：内容被限制在狭窄的列宽内，因此两侧有较大的空白空间，使用户的注意力集中在文字上。
- **通过间距区分板块**：不使用装饰性分隔线，而是通过 48-96px 的较大垂直间距来区分不同板块，而非依靠边框或背景颜色变化。

### 圆角半径尺度
- 微型（4px）：所有元素的默认圆角半径——包括按钮、容器及徽章
- 输入框（6px）：表单输入框的圆角略大一些
- 整个系统仅使用两种圆角半径，进一步强化了实用主义的设计风格

## 6. 深度与层次感

| 层级 | 处理方式 | 用途 |
|------|----------|-----|
| 平面层（第 0 层） | 无阴影，无边框 | 大多数元素的默认状态 |
| 微妙边框层（第 1 层） | `1px solid rgba(15, 0, 0, 0.12)` | 用于分隔板块、输入框边框及水平分隔线 |
| 标签边框层（第 2 层） | 仅底部为 `2px solid #9a9898` | 用于标识当前激活的选项卡 |
| 轮廓边框层（第 3 层） | `1px solid #646262` | 用于容器轮廓及需要突出显示的元素 |**阴影设计理念**：OpenCode的深度系统刻意采用扁平化设计。提取出的标记中不存在盒影效果——未检测到任何阴影值。深度感完全通过边框处理和背景色变化来体现。这种扁平化设计与终端界面美学保持一致：终端本身没有阴影，OpenCode同样如此。三种边框样式（透明暖色调、制表符指示器、实线轮廓）足以构建清晰的视觉层次，而不会造成立体错觉。

### 装饰性深度效果
- 背景色在`#201d1d`与`#302c2c`之间切换，从而实现微妙的表面差异
- 12%透明度的透明边框可提供几乎不可见的结构感
- 边框颜色中含有的暖红色调（`rgba(15, 0, 0, 0.12)`）使边框与整体暖暗色调风格相统一
- 无渐变、无模糊效果、无环境光效果——纯粹的扁平化终端美学

## 7. 交互与动画效果

### 悬停状态
- 链接：颜色从默认值变为强调蓝色（`#007aff`），或改变下划线样式
- 按钮：背景略微变亮或边框更加突出
- 强调蓝色采用三阶段悬停过渡：`#007aff` → `#0056b3` → `#004085`（默认状态 → 悬停状态 → 活动状态）
- 危险红色：`#ff3b30` → `#d70015` → `#a50011`
- 警告橙色：`#ff9f0a` → `#cc7f08` → `#995f06`

### 受焦点状态
- 通过边框实现焦点指示：增加边框透明度或设置实线边框颜色
- 不使用基于阴影的焦点环——这与扁平化、无阴影的设计理念保持一致
- 键盘焦点通常通过轮廓效果或边框颜色变为强调蓝色来体现

### 过渡效果
- 建议使用极简的过渡效果——受终端界面启发的设计更倾向于即时状态切换
- 颜色过渡：100-150毫秒，用于提供细微的状态反馈
- 无缩放、旋转或复杂的变换动画

## 8. 响应式行为

### 分界点
| 名称 | 宽度 | 主要变化 |
|------|-------|-----------|
| 移动端 | <640px | 单列布局，内边距减小，标题尺寸缩小 |
| 平板端 | 640-1024px | 内容宽度增加，内边距略有提升 |
| 桌面端 | >1024px | 全宽内容区域（约800-900px居中显示），最大化空白空间 |

### 触控目标区域
- 宽度为4px、高度为20px的按钮可提供足够的水平触控区域
- 宽度为20px的输入框便于在移动设备上输入文字
- 宽度为16px且行高较紧的标签项可能需要针对移动端进行优化

### 布局折叠策略
- 标题区域：在较小屏幕上从38px变为28px，再变为24px
- 导航栏：在移动端由水平链接变为汉堡菜单/抽屉式导航
- 功能列表：保持单列布局，减少水平内边距
- 终端风格标题区：保持全宽，减少内部内边距
- 页脚列：多列布局变为堆叠式单列布局
- 区段间距：在移动端从96px变为64px，再变为48px

### 图片处理方式
- 终端截图会保持原有的宽高比和边框样式
- 全宽元素会按比例缩放
- 因为等宽字体特性，其在任何尺寸下都能保持可读性

### 优化迭代指南
1. 仅允许使用Berkeley Mono字体——切勿引入其他字体。通过字体大小和字重来构建所有视觉层次。
2. 保持界面扁平化：无阴影、无渐变、无模糊效果。仅使用边框和背景色变化。
3. 暖色调至关重要：请使用`#201d1d`而非`#000000`，使用`#fdfcfc`而非`#ffffff`。微妙的暖红色调虽不显眼，但不可或缺。
4. 除输入框外，所有元素的圆角均为4px（输入框为6px）。切勿使用圆形按钮或过大圆角。
5. 颜色遵循Apple HIG标准：蓝色为`#007aff`，红色为`#ff3b30`，绿色为`#30d158`，橙色为`#ff9f0a`。每种颜色都有悬停状态和活动状态的深色变体。
6. 所有语义颜色均采用三阶段交互效果：默认状态 → 悬停状态（颜色变深） → 活动状态（颜色进一步变深）。
7. 边框颜色统一使用`rgba(15, 0, 0, 0.12)`——这是一种暖色调的透明深色，而非中性灰色。这有助于将边框与整体暖色调风格相衔接。
8. 空间间距遵循8px网格系统：8px、16px、24px、32px、40px、48px、64px、80px、96px。仅在需要微调时才使用4px间距。
