## 1. 视觉主题与氛围

ClickHouse的界面采用酸黄绿色与深黑色相结合的高性能驾驶舱风格——还未阅读任何文字，这种设计就已凸显出“速度”感。整个界面都沉浸在黑暗之中：纯黑色背景（`#000000`）搭配深炭灰色卡片（边框颜色为`#414141`），营造出类似终端的视觉效果。唯一的色彩亮点便是标志性的酸黄绿色（`#faff69`），它如同荧光笔一般，出现在各种操作按钮、边框以及重点内容上，为黑暗的界面增添醒目色彩。

其字体设计极为厚重——主标题使用900号重度的Inter字体，字高达96像素，这样的文字块仿佛具有实体重量。这个“专为AI设计的数据库”网站通过强烈的视觉冲击力来展现其强大性能：粗大的字体、高对比度的霓虹色点缀，以及以超大数字形式呈现的性能指标。ClickHouse的设计毫无含蓄之处，而这正是它的意图——它完美体现了产品所承诺的极致速度与高性能。

让ClickHouse独具特色的是近乎纯黑的背景与酸黄绿色点缀之间形成的强烈对比。这种颜色组合（`#faff69`搭配`#000000`）在各类科技品牌中拥有最高的对比度，使得每一个操作按钮、每一张突出显示的卡片以及每一条强调边框都极为醒目。此外，次要操作按钮还使用了森林绿（`#166534`）颜色，它在不与霓虹色竞争的情况下，为操作层次增添了深度。

**核心特征：**
- 纯黑色背景（`#000000`）搭配酸黄绿色（`#faff69`）点缀——实现最大对比度
- 非常厚重的显示字体：900号重度的Inter字体，字高可达96像素
- 深炭灰色卡片系统，边框颜色为`#414141`，透明度为80%
- 森林绿（`#166534`）色的次要操作按钮
- 以超大数字形式呈现的性能指标
- 导航结构使用大写字母，字母间距为1.4像素
- 按钮处于活动状态或被点击时，文字颜色变为淡黄色（`#f4f692`）
- 所有链接悬停时都会变为酸黄绿色——统一的交互反馈信号
- 部分元素带有内嵌阴影，营造出“凹陷在表面之下”的深度感

## 2. 色彩方案与用途

### 主要色彩
- **霓虹伏特色**（`#faff69`）：品牌的标志性颜色——这是一种鲜艳的酸黄绿色，是黑色背景上唯一的色彩点缀。用于主要操作按钮、强调边框、链接悬停状态以及重点内容。
- **森林绿**（`#166534`）：次要操作按钮颜色——一种深沉饱和的绿色，用于“开始使用”按钮以及那些需要与霓虹色区分开来的主要操作按钮。
- **深森林色**（`#14572f`）：一种更深的绿色变体，用于边框和次要强调元素。

### 次要色彩与点缀色
- **淡黄色**（`#f4f692`）：按钮处于活动状态或被点击时的文字颜色——这是霓虹伏特色的柔和、低饱和度版本，用于状态反馈。
- **橄榄灰边框色**（`#4f5100`）：一种深橄榄黄色，用于按钮的半透明边框——可视为霓虹色的柔和版本。
- **深橄榄色**（`#161600`）：最接近霓虹色的深色调，用于细微的品牌文字。

### 背景与表面颜色
- **纯黑色**（`#000000`）：页面的主要背景色——使用绝对黑色以实现最大对比度。
- **近黑色**（`#141414`）：按钮背景以及略微凸起的深色表面。
- **炭灰色**（`#414141`）：主要边框颜色，透明度为80%——是用于包裹卡片和容器的主要颜色。
- **深炭灰色**（`#343434`）：更深的边框变体，用于绘制细微的分隔线。
- **悬停灰色**（`#3a3a3a`）：按钮悬停时的背景色——比近黑色稍亮一些。

### 中性色与文字颜色
- **纯白色**（`#ffffff`）：深色背景上的主要文字颜色。
- **银灰色**（`#a0a0a0`）：次要正文内容及低饱和度文字。
- **中灰**（`#585858`，透明度为28%）：用于营造深度效果的柔和灰色叠加层。
- **边框灰色**（`#e5e7eb`）：较浅的边框颜色（仅在极少数浅色场景中使用）。

### 渐变系统
- **不存在传统意义上的渐变**。ClickHouse采用纯色块与高对比度边框的设计。所谓的“渐变”其实就是对比度本身——酸黄绿色与纯黑色的强烈对比所营造出的视觉冲击力，是传统渐变无法替代的。

### 设计原则
- **900号字体重量是核心设计要素**：主标题使用Inter黑体（900号重量）——这种字体重量大多数网站都很少使用。再加上96像素的超大字号，使得文字具有强烈的视觉存在感，近乎建筑般的厚重感。
- **覆盖完整的字体重量范围**：该设计系统使用了400、500、600、700和900号五种字体重量，涵盖了所有可能的层次。字体重量本身就代表了层级关系。
- **大写字母搭配最大字母间距**：板块标题线采用1.4像素的字母间距——这一数值比大多数设计系统都要大——从而形成醒目的结构化标签，在深色背景上格外突出。
- **双无衬线字体组合**：Inter用于显示文字和正文；Basier则用于功能板块的标题，字体重量为600。这种搭配在“数据/性能”相关内容（使用Inter）与“产品/功能”相关内容（使用Basier）之间形成了微妙的风格差异。

## 4. 组件样式设计

### 按钮

**霓虹主按钮**
- 背景色：霓虹伏特色（`#faff69`）
- 文字颜色：近黑色（`#151515`）
- 内边距：0px 16px
- 圆角：锐角（4px）
- 边框：`1px solid #faff69`
- 悬停状态：背景色变为深色（`rgb(29, 29, 29)`），文字颜色保持不变
- 被点击状态：文字颜色变为淡黄色（`#f4f692`）
- 这是一种极具视觉冲击力的操作按钮——在黑色背景上闪耀着霓虹光芒。

**深色实心按钮**
- 背景色：近黑色（`#141414`）
- 文字颜色：纯白色（`#ffffff`）
- 内边距：12px 16px
- 圆角：4px或8px
- 边框：`1px solid #141414`
- 悬停状态：背景色变为悬停灰色（`#3a3a3a`），文字颜色透明度降低至80%
- 被点击状态：文字颜色变为淡黄色
- 这是标准的操作按钮。

**森林绿按钮**
- 背景色：森林绿（`#166534`）
- 文字颜色：纯白色（`#ffffff`）
- 内边距：12px 16px
- 边框：`1px solid #141414`
- 悬停状态：背景色与深色实心按钮相同
- 被点击状态：文字颜色变为淡黄色
- 这是“开始使用”按钮，也是主要的转化按钮。

**半透明/轮廓按钮**
- 背景色：透明
- 文字颜色：纯白色（`#ffffff`）
- 内边距：0px 32px
- 圆角：4px
- 边框：`1px solid #4f5100`（橄榄色调）
- 悬停状态：背景色变为深色
- 被点击状态：文字颜色变为淡黄色
- 这是一种带有霓虹色调边框的次要操作按钮。

**药丸形切换按钮**
- 背景色：透明
- 圆角：药丸形（9999px）
- 用于实现切换/开关功能。

### 卡片与容器
- 背景色：透明或近黑色
- 边框：`1px solid rgba(65, 65, 65, 0.8)`——即标志性的炭灰色边框
- 圆角：小元素为4px，卡片和容器为8px
- 阴影效果1：柔和阴影（`rgba(0,0,0,0.1) 0px 1px 3px, rgba(0,0,0,0.1) 0px 1px 2px -1px`）
- 阴影效果2：中等阴影（`rgba(0,0,0,0.1) 0px 10px 15px -3px, rgba(0,0,0,0.1) 0px 4px 6px -4px`）
- 阴影效果3：内嵌阴影（`rgba(0,0,0,0.06) 0px 4px 4px, rgba(0,0,0,0.14) 0px 4px 25px inset`）——即“凹陷”效果
- 霓虹高亮卡片：被选中或处于活动状态的卡片会带有酸黄绿色的边框或强调色。

### 导航栏
- 在黑色背景上的深色导航栏
- 标识：ClickHouse品牌标识加上黄色/霓虹色的图标
- 链接文字：白色，悬停时变为霓虹伏特色（`#faff69`）
- 操作按钮：霓虹伏特色按钮或森林绿按钮
- 分类标签使用大写字母

### 特色组件

**性能指标**
- 超大数字显示（72像素以上，字体重量为700–900）
- 下方附有简短描述
- 关键指标配有高对比度的霓虹色点缀
- 这是展示产品性能优势的最直观视觉元素。

**霓虹高亮卡片**
- 标准的深色卡片，带有酸黄绿色的边框高亮
- 用于突出显示“已选中”或“特色”内容
- 这种强调边框让卡片在黑暗背景中更加醒目。

**代码块**
- 深色背景，使用600号重度的Inconsolata字体
- 采用霓虹色与白色相结合的代码高亮效果
- 具有类似终端的视觉风格。

**信任标识栏**
- 深色背景上排列着公司标志
- 标志以单色或白色呈现
- 水平布局。

## 5. 布局原则

### 空间系统
- 基础单位：8像素
- 缩放比例：2px、6px、7px、8px、10px、12px、16px、20px、24px、25px、32px、40px、44px、48px、64px
- 按钮内边距：标准值为12px 16px，紧凑型为0px 16px，宽型半透明按钮为0px 32px
- 各板块的垂直间距：较大（48–64像素）

### 网格与容器
- 容器最大宽度：可达2200像素（超宽布局），并具备响应式缩放功能
- 主标题区域：全宽深色背景，搭配超大字体
- 功能板块：多列卡片网格，带有深色边框
- 性能指标区域：横向的指标条
- 整个页面均为深色风格——没有浅色区块。

### 空白设计理念
- **将黑暗空间视为画布**：纯黑色背景提供了无限的深度感——各种元素仿佛悬浮在黑暗之中。
- **密集的信息呈现**：功能卡片和性能指标都包含大量数据，体现了这款数据库产品注重性能的特点。
- **霓虹色高亮作为导航指引**：酸黄绿色的点缀如同跑道灯一般，引导用户在黑暗的界面中找到所需内容。

### 圆角尺寸比例表- 锋利型（4px）：按钮、徽章、小型元素、代码块  
- 舒适型（8px）：卡片、容器、分隔线  
- 粒子型（9999px）：切换按钮、状态指示器  

## 6. 深度与层次感

| 级别 | 处理方式 | 适用场景 |
|------|----------|----------|
| 平面型（第0级） | 无阴影 | 黑色背景、文本块 |
| 边框型（第1级） | `1px solid rgba(65,65,65,0.8)` | 标准卡片、容器 |
| 微妙型（第2级） | `0px 1px 3px rgba(0,0,0,0.1)` | 轻微的卡片凸起效果 |
| 提升型（第3级） | `0px 10px 15px -3px rgba(0,0,0,0.1)` | 功能卡片、悬停状态 |
| 按压/内陷型（第4级） | `0px 4px 25px rgba(0,0,0,0.14) inset` | 活动/被按压的元素——呈现“陷入表面”的效果 |
| 霓虹高亮型（第5级） | 霓虹伏特色边框（`#faff69`） | 突出显示的卡片、需重点强调的内容 |

**阴影设计理念**：ClickHouse在黑色背景上使用几乎不可见的阴影，其作用更多是营造微妙的层次感，而非明显的凸起效果。最独特的深度表现方式是**内陷阴影**（第4级），它能带来ClickHouse独有的“陷入表面”的视觉效果。而霓虹色边框高亮（第5级）则是主要的视觉焦点强化手段。

## 7. 正确做法与禁忌

### 正确做法
- 仅使用霓虹伏特色（#faff69）作为唯一色彩点缀——它在纯黑色背景下能形成鲜明对比  
- 使用Inter字体900号重量来展示主标题——极高的字体重量正是其独特风格的核心  
- 所有元素均使用纯黑色（#000000）背景——切勿使用深灰色作为页面背景  
- 所有卡片边框均采用炭黑色（rgba(65,65,65,0.8)）  
- 主要操作按钮使用森林绿（#166534）——与霓虹色区分开来，以体现操作层级差异  
- 用超大号数字展示性能数据——这是最核心的视觉表达方式  
- 章节标题使用大写字母，并设置1.4px的宽字母间距  
- 活动/被按压状态的文本使用淡黄色（#f4f692）  
- 链接悬停时务必变为霓虹伏特色——保持统一的交互反馈  

### 禁忌事项
- 不要添加其他颜色——配色方案严格限定为黑色、霓虹色、绿色和灰色  
- 不要将霓虹色用作背景填充色——它仅可用于点缀和边框（操作按钮除外）  
- 字体重量不得低于700——较高的字体重量是该设计风格的核心特征  
- 任何地方都不要使用浅色或白色背景——整个界面均为深色主题  
- 圆角半径不得超过8px——锐利的几何形状体现了数据库的精准性  
- 不要在黑色背景上使用柔和/模糊的阴影——这类阴影几乎不可见，应改用边框来营造深度感  
- 活动状态切勿省略内陷阴影——“被按压”的效果是其独特之处  
- 不要使用暖色调的中性色——所有灰色均已属于完美中性色  

## 8. 响应式设计

### 分界点
| 名称 | 宽度 | 主要变化 |
|------|------|----------|
| 移动端 | <640px | 单列布局，卡片堆叠显示 |
| 小型平板 | 640–768px | 轻微调整 |
| 平板端 | 768–1024px | 双列网格布局 |
| 桌面端 | 1024–1280px | 标准布局 |
| 大型桌面端 | 1280–1536px | 内容扩展显示 |
| 超宽屏 | 1536–2200px | 最大容器宽度 |

### 触控区域
- 按钮最小内边距为12px×16px  
- 卡片表面可作为触控区域  
- 导航链接之间需保持足够间距  

### 布局折叠策略
- **主标题**：96px → 72px → 48px → 36px  
- **功能网格**：多列布局 → 2列 → 1列  
- **数据统计**：水平排列 → 堆叠显示  
- **导航栏**：完整显示 → 汉堡菜单  

### 图片处理方式
- 产品截图保持原始宽高比  
- 在窄屏幕上，代码块需支持水平滚动  
- 所有图片均置于黑色背景上

- 活动状态颜色：“淡黄色（#f4f692）”  
- 按钮表面颜色：“接近黑色（#141414）”  

### 组件提示词示例
- “在纯黑色（#000000）背景上创建一个主标题区域，标题字体为Inter 900号重量，大小为96px，行高为1.0，文本颜色为纯白色。添加一个霓虹伏特色（#faff69）的操作按钮（文字为深色，圆角4px，内边距0px×16px），以及一个透明背景、带1px厚#4f5100边框的“虚线”按钮。”  
- “设计一张黑色背景的卡片，边框为1px厚的rgba(65,65,65,0.8)色，圆角为8px。标题字体为Inter 700号重量，大小为24px；正文字体为Inter 700号重量，大小为16px，颜色为银色（#a0a0a0）。再添加一个带有1px厚霓虹伏特色边框的高亮版本。”  
- “创建一个性能数据栏：主要数值使用Inter 700号重量，大小为72px，颜色为纯白色；简要描述文字使用Inter 700号重量，大小为14px，颜色为银色。所有元素均置于黑色背景上。”  
- “设计一个森林绿（#166534）色的操作按钮：文字为白色，内边距12px×16px，圆角4px，边框为1px厚的#141414色。悬停时，背景色变为#3a3a39，文字透明度降低至80%。”  
- “设计一个大写字母的章节标题：字体为Inter 600号重量，大小为14px，字母间距为1.4px，全部为大写形式。文本颜色为银色（#a0a0a0），背景为黑色。”  

### 修改指南
1. 所有元素必须保持纯黑色背景——不可使用深灰色替代  
2. 霓虹伏特色（#faff69）仅用于点缀和操作按钮——严禁用作大面积背景色  
3. 主标题字体重量为900，标题为700，标签为600，正文为400-500  
4. 活动状态需使用淡黄色（#f4f692）——而不仅仅是调整透明度  
5. 所有链接悬停时均变为霓虹伏特色——保持一致的交互反馈  
6. 炭黑色边框（rgba(65,65,65,0.8)）是主要的深度表现手段
