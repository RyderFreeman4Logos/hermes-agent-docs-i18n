## 1. 视觉主题与氛围

Sentry 的网站采用深色模式作为主导的开发者工具界面，其设计语言与代码编辑器和终端窗口高度契合。整个界面以深紫黑色背景（`#1f1633`、`#150f23`）为基调，让人联想到 Sentry 所服务的那些深夜调试场景。在这片深色背景之上，精心挑选的紫色、粉色系列色彩以及独特的青绿色点缀（`#c2ef4e`）共同构成了一个既充满技术感又富有活力的视觉系统。

字体搭配经过精心设计：“Dammit Sans”以88像素、700号字重的超大尺寸作为展示字体，其独特的风格与态度完美契合Sentry那不拘一格的品牌理念（“代码出错？更快修复它！”）。而Rubik则被用作所有功能性文本的通用界面字体，涵盖标题、正文、按钮、说明文字以及导航元素。Monaco则为代码片段和技术内容提供了等宽字体支持，从而构成了开发者工具领域的三大核心字体。

Sentry的独特之处在于它采用了“深色IDE”设计风格，却丝毫不会显得冰冷或单调。温暖的紫色色调取代了传统开发者工具中常见的冷灰色，同时大胆的插图元素（3D角色、色彩鲜明的产品截图）为这深色背景增添了活力。按钮系统则采用了标志性的暗紫色（`#79628c`），并搭配内嵌阴影效果，营造出一种具有触感、仿佛真实可触的视觉体验——这些按钮给人的感觉就像真的可以按进表面一样。

**主要特点：**
- 深紫黑色背景（`#1f1633`、`#150f23`）——绝非纯黑色  
- 温暖紫色系：从深色（`#362d59`）到中间色调（`#79628c`、`#6a5fc1`），再到明亮色调（`#422082`）  
- 青绿色作为强调色（`#c2ef4e`），用于提升关键操作按钮及重点内容的可见度  
- 粉色/珊瑚色作为辅助强调色（`#ffb287`、`#fa7faa`），用于表示焦点状态及次要高亮区域  
- 使用“Dammit Sans”字体在主视觉区域展现品牌特色  
- 以Rubik字体作为主要界面文字，标签采用大写且字母间有适当间距  
- 代码部分使用Monaco等等宽字体  
- 按钮上添加内嵌阴影，以营造触感上的深度效果  
- 通过`blur(18px) saturate(180%)`效果实现磨砂玻璃质感  

## 2. 颜色方案与用途  

### 主品牌颜色  
- **深紫色**（`#1f1633`）：主要背景色，也是该品牌的标志性色彩  
- **更深的紫色**（`#150f23`）：较暗区域、页脚及次要背景使用  
- **边框紫色**（`#362d59`）：用于边框、分隔线以及细微的结构线条  

### 强调色  
- **Sentry紫色**（`#6a5fc1`）：主要交互颜色——用于链接、悬停状态及焦点环  
- **柔和紫色**（`#79628c`）：按钮背景及次要交互元素的颜色  
- **深紫罗兰色**（`#422082`）：下拉菜单选项、活动状态及需要重点突出的区域  
- **青绿色**（`#c2ef4e`）：高可见度强调色，用于特殊链接及徽章的高亮部分  
- **珊瑚色**（`#ffb287`）：焦点状态背景及暖色调强调色  
- **粉色**（`#fa7faa`）：焦点轮廓线及装饰性强调元素  

### 文本颜色
- **纯白色**（`#ffffff`）：深色背景上的主文本颜色  
- **浅灰色**（`#e5e7eb`）：辅助文本及色调较淡的内容  
- **代码黄**（`#dcdcaa`）：语法高亮与代码标识符的颜色  

### 表面与叠加层
- **玻璃白**（`rgba(255, 255, 255, 0.18)`)：磨砂玻璃风格按钮背景  
- **玻璃深色**（`rgba(54, 22, 107, 0.14)`）：玻璃元素上的悬停叠加层  
- **输入框白色**（`#ffffff`）：表单输入框背景（浅色场景）  
- **输入框边框**（`#cfcfdb`）：表单字段的边框颜色  

### 阴影效果
- **环境光晕阴影**（`rgba(22, 15, 36, 0.9) 0px 4px 4px 9px`）：深紫色环境光晕阴影  
- **按钮悬停效果**（`rgba(0, 0, 0, 0.18) 0px 0.5rem 1.5rem`）：按钮悬停时的凸起效果  
- **卡片阴影**（`rgba(0, 0, 0, 0.1) 0px 10px 15px -3px`）：标准卡片凸起阴影  
- **内嵌按钮阴影**（`rgba(0, 0, 0, 0.1) 0px 1px 3px 0px inset`）：模拟按下时的触感效果  

## 3. 字体规范

### 字体系列
- **展示字体**：`Dammit Sans`——用于标题的体现品牌特色的字体  
- **主要用户界面字体**：`Rubik`，备用字体包括：`-apple-system, system-ui, Segoe UI, Helvetica, Arial`  
- **等宽字体**：`Monaco`，备用字体包括：`Menlo, Ubuntu Mono`

### 设计原则
- **双重风格定位**：Dammit Sans为界面带来充满个性的非传统品牌气质；Rubik则为所有功能元素提供简洁专业的视觉呈现。
- **统一大写格式**：按钮、标题、标签及微文本均采用`text-transform: uppercase`格式，并设置0.2px–0.25px的适度字距，从而在整个界面中形成统一的“技术标签”风格。
- **字体粗细分层**：Rubik字体采用400（正文）、500（强调/导航文字）、600（标题/强调文字）、700（按钮/行动号召文字）的四级粗细体系，结构清晰。
- **标题紧凑，正文宽松**：所有标题的行高为1.10–1.25；正文行高为1.50；在极小尺寸显示时，小标题的行高会调整为2.00，以确保可读性。

## 4. 组件样式设计

### 按钮样式

**主色调：淡紫色**
- 背景色：`#79628c`（rgb(121, 98, 140)）
- 文字颜色：`#ffffff`，大写，14像素，字体粗细为500–700，字距为0.2px
- 边框：`1px solid #584674`
- 圆角半径：13px
- 阴影效果：`rgba(0, 0, 0, 0.1) 0px 1px 3px 0px inset`（具有触感的内阴影）
- 悬停状态：阴影加深为`rgba(0, 0, 0, 0.18) 0px 0.5rem 1.5rem`

**玻璃态白色**
- 背景色：`rgba(255, 255, 255, 0.18)`（磨砂玻璃效果）
- 文字颜色：`#ffffff`
- 内边距：8px
- 圆角半径：12px（左对齐版本为`12px 0px 0px 12px`）
- 阴影效果：`rgba(0, 0, 0, 0.08) 0px 2px 8px`
- 悬停时背景色变为：`rgba(54, 22, 107, 0.14)`
- 适用场景：在深色背景上作为次要操作按钮使用

**纯白色实心按钮**
- 背景色：`#ffffff`
- 文字颜色：`#1f1633`
- 内边距：12px 16px
- 圆角：8px
- 鼠标悬停时：背景色变为 `#6a5fc1`，文字颜色变为白色
- 聚焦状态时：背景色为 `#ffb287`（珊瑚色），边框为 `rgb(106, 95, 193)`，宽度为 0.125rem
- 用途：在深色背景下用于突出显示操作提示

**深紫色（选项/下拉菜单）**
- 背景色：`#422082`
- 文字颜色：`#ffffff`
- 内边距：8px 16px
- 圆角：8px

### 输入框

**文本输入框**
- 背景色：`#ffffff`
- 文字颜色：`#1f1633`
- 边框：`1px solid #cfcfdb`
- 内边距：8px 12px
- 圆角：6px
- 聚焦状态时：边框颜色保持为 `#cfcfdb`，阴影为 `rgba(0, 0, 0, 0.15) 0px 2px 10px inset`

### 链接
- **深色背景下的默认样式**：文字颜色为 `#ffffff`，带有下划线装饰
- **鼠标悬停时**：颜色变为 `#6a5fc1`（Sentry 紫色）
- **紫色链接**：默认颜色为 `#6a5fc1`，悬停时显示下划线
- **青绿色强调链接**：默认颜色为 `#c2ef4e`，悬停时变为 `#6a5fc1`
- **深色背景中的链接**：默认颜色为 `#362d59`，悬停时变为 `#ffffff`

### 卡片与容器
- 背景色：半透明或深紫色
- 圆角：8px–12px
- 阴影：`rgba(0, 0, 0, 0.1) 0px 10px 15px -3px`
- 为呈现玻璃态效果，还会应用背景模糊滤镜 `blur(18px) saturate(180%)`

### 导航栏
- 在主要内容上方设置深色透明标题栏
- 导航链接使用 Rubik 字体，字重为 15px，字体系列为 500
- 文字颜色为白色，鼠标悬停时变为 Sentry 紫色（`#6a5fc1`）
- 分类标签为大写形式，字母间距为 0.2px
- 移动端：显示汉堡菜单，展开后占据全屏宽度

## 5. 布局原则

### 缩放系统
- 基础单位：8px
- 可用缩放值：1px、2px、4px、5px、6px、8px、12px、16px、24px、32px、40px、44px、45px、47px

### 网格与容器
- 内容最大宽度：1152像素（XL断点）
- 响应式内边距：手机端为2rem → 平板及以上设备为4rem
- 内容在容器中居中显示
- 全宽深色区域，内部内容保持紧凑布局

### 断点设置
| 名称 | 宽度 | 主要变化 |
|------|------|----------|
| 手机端 | < 576px | 单列堆叠式布局 |
| 小型平板 | 576–640px | 稍微调整宽度 |
| 平板端 | 640–768px | 开始采用双列布局 |
| 小型桌面端 | 768–992px | 完整导航栏可见 |
| 桌面端 | 992–1152px | 标准布局 |
| 大型桌面端 | 1152–1440px | 内容限制在最大宽度内 |

### 空白设计理念
- **深色区域中的呼吸空间**：各板块之间保留充足的垂直间距（64px–80px+），让深色背景起到视觉休憩的作用。
- **内容岛屿**：特色板块作为独立区块悬浮在深紫色背景中，每个板块都有其独特的内部间距节奏。
- **不对称内边距**：按钮采用不对称的内边距设计（12px 16px、8px 12px），显得更为自然而非生硬。

### 圆角尺寸规范
- 最小值（6px）：表单输入框、小型交互元素
- 标准值（8px）：按钮、卡片、容器
- 舒适值（10px–12px)：较大尺寸的容器、玻璃态面板
- 圆润值（13px）：主色调的柔和风格按钮
- 矩形值（18px）：图片容器、徽章

## 6. 深度与层次感设计

| 级别 | 阴影效果 | 使用场景 |
|-------|-----------|----------|
| 下沉式（级别 -1） | 内嵌阴影 `rgba(0, 0, 0, 0.1) 0px 1px 3px inset` | 主要按钮（提供逼真的按压感） |
| 平面式（级别 0） | 无阴影 | 默认界面元素、深色背景 |
| 表面式（级别 1） | `rgba(0, 0, 0, 0.08) 0px 2px 8px` | 玻璃质感按钮、简约卡片 |
| 升起式（级别 2） | `rgba(0, 0, 0, 0.1) 0px 10px 15px -3px` | 卡片、悬浮面板 |
| 突出式（级别 3） | `rgba(0, 0, 0, 0.18) 0px 0.5rem 1.5rem` | 悬停状态、模态框 |
| 环境光式（级别 4） | `rgba(22, 15, 36, 0.9) 0px 4px 4px 9px` | 主要内容区域周围的深紫色环境光 |

**阴影设计理念**：Sentry采用了独特的阴影组合——内嵌阴影让按钮仿佛被按入表面，而环境光效果则使内容从深色背景中透出光芒。那道深紫色的环境光阴影（`rgba(22, 15, 36, 0.9)`）正是其标志性特征，它营造出一种生物发光般的视觉效果，让内容仿佛自身能散发紫色光芒。

## 7. 正确做法与禁忌

### 应该这样做
- 请使用深紫色背景色（`#1f1633`、`#150f23`），切勿使用纯黑色（`#000000`）
- 为主按钮添加内嵌阴影，以营造按下时的触感效果
- 仅将 Dammit Sans 用于标题区域，其他所有元素均需使用 Rubik 字体
- 为按钮和标签应用 `text-transform: uppercase` 及 `letter-spacing: 0.2px` 样式
- 尽量少用青绿色点缀色（`#c2ef4e`），以获得最佳视觉效果
- 对多层界面元素使用磨砂玻璃效果（`blur(18px) saturate(180%)`）
- 保持温暖的紫色阴影色调——阴影应带有紫色调，而非中性灰色
- 遵循 Rubik 的四级字体粗细规范：400（正文）、500（导航/强调文本）、600（标题）、700（行动号召按钮）

### 不建议这样做
- 背景色切勿使用纯黑色（`#000000`），应始终选择带有紫色调的黑色
- Dammit Sans 仅适用于标题展示，不可用于正文或其他 UI 元素
- 边框颜色不要使用标准灰色（`#666`、`#999`），而应选用带紫色调的灰色（`#362d59`、`#584674`）
- 按钮必须保持大写格式，这是全系统的统一规范
- 所有交互式元素的圆角半径不得为 0px，最小值应为 6px
- 同一个组件中不可同时使用青绿色与珊瑚色/粉色作为点缀色
- 主按钮严禁使用平直阴影（无内嵌效果），触感体验是其核心特点
- 大写文本务必设置字距，最小值为 0.2px

## 8. 响应式设计行为

### 分界点
| 名称 | 宽度 | 主要变化 |
|------|-------|-------------|
| 手机端 | <576px | 单列布局、汉堡菜单导航、堆叠式操作按钮 |
| 平板端 | 576–768px | 开始采用双列功能网格布局 |
| 小型桌面端 | 768–992px | 完整导航栏、并排布局 |
| 桌面端 | 992–1152px | 最大宽度容器、完整布局 |
| 大屏幕端 | >1152px | 内容保持最大宽度，留出充足边距 |

### 布局折叠策略
- 标题文字：88px的Dammit Sans字体 → 60px → 手机端进一步缩小
- 导航栏：水平布局 → 汉堡菜单+滑动显示内容
- 功能板块：并排布局 → 堆叠式卡片展示
- 按钮：内联样式 → 手机端变为全宽堆叠布局
- 容器内边距：4rem → 2rem
