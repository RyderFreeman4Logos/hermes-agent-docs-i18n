## 1. 视觉主题与氛围

IBM 的网站是基于 Carbon 设计系统构建的企业权威数字化体现——这种设计语言结构极为严谨，宛如工程规范以网页形式呈现。整个页面呈现出鲜明的二元对比：以纯白色（`#ffffff`）作为背景，文字颜色接近黑色（`#161616`），唯一不变的强调色则是 IBM 蓝 60（`#0f62fe`）。这并非那种追求极简风格的科技初创公司设计，而是将企业精准度转化为像素级的视觉表达。每一个元素都遵循 Carbon 系统严格的 2x 网格布局，每种颜色都有其特定的语义含义，所有间距值也都严格对齐到 8px 的基准单位。

IBM Plex 字体系列是该系统的核心。用于显示标题的浅色款（300）在较大尺寸下能呈现出出人意料地轻盈、近乎精致的视觉效果，这与 IBM 的企业厚重感形成巧妙对比。而在正文区域，常规款（400）搭配 14px 字号及 0.16px 的字距，通过精细的微调整让 Carbon 字体看起来更像是经过工程设计而非单纯设计而成。IBM Plex Mono 则用于显示代码、数据和技术标签，与较少使用的 IBM Plex Serif 一起构成完整的字体家族。

除黑白加蓝色之外，定义 IBM 视觉身份的另一个关键要素便是对 Carbon 组件标记系统的依赖。每种交互状态都对应一个以 `--cds-`（Carbon Design System）为前缀的 CSS 自定义属性。按钮并非使用固定颜色，而是引用 `--cds-button-primary`、`--cds-button-primary-hover`、`--cds-button-primary-active` 等属性。这种基于标记的系统架构意味着整个视觉层只是建立在高度系统化基础之上的薄层封装——在设计领域就如同结构严谨的 API 一样。

**主要特征：**
- 显示用字体为 IBM Plex Sans 300（浅色款），通过严谨的排版体现企业厚重感
- 代码及技术内容使用 IBM Plex Mono，小尺寸时保持统一的 0.16px 字距
- 唯一强调色为 IBM 蓝 60（`#0f62fe`），适用于所有交互元素、操作按钮及链接
- 所有语义颜色均由 Carbon 标记系统（`--cds-*`）驱动，支持在变量层面切换主题
- 严格遵循 8px 间距网格，无任意数值，所有元素都对齐
- 卡片采用 `#f4f4f4`（灰色 10）的纯平设计，无边框——通过背景色叠加而非阴影营造深度感
- 输入框位于底部边框位置（非方框式），这是 Carbon 表单的典型设计风格
- 主要按钮的圆角为 0px，保持纯粹的矩形外观，无柔和处理

## 2. 颜色方案与用途

- **IBM 蓝 60**（`#0f62fe`）：唯一的交互用颜色，用于主要按钮、链接、焦点状态及激活指示器。这是核心用户界面颜色方案中唯一的色彩。

### 设计原则
- **显示尺寸使用浅色字重**：Carbon 的表现力强的字体系列在 42px 及以上尺寸时使用 300（浅色款）字重。这种设计营造出独特的张力——内容以企业般的严谨感呈现，同时字体形态又展现出轻盈的排版风格。
- **小尺寸下采用微调整**：14px 字号时字距为 0.16px，12px 字号时为 0.32px。这些看似微不足道的数值其实是 Carbon 在紧凑尺寸下提升可读性的关键所在——它们恰到好处地让 IBM Plex 字形略显宽松。
- **三种功能字重**：300（用于显示/表现性内容）、400（用于正文/阅读内容）、600（用于强调/界面标签）。刻意没有在正式使用中加入 700 字重。
- **实用型与表现型字体系列**：实用型字体系列采用更紧密的行高（1.29），适用于信息密集的 UI；而表现型字体系列则拥有更大的行高（1.40-1.50），更适合营销及编辑类内容。

## 5. 布局原则

### 空间系统
- 基本单位：8px（Carbon的2x网格系统）
- 组件间距等级：2px、4px、8px、12px、16px、24px、32px、40px、48px
- 页面布局间距等级：16px、24px、32px、48px、64px、80px、96px、160px
- 最小单位：8px（最小的可用间距）
- 组件内部内边距：通常为16px
- 卡片/元素之间的间隔：1px（极细间隔）或16px（标准间隔）

### 网格与容器
- 16列网格系统（Carbon的2x网格体系）
- 内容最大宽度：1584px（最大断点宽度）
- 列间距：32px（移动端为16px）
- 外边距：移动端为16px，平板及以上设备为32px
- 为保证行长度适中，内容通常占据8至12列
- 全屏内容区域与有限内容区域交替出现

### 空白设计理念
- **功能密度优先**：Carbon更注重高效的信息密度，而非大量的空白空间。与面向消费者的设计系统相比，其页面元素更为紧凑——这体现了IBM的企业风格。
- **背景色分区**：IBM不使用大块空白来分隔内容，而是通过交替使用不同深浅的背景色（白色→浅灰10→白色），以最少的垂直空间实现视觉区分。
- **统一的48px间距节奏**：主要内容区块之间的过渡通常采用48px的垂直间距。主标题区域则可能使用80px–96px的间距。

### 圆角尺寸规范
- **0px**：主按钮、输入框、卡片式元素——这是该设计系统中最常见的圆角处理方式。Carbon的设计本质上是矩形风格。
- **2px**：偶尔用于小型交互元素（如标签）
- **24px**：标签/标识（药丸形——唯一采用圆角的例外）
- **50%**：头像圆形区域、图标容器

| 第一层（Layer 01） | 无阴影，背景色为`#f4f4f4` | 卡片、元素区块及交替排列的内容区域 |
| 第二层（Layer 02） | 无阴影，背景色为`#e0e0e0` | 位于第一层内的突出面板 |
| 浮起层 | `0 2px 6px rgba(0,0,0,0.3)`的阴影效果 | 下拉菜单、工具提示、溢出菜单 |
| 叠加层 | `0 2px 6px rgba(0,0,0,0.3)`的阴影 + 深色遮罩 | 弹出对话框、侧边面板 |
| 获得焦点状态 | 内部有`2px solid #0f62fe`的阴影环，外加`1px solid #ffffff`的边框 | 键盘焦点指示环 |
| 底部边框 | 下边缘有`2px solid #161616`的实线 | 活动中的输入框、当前选中标签的指示 |

**阴影设计理念**：Carbon刻意避免使用阴影效果。IBM主要通过背景色层次来营造深度——通过叠加逐渐变深的灰色背景，而非添加盒影。这种设计风格呈现出扁平化、类似打印文档的视觉效果，层次感通过颜色深浅来体现，而非模拟光线效果。阴影仅用于那些真正覆盖在内容之上的浮动元素（如下拉菜单、工具提示、模态框）。这种克制使得偶尔出现的阴影更具影响力——在Carbon中，当某个元素浮出时，它确实会显得格外重要。

## 7. 应该做与不应该做的事

### 应该做的
- 对于42px及以上的显示文字，使用IBM Plex Sans字重300——这种较轻的字重是刻意设计的
- 14px的正文文字设置0.16px的字距，12px的标题文字设置0.32px的字距
- 按钮、输入框、卡片和元素区块均使用0px圆角——矩形是该设计系统的核心形态
- 在实现相关功能时，使用`--cds-*`前缀的标识符（如`--cds-button-primary`、`--cds-text-primary`）
- 通过背景色层次（白色→浅灰10→灰20）来营造深度，而非依赖阴影
- 对于输入框的焦点指示，使用底部边框而非完整边框
- 保持按钮默认高度为48px，并采用非对称内边距以容纳图标
- 仅使用蓝60颜色（`#0f62fe`）作为唯一强调色——统一使用一种蓝色即可

### 不应该做的
- 不要给按钮添加圆角——0px圆角是Carbon设计系统的核心特征
- 不要在卡片或元素区块上使用阴影——扁平化正是其设计目标
- 不要引入额外的强调颜色——IBM的设计系统以单色系加蓝色为主
- 不要使用字重700（粗体）——该系统最大的字重为600（半粗体）
- 不要对显示文字添加字距——字距调整仅适用于14px及更小的字体大小
- 不要用完整边框包裹输入框——Carbon的输入框仅使用底部边框
- 不要使用渐变背景——IBM的设计元素均为纯色、扁平设计
- 不要偏离8px的间距网格——所有数值都应能被8整除，微调时可使用2px和4px

## 8. 响应式行为

### 断点设置
| 名称 | 宽度 | 主要变化 |
|------|------|----------|
| 小屏幕（sm） | 320px | 单列布局，汉堡菜单导航，外边距为16px |
| 中等屏幕（md） | 672px | 开始出现2列网格，内容区域扩大 |
| 大屏幕（lg） | 1056px | 完整的导航栏可见，网格变为3-4列 |
| 超大屏幕（xlg） | 1312px | 内容密度最高，布局更加宽大 |
| 最大宽度 | 1584px | 内容最大宽度，居中显示并带有外边距 |

### 触控目标区域大小
- 按钮默认高度为48px，最小高度为40px（紧凑版）
- 导航链接的行高为48px，便于触摸操作
- 输入框默认高度为40px，大号版本为48px
- 图标按钮的触控目标区域为48px×48px的正方形
- 移动端菜单项为全宽48px高的行

### 布局折叠策略
- 主标题区域：随着屏幕变窄，标题显示字体大小从60px逐渐变为42px，再变为32px
- 导航栏：从完整水平页眉变为汉堡菜单，搭配滑出式面板
- 网格布局：从4列变为2列，最终变为单列
- 卡片/元素区块：从水平排列变为垂直堆叠
- 图片：保持宽高比，最大宽度为100%
- 页脚：多列链接组变为单列堆叠布局
- 各内容区块的内边距：从48px逐渐变为32px，再变为16px

### 图片处理方式
- 响应式图片，设置`max-width: 100%`
- 产品插图会按比例缩放
- 主标题区域的图片可能会从并排显示变为下方堆叠显示
- 数据可视化图表在移动端会保持宽高比，并可通过水平滚动查看

### 修改优化指南
1. 按钮、输入框和卡片始终必须使用0px圆角——这是Carbon设计系统的基本要求，不可违背。
2. 字距调整仅适用于较小字体大小：14px时为0.16px，12px时为0.32px——显示文字绝不能调整字距。
3. 字体仅有三种字重：300（显示用）、400（正文用）、600（强调用）——系统中没有粗体字体。
4. 蓝60是唯一的强调颜色——不得引入其他辅助强调色。
5. 深度感通过背景色层次（白色→浅灰10→灰100）来体现，而非依靠阴影。
6. 输入框仅使用底部边框，绝不能被完整包裹在边框中。
7. 在编写提示词时，请使用`--cds-`前缀作为标识符，以确保与Carbon设计系统兼容。
8. 48px是所有交互式元素的统一高度标准。
