## 1. 视觉主题与氛围

Supabase 的网站是一个专为深色模式设计的开发者平台，其美学风格借鉴了高端代码编辑器的设计理念——深黑色背景（`#0f0f0f`、`#171717`），辅以翠绿色点缀（`#3ecf8e`、`#00c573`），这些色彩均源自该品牌所代表的开源文化以及 PostgreSQL 的绿色标识。整个设计系统仿佛诞生于终端窗口，而后逐渐演变为一种精致的营销界面，却依然保留着开发者专属的特质。

其字体选择为 “Circular”——一种具有圆润端点的几何无衬线字体，这种设计弱化了技术的生硬感。标题文字的字体大小为 72px，行高为 1.00，通过极致压缩垂直空间，呈现出紧凑且富有冲击力的排版风格，毫不浪费任何空间。等宽字体 “Source Code Pro” 则被少量用于大写的技术标签，字母间距为 1.2px，从而营造出类似“开发者控制台”的视觉效果，将营销页面与产品体验紧密相连。

Supabase 的独特之处在于它成熟的基于 HSL 的颜色系统。与单纯的十六进制颜色值不同，Supabase 几乎为所有颜色都使用了带有透明度通道的 HSL 格式（如 `--colors-crimson4`、`--colors-purple5`、`--colors-slateA12`），这使得颜色之间可以通过透明度实现细腻的层次叠加。通过半透明效果营造出深度感——边框使用 `rgba(46, 46, 46)`，表面层使用 `rgba(41, 41, 41, 0.84)`，而各种点缀色则通过不同的透明度与深色背景融为一体，仅用有限的色彩便打造出丰富且具有立体感的配色方案。

翠绿色点缀色（`#3ecf8e`）被精心地运用在多个地方——Supabase 徽标、链接颜色（`#00c573`）以及边框高亮处（`rgba(62, 207, 142, 0.3)`），始终起到标识“这是 Supabase”的作用，而非单纯的装饰元素。用于主要操作按钮的圆角按钮半径为 9999px，而次要元素的半径则为 6px，这种明显的尺寸差异构成了清晰的视觉层次结构。

**核心特征：**
- 专为深色模式设计：背景接近纯黑（`#0f0f0f`、`#171717`），绝非纯黑色
- 翠绿色作为品牌标识，少量使用以强化品牌认知（`#3ecf8e`、`#00c573`）
- Circular 字体——具有圆润端点的几何无衬线字体
- 大写技术标签使用 Source Code Pro 字体，字母间距为 1.2px
- 基于 HSL 的颜色系统，配合透明度通道实现层次叠加效果
- 主要操作按钮采用半径为 9999px 的圆角设计，次要按钮半径为 6px
- 中性灰度序列，从 `#171717` 到 `#898989` 再到 `#fafafa`
- 边框颜色使用深灰色系（`#2e2e2e`、`#363636`、`#393939`）
- 几乎不使用阴影效果——依靠边框对比度和透明度营造深度感
- 使用 Radix 颜色原色体系（深红、紫色、紫罗兰、靛蓝、黄色、番茄红、橙色、石板灰）

## 2. 配色方案与用途

### 品牌颜色
- **Supabase 绿色**（`#3ecf8e`）：核心品牌颜色，用于徽标及边框点缀
- **绿色链接色**（`#00c573`）：用于链接和操作按钮的交互式绿色
- **绿色边框色**（`rgba(62, 207, 142, 0.3)`）：柔和的绿色边框点缀

### 深色模式下的中性色系
- **接近纯黑**（`#0f0f0f`）：主要按钮背景及最深的表面色
- **深灰**（`#171717`）：页面背景及主要内容区域颜色
- **深色边框**（`#242424`）：水平分隔线及板块分隔线颜色
- **深色边框版**（`#2e2e2e`）：卡片边框及标签页边框颜色
- **中等深边框**（`#363636`）：按钮边框及内容分隔线颜色
- **浅色边框**（`#393939`）：次要边框颜色
- **炭灰**（`#434343`）：三级边框及深色点缀色
- **深灰**（`#4d4d43`）：较重的次要文本颜色
- **中灰**（`#898989`）：柔和的文本颜色及链接颜色
- **浅灰**（`#b4b4b4`）：次要链接文本颜色
- **接近白色**（`#efefef`）：浅色边框及柔和表面色
- **米白**（`#fafafa`）：主要文本及按钮文字颜色

### Radix 颜色标记（基于 HSL）
- **石板灰系列**：`--colors-slate5` 至 `--colors-slateA12`——构成连续的中性色谱
- **紫色系**：`--colors-purple4`、`--colors-purple5`、`--colors-purpleA7`——用于点缀效果
- **紫罗兰色**：`--colors-violet10`（`hsl(251, 63.2%, 63.2%)`）——鲜艳的点缀色
- **深红色**：`--colors-crimson4`、`--colors-crimsonA9`——温暖的点缀色/警告色
- **靛蓝色**：`--colors-indigoA2`——柔和的蓝色色调
- **黄色**：`--colors-yellowA7`——用于吸引注意力或表示警告
- **番茄红**：`--colors-tomatoA4`——错误状态下的点缀色
- **橙色**：`--colors-orange6`——温暖的点缀色

### 表面层与叠加层
- **深色玻璃效果**（`rgba(41, 41, 41, 0.84)`）：半透明的深色叠加层
- **石板灰透明度版本**（`hsla(210, 87.8%, 16.1%, 0.031)`）：极淡的蓝色色调叠加层
- **固定层级透明度版本**（`hsla(200, 90.3%, 93.4%, 0.109)`）：轻微的霜状叠加层

### 阴影效果
- Supabase 在其深色主题中几乎不使用阴影效果。页面的深度感是通过边框对比度以及表面颜色差异来实现的，而非传统的盒状阴影。处于焦点状态的元素仅使用 `rgba(0, 0, 0, 0.1) 0px 4px 12px` 的轻微阴影，功能性强且简洁。

## 3. 字体排版规则

### 字体系列
- **正文字体**：`Circular`，备选字体为 `custom-font, Helvetica Neue, Helvetica, Arial`
- **等宽字体**：`Source Code Pro`，备选字体为 `Office Code Pro, Menlo`

### 排版层级

| 元素类型 | 字体 | 字号 | 字重 | 行高 | 字母间距 | 备注 |
|----------|------|------|------|------|----------|------|
| 标题文字 | Circular | 72px（4.50rem） | 400 | 1.00（紧密） | 正常 | 最高密度排版，毫不浪费空间 |
| 板块标题 | Circular | 36px（2.25rem） | 400 | 1.25（紧密） | 正常 | 功能板块的标题 |
| 卡片标题 | Circular | 24px（1.50rem） | 400 | 1.33 | -0.16px | 稍微缩小字母间距 |
| 子标题 | Circular | 18px（1.13rem） | 400 | 1.56 | 正常 | 次要标题 |
| 正文内容 | Circular | 16px（1.00rem） | 400 | 1.50 | 正常 | 标准正文文本 |
| 导航链接 | Circular | 14px（0.88rem） | 500 | 1.00–1.43 | 正常 | 导航项文字 |
| 按钮文字 | Circular | 14px（0.88rem） | 500 | 1.14（紧密） | 正常 | 按钮标签文字 |
| 图片说明 | Circular | 14px（0.88rem） | 400–500 | 1.43 | 正常 | 元数据、标签信息 |
| 小字内容 | Circular | 12px（0.75rem） | 400 | 1.33 | 正常 | 小字说明、页脚链接 |
| 代码标签 | Source Code Pro | 12px（0.75rem） | 400 | 1.33 | 1.2px | 需设置 `text-transform: uppercase` |

### 设计原则
- **控制字体粗细**：几乎所有文本都使用 400 级别字体（常规/标准粗细）。仅导航链接和按钮标签会使用 500 级别字体。该设计系统中不存在 700 级别的粗体字体——排版层级完全通过字号差异来体现，而非字体粗细。
- **标题行高固定为 1.00**：标题文字的行高被压缩到最低，这种设计手法让文字看起来如同终端命令一般：紧凑、高效，没有多余的垂直空间。
- **卡片标题的微调字母间距**：卡片标题的字母间距设置为 -0.16px，这种微小的调整能让标题与正文文本形成明显区分，但又不会过于突兀。
- **等宽字体作为独特标识**：大写且带有 1.2px 字母间距的 Source Code Pro 字体具有“开发者控制台”的风格——仅用于那些与产品功能相关的技术标签，使用频率较低。
- **几何风格的亲和力**：Circular 字体圆润的端点为原本可能显得冷峻的技术界面增添了温暖感，是整个设计中体现人性化特质的关键元素。

## 5. 布局原则

### 空间系统
- 基本单位：8px
- 常用间距值：1px、4px、6px、8px、12px、16px、20px、24px、32px、40px、48px、90px、96px、128px
- 主要板块之间的间距会出现较大的跳跃，分别为 48px → 90px → 96px → 128px

### 网格与容器布局
- 内容居中显示，同时设置较大的最大宽度
- 全宽的深色板块，内部内容则有所限制
- 功能展示网格：基于图标的网格布局，卡片大小统一
- “备受信赖”板块采用徽标网格形式
- 页脚在深色背景上采用多列布局

### 断点设置
| 名称 | 宽度 | 主要变化 |
|------|------|----------|
| 移动端 | <600px | 单列布局，内容堆叠显示 |
| 桌面端 | >600px | 多列网格布局，页面更加宽敞 |

*注：Supabase 的断点系统相当简洁——仅设置一个 600px 的断点，这表明其采用移动优先的设计理念，并通过渐进增强来实现更好的适配效果。*

### 空白处理理念
- **大幅的板块间距**：主要板块之间设置 90px–128px 的较大间距，营造出类似电影般的节奏感——每个板块都仿佛是黑暗背景中的独立场景。
- **紧凑的内容块**：在单个板块内，页面间距较紧（16px–24px），使信息更加集中。
- **以边框界定空间**：Supabase 并非依靠空白区域加阴影来分隔元素，而是通过在深色背景上使用细边框来实现分隔——依靠线条而非间隙来划分空间。

### 圆角半径等级
- **标准圆角**（6px）：用于透明背景按钮及小型元素
- **舒适圆角**（8px）：用于卡片及容器
- **中等圆角**（11px–12px）：用于中等大小的面板
- **大圆角**（16px）：用于功能展示卡片及大型容器
- **圆形圆角**（9999px）：用于主要操作按钮及标签页指示器## 6. 深度与层次感

| 级别 | 处理方式 | 适用场景 |
|------|----------|----------|
| 平面（0级） | 无阴影，边框颜色为 `#2e2e2e` | 默认状态，适用于大多数界面元素 |
| 微妙边框（1级） | 边框颜色为 `#363636` 或 `#393939` | 交互式元素及悬停状态 |
| 焦点状态（2级） | 边框样式为 `rgba(0, 0, 0, 0.1) 0px 4px 12px` | 仅用于焦点状态 |
| 绿色强调色（3级） | 边框颜色为 `rgba(62, 207, 142, 0.3)` | 用于突出显示品牌相关元素 |

**关于阴影的设计理念**：Supabase 故意避免使用阴影。在以深色模式为设计基础的情况下，阴影几乎不可见，且毫无实际作用。因此，设计师通过精心设计的边框层次感来体现深度——从几乎看不见的 `#242424`，到标准的 `#2e2e2e`，再到更为醒目的 `#393939`。透明度为 30% 的绿色强调边框（`rgba(62, 207, 142, 0.3)`）则代表了“突出状态”——品牌颜色本身便成为了体现深度的信号。

## 7. 正确做法与禁忌

### 正确做法
- 使用接近黑色的背景色（如 `#0f0f0f`、`#171717`）——深度感源自灰度边框层次
- 适度使用 Supabase 的绿色色调（如 `#3ecf8e`、`#00c573`）——它们是品牌标识，而非装饰元素
- 几乎所有元素都使用 400 粗细的圆形字体，仅按钮和导航栏使用 500 粗细
- 主标题的行高设置为 1.00——无前导空格是该设计的典型排版特征
- 通过不同的边框颜色差异来营造深度感（如 `#242424` → `#2e2e2e` → `#363639`）
- 仅将圆形按钮形状（半径为 9999px）用于主要操作按钮和标签页
- 使用带透明度通道的 HSL 颜色来实现半透明层次效果
- 为开发者相关标识使用 Source Code Pro 字体的大写形式

### 禁忌事项
- 不要添加盒阴影——在深色背景下它们不可见，还会破坏由边框构成的深度体系
- 不要使用 700 粗细的粗体文字——系统仅支持 400 和 500 粗细
- 不要将绿色用于背景或大面积区域——它仅适用于边框、链接及小型强调元素
- 不要将暖色调（如深红、橙色）作为主要设计元素——这些颜色仅用于表示不同状态
- 主标题的行高不要超过 1.00——这种较高的密度是刻意设计的
- 按钮的边框圆角不要大于 16px——只能使用圆形形状（半径 9999px）或标准形状（半径 6px），不能介于两者之间
- 主要区域的背景色不要浅于 `#171717`——深色是该设计的结构基础
- 不要忽略半透明边框——`rgba` 格式的边框颜色正是实现层次感的机制

## 8. 响应式行为

### 分界点
| 名称 | 宽度 | 主要变化 |
|------|------|----------|
| 移动端 | <600px | 单列布局，功能元素堆叠显示，导航栏简化 |
| 桌面端 | >600px | 多列网格布局，完整导航栏，内容区域展开 |

### 布局折叠策略
- 主标题：72px → 按比例缩小
- 功能卡片网格：多列布局 → 单列堆叠布局
- Logo 行：水平排列 → 自动换行网格布局
- 导航栏：完整显示 → 汉堡菜单样式
- 内容区域间距：90–128px → 48–64px
- 按钮：内联显示 → 全宽堆叠显示

### 修改指南
1. 以 `#171717` 作为背景色开始设计——所有元素均遵循深色模式设计原则
2. 绿色是品牌标识，仅可用于链接、徽标及强调边框
3. 深度感来自边框颜色层次（`#242424` → `#2e2e2e` → `#363639`），而非阴影
4. 所有元素的默认字体粗细为 400，仅交互式元素使用 500 粗细
5. 主标题的行高设置为 1.00是该设计的典型排版特征
6. 主要操作按钮使用圆形形状（半径 9999px），次要操作按钮使用半径 6px 的圆形，卡片则使用 8–16px 的圆形
7. 结合透明度通道的 HSL 颜色可实现精致的半透明层次效果
