## 1. 视觉主题与氛围

Spotify 的网页界面采用深色设计，营造出沉浸式的音乐播放体验，将用户包裹在近乎纯黑的背景中（颜色值为 `#121212`、`#181818`、`#1f1f1f`），此时专辑封面和内容便成为主要的色彩来源。其设计理念为“以内容为核心的深色风格”——界面元素隐没在阴影之中，从而使音乐、播客和播放列表更加突出。所有界面元素均为深灰色调，营造出类似剧院的视觉环境，而唯一的真实色彩则来自标志性的 Spotify 绿色（`#1ed760`）以及专辑封面本身。

该界面所采用的字体为 SpotifyMixUI 和 SpotifyMixUITitle——它们均属于 CircularSp 字体系列中的专有字体（由 Lineto 设计的 Circular 字体，经定制后用于 Spotify）。该字体系列拥有完善的备用字体体系，涵盖了阿拉伯文、希伯来文、西里尔文、希腊文、天城文以及中文字体，充分体现了 Spotify 的全球业务布局。其字体系统设计简洁实用：700 级（粗体）用于强调内容及导航操作，600 级（半粗体）用于次要强调，400 级（常规体）则用于正文显示。按钮则采用大写字体，并设置适当的字距（1.4px–2px），从而呈现出规整的标签式视觉效果。

Spotify 的独特之处在于其“药丸状圆形”设计理念。主要按钮的半径为 500px–9999px（即完整的药丸形状），圆形播放按钮的半径为 50%，而搜索输入框则呈现为 500px 的药丸形状。再加上对突出元素施加的厚重阴影效果（`rgba(0,0,0,0.5) 0px 8px 24px`），以及独特的内嵌边框阴影组合（`rgb(18,18,18) 0px 1px 0px, rgb(124,124,124) 0px 0px 0px 1px inset`），共同造就了如同高端音频设备般的界面体验——触感舒适、边缘圆润，且专为触摸操作而设计。

**主要特点：**
- 几近纯黑的沉浸式深色主题（`#121212`–`#1f1f1f`）——界面元素完全融入内容之中  
- 以 Spotify Green（`#1ed760`）作为唯一的品牌色彩点缀——仅用于体现品牌特性，绝不具有装饰性  
- 支持全球各种文字脚本的 SpotifyMixUI/CircularSp 字体系列  
- 圆形按钮（尺寸范围：500px–9999px）与圆形控件（占比50%）——采用圆角设计，专为触摸操作优化  
- 按钮标签使用大号字体，字母间距较宽（1.4px–2px）  
- 高出部分的元素带有深色阴影（`rgba(0,0,0,0.5) 0px 8px 24px`）  
- 符合语义的色彩体系：警示红（`#f3727f`）、警告橙（`#ffa42b`）、通知蓝（`#539df5`）  
- 以专辑封面作为主要色彩来源——该界面设计上刻意采用无色系风格  

## 2. 色彩方案与用途  

### 核心品牌色彩  
- **Spotify Green**（`#1ed760`）：核心品牌点缀色——用于播放按钮、激活状态及行动号召元素  
- **近黑色**（`#121212`）：最深的背景色  
- **深色背景**（`#181818`）：用于卡片、容器及凸起元素  
- **中深色**（`#1f1f1f`）：按钮背景及交互式表面  

### 文本颜色  
- **白色**（`#ffffff`）：基础文本颜色，用于主要文本内容  
- **银色**（`#b3b3b3`）：次要文本颜色，用于弱化显示的标签及非激活状态的导航元素  
- **近白色**（`#cbcbcb`）：稍亮一些的次要文本颜色  
- **浅色**（`#fdfdfd`）：近乎纯白的颜色，用于需要特别强调的场景  

### 符合语义的特殊颜色  
- **警示红**（`#f3727f`）：用于错误状态下的文本显示  
- **警告橙**（`#ffa42b`）：用于提示警告状态的文本显示  
- **通知蓝**（`#539df5`）：用于信息提示类的文本显示  

### 背景与边框颜色
- **深色卡片** (`#252525`)：高亮显示的卡片背景  
- **中间色卡片** (`#272727`)：备用卡片背景  
- **深色边框灰** (`#4d4d4d`)：深色模式下的按钮边框  
- **浅色边框** (`#7c7c7c`)：带轮廓的按钮边框及柔和色调的链接  
- **分隔线** (`#b3b3b3`)：分割线  
- **浅色背景** (`#eeeeee`)：浅色模式下的按钮（较少使用）  
- **Spotify绿色边框** (`#1db954`)：绿色强调边框变体  

### 阴影效果
- **深阴影** (`rgba(0,0,0,0.5) 0px 8px 24px`)：用于对话框、菜单及突出显示的面板  
- **中阴影** (`rgba(0,0,0,0.3) 0px 8px 8px`)：用于卡片和下拉菜单  
- **内嵌边框阴影** (`rgb(18,18,18) 0px 1px 0px, rgb(124,124,124) 0px 0px 0px 1px inset`)：输入框的边框与阴影组合

### 设计原则
- **粗体/普通字体**：大部分文本采用700号（粗体）或400号（普通体）字体，600号字体则较少使用。通过字体粗细的对比而非字号差异来构建清晰的视觉层次结构。
- **大写按钮作为系统标识**：按钮标签采用大写字母并设置较大的字距（1.4px–2px），从而形成一种有辨识度的“标签式”风格，与普通内容文本相区分。
- **紧凑的字体大小**：字体大小范围在10px–24px之间，比大多数系统更为紧凑。Spotify的字体设计注重实用性与简洁性，旨在便于用户快速浏览播放列表，而非阅读长文。
- **全球语言脚本支持**：完善的备用字体方案（包括阿拉伯语、希伯来语、西里尔字母、希腊语、天城文以及中文字体）体现了Spotify在180多个市场的业务覆盖范围。

## 4. 组件样式设计

- 内边距：8px 16px
- 圆角半径：9999px（完全圆形）
- 适用场景：导航按钮、次要操作按钮

**深色大圆角按钮**
- 背景色：`#181818`
- 文字颜色：`#ffffff`
- 内边距：0px 43px
- 圆角半径：500px
- 适用场景：应用的主要导航按钮

**浅色圆角按钮**
- 背景色：`#eeeeee`
- 文字颜色：`#181818`
- 圆角半径：500px
- 适用场景：浅色模式下的操作提示（如Cookie同意选项、营销相关内容）

**轮廓圆角按钮**
- 背景色：透明
- 文字颜色：`#ffffff`
- 边框颜色：`1px solid #7c7c7c`
- 内边距：4px 16px 4px 36px（图标位置不对称）
- 圆角半径：9999px
- 适用场景：关注按钮、次要操作按钮

**圆形播放按钮**
- 背景色：`#1f1f1f`
- 文字颜色：`#ffffff`
- 内边距：12px
- 圆角半径：50%（圆形）
- 适用场景：播放/暂停控制按钮

### 卡片与容器
- 背景颜色：`#181818` 或 `#1f1f1f`
- 半径：6px–8px
- 大多数卡片无可见边框
- 鼠标悬停时：背景略微变亮
- 卡片凸起部分带有阴影效果：`rgba(0,0,0,0.3) 0px 8px 8px`

### 输入元素
- 搜索输入框：背景色为 `#1f1f1f`，文字颜色为 `#ffffff`
- 半径：500px（圆角药丸形）
- 内边距：12px 96px 12px 48px（考虑图标尺寸）
- 聚焦状态时：边框变为 `#000000`，轮廓线宽度为1px

### 导航设计
- 深色侧边栏，使用 SpotifyMixUI 字体，活跃项字体粗细为14px、权重为700，非活跃项为400
- 非活跃项颜色为柔和的 `#b3b3b3`，活跃项为 `#ffffff`
- 圆形图标按钮，半径为50%
- 左上角为绿色 Spotify 徽标

## 5. 布局原则

### 空间系统
- 基本单位：8px
- 缩放比例：1px、2px、3px、4px、5px、6px、8px、10px、12px、14px、15px、16px、20px

### 网格与容器
- 固定侧边栏 + 主内容区域
- 基于网格布局的专辑/播放列表卡片
- 底部为全宽的当前播放栏
- 响应式内容区域填充剩余空间

### 空白设计理念
- **深色紧凑布局**：Spotify 以密集的方式呈现内容——播放列表网格、曲目列表及导航元素之间的间距都很小。深色背景能够在无需较大间隙的情况下为各元素之间提供视觉上的分隔。
- **内容密度优先**：这是一款音乐应用，而非营销网站。每一个像素都服务于听觉体验。

### 边框圆角比例尺度
- 最小（2像素）：徽章、显式标签  
- 微妙（4像素）：输入框、小型元素  
- 标准（6像素）：专辑封面容器、卡片  
- 舒适（8像素）：内容板块、对话框  
- 中等（10像素–20像素)：面板、叠加元素  
- 大型（100像素）：大型圆形按钮  
- 圆形（500像素）：主要操作按钮、搜索输入框  
- 完整圆形（9999像素）：导航按钮、搜索栏  
- 圆形（50%尺寸）：播放按钮、头像、图标  

## 6. 深度与层次感

| 层级 | 处理方式 | 用途 |
|-------|-----------|-----|
| 基层（第0层） | 背景色为`#121212` | 最底层，用于页面背景 |
| 表层（第1层） | 背景色为`#181818`或`#1f1f1f` | 用于卡片、侧边栏、容器 |
| 提升层（第2层） | 阴影效果为`rgba(0,0,0,0.3) 0px 8px 8px` | 用于下拉菜单、悬停卡片 |
| 对话框层（第3层） | 阴影效果为`rgba(0,0,0,0.5) 0px 8px 24px` | 用于模态框、叠加层、菜单 |
| 内嵌边框层 | 边框样式为`rgb(18,18,18) 0px 1px 0px, rgb(124,124,124) 0px 0px 0px 1px inset` | 用于输入框边框 |

**阴影设计理念**：Spotify在深色主题应用中采用了相当明显的阴影效果。对话框和菜单使用透明度为0.5、模糊度为24像素的阴影，从而营造出“悬浮在黑暗中”的强烈视觉效果；而卡片则采用透明度为0.3、模糊度为8像素的阴影，实现更为柔和的凸起感。输入框则通过独特的内嵌边框与阴影组合，呈现出凹陷的触感效果。  

## 7. 正确做法与禁忌

### 应该做的
- 请使用接近黑色的背景色（`#121212`–`#1f1f1f`），通过明暗变化营造深度感。  
- 仅在播放控件、处于活动状态的元素以及主要操作按钮上使用 Spotify 绿色（`#1ed760`）。  
- 所有按钮均采用药丸形设计，尺寸范围为 500px–9999px；播放控件则需为圆形，占比 50%。  
- 按钮文字应使用大写字母，并设置较大的字距（1.4px–2px）。  
- 字体大小需保持紧凑，范围在 10px–24px 之间——这是一款应用，而非杂志。  
- 在深色背景下，为突出显示的元素添加较重的阴影效果，不透明度为 0.3–0.5。  
- 颜色效果由专辑封面提供，界面本身应采用无彩色设计。  

### 不建议的做法  
- 不要将 Spotify 绿色用于装饰或背景色——它仅具有功能性用途。  
- 不要在主要界面区域使用浅色背景——深色沉浸式设计是该应用的核心特色。  
- 不要省略按钮的药丸形或圆形设计——方形按钮会破坏其独特风格。  
- 不要使用较淡或隐约的阴影——在深色背景下，阴影需足够明显才能被察觉。  
- 不要添加额外的品牌颜色——绿色与无彩色灰色已构成完整的配色方案。  
- 不要使用过大的行高——Spotify 的字体设计应当紧凑且密集。  
- 不要直接显示灰色的边框——应采用基于阴影或内嵌式的边框替代。

| 名称 | 宽度 | 主要变化 |

| 手机标准屏 | 425–576px | 标准手机布局 |

| 平板电脑大屏 | 768–896px | 扩展布局 |
| 桌面电脑小屏 | 896–1024px | 显示侧边栏 |
| 桌面电脑标准屏 | 1024–1280px | 完整桌面布局 |
| 大屏幕桌面 | >1280px | 扩展网格布局 |

### 布局折叠策略
- 侧边栏：完整显示 → 折叠显示 → 隐藏
- 相册网格：5列 → 3列 → 2列 → 1列
- 正在播放栏：所有尺寸下均保持显示
- 搜索功能：药丸形输入框保持不变，宽度会相应调整
- 导航栏：手机端为侧边栏，平板及桌面端为底部栏
