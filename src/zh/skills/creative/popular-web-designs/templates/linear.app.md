## 1. 视觉主题与氛围

Linear 的网站堪称以深色模式为核心的产品设计典范——它以近乎纯黑的背景 (`#08090a`) 为载体，内容如同星光般从黑暗中显现。整体给人一种极度精密工程的感觉：每一个元素都处于精心调整的亮度层级之中，从几乎不可见的边框 (`rgba(255,255,255,0.05)`) 到柔和明亮的文字 (`#f7f8f8`)，皆有严格把控。这并非在浅色设计上叠加深色主题，而是将黑暗本身作为核心表现媒介，通过白色透明度的细微渐变而非色彩变化来控制信息密度。

其排版系统完全基于 Inter Variable 字体，并全局启用了 OpenType 特性 `"cv01"` 和 `"ss03"`，从而使字体呈现出更为简洁、几何感更强的风格。Inter 字体被广泛应用于多种粗细级别——从 300（浅体）到 510（线性品牌标志性的中等粗细），再到 590（半粗强调体）。其中 510 粗细尤为独特：它介于普通体与中等体之间，能带来恰到好处的强调效果而不会显得突兀。在较大显示尺寸（72px、64px、48px）下，Inter 字体会使用较大的负字距（-1.584px 至 -1.056px），从而形成紧凑且富有权威感的标题，给人一种经过精心设计而非随意制作的印象。代码及技术标签则使用 Berkeley Mono 作为等宽字体，必要时也可选用 ui-monospace、SF Mono 和 Menlo 作为替代。

该设计的色彩系统几乎完全采用无彩色方案——深色背景搭配白色/灰色文字——仅点缀着一种品牌专用色：Linear 标志性的靛紫色（背景色为 `#5e6ad2`，交互元素强调色为 `#7170ff`）。这种强调色被谨慎且刻意地使用，仅出现在操作按钮、活动状态及品牌相关元素上。边框系统则采用极细的半透明白色边框（`rgba(255,255,255,0.05)` 至 `rgba(255,255,255,0.08)`），在不会造成视觉干扰的情况下构建结构，宛如月光下绘制的线框图。

**核心特征：**
- 原生深色模式：营销页面背景为 `#08090a`，面板背景为 `#0f1011`，凸起区域背景为 `#191a1b`
- 全局启用 Inter Variable 的 `"cv01"`、`"ss03"` 特性——通过几何变体实现更简洁的视觉效果
- 大部分界面文字采用标志性 510 粗细（介于普通体与中等体之间）
- 在较大显示尺寸下使用较大的负字距（72px 时为 -1.584px，48px 时为 -1.056px）
- 品牌靛紫色：背景色 `#5e6ad2` / 强调色 `#7170ff` / 悬停态颜色 `#828fff`——这是整个系统中唯一的彩色元素
- 全局使用半透明白色边框：`rgba(255,255,255,0.05)` 至 `rgba(255,255,255,0.08)`
- 按钮背景透明度极低：`rgba(255,255,255,0.02)` 至 `rgba(255,255,255,0.05)`
- 在深色背景上通过多层阴影及内嵌阴影效果增强深度感
- 以 Radix UI 原始组件作为基础（共检测到 6 种原始组件）
- 仅状态指示器使用绿色表示成功：`#27a644`、`#10b981`

## 2. 色彩方案与用途

### 背景色
- **营销黑** (`#010102` / `#08090a`)：最深的背景色，用于主视觉区域和营销页面。近乎纯黑，带有难以察觉的蓝冷色调。
- **面板深色** (`#0f1011`)：侧边栏及面板的背景色，比营销黑稍浅一级。
- **第三级表面** (`#191a1b`)：凸起区域、卡片背景及下拉菜单的背景色。
- **次级表面** (`#28282c`)：最浅的深色背景，用于悬停状态及略微凸起的组件。

### 文本与内容
- **主文本** (`#f7f8f8`)：接近白色，略带暖色调。为默认文本颜色，并非纯白，可避免在深色背景下造成视觉疲劳。
- **次级文本** (`#d0d6e0`)：冷银灰色，用于正文、描述及次要内容。
- **三级文本** (`#8a8f98`)：暗灰色，用于占位符、元数据及弱化显示的内容。
- **四级文本** (`#62666d`)：最浅的文字颜色，用于时间戳、禁用状态及细微标签。

### 品牌色与强调色
- **品牌靛蓝** (`#5e6ad2`)：主要品牌颜色，用于操作按钮背景、品牌标识及关键交互区域。
- **强调紫** (`#7170ff`)：更明亮的色调，用于链接、活动状态及已选中项目等交互元素。
- **强调色悬停态** (`#828fff`)：更浅且饱和度更高的颜色，用于强调色元素的悬停状态。
- **安全薰衣草色** (`#7a7fad`)：柔和的靛蓝色，专门用于与安全相关的界面元素。

### 状态颜色
- **绿色** (`#27a644`)：主要表示成功/激活状态，用于“进行中”指示器。
- **翡翠绿** (`#10b981`)：次要成功状态，用于圆点徽章及完成状态。

### 边框与分隔线
- **主边框** (`#23252a`)：用于重要分隔的实心深色边框。
- **次级边框** (`#34343a`)：稍浅的实心边框。
- **三级边框** (`#3e3e44`)：最浅的实心边框版本。
- **微妙边框** (`rgba(255,255,255,0.05)`)：极微妙的半透明边框，为默认选项。
- **标准边框** (`rgba(255,255,255,0.08)`)：用于卡片、输入框及代码块的常规半透明边框。
- **细线色** (`#141516`)：几乎不可见的线条，用于最细微的分隔。
- **三级细线色** (`#18191a`)：略显明显的分隔线。

### 浅色模式中性色（用于浅色主题场景）
- **浅色背景** (`#f7f8f8`)：浅色模式下的页面背景。
- **浅色表面** (`#f3f4f5` / `#f5f6f7`)：带有细微色调变化的表面。
- **浅色边框** (`#d0d6e0`)：浅色场景下可见的边框。
- **浅色边框替代色** (`#e6e6e6`)：另一种更浅的边框颜色。
- **纯白色** (`#ffffff`)：卡片表面及高亮区域。

### 叠加层
- **主叠加层** (`rgba(0,0,0,0.85)`)：模态框/对话框的背景，颜色极深，用于突出焦点。

## 3. 排版规则

### 字体家族
- **正文字体**：`Inter Variable`，备选字体包括：`SF Pro Display`、`-apple-system`、`system-ui`、`Segoe UI`、`Roboto`、`Oxygen`、`Ubuntu`、`Cantarell`、`Open Sans`、`Helvetica Neue`
- **等宽字体**：`Berkeley Mono`，备选字体包括：`ui-monospace`、`SF Mono`、`Menlo`
- **OpenType 特性**：全局启用 `"cv01"` 和 `"ss03"` —— `cv01` 可提供另一种小写 ‘a’ 字形（单层结构），`ss03` 能调整特定字母形状，使字体更具几何感与清晰度。

### 设计原则
- **510 是标志性粗细**：Linear 采用 Inter Variable 的 510 粗细（介于普通体 400 和中等体 500 之间）作为默认的强调粗细。这种设置能带来微妙的加粗效果，却不会像传统的中等体或半粗体那样显得沉重。
- **按比例逐步压缩字距**：在较大显示尺寸下，字距会逐渐缩小——72px 时为 -1.584px，64px 时为 -1.408px，48px 时为 -1.056px，32px 时为 -0.704px。低于 24px 时，字距会恢复至正常水平。
- **OpenType 特性塑造独特风格**：`"cv01"` 和 `"ss03"` 并非仅用于装饰，它们让 Inter 字体呈现出 Linear 独特的风格，更具几何感与设计意图。
- **三级粗细体系**：400（阅读用）、510（强调/界面用）、590（强烈强调用）。300 粗细仅用于刻意需要弱化视觉效果的场景。

## 5. 布局原则

### 空间系统
- 基本单位：8px
- 缩放值：1px、4px、7px、8px、11px、12px、16px、19px、20px、22px、24px、28px、32px、35px
- 7px与11px这两个数值用于微调以实现视觉对齐
- 主要节奏间距：8px、16px、24px、32px（标准8px网格）

### 网格与容器
- 内容最大宽度：约1200px
- 主页区域：居中单列布局，垂直内边距较大
- 功能展示区：功能卡片采用2–3列网格布局
- 全宽深色区域，内部设有最大宽度限制
- 更新日志：单列时间轴布局

### 空白设计理念
- **以黑暗作为空间**：在Linear的深色背景上，空白并非纯白色，而是“缺失”。接近纯黑的背景本身就是空白，内容则从中显现出来。
- **标题紧凑，周围空间宽敞**：文本以72px字号显示，字距调整为-1.584px，显得密集紧凑，但处于广阔的深色背景之中。这种文字密度与空间宽度的对比营造出张力。
- **区域分隔**：每个功能区域之间通过较大的垂直内边距（80px以上）分隔，无需可见的分隔线——深色背景本身即可实现自然区分。

### 圆角尺度标准
- 微型（2px）：内联徽章、工具栏按钮、柔和标签
- 标准（4px）：小型容器、列表项
- 舒适型（6px）：按钮、输入框、功能元素
- 卡片型（8px）：卡片、下拉菜单、弹出窗口
- 面板型（12px）：大型面板、特色卡片、区域容器
- 大型（22px）：大型面板元素
- 全圆标签型（9999px）：筛选标签、状态标签
- 圆形（50%）：图标按钮、头像、状态点

## 6. 深度与层次感

| 级别 | 处理方式 | 用途 |
|------|-----------|-----|
| 平面层（第0级） | 无阴影，背景色`#010102` | 页面背景，最深层的画布 |
| 柔和层（第1级） | `rgba(0,0,0,0.03) 0px 1.2px 0px` | 工具栏按钮、微弱凸起效果 |
| 表面层（第2级） | 背景色`rgba(255,255,255,0.05)` + 边框`1px solid rgba(255,255,255,0.08)` | 卡片、输入字段、容器 |
| 凹入层（第2b级） | `rgba(0,0,0,0.2) 0px 0px 12px 0px inset` | 凹进式面板、内部阴影效果 |
| 环形层（第3级） | `rgba(0,0,0,0.2) 0px 0px 0px 1px` | 以边框模拟阴影的效果 |
| 凸出层（第4级） | `rgba(0,0,0,0.4) 0px 2px 4px` | 浮动元素、下拉菜单 |
| 对话框层（第5级） | 多层叠加阴影：`rgba(0,0,0,0) 0px 8px 2px, rgba(0,0,0,0.01) 0px 5px 2px, rgba(0,0,0,0.04) 0px 3px 2px, rgba(0,0,0,0.07) 0px 1px 1px, rgba(0,0,0,0.08) 0px 0px 1px` | 弹出窗口、命令面板、模态框 |
| 聚焦状态 | `rgba(0,0,0,0.1) 0px 4px 12px` + 其他多层阴影 | 键盘聚焦时的交互元素效果 |

**阴影设计理念**：在深色表面上，传统的深色阴影几乎不可见。Linear通过使用半透明的白色边框作为主要的深度指示器来解决这一问题。层次感并非通过阴影的深浅来体现，而是通过背景亮度的逐步提升——每一层都会略微增加表面背景的白色透明度（从`0.02`到`0.04`再到`0.05`），从而形成柔和的叠加效果。凹入阴影技术（`rgba(0,0,0,0.2) 0px 0px 12px 0px inset`）则为凹进式面板带来独特的“下沉”效果，增添了传统深色主题所缺乏的立体感。

## 7. 应该做与不应该做的事

### 应该做的
- 所有文本均使用Inter字体的`"cv01"`、`"ss03"`变量——这些特性是Linear字体风格的核心所在。
- 将粗细510设为默认的强调字体粗细——这是Linear特有的中间粗细级别。
- 在显示尺寸下应用较大的负字距（72px时为-1.584px，48px时为-1.056px）。
- 以接近纯黑的背景作为设计基础：营销页面使用`#08090a`，面板使用`#0f1011`，凸起区域使用`#191a1b`。
- 使用半透明的白色边框（`rgba(255,255,255,0.05)`至`rgba(255,255,255,0.08)`），而非纯色深色边框。
- 按钮背景保持近乎透明：`rgba(255,255,255,0.02)`至`rgba(255,255,255,0.05)`。
- 仅将品牌靛蓝色（`#5e6ad2` / `#7170ff`）用于主要行动号召按钮及交互式强调元素。
- 主要文字颜色使用`#f7f8f8`——而非纯白色`#ffffff`，后者会过于刺眼。
- 采用亮度叠加模型：层级越深，背景越暗；层级越高，背景略亮。

### 不应该做的
- 不要将纯白色`#ffffff`作为主要文字颜色——使用`#f7f8f8`可避免视觉疲劳。
- 不要为按钮使用纯色背景——透明度才是该设计系统的核心原则（白色半透明值在0.02–0.05之间）。
- 不要将品牌靛蓝色用于装饰性用途——它仅限于交互元素和行动号召按钮。
- 不要在显示文本上使用正字距——大字体尺寸下的Inter字体始终应使用负字距。
- 不要在深色背景上使用可见的实心边框——边框应为极细的半透明白色线条。
- 不要省略OpenType字体特性（`"cv01"`、`"ss03"`）——缺少这些特性，文字将只是普通的Inter字体，而非Linear特有的风格。
- 不要使用粗细700（加粗）——Linear字体的最大粗细为590，其中510是最常用的粗细级别。
- 不要在界面元素中加入暖色调——整个配色方案仅包含冷灰色调及蓝紫色点缀。
- 不要在深色表面上使用投影来营造层次感——应依靠背景亮度的逐步变化来实现。

## 8. 响应式行为

### 分界点
| 名称 | 宽度范围 | 主要变化 |
|------|----------|-----------|
| 移动端小屏幕 | <600px | 单列布局，内边距紧凑 |
| 移动端 | 600–640px | 标准移动端布局 |
| 平板端 | 640–768px | 开始出现双列网格布局 |
| 桌面端小屏幕 | 768–1024px | 完整的卡片网格布局，内边距增大 |
| 桌面端 | 1024–1280px | 标准桌面布局，完整导航栏 |
| 大桌面端 | >1280px | 完整布局，更大间距 |

### 触摸目标区域
- 按钮需具备足够的舒适内边距，圆角至少为6px。
- 导航链接文字大小为13–14px，且间距充足。
- 信息标签的横向内边距为10px，以确保触摸操作便捷性。
- 图标按钮的圆角为50%，确保呈现圆形、易于点击的目标区域。
- 搜索触发区域位置显眼，点击区域足够大。

### 收缩策略
- 主页标题文字大小：72px → 48px → 32px，字距相应调整。
- 导航栏：水平链接与行动号召按钮 → 在768px宽度时切换为汉堡菜单。
- 功能卡片：3列 → 2列 → 单列堆叠显示。
- 产品截图：保持原有宽高比，内边距可能适当减小。
- 更新日志：在所有屏幕尺寸下均保持单列时间轴布局。
- 底部导航：多列布局 → 堆叠式单列布局。
- 区域间距：80px以上 → 移动端为48px。

### 图片表现
- 仪表板截图在所有屏幕尺寸下均保持边框处理方式。
- 移动端上，主页视觉元素更为简化（悬浮的界面元素减少）。
- 产品截图采用响应式尺寸设置，同时保持一致的圆角。
- 深色背景确保截图在任何视口尺寸下都能自然融合。
