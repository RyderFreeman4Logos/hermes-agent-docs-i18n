## 1. 视觉主题与氛围

Vercel的网站体现了“让开发者基础设施隐形”的视觉理念——其设计系统极为克制，近乎具有哲学意味。页面以纯白色（`#ffffff`）为主，文字颜色接近黑色（`#171717`），营造出类似艺术画廊般的空灵感，每一个元素都显得格外重要。这并非仅为装饰而采用的极简主义，而是作为一种工程原则。Geist设计系统将界面视同编译器处理代码的方式——所有不必要的元素都被剔除，仅保留核心结构。

定制的Geist字体系列是该设计的精髓所在。Geist Sans采用了极大的负字距（在显示尺寸下为-2.4px至-2.88px），使得标题看起来紧凑、富有紧迫感，仿佛经过压缩和优化，就像为生产环境而缩写的代码。在正文尺寸下，字距虽有所放宽，但几何精度依然保持不变。Geist Mono则作为代码、终端输出及技术标签的等宽字体，完善了整个系统。这两种字体均支持OpenType的“连字”功能，为排版增添了一层精致感，值得仔细品鉴。

Vercel与其他单色设计系统的不同之处在于它采用了“阴影作为边框”的理念。它没有使用传统的CSS边框，而是采用`box-shadow: 0px 0px 0px 1px rgba(0,0,0,0.08)`——即零偏移、零模糊、1像素宽度的阴影，从而形成类似边框的线条，同时避免了传统盒模型带来的影响。这种技术使得边框可以存在于阴影层中，从而实现更平滑的过渡效果、无裁剪的圆角，以及比传统边框更为微妙的视觉层次感。整个深度效果系统都是通过多层、多值的阴影堆叠来实现的，每层都有特定的作用：一层用于边框，一层用于柔和的凸起效果，还有一层用于营造整体氛围。

**主要特征：**
- Geist Sans采用极大的负字距（显示尺寸下为-2.4px至-2.88px）——文字如同经过压缩的基础设施
- Geist Mono用于显示代码和技术标签，所有字体均支持OpenType“连字”功能
- “阴影作为边框”的技术：全程使用`box-shadow 0px 0px 0px 1px`替代传统边框
- 多层阴影堆叠以实现精细的深度效果（在单行声明中同时实现边框、凸起和氛围效果）
- 几乎纯白的背景搭配接近黑色的文字（`#171717`），形成微妙的对比度
- 针对不同工作流程的强调色：发布红（`#ff5b4f`）、预览粉（`#de1d8d`）、开发蓝（`#0a72ef`）
- 使用`hsla(212, 100%, 48%, 1)`实现的焦点环系统——饱和的蓝色，有助于提升可访问性
- 带有渐变背景的圆角徽章（尺寸为9999px），用于显示状态信息

## 2. 色彩方案与用途

### 主要色彩
- **Vercel黑色**（`#171717`）：用于正文、标题以及深色背景。并非纯黑，略带暖色调，避免了生硬感。
- **纯白色**（`#ffffff`）：用于页面背景、卡片表面以及深色背景上的按钮文字。
- **纯黑色**（`#000000`）：仅作次要用途，如`--geist-console-text-color-default`，用于特定的控制台或代码场景。

### 工作流程强调色
- **发布红**（`#ff5b4f`）：对应`--ship-text`，用于“部署到生产环境”这一工作流程步骤——温暖的珊瑚红色，富有紧迫感。
- **预览粉**（`#de1d8d`）：对应`--preview-text`，用于预览部署工作流程——鲜艳的洋红色。
- **开发蓝**（`#0a72ef`）：对应`--develop-text`，用于开发工作流程——明亮的蓝色，象征专注。

### 控制台/代码颜色
- **控制台蓝**（`#0070f3`）：对应`--geist-console-text-color-blue`，用于语法高亮。
- **控制台紫**（`#7928ca`）：对应`--geist-console-text-color-purple`，用于语法高亮。
- **控制台粉**（`#eb367f`）：对应`--geist-console-text-color-pink`，用于语法高亮。

### 交互元素颜色
- **链接蓝**（`#0072f5`）：主要的链接颜色，带有下划线装饰。
- **焦点蓝**（`hsla(212, 100%, 48%, 1)`）：对应`--ds-focus-color`，用于交互元素上的焦点环。
- **环状蓝**（`rgba(147, 197, 253, 0.5)`）：对应`--tw-ring-color`，用于Tailwind框架的环状效果。

### 中性色系
- **深灰900**（`#171717`）：用于正文、标题以及导航文字。
- **灰600**（`#4d4d4d`）：用于次要文字及描述内容。
- **灰500**（`#666666`）：用于三级文字及颜色较浅的链接。
- **灰400**（`#808080`）：用于占位符文字及禁用状态。
- **灰100**（`#ebebeb`）：用于边框、卡片轮廓及分隔线。
- **灰50**（`#fafafa`）：用于轻微的背景色调及内阴影高亮。

### 背景与叠加层颜色
- **叠加层背景**（`hsla(0, 0%, 98%, 1)`）：对应`--ds-overlay-backdrop-color`，用于模态框或对话框的背景。
- **选中文本颜色**（`hsla(0, 0%, 95%, 1)`）：对应`--geist-selection-text-color`，用于文本选中时的高亮色。
- **徽章蓝色背景**（`#ebf5ff`）：用于圆角徽章的背景，带有蓝色色调。
- **徽章蓝色文字**（`#0068d6`）：用于徽章的文字，颜色较深以便清晰显示。

### 阴影与深度效果
- **边框阴影**（`rgba(0, 0, 0, 0.08) 0px 0px 0px 1px`）：该设计的标志性元素——替代了传统边框。
- **柔和凸起效果**（`rgba(0, 0, 0, 0.04) 0px 2px 2px`）：为卡片添加轻微的凸起感。
- **完整卡片阴影堆叠**（`rgba(0,0,0,0.08) 0px 0px 0px 1px, rgba(0,0,0,0.04) 0px 2px 2px, rgba(0,0,0,0.04) 0px 8px 8px -8px, #fafafa 0px 0px 0px 1px`）：完整的多层卡片阴影效果。
- **环形边框**（`rgb(235, 235, 235) 0px 0px 0px 1px`）：用于标签页和图片的浅灰色环形边框。

### 设计原则
- **压缩即身份标识**：Geist Sans在显示尺寸下采用-2.4px至-2.88px的极大负字距，这是所有主流设计系统中最为极端的负字距设置。这样的处理方式让文字看起来如同经过压缩的代码，为生产环境做了优化。随着字体尺寸的缩小，字距会逐渐放宽：32px时为-1.28px，24px时为-0.96px，16px时为-0.32px，14px时则恢复为正常值。
- **处处使用连字**：所有Geist字体元素都支持OpenType“连字”功能。这些连字并非装饰性元素，而是具有结构意义，能够形成更为紧凑、高效的字形组合。
- **三种字重，严格分工**：400（正文/阅读用）、500（界面/交互用）、600（标题/强调用）。除了极小的微型徽章外，没有使用700号粗体字重。这种有限的字重范围使得层级感通过字体大小和字距来体现，而非依赖字重差异。
- **等宽字体作为身份标识**：大写形式的Geist Mono，结合“数字连写”或“连字”功能，充当了“开发者控制台”的风格载体——即紧凑的技术标签，将营销网站与产品功能紧密相连。

## 4. 组件样式

### 按钮

**主白色按钮（带阴影边框）**
- 背景色：`#ffffff`
- 文字颜色：`#171717`
- 内边距：0px 6px（极小，宽度由内容决定）
- 圆角：6px（轻微圆角）
- 阴影：`rgb(235, 235, 235) 0px 0px 0px 1px`（环形边框效果）
- 悬停状态：背景色变为`var(--ds-gray-1000)`（深色）
- 焦点状态：2px宽的`var(--ds-focus-color)`轮廓线，外加`var(--ds-focus-ring)`阴影
- 用途：标准的次要按钮

**主深色按钮（基于Geist系统推导）**
- 背景色：`#171717`
- 文字颜色：`#ffffff`
- 内边距：8px 16px
- 圆角：6px
- 用途：主要行动号召按钮，如“开始部署”或“立即开始”

**圆角徽章按钮/标签**
- 背景色：`#ebf5ff`（带蓝色色调）
- 文字颜色：`#0068d6`
- 内边距：0px 10px
- 圆角：9999px（完全圆形）
- 字体：12px，字重500
- 用途：状态徽章、标签及功能标识

**大型圆角徽章（用于导航）**
- 背景色：透明或`#171717`
- 圆角：64px–100px
- 用途：标签页导航及章节选择器

### 卡片与容器
- 背景色：`#ffffff`
- 边框：通过阴影实现——`rgba(0, 0, 0, 0.08) 0px 0px 0px 1px`
- 圆角：标准为8px，特色/图片卡片为12px
- 阴影堆叠：`rgba(0,0,0,0.08) 0px 0px 0px 1px, rgba(0,0,0,0.04) 0px 2px 2px, #fafafa 0px 0px 0px 1px`
- 图片卡片：额外添加1px宽、颜色为`#ebebeb`的边框，上圆角为12px
- 悬停状态：阴影效果略微增强

### 输入框与表单
- 单选按钮：标准样式，焦点状态时背景色为`var(--ds-gray-200)`
- 焦点阴影：`1px 0 0 0 var(--ds-gray-alpha-600)`
- 焦点轮廓线：2px宽的`var(--ds-focus-color)`蓝色轮廓线——保持一致的蓝色焦点环
- 边框：同样通过阴影技术实现，而非传统边框

### 导航栏- 白色背景上带有固定定位的简洁水平导航栏  
- Vercel标志左对齐，尺寸为262×52像素  
- 链接文字使用Geist字体，字重14px、粗细500，颜色为`#171717`  
- 活动状态链接：字重调整为600或添加下划线  
- 行动号召按钮采用深色圆角设计（如“开始部署”、“联系销售”）  
- 移动端：汉堡菜单可折叠显示  
- 产品相关内容采用带多级菜单的下拉框形式  

### 图片处理规范
- 产品截图需添加`1px solid #ebebeb`的边框  
- 图片顶部采用圆角设计，半径为`12px 12px 0px 0px`  
- 功能介绍区域以控制台/代码预览截图为主  
- 主图背景使用柔和的多色渐变效果  

### 独特视觉元素  

**工作流流程图**  
- 采用三步水平流程结构：开发 → 预览 → 发布  
- 每个阶段对应不同强调色：蓝色 → 粉色 → 红色  
- 各步骤之间用线条/箭头连接  
- 此设计体现了Vercel的核心价值理念  

**信任栏/品牌标志网格**  
- 展示Perplexity、ChatGPT、Cursor等公司的灰度标志  
- 采用水平滚动或网格布局  
- 标志之间以`#ebebeb`色的细边框分隔  

**指标卡片**  
- 数值以较大字体显示（例如“快10倍”）  
- 指标文字使用Geist字体，字重48px、粗细600  
- 下方为灰色文字说明  
- 卡片容器带有阴影边框  

## 5. 布局原则  

### 空间系统  
- 基础单位：8像素  
- 可用尺寸：1px、2px、3px、4px、5px、6px、8px、10px、12px、14px、16px、32px、36px、40px  
- 特殊间距：从16px直接跳至32px，主要尺寸体系中不存在20px或24px  

### 网格与容器  
- 内容最大宽度约为1200像素  
- 主图区域：居中单列布局，顶部留有充足间距  
- 功能介绍区：卡片采用2–3列网格排列  
- 使用`border-bottom: 1px solid #171717`创建全宽分隔线  
- 代码/控制台截图可全宽显示或用边框包裹  

### 空白设计理念  
- **大量留白**：各功能区块之间设置极大的垂直间距（80px–120px以上）。这种空白本身就是设计的一部分，旨在体现Vercel无需证明什么、也无需隐藏什么的态度。  
- **紧凑文字与宽敞空间**：标题采用较大的负字距设计，而周围则保留充足空白，形成对比。文字内容密集，但周围空间极为宽敞。  
- **区块节奏感**：所有区域均为纯白色，彼此之间没有颜色差异。区分各区块仅依靠边框（带阴影的边框）和间距。  

### 圆角尺寸标准  
- 微圆角（2px）：用于内联代码片段、小型标签等  
- 柔和圆角（4px）：用于小型容器  
- 标准圆角（6px）：用于按钮、链接及功能性元素  
- 舒适圆角（8px）：用于卡片、列表项  
- 图片圆角（12px）：用于重点展示的卡片及带圆角的图片容器  
- 大圆角（64px）：用于标签页导航按钮  
- 特大圆角（100px）：用于大型导航链接  
- 完全填充圆角（9999px）：用于徽章、状态指示按钮及标签  
- 圆形圆角（50%）：用于菜单切换按钮、头像容器  

## 6. 深度与层次感  

| 层级 | 效果处理 | 适用场景 |
|------|-----------|----------|
| 平面层（第0层） | 无阴影 | 页面背景、文本块 |
| 环形层（第1层） | `rgba(0,0,0,0.08) 0px 0px 0px 1px` | 大多数元素采用阴影作为边框效果 |
| 轻环形层（第1b层） | `rgb(235,235,235) 0px 0px 0px 1px` | 标签页、图片等使用较浅的环形效果 |
| 柔和卡片层（第2层） | 环形层 + `rgba(0,0,0,0.04) 0px 2px 2px` | 具有轻微立体感的普通卡片 |
| 完整卡片层（第3层） | 环形层 + 柔和层 + `rgba(0,0,0,0.04) 0px 8px 8px -8px` + 内部`#fafafa`环形层 | 重点展示的卡片、高亮面板 |
| 可访问性焦点层 | `2px solid hsla(212, 100%, 48%, 1)`轮廓线 | 所有交互元素在键盘操作时的焦点指示 |

**阴影设计理念**：Vercel拥有现代网页设计中最复杂的阴影系统。它并非像传统Material Design那样单纯利用阴影来营造层次感，而是采用多层阴影叠加技术——每一层都有明确的视觉功能：一层用于创建“边框”效果（扩散值为0px，厚度为1px）；另一层增加整体柔和度（模糊值为2px）；还有一层负责营造远距离的深度感（模糊值为8px，同时带有负扩散值）；最内层的`#fafafa`色环形层则能产生微妙的高光效果，让卡片仿佛从内部发光。这种分层设计使得卡片看起来像是实体的，而非悬浮在空中的元素。

### 装饰性深度效果  
- 主图渐变：在主图内容背后使用柔和的多色渐变背景（几乎不可见，仅起到氛围营造作用）  
- 区块分隔线：主要区块之间使用`1px solid #171717`的实线分隔  
- 不存在背景颜色变化——所有深度感完全来自阴影层次与边框对比  

## 7. 正确做法与禁忌  

### 应该这样做  
- 在显示尺寸下为Geist Sans字体应用较大的负字距（48px字号时为-2.4px至-2.88px）  
- 采用阴影作为边框替代传统的CSS边框，即使用`0px 0px 0px 1px rgba(0,0,0,0.08)`格式  
- 为所有Geist字体文本启用“连字”功能——连字是字体结构的重要组成部分，而非可选设置  
- 采用三种字重体系：400（正文）、500（界面元素）、600（标题）  
- 仅在对应工作流场景中使用红/粉/蓝三色作为强调色  
- 为卡片应用多层阴影效果（边框层 + 立体感层 + 柔和背景层 + 内部高光层）  
- 保持配色方案以灰色系为主，从`#171717`到`#ffffff`均为系统常用颜色  
- 主要文本优先使用`#171717`而非`#000000`——微弱的暖色调能提升视觉效果  

### 不应该这样做  
- 不要在Geist Sans字体上使用正字距——始终应保持负字距或零字距  
- 不要在正文文本中使用700号粗体字重——600已是最大值，仅用于标题  
- 不要为卡片使用传统的CSS边框——应采用阴影边框技术  
- 不要在界面元素中加入暖色调（橙色、黄色、绿色）  
- 不要将工作流强调色用于装饰性目的  
- 不要使用过重的阴影效果（透明度超过0.1）——Vercel的阴影效果应以柔和为主  
- 不要增加正文文本的字距——Geist字体本身就适合紧凑排版  
- 不要在主要操作按钮上使用9999px的超大圆角——该圆角仅适用于徽章和标签  
- 不要省略卡片阴影中的内部`#fafafa`环形层——正是这一高光效果让Vercel的卡片具有独特视觉体验  

## 8. 响应式设计规则  

### 分界点  
| 名称 | 宽度范围 | 主要变化 |
|------|----------|----------|
| 小型移动端 | <400px | 紧凑的单列布局，最小化间距 |
| 移动端 | 400–600px | 标准移动端布局，采用堆叠式显示 |
| 小型平板端 | 600–768px | 开始出现2列网格布局 |
| 平板端 | 768–1024px | 完整的卡片网格布局，增加间距 |
| 小型桌面端 | 1024–1200px | 标准桌面端布局 |
| 桌面端 | 1200–1400px | 完整布局，内容宽度达到最大值 |
| 大型桌面端 | >1400px | 居中布局，留有充足边距 |

### 触控目标区域尺寸  
- 按钮的垂直内边距应保持在8px–16px之间，确保易于触摸操作  
- 导航链接的字体大小为14px，并保留足够间距  
- 徽章式按钮的横向内边距为10px，便于点击  
- 移动端菜单切换按钮采用半径为50%的圆形设计  

### 布局折叠策略  
- 主图区域：初始显示尺寸为48px，缩小时会按比例保持负字距效果  
- 导航栏：水平链接与行动号召按钮 → 平板端转为汉堡菜单  
- 功能卡片：3列布局 → 2列布局 → 单列堆叠布局  
- 代码截图：保持原有宽高比，可能需横向滚动  
- 信任栏标志：网格布局 → 水平滚动显示  
- 页脚：多列布局 → 堆叠式单列布局  
- 区块间距：移动端从80px以上缩小至48px  

### 图片显示规则  
- 控制台截图在所有尺寸下均保持原有的边框处理方式  
- 移动端上主图渐变效果会变得更柔和、更简单  
- 产品截图采用响应式图片，并保持一致的圆角设计  
- 全宽区域始终保持边缘到边缘的完整显示效果

### 组件提示词示例

### 优化迭代指南  
1. 始终优先使用阴影作为边框替代传统的CSS边框——`0px 0px 0px 1px rgba(0,0,0,0.08)`是基础格式  
2. 字距应随字体大小同步变化：48px时为-2.4px，32px时为-1.28px，24px时为-0.96px，14px时为正常值  
3. 仅使用三种字重：400（用于正文阅读）、500（用于界面交互元素）、600（用于标题显示）  
4. 颜色仅具有功能意义，不可用于装饰——工作流相关颜色（红/粉/蓝）仅用于标识不同流程阶段  
5. 卡片阴影中的内部`#fafafa`环形层是让Vercel卡片呈现微妙内发光效果的关键  
6. 技术标签应使用Geist Mono粗体字体，其他内容则统一使用Geist Sans字体
