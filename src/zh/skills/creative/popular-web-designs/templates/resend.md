## 1. 视觉主题与氛围

Resend 的网站采用深色电影风格设计，将邮件服务视作高端奢侈品来呈现。整个页面以纯黑色（`#000000`）为背景，文字则以近乎白色的色调（`#f0f0f0`）呈现，营造出如同在虚无舞台上演出的剧场般体验。这与典型的开发者工具式深色界面不同——它更像是摄影画廊里经过精心控制的暗光环境，每个元素都受到精准的照明处理，互不干扰地吸引用户的注意力。

字体系统是整个设计的焦点。三种精心挑选的字体共同构成了层次分明的视觉结构，兼具编辑风格与技术感：Domaine Display（由Klim Type Foundry设计的一款衬线字体）被用于标题，字号高达96像素，行高极低（1.00），字距负值达-0.96像素，营造出类似杂志封面的视觉效果。Dinamo设计的ABC Favorit则用于章节标题，其字距调整更为激进——在56像素的字号下字距为-2.8像素，从而使中层文本呈现出紧凑而富有设计感的特点。Inter字体则负责正文与用户界面内容，凭借出色的可读性让那些展示用字体更加突出。最后，Commit Mono字体则为代码块提供了合适的显示效果。

Resend的独特之处在于其带有蓝色调的冰凉边框系统。它没有使用中性的灰色边框，而是采用了`rgba(214, 235, 253, 0.19)`这一参数——即透明度为19%的淡蓝色线条，为每一个容器和分隔线增添了冷峻、如水晶般的质感，与黑色背景形成鲜明对比。再结合药丸形状的按钮（半径为9999像素）、多色强调色系统（橙色、绿色、蓝色、黄色、红色，每种颜色都有独立的CSS变量），以及OpenType风格集（`"ss01"`、`"ss03"`、`"ss04"`、`"ss11"`），最终造就了一个高端、精准且充满自信的设计系统。

**主要特点：**
- 纯黑色背景搭配近乎白色的文字（`#f0f0f0`）——营造出类似剧院或画廊般的深邃氛围  
- 三级字体层级：Domaine Display（用于标题，衬线字体）、ABC Favorit（用于几何结构部分，无衬线字体）、Inter（用于正文与用户界面元素）  
- 带冰蓝色调的边框：`rgba(214, 235, 253, 0.19)`——每条边框都带有清冷、如水晶般的闪光效果  
- 多色强调色系统：橙色、绿色、蓝色、黄色、红色——每种颜色均配有编号的CSS变量配色方案  
- 圆形按钮与标签（半径为9999像素），背景透明  
- 显示字体应用了OpenType风格集（`"ss01"`、`"ss03"`、`"ss04"`、`"ss11"`）  
- 代码部分使用Commit Mono字体——将等宽字体视为设计元素而非临时补充  
- 阴影效果极为柔和，采用带蓝色调的环形阴影：`rgba(176, 199, 217, 0.145) 0px 0px 0px 1px`

### 设计原则
- **三级字体层级结构**：标题区域使用 Domaine Display（衬线体，用于主标题），内容板块采用 ABC Favorit（几何无衬线体），正文则使用 Inter（易读性强的字体）。每种字体都有明确的用途，绝不会相互混用。
- **标题区域采用较大的负字距**：Domaine 字体的负字距为 -0.96px，ABC Favorit 为 -2.8px。这样的设计能让标题显得更为紧凑、富有紧迫感，极具设计感，类似杂志的页眉风格。
- **导航栏采用正字距**：ABC Favorit 导航链接的字母间距设置为 +0.35px，这是整个系统中唯一的正字距设置。这样的处理让导航文字显得更加疏朗，与紧凑的标题形成鲜明对比。
- **OpenType 字形特性作为设计亮点**：所有 ABC Favorit 和 Domaine 字体都启用了 `"ss01"`、`"ss03"`、`"ss04"`、`"ss11"` 这些风格集，从而展现出不同的字形变体，为 Resend 的排版赋予独特的特色。
- **将等宽字体作为设计元素**：等宽字体并不会仅限于代码块中使用，它会被广泛用于代码示例和技术内容中，被视为一种重要的视觉元素。

## 5. 布局原则

### 空间系统
- 基本单位：8px
- 可用比例值：1px、2px、4px、5px、6px、7px、8px、10px、12px、16px、20px、24px、30px、32px、40px

### 网格与容器
- 内容居中显示，并设置合理的最大宽度
- 全宽黑色区域，内部内容有明确边界
- 顶部为单列展示区，下方依次为功能网格
- 代码预览面板可为全宽展示或有限空间展示形式

### 空白设计理念
- **电影级黑色空白**：黑色背景本身即为空白。各板块之间设置充足的垂直间距（80px–120px+），营造出逐屏浏览的沉浸式黑暗体验，让每个板块如同场景般依次呈现。
- **紧凑内容与广阔背景**：文本块和卡片内部结构紧凑，但悬浮在广阔的黑色空间中——从而形成孤立的“内容岛屿”。
- **以排版引领节奏**：巨大的显示字体（96px）形成了独特的垂直节奏感——每个标题都如同视觉焦点，为周围空间定下基调。

### 圆角比例表
- 锋利（4px）：按钮（半透明）、输入框、小型交互元素  
- 微妙（6px)：菜单面板、导航项  
- 标准（8px）：标签页、内容区块  
- 舒适（10px）：强调元素  
- 卡片式（12px）：剪贴板按钮、中等尺寸容器  
- 大号（16px）：功能卡片、图片、主要按钮  
- 区块级（24px）：大型面板、区域容器  
- 粒子状（9999px）：核心操作按钮、标签、徽章  

## 6. 深度与层次感

| 级别 | 处理方式 | 适用场景 |
|------|----------|----------|
| 平面（第0级） | 无阴影，透明背景 | 默认样式——适用于深色背景上的大多数元素 |
| 环形（第1级） | `rgba(176, 199, 217, 0.145) 0px 0px 0px 1px` | 以阴影作为卡片和容器的边框 |
| 冰霜边框（第1b级） | `1px solid rgba(214, 235, 253, 0.19)` | 明确的边框设计——适用于按钮、分隔线、标签页 |
| 微妙层次（第2级） | `rgba(0, 0, 0, 0.1) 0px 1px 3px, rgba(0, 0, 0, 0.1) 0px 1px 2px -1px` | 轻微的卡片凸起效果 |
| 焦点状态（第3级） | `rgb(0, 0, 0) 0px 0px 0px 8px` | 浅黑色焦点环——提升可访问性 |

**阴影设计理念**：Resend几乎不使用传统阴影效果。在纯黑色背景上，传统阴影根本不可见——因为无法在虚空中投下阴影。因此，Resend通过其特有的冰霜边框（`rgba(214, 235, 253, 0.19)`）来营造深度感——这些淡蓝色的细线能在黑暗背景下反射光线。这种设计营造出“悬浮在空中的玻璃面板”般的视觉效果，使边框成为实现层次感的主要手段。

### 装饰性深度效果
- 主要内容区域背后采用柔和的暖色调渐变光效（橙色/琥珀色系）  
- 产品截图通过其内置界面设计营造视觉深度  
- 避免使用渐变背景——层次感应通过边框亮度和内容对比度来实现  

## 7. 正确做法与禁忌  

### 正确做法  
- 将纯黑色（`#000000`）作为页面背景——空白本身即构成画布  
- 为所有结构线条应用半透明冰晶边框（`rgba(214, 235, 253, 0.19)`），这种蓝色调元素可作为品牌标识  
- 仅对主标题使用 Domaine Display 字体（96px），章节标题使用 ABC Favorit，其他所有内容均使用 Inter 字体  
- 在 Domaine 和 ABC Favorit 字体中启用 OpenType 特性 `"ss01"`、`"ss04"`、`"ss11"`  
- 为主要行动号召按钮和标签设置圆角半径（9999px）  
- 采用多色强调色方案（橙色/绿色/蓝色/黄色/红色），并搭配不同透明度以实现针对性高亮  
- 阴影效果保持在环状层级（`0px 0px 0px 1px`）——在黑色背景上，传统阴影效果并不适用  
- 为 ABC Favorit 导航链接设置 +0.35px 的字距——这是唯一允许的正向字距调整  

### 禁忌事项
- 请勿将背景色亮度调高至 `#000000` 以上——纯黑色背景是必须遵守的准则  
- 禁止使用中性灰色边框——所有边框都必须带有冰霜蓝色色调  
- 不得对正文应用 Domaine Display 字体——该字体仅适用于显示用途  
- 同一组件内不可混用多种强调色——每个功能仅可使用一种强调色  
- 在深色背景下，不要通过阴影来营造立体感——应改用冰霜风格边框  
- 请勿省略 OpenType 样式集——它们决定了文字的排版特性  
- 导航链接不应使用负值字距——ABC Favorit 的导航链接采用 +0.35px 的正值字距  
- 按钮在深色背景下不可设为不透明——应结合冰霜边框来实现透明效果  

## 8. 响应式行为

### 分界点
| 名称 | 宽度 | 主要变化 |
|------|-------|-----------|
| 小型移动端 | <480px | 单列布局，紧凑的内边距，76.8px 高度的头部区域 |
| 移动端 | 480–600px | 标准移动端布局，堆叠式排列 |
| 桌面端 | >600px | 完整布局，96px 高度的头部区域，内容区域更宽敞 |

*注：Resend 采用极简的分界点系统——仅检测到 480px 和 600px 两个阈值。该设计以桌面端为优先，移动端则采用简洁的折叠样式。*

### 触控目标区域
- 圆形按钮：需具备足够的内边距（至少 5px × 12px）  
- 标签项：半径为 8px，且触控区域需足够舒适  
- 导航链接之间需保留 0.35px 的间距，以实现视觉分隔  

### 折叠策略
- 标题区域：桌面端为96像素，移动端缩小至76.8像素  
- 导航栏：水平布局改为汉堡菜单样式  
- 功能板块：并排显示改为堆叠显示  
- 代码面板：保持宽度不变，必要时支持水平滚动  
- 各元素间距会按比例相应缩小  

### 图片显示规则
- 产品截图将保持原有宽高比  
- 深色主题下的截图在所有尺寸下都能与深色背景完美融合  
- 所有断点处均保留12像素至16像素的圆角设计  

## 9. 智能体提示词指南

### 颜色快速参考表
- 背景色：虚空黑 (`#000000`)  
- 主要文本色：接近白色 (`#f0f0f0`)  
- 辅助文本色：银色 (`#a1a4a5`)  
- 边框色：冰霜边框 (`rgba(214, 235, 253, 0.19)`)  
- 橙色强调色：`#ff801f`  
- 绿色强调色：`#11ff99`（透明度为18%）  
- 蓝色强调色：`#3b9eff`  
- 焦点环颜色：`rgb(0, 0, 0) 0px 0px 0px 8px`  

### 组件提示词示例
- “创建一个位于纯黑色（#000000）背景上的头部区域。标题字体为Domaine Display，大小96像素，字体粗细400，行高1.00，字距为-0.96像素；文字颜色为接近白色的#f0f0f0，支持OpenType字体特征‘ss01 ss04 ss11’。副标题字体为ABC Favorit，大小20像素，字体粗细400，行高1.30。此外还包括两个圆形按钮：一个为纯白色（#ffffff，圆角9999像素），另一个为半透明并带有冰晶状边框（rgba(214,235,253,0.19)）。”
- “设计导航栏：采用深色背景，并在底部添加冰晶状边框（1像素宽的rgba(214,235,253,0.19)实线边框）。导航链接字体为ABC Favorit，大小14像素，字体粗细500，字距为+0.35像素，支持OpenType字体特征‘ss01 ss03 ss04’。右侧则放置一个白色的圆形操作按钮。”
- “制作功能卡片：背景透明，带有冰晶状边框（rgba(214,235,253,0.19)），圆角为16像素。标题字体为ABC Favorit，大小56像素，字体粗细400，字距为-2.8像素。内容文字则使用Inter字体，大小16像素，字体粗细400，颜色为#a1a4a5。”
- “在深色背景上创建代码块，代码字体为Commit Mono，大小16像素。代码块容器带有冰晶状边框，圆角为24像素。语法高亮颜色分别为橙色（#ff801f）、蓝色（#3b9eff）、绿色（#11ff99）和黄色（#ffc53d）。”
- “设计强调徽章：背景为透明度为22%的#ff5900色，文字颜色为#ffa057，圆角为9999像素，文字使用Inter字体，大小12像素，字体粗细500。”
1. 从纯黑色开始——所有元素都悬浮在虚空中。  
2. 冰霜色边框（`rgba(214, 235, 253, 0.19)`）是通用的结构元素，既非灰色也非中性色调。  
3. 三种字体承担不同功能：Domaine用于标题区域，ABC Favorit用于章节标题，Inter用于正文内容——严禁混用。  
4. 显示字体必须使用OpenType风格集，它决定了字符的呈现效果。  
5. 背景颜色采用低透明度（12–42%）的多色点缀，而文字则使用全透明度。  
6. CTA按钮和徽章采用pill形状（9999像素），容器则使用标准圆角半径（4px–16px）。  
7. 禁止使用阴影效果——依靠冰霜色边框来营造出在虚空中的深度感。
