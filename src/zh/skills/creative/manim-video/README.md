# Manim 视频生成技能

基于 [Manim Community Edition](https://www.manim.community/) 构建的数学与技术动画制作流程。

## 功能说明

该技能能够根据文本提示生成类似 3Blue1Brown 风格的动画视频。智能体可全程处理整个制作流程：创意策划、Python 代码生成、渲染、场景拼接以及迭代优化。

## 典型应用场景

- **概念讲解** — “解释神经网络是如何学习的”
- **公式推导** — “为勾股定理的证明制作动画”
- **算法可视化** — “逐步展示快速排序的工作原理”
- **数据呈现** — “用动画展示性能指标的改进过程”
- **架构图展示** — “逐步呈现微服务架构的构建过程”

## 前提条件

Python 3.10 及以上版本、Manim CE（通过 `pip install manim` 安装）、LaTeX 编辑器以及 ffmpeg 工具。

```bash
bash skills/creative/manim-video/scripts/setup.sh
```
