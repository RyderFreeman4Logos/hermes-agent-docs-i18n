# 宝可梦游戏模拟器

通过使用 `pokemon-agent` 包，在无界面模拟环境中运行宝可梦游戏。

## 适用场景
- 用户说出“玩宝可梦”、“启动宝可梦游戏”等类似语句；
- 用户询问关于《宝可梦红》、《宝可梦蓝》、《宝可梦黄》、《火红》等游戏的信息；
- 用户希望观看人工智能扮演角色进行宝可梦游戏；
- 用户提及 ROM 文件（.gb、.gbc、.gba 格式）。

## 启动流程

### 1. 首次设置（克隆仓库、创建虚拟环境、安装包）
该项目的 GitHub 地址为 NousResearch/pokemon-agent。首先克隆该仓库，随后创建一个 Python 3.10 及以上版本的虚拟环境。推荐使用 uv 工具来快速创建虚拟环境，并以可编辑模式安装包含 pyboy 扩展功能的包；如果未安装 uv，则可使用 python -m venv + pip 的方式替代。

如果已有相关设置（例如在 ~/pokemon-agent 目录下已存在准备好的虚拟环境），可直接进入该目录并执行 .venv/bin/activate 命令激活虚拟环境，无需重新克隆仓库。

此外还需要一个 ROM 文件。请向用户索取该文件（之前的设置中可能在仓库内的 roms/pokemon_red.gb 目录下已有相关文件）。**绝不要自行下载或提供 ROM 文件**，务必始终询问用户。

### 2. 启动游戏服务器
在已激活虚拟环境的 pokemon-agent 目录下，运行 `pokemon-agent serve` 命令，同时指定 --rom 参数指向对应的 ROM 文件，并设置端口为 9876。可使用 & 符号将命令在后台运行。若要从保存的游戏状态继续游玩，可添加 --load-state 参数并指定保存文件的名称。等待约 4 秒让服务器启动完成，随后可通过访问 GET /health 接口来验证服务器状态。

### 3. 设置实时仪表板供用户查看
通过 localhost.run 建立 SSH 反向隧道，使用户能够在浏览器中查看仪表板。使用 ssh 连接，并将本地的 9876 端口转发到无密钥的 localhost.run 服务器端的 80 端口（命令：ssh -R 80:localhost:9876 ssh://nokey@localhost.run）。将输出重定向到日志文件，等待 10 秒后，通过 grep 在日志中查找 .lhr.life URL。随后将带有 /dashboard/ 后缀的 URL 提供给用户。该隧道 URL 每次都会变化——如果服务重新启动，需将新地址告知用户。

## 保存与加载

### 何时保存
- 每进行 15–20 轮游戏后
- 在参加道馆对战、对手对决或高风险战斗之前务必保存
- 进入新城镇或地下城之前
- 对任何不确定的操作执行前都应保存

### 如何保存
发送 POST /save 请求，并指定描述性名称。推荐示例：
before_brock、route1_start、mt_moon_entrance、got_cut

### 如何加载
发送 POST /load 请求，并提供保存时的名称。

### 列出所有可用保存状态
发送 GET /saves 请求即可查看所有已保存的状态。

### 在服务器启动时自动加载
启动服务器时可使用 --load-state 参数来自动加载某个保存状态。这种方式比启动后再通过 API 加载更快。

## 游戏流程循环

### 第一步：观察——检查状态并截取屏幕截图
发送 GET /state 请求以获取角色位置、生命值、战斗状况及对话内容。同时发送 GET /screenshot 请求并将截图保存到 /tmp/pokemon.png 文件中，随后使用 vision_analyze 工具进行分析。这两步必须同时执行——内存状态提供数值数据，而视觉分析则有助于了解空间布局。

### 第二步：定位方向
- 屏幕上的对话/文字 → 向前推进  
- 战斗中 → 攻击或逃跑  
- 队友受伤 → 前往宝可梦中心  
- 接近目标点 → 小心行进  

### 第3步：决策  
优先级：对话 > 战斗 > 治疗 > 故事目标 > 训练 > 探索  

### 第4步：执行——最多移动2-4步，然后重新检查  
通过POST /action发送简短的行动列表（2-4个动作，而非10-15个）。  

### 第5步：验证——每次行动序列后截屏  
截取屏幕并使用vision_analyze工具确认是否已移动到预定位置。这是**最关键的一步**，若没有视觉功能，你必定会迷路。

## 动作参考  
- press_a — 确认、对话、选择  
- press_b — 取消、关闭菜单  
- press_start — 打开游戏菜单  
- walk_up/down/left/right — 移动一格  
- hold_b_N — 按住B键N帧（用于快速浏览文字）  
- wait_60 — 等待约1秒（60帧）  
- a_until_dialog_end — 不断按A键直到对话结束  

## 根据经验总结的关键提示  

### 持续使用视觉功能  
- 每移动2-4步就截取一次屏幕  
- RAM状态可显示位置和生命值，但无法展示周围环境  
- 梯台、围栏、标识牌、建筑门、NPC——只能通过截图查看  
- 可向视觉模型提出具体问题，例如：“我正北方一格是什么？”  
- 当陷入困境时，务必先截屏，再尝试随机方向移动
### 异地传送需要额外等待时间  
在穿过门或楼梯时，地图切换期间屏幕会变黑。您必须等待该过程完成。在任何通过门或楼梯的异地传送后，需添加2到3次wait_60指令。如果不等待，角色位置信息将会失效，导致您误以为自己仍处于旧地图中。

### 出入建筑物时的陷阱  
当您离开建筑物时，会直接出现在门的正前方。如果您向北行走，就会再次回到建筑物内。务必先向左或向右移动2格以绕到侧面，然后再朝预定方向前进。

### 对话处理  
第一代系统的文本会逐个字母缓慢滚动。若想加快对话阅读速度，可按住B键120帧后再按下A键，根据需要重复操作。按住B键可使文本以最快速度显示，随后按下A键即可切换到下一行。a_until_dialog_end指令虽能检测RAM中的对话状态标志，但该标志无法覆盖所有文本显示情况。如果发现对话似乎卡住了，建议改用手动按住B键再按下A键的方法，并通过截图确认情况。

### 缸道为单向通道  
缸道（小型悬崖边缘）仅可向下（向南）跳跃，绝不能向上（向北）攀爬。若前方有缸道阻挡去路，必须向左或向右移动以找到其周围的缺口。可使用视觉功能判断缺口的方位，也可直接询问视觉模型。

### 导航策略
- 每次移动2到4步，然后截屏确认位置  
- 进入新区域时立即截屏以便定位  
- 向视觉模型询问“去[目的地]该往哪个方向走？”  
- 若尝试3次以上仍无法前进，需截屏并重新全面评估情况  
- 避免连续进行10到15次移动——否则可能会越界或陷入困境  

### 从战斗菜单逃跑  
在战斗菜单中，“RUN”选项位于右下角。若当前光标位于默认位置（左上角的“FIGHT”），需先向下再向右移动光标至“RUN”处，随后按下A键。按住hold_b可加速浏览文字与动画。  

### 开战（FIGHT）  
在战斗菜单中，“FIGHT”选项位于左上角（即默认光标位置）。按下A键进入招式选择界面，再次按下A键即可使用第一个招式。接着按住B键可加快攻击动画与文字的显示速度。  

## 战斗策略  

### 决策树  
1. 想捕捉？→ 先削弱对手再投掷精灵球  
2. 不需要捕获野怪？→ 立即逃跑  
3. 有属性优势？→ 使用超效招式  
4. 没有属性优势？→ 使用最强同类相克招式  
5. 对手生命值较低？→ 更换对手或使用药水  

### 第一代属性相克表（关键对战关系）  
- 水属性克制火、地面、岩石属性  
- 火属性克制草、虫、冰属性  
- 草属性克制水、地面、岩石属性  
- 电属性克制水、飞行属性  
- 地面属性克制火、电、岩石、毒属性  
- 心灵属性克制格斗、毒属性（在第一代中极具优势！）  

### 第一代特殊特性
- 特殊技能的专属属性 = 进攻与防御能力兼备  
- 心灵属性过于强大（幽灵系技能存在漏洞）  
- 临界命中率取决于速度属性值  
- “缠绕/束缚”技能可阻止对手行动  
- “聚气”技能存在错误：会降低临界命中率而非提升它

## 成长里程碑
- 选择初始宝可梦  
- 从绿叶市场送回包裹并获取图鉴  
- “巨石徽章”——布洛克（岩石系）→ 使用水系/草系技能  
- “瀑布徽章”——米斯蒂（水系）→ 使用草系/电系技能  
- “雷电徽章”——萨吉（电系）→ 使用地面系技能  
- “彩虹徽章”——艾丽卡（草系）→ 使用火系/冰系/飞行系技能  
- “灵魂徽章”——科加（毒系）→ 使用地面系/心灵系技能  
- “沼泽徽章”——萨布丽娜（心灵系）→ 最难的道馆挑战  
- “火山徽章”——布莱恩（火系）→ 使用水系/地面系技能  
- “大地徽章”——乔瓦尼（地面系）→ 使用水系/草系/冰系技能  
- 击败四强 → 决战冠军！  

## 中止游戏
1. 通过POST /save命令使用描述性名称保存游戏  
2. 用PKM:PROGRESS更新记忆标记  
3. 告诉用户：“游戏已保存为[名称]！输入‘play pokemon’即可继续游戏。”  
4. 关闭服务器并终止后台进程
## 常见陷阱
- 绝对不要下载或提供 ROM 文件
- 未经视觉确认，切勿一次性发送超过 4-5 个操作指令
- 离开建筑物后向北移动前，务必先绕行至侧面
- 在通过门或楼梯传送后，务必添加两次 60 秒的等待时间
- 通过 RAM 进行对话检测并不可靠——请通过截图进行验证
- 在面临高风险情况之前务必先保存进度
- 每次重启后，隧道的 URL 都会发生变化
