# OBLITERATUS 方法——详细指南

> 命令行工具可通过 `--method` 参数选择 9 种方法：basic、advanced、aggressive、spectral_cascade、informed、surgical、optimized、inverted、nuclear。另有四种方法（failspy、gabliteration、heretic、rdo）仅能通过 Python API 使用。

## 消除机制的工作原理（理论基础）

消除机制会识别出“拒绝方向”——即模型激活空间中与拒绝行为相对应的向量——并将其从权重矩阵中剔除。

数学表达式为：`W_new = W_old - (W_old @ d @ d.T)`，其中 `d` 即为该拒绝方向。

核心挑战在于在不损害模型其他功能的前提下，精准定位这些拒绝方向。

---

## 方向提取方法

在执行投影操作之前，OBLITERATUS 会通过以下三种方法之一来提取拒绝方向：

| 方法 | 参数标志 | 描述 | 最佳适用场景 |
|:-------|:-----|:------------|:---------|
| Diff-in-Means | `--direction-method diff_means` | 计算被拒绝提示与被接受提示的激活值均值差异 | 默认选项，速度快且稳定性高 |
| SVD | `--direction-method svd` | 通过奇异值分解实现多方向提取 | 面临复杂对齐问题或存在多重拒绝机制的场景 |
| LEACE | `--direction-method leace` | 基于封闭形式估计的线性消除方法——数学上最为优化 | 需要最高精度时的研究场景 |

## 各方法详细说明

### basic
- **方向数量：** 1个（单个 Diff-in-Means 向量）
- **速度：** 快（8B 模型约需 5-10 分钟）
- **风险：** 低
- **适用场景：** 快速测试、原型开发，以及验证该模型是否适合使用消除机制
- **工作原理：** 提取一个拒绝方向，然后将其均匀地应用到所有层中

### advanced（默认选项——推荐使用）
- **方向数量：** 4个（多方向 SVD 方法）
- **速度：** 中等（8B 模型约需 10-20 分钟）
- **风险：** 低至中等
- **优化迭代次数：** 2次
- **适用场景：** 大多数模型的默认选择，经过充分测试且稳定性良好
- **工作原理：** 通过 SVD 提取多个拒绝方向，同时运用保范双投影技术来维持权重矩阵的范数。后续两次优化迭代可进一步消除残留的拒绝行为

### aggressive
- **方向数量：** 8个以上（白化 SVD 方法 + 强制合规对比方法）
- **速度：** 中等至较慢
- **风险：** 中高（可能损害模型的连贯性）
- **适用场景：** 当使用 `advanced` 方法后仍有超过 10% 的拒绝行为，或面对顽固模型的情况
- **工作原理：** 先通过白化 SVD 实现基于协方差标准化的方向提取，再加入强制合规对比方向，最后对那些最容易引发拒绝行为的注意力头进行针对性处理

### spectral_cascade
- **速度：** 中等
- **风险：** 中等
- **适用场景：** 研究工作及探索新型方法
- **工作原理：** 对拒绝信号进行离散余弦变换（DCT）频域分解，从而区分高频的（表面层面的）与低频的（深层结构中的）拒绝模式

### informed（实验性功能）
- **速度：** 慢（8B 模型约需 20-40 分钟）
- **风险：** 不稳定——结果取决于分析质量
- **适用场景：** 当需要自动配置时使用，但请注意该功能仍处于实验阶段，其效果未必优于 `advanced` 方法
- **工作原理：** 首先运行 4 个分析模块（对齐印记分析、概念几何分析、逻辑斯蒂透镜分析、奥罗伯罗斯循环检测），随后自动确定提取策略。该方法还包含一个“奥罗伯罗斯循环”，可用于检测并抵消模型的自我修复行为
- **注意：** 自动检测功能有时可能会出现配置错误。如果分析结果不佳，建议改用 `advanced` 方法

### surgical
- **速度：** 极慢（8B 模型约需 1-2 小时）
- **风险：** 低（精度极高）
- **适用场景：** 需要保留思维链的推理模型（如 R1 distills、QwQ 等）
- **工作原理：** 结合稀疏自编码器特征、单个神经元屏蔽技术、注意力头针对性处理，以及针对混合专家架构的专家级分解功能。该方法具备思维链感知能力，会在执行投影操作之前识别并保护对推理至关重要的方向

### optimized
- **速度：** 极慢（需运行大量试验，耗时数小时）
- **风险：** 低（可找到最优参数组合）
- **适用场景：** 当质量比速度更为重要时的生产环境模型
- **工作原理：** 通过 Optuna TPE 采样器进行贝叶斯超参数搜索，同时优化方向数量、正则化强度、优化迭代次数以及层选择策略。会通过拒绝率与困惑度指标来评估每种配置的效果

### inverted
- **速度：** 快
- **风险：** 高（模型行为会发生显著变化）
- **适用场景：** 研究工作，用于分析模型的拒绝机制
- **工作原理：** 不是直接剔除拒绝方向，而是对其进行反射处理。这样模型会主动选择合规响应，而非被动地避免拒绝。该方法有助于深入理解模型对齐的几何结构

### nuclear
- **速度：** 慢
- **风险：** 中高
- **适用场景：** 面临顽固混合专家架构模型（如 DeepSeek-MoE、Mixtral 等）的情况
- **工作原理：** 结合专家级精细消除技术、引导向量注入、注意力头剪枝以及多轮优化迭代。针对混合专家架构，会将拒绝信号分解为各个专家组对应的独立成分

## 方法选择流程图

```
Is this a quick test?
  → YES: basic
  → NO: continue

Is it an MoE model (Mixtral, DeepSeek-MoE)?
  → YES: nuclear
  → NO: continue

Is it a reasoning model (R1, QwQ, CoT-focused)?
  → YES: surgical
  → NO: continue

Do you need the absolute best quality and have time?
  → YES: optimized
  → NO: advanced (recommended default)

Did advanced leave > 10% refusals?
  → YES: aggressive
  → Still refusing: nuclear
```

## 关键参数

| 参数 | 取值范围 | 默认值 | 效果说明 |
|:----------|:------|:--------|:-------|
| `--n-directions` | 1-32 | 视方法而定 | 方向数越多，清除效果越彻底，但造成损伤的风险也越高 |
| `--regularization` | 0.0-1.0 | 0.1 | 值越大，策略越保守（清除量越少，损伤越小） |
| `--refinement-passes` | 1-5 | 2 | 迭代次数越多，越能消除残留的拒绝现象，但收益逐渐递减 |
| `--quantization` | 4bit、8bit | 无 | 可降低显存占用；对提取质量的影响极小 |
| `--verify-sample-size` | 10-200 | 20 | 样本数量越多，拒绝率估算的准确性越高 |

## 故障排除

| 问题现象 | 可能原因 | 解决方案 |
|:--------|:-------------|:----|
| 拒绝率 > 20% | 方向数过少 | 增加 `--n-directions` 的数值，尝试使用 `aggressive` 模式 |
| 拒绝率在 5-20% 之间 | 存在残留拒绝现象 | 增加 `--refinement-passes 3` 的数值，尝试使用 `--direction-method svd` |
| 混乱度飙升 > 20% | 清除力度过大 | 减少 `--n-directions` 的数值，提高 `--regularization` 的值 |
| 输出内容重复 | 权重矩阵受损 | 使用方向数较少的 `basic` 模式，并检查范数是否得以保留 |
| MoE 模型仍出现拒绝现象 | 使用了非专家感知型方法 | 更改为 `nuclear` 模式 |
| 推理质量下降 | 逻辑推导方向受损 | 使用 `surgical` 方法 |
| 提取过程中出现内存不足 | 显存容量不足 | 添加 `--quantization 4bit` 和/或 `--large-model` 参数 |
