## 环境要求

该技能依赖**无界面版 openpyxl**——即需在磁盘上生成 .xlsx 文件。  
在处理单元格着色、公式、命名范围及敏感性分析表时，需遵循 `excel-author` 技能的规范。  
交付前请先重新计算：`python /path/to/excel-author/scripts/recalc.py ./out/model.xlsx`。
```bash
python /path/to/excel-author/scripts/recalc.py model.xlsx
```
必须以零错误的状态返回成功结果。

### 各板块平衡性检查
- [ ] 所有需要保持平衡的板块（如收入与支出、资产与负债）都必须完全相等
- [ ] 用作平衡数值的插入项计算正确
- [ ] 不同板块之间应相互匹配的金额需保持一致

### 收入/运营预测
- [ ] 根据驱动因素或增长率正确计算出营收或总营收额
- [ ] 所有成本和费用项目均得到恰当计算
- [ ] 小计与总计的数值相加正确
- [ ] 利润率和各项比率均处于合理范围
- [ ] 对应假设条件的链接准确无误

### 资产负债表（如适用）
- [ ] 资产 = 负债 + 所有者权益（必须保持平衡）
- [ ] 所有项目均与相应的明细表或滚动计算结果相关联
- [ ] 期初余额等于上一期间的期末余额
- [ ] 已包含校验行，且其显示数值为零

### 现金流表（如适用）
- [ ] 以正确的收入数值作为起始点
- [ ] 非现金项目被恰当地添加或扣除
- [ ] 流动资本的变化具有正确的符号
- [ ] 期末现金 = 期初现金 + 净现金流
- [ ] 各报表中的现金余额保持一致

### 支持性明细表
- [ ] 滚动计算的明细表保持平衡（期初余额 + 变动额 = 期末余额）
- [ ] 各明细表与主报表之间的链接正确
- [ ] 计算所得的数值使用了恰当的驱动因素
- [ ] 所有期间的计算结果均保持一致

### 债务/融资明细表（如适用）
- [ ] 期初余额可追溯至数据来源或上一期间
- [ ] 利息是基于适当的余额（通常为期初余额）进行计算的
- [ ] 偿还金额需考虑现金可用性及优先级
- [ ] 期末余额不得为负数
- [ ] 各部分的总计数值相加正确

### 收益/回报分析
- [ ] 退出价值/终端价值计算正确
- [ ] 已包含所有相关的调整项
- [ ] 现金流的符号正确（投资活动为负，所得资金为正）
- [ ] IRR/MOIC公式所引用的数据范围完整
- [ ] 分析结果与给定场景相符合

### 敏感性分析表（如适用）
- [ ] 表格的行列尺寸为奇数（如5×5或7×7），从而存在真正的中心单元格
- [ ] 行和列的数值以基准情况为中心对称分布（`[base-2Δ, base-Δ, base, base+Δ, base+2Δ]`）
- [ ] 中心单元格的输出值等于模型实际的IRR/MOIC数值，以此确认表格的连接逻辑正确
- [ ] 中心单元格会被高亮显示——填充色为中等蓝色`#BDD7EE`，字体加粗
- [ ] 行和列的标题包含恰当的输入数值
- [ ] 每个数据单元格都包含公式（而非硬编码值）
- [ ] 每个数据单元格显示的数值各不相同
- [ ] 数值变化方向符合预期（退出倍数越高，IRR通常也越高，以此类推）

### 格式规范
- [ ] 硬编码的输入数值显示为蓝色（0000FF）
- [ ] 计算得出的公式数值显示为黑色（000000）
- [ ] 同一工作表内的链接显示为紫色（800080）
- [ ] 不同工作表之间的链接显示为绿色（008000）
- [ ] 所有数字均右对齐
- [ ] 全文应用了合适的数字格式
- [ ] 无单元格显示错误值（如#REF!、#DIV/0!、#VALUE!、#NAME?）

### 逻辑合理性检查
- [ ] 数值的数量级处于合理范围
- [ ] 发展趋势符合预期（如增长、下降或稳定）
- [ ] 不存在明显错误的数值（本应为正数却出现负值，百分比不合理等）
- [ ] 核心输出数值处于该类型分析所要求的合理区间内

## 需要避免的常见错误

| 错误类型 | 具体问题表现 | 解决方法 |
|----------|--------------|----------|
| 硬编码计算结果 | 当输入参数发生变化时，模型无法自动更新 | 始终使用引用源单元格的公式 |
| 复制后单元格引用出错 | 公式指向了错误的单元格 | 仔细核对所有链接，合理使用$
