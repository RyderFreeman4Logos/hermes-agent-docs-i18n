# SEC 文件数据提取参考指南

**适用场景：** 仅当模型模板明确要求从 SEC 文件（10-K、10-Q）中提取数据时，才需参考本文件。对于那些可直接提供数据或使用其他数据源的模板，则无需使用本参考指南。

---

## 从 SEC 文件（10-K / 10-Q）中提取数据

在用上市公司数据填充模型模板时，应直接从 SEC 文件中提取财务数据。

### 步骤 1：定位相关文件

1. 使用 SEC EDGAR 网站：`https://www.sec.gov/cgi-bin/browse-edgar?action=getcompany&CIK=[股票代码]&type=10-K`
2. 若需获取季度数据，请使用 `type=10-Q`

### 步骤 2：确定文件所使用的货币单位

在提取数据之前，首先需要明确报告货币：
- 查看封面页或页眉中的报告货币说明
- 观察各类报表的标题（例如“以千美元计”）
- 阅读附注1（重要会计政策概要）

**常见的货币标识符**

| 标识符 | 货币类型 |
|---------|----------|
| $, USD | 美元 |
| €, EUR | 欧元 |
| £, GBP | 英镑 |
| ¥, JPY | 日元 |
| ¥, CNY, RMB | 人民币 |
| CHF | 瑞士法郎 |
| CAD, C$
