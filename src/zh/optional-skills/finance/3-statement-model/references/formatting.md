# 格式标准参考

| 元素 | 格式要求 |
|------|----------|
| 硬编码输入内容 | 蓝色字体 |
| 公式 | 黑色字体 |
| 链接到其他工作表的链接 | 绿色字体 |
| 校验单元格 | 出现错误时显示为红色，平衡时显示为绿色 |
| 负数值 | 使用括号表示，而非减号 |
| 货币金额 | 大额数字不显示小数位，每股数据保留两位小数 |
| 百分比 | 保留一位小数 |
| 表头 | 加粗显示，并添加底部边框 |
| 单位行 | 在表头下方添加单位行（如百万美元、百分比等） |

## 视觉分隔指南

- 历史数据列与预测数据列之间使用细垂直线分隔
- 各部分总计行（例如“总资产”）后添加粗底部边框
- 小计行仅使用单层底部边框
- 总计行则使用双层底部边框

## 总计行与小计行的格式要求

所有总计行及小计行的数值都必须采用**加粗字体**，以便将汇总数据与各项明细清晰区分开来。

| 总成本 | 加粗 |

| 总销售、一般及行政费用 | 加粗 |
| EBITDA | 加粗 |
| EBIT | 加粗 |
| EBT | 加粗 |

| 其他资产总计 | 加粗 |

### 现金流量表选项卡
| 行号 | 格式要求 |
|------|----------|

## 资产负债表校验行的格式要求

资产负债表中的校验行（位于“负债及股东权益总计”下方）会使用条件数字格式，将非零数值以红色显示。当资产负债表平衡无误（校验值=0）时，数值将以黑色或常规格式显示。

| 校验值 | 字体颜色 |
|--------|----------|
| = 0（平衡） | 黑色（常规格式） |
| ≠ 0（出现错误） | 红色 |

**实现方式：** 可应用自定义数字格式 `[Red][<>0]0.00;[Red][<>0](0.00);0.00`，或使用Excel的条件格式功能，设置规则“单元格值≠0”时显示为红色字体。

## 利润率行的格式要求

| 元素 | 格式要求 |
|------|----------|
| 利润率行 | 缩进显示，斜体，保留一位小数 |
| 正向趋势 | 无需特殊格式（或可使用浅绿色标识） |
| 负向趋势 | 标记需进一步核查（使用浅黄色标识） |
| 低于行业平均水平 | 可考虑高亮显示以便讨论 |

## 信用指标的格式要求

| 元素 | 格式要求 |
|------|----------|
| 杠杆比率 | 保留一位小数，并在数值后加上“x”后缀（例如2.5x） |
| 百分比类数据 | 保留一位小数，并在数值后加上“%”后缀 |
| 净负债为负值时 | 使用括号表示，用以体现净现金状况 |
| 选项卡标题 | 加粗显示，内容为“CREDIT METRICS” |
| 分隔线 | 信用指标部分上方添加细边框 |

## 信用指标阈值对应的颜色标识

| 指标 | 绿色 | 黄色 | 红色 |
|------|-------|------|-----|
| 总负债/EBITDA | < 2.5x | 2.5x-4.0x | > 4.0x |
| 净负债/EBITDA | < 2.0x | 2.0x-3.5x | > 3.5x |
| 利息保障倍数 | > 4.0x | 2.5x-4.0x | < 2.5x |
| 负债/总资本上限 | < 40% | 40%-60% | > 60% |
| 流动比率 | > 1.5x | 1.0x-1.5x | < 1.0x |
| 速动比率 | > 1.0x | 0.75x-1.0x | < 0.75x |

## “校验”选项卡的条件格式设置

- 单元格显示通过标识 → 填充绿色
- 单元格显示未通过标识 → 填充红色
- 单元格显示警告标识 → 填充黄色
- 各单元格数值差值为0 → 填充浅绿色
- 各单元格数值差值不为0 → 填充浅红色

## 利润率合理性预警标志

- 毛利率 < 0% → 错误：需核查成本费用
- 毛利率 > 80% → 警告：需核实收入与成本费用情况
- EBITDA利润率 < 0% → 警示：存在经营亏损
- EBITDA利润率 > 50% → 警告：比率过高，需进一步分析
- 净利润率 < 0% → 警示：出现净亏损（处于成长阶段时可能属于正常现象）
- 净利润率高于毛利率 → 错误：公式存在问题
