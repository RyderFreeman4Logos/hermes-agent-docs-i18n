## 环境要求

该技能基于**无界面版 openpyxl**实现——您需要在磁盘上生成 .xlsx 文件。在处理单元格着色、公式、命名范围以及敏感性分析表时，请遵循 `excel-author` 技能的规范。在输出结果前请先重新计算：`python /path/to/excel-author/scripts/recalc.py ./out/model.xlsx`。

# 合并模型

用于构建并购交易中的资产增值/稀释分析模型。可计算备考每股收益影响、协同效应敏感性以及收购价格分配情况。该技能适用于评估潜在收购项目、为演示文稿准备合并后果分析，或为交易条款提供咨询。

## 工作流程

### 步骤 1：收集输入数据

**收购方：**
- 公司名称、当前股价、流通股数量
- 近期及最近一个会计年度的每股收益（GAAP 标准及调整后数值）
- 市盈率
- 税前债务成本、税率
- 资产负债表中的现金余额、现有债务规模

**目标公司：**
- 公司名称、当前股价、流通股数量（如为上市公司）
- 近期及最近一个会计年度的每股收益或净利润
- 企业价值或股权价值

**交易条款：**
- 每股收购价格（或较当前价格的溢价比例）
- 对价构成：现金支付比例与股票支付比例
- 为支付现金部分而新举借的债务
- 预期产生的协同效应（收入和成本方面）及逐步实现的时间表
- 交易费用及融资成本
- 预计完成交易日期

## 重要注意事项

- 在相关情况下，务必同时展示 GAAP 标准下的每股收益及调整后的（现金）每股收益数值。
- 对于股票收购交易：计算换股比率时应使用收购方的当前股价，并注明新增股份带来的稀释效应。
- 需要明确展示收购价格分配情况——对于 GAAP 标准下的每股收益计算而言，商誉和无形资产摊销至关重要。
- 协同效应的逐步实现非常重要——通常第1年的协同效应仅能达到全年预期值的25%至50%。
- 切勿忽略因使用现金而错过的利息收入，以及新举借债务所产生的利息支出。
- 协同效应相关的税收处理及利息调整的税率，应与收购方的边际税率保持一致。

## 数据来源——优先使用 MCP，无法获取时再启用网页搜索

下文多处提到“使用 S&P Kensho MCP / Daloopa MCP / FactSet MCP”等商业金融数据 MCP。这些功能源自原有的 Cowork 插件环境。在 Hermes 环境中：

- **如果您已配置了任何结构化的金融数据 MCP**（Hermes 支持 MCP 功能，参见 `native-mcp` 技能），则优先使用它们来获取特定时间点的财务数据、历史交易案例及监管文件信息。
- **否则**，可采取以下替代方案：
  - 对于美国市场的监管文件，可使用 `web_search` / `web_extract` 功能查询 SEC EDGAR 网站（`https://www.sec.gov/cgi-bin/browse-edgar`）；
  - 从公司的投资者关系页面获取新闻稿和盈利报告；
  - 使用 `browser_navigate` 功能访问交互式数据平台；
  - 若上下文信息不足，可要求用户提供相关数据。
- **绝不可编造数据**。如果无法找到某个倍数、历史案例或文件编号，请将该单元格标记为 `[UNSOURCED]`，并向用户说明情况。
