## 环境要求

该技能依赖**无界面版 openpyxl**——即需在磁盘上生成 .xlsx 文件。  
在处理单元格着色、公式、命名范围及敏感性分析表时，请遵循 `excel-author` 技能的规范。  
交付前请先重新计算：`python /path/to/excel-author/scripts/recalc.py ./out/model.xlsx`。

# 合并模型

用于构建并购交易中的资产增值/稀释分析模型。可测算备考后每股收益的影响、协同效应的敏感性以及收购价格分配情况。适用于评估潜在收购项目、为演示文稿准备合并影响分析，或为交易条款提供咨询。

## 工作流程

### 第一步：收集输入数据

**收购方：**
- 公司名称、当前股价、已发行股数
- 近期及当前会计年度的每股收益（GAAP 标准及调整后）
- 市盈率
- 税前债务成本、税率
- 资产负债表中的现金余额、现有债务

**目标公司：**
- 公司名称、当前股价、已发行股数（若为上市公司）
- 近期及当前会计年度的每股收益或净利润
- 企业价值或股权价值

**交易条款：**
- 每股要约价格（或较当前价格的溢价比例）
- 对价构成：现金支付占比与股票支付占比
- 为支付现金部分而新发行的债务
- 预期产生的协同效应（收入与成本方面）及逐步实现的时间表
- 交易费用及融资成本
- 预计完成交易日期

## 重要注意事项

- 在相关情况下，务必同时展示GAAP标准下的每股收益及调整后的（现金）每股收益。
- 对于股票支付形式的交易：应使用收购方的当前股价作为换股比例，并注明新发行股票带来的稀释效应。
- 需明确标注收购价格分配方式——商誉及无形资产摊销会对GAAP标准下的每股收益产生影响。
- 协同效应的逐步实现至关重要——通常第1年的协同效应仅能达到预期总效果的25%-50%。
- 切勿忽略因使用现金而错过的利息收入，以及新发行债务带来的利息支出。
- 协同效应相关的税率及利息调整项应与收购方的边际税率保持一致。

## 数据来源——优先使用MCP，无法使用时再启用网页接口

下文多处提到“使用S&P Kensho MCP / Daloopa MCP / FactSet MCP”。这些均为源自原Cowork插件环境的商业金融数据MCP服务。在Hermes系统中：- **如果您已配置了结构化的金融数据 MCP**（Hermes 支持 MCP——参见 `native-mcp` 技能），建议优先使用该方式来获取特定时间点的财务数据、历史交易记录及监管申报文件。
- **若未配置 MCP**，则可采取以下替代方案：
  - 对于美国的监管申报文件，可通过 SEC EDGAR 网站（`https://www.sec.gov/cgi-bin/browse-edgar`）使用 `web_search` / `web_extract` 功能进行检索；
  - 从公司的投资者关系页面获取新闻稿和业绩展示材料；
  - 对于交互式数据门户，则可使用 `browser_navigate` 功能；
  - 若上下文信息中缺乏所需数据，可让用户直接提供。
- **绝不可编造数据**。如果无法找到相关倍数、历史交易记录或申报编号，请将该数据单元标记为 `[UNSOURCED]`，并向用户显示。
