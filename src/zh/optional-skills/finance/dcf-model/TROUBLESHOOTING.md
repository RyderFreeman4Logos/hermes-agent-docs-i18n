# DCF模型故障排查指南

**何时查阅本文档：** 当recalc.py脚本出现错误、估值结果不合理，或案例选择器无法正常工作时。

## 模型返回错误值

### #REF! 错误
- 通常是由于在插入表头后，公式引用了错误的行号所致
- 解决方案：使用正确的行号重新构建模型，或按照规划好的结构从头开始
- 预防措施：在编写公式之前先确定所有行的位置

### #DIV/0! 错误
- 发生除以零或引用空单元格的情况
- 解决方案：添加IF语句来处理零值：`=IF([Divisor]=0,0,[Numerator]/[Divisor])`

### #VALUE! 错误
- 计算过程中使用了错误的数据类型（文本而非数字）
- 解决方案：确认所有输入数据均为数字格式

## 估值结果不合理

### 内含价值过高
- 检查终端价值是否超过企业价值的80%
- 确认终端增长率低于加权平均资本成本
- 审核增长假设是否现实
- 考虑利润率预期是否过于乐观

### 内含价值过低
- 核实净债务与净现金的数值是否正确
- 检查加权平均资本成本是否过高
- 审核预测数据是否过于保守
- 考虑终端增长率是否过低
