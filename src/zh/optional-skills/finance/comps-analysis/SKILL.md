## 环境要求

该技能依赖**无界面版 openpyxl**——即需在磁盘上生成 .xlsx 文件。在处理单元格着色、公式、命名范围及敏感度表时，请遵循 `excel-author` 技能的规范。在输出结果前请先重新计算：`python /path/to/excel-author/scripts/recalc.py ./out/model.xlsx`。

# 可比公司分析

## ⚠️ 重要提示：数据源优先级（请首先阅读）

**务必遵循以下数据源层级顺序：**

1. **首要步骤：检查 MCP 数据源**——若可用 S&P Kensho MCP、FactSet MCP 或 Daloopa MCP，应优先使用这些数据源获取财务与交易信息。
2. **若上述 MCP 数据源可用，则切勿使用网络搜索。**
3. **仅当 MCP 数据源不可用时**，方可使用彭博终端、SEC EDGAR 文件或其他机构级数据源。
4. **绝不要将网络搜索作为主要数据源**——其准确性、审计追踪能力及可靠性均无法满足机构级分析的需求。

**为何如此重要？** MCP 数据源能提供经过验证的机构级数据，并附带完整的引用信息。而网络搜索结果可能过时、不准确，或无法满足金融分析的要求。

## 概述
该技能旨在指导智能体构建具备机构级水准的可比公司分析报告，这类分析结合了运营指标、估值倍数及统计基准对比。最终输出为结构化的 Excel/电子表格，便于通过同行对比做出明智的投资决策。

**参考资料与使用建议：**

示例文件 `examples/comps_example.xlsx` 中提供了可比公司分析的范例。在使用该文件或技能目录中的其他示例文件时，请合理运用：

**适宜使用示例的情况：**
- 了解文件的结构层级（各部分之间的逻辑关系）
- 掌握所需的分析严谨程度（统计深度、文档规范等）
- 学习相关原则（清晰的标题、透明的公式、可追溯的审计轨迹）

**不宜直接复制示例的情况：**
- 精确复制格式或具体指标
- 不考虑上下文随意套用布局
- 无视受众群体而统一采用某种视觉风格

**使用前请务必先自问：**
1. **“是否有指定的格式要求？还是需要我调整模板风格？”**
2. **“目标受众是谁？”**（投资委员会、董事会汇报、快速参考资料，还是详细备忘录）
3. **“核心分析问题是什么？”**（估值、增长分析、竞争地位、效率等）
4. **“背景信息是什么？”**（并购评估、投资决策、行业基准对比，还是绩效审查）

**需根据具体情况进行调整：**
- **行业特性**：大型科技巨头与新兴 SaaS 初创企业所需的指标截然不同。
- **行业特定需求**：应尽早加入相关指标（例如科技行业的云服务年度经常性收入、企业客户数量、开发者生态等）。
- **公司熟悉度**：对于知名企业，可减少背景介绍，更多聚焦于差异分析。
- **决策类型**：并购分析所需的侧重点与日常投资组合监控有所不同。

**核心原则**：遵循模板的设计原则（清晰的结构、严谨的统计方法、透明的公式），但需根据具体情境灵活调整实现方式。目标应是产出具备机构级质量的分析报告，而非仅仅模仿机构风格的模板。用户提供的示例及明确偏好始终优先于默认设置。

## 核心理念
**“先构建合理的结构，再让数据讲述故事。”**

从能够引导人们思考关键问题的标题开始，输入干净的数据，编写透明的公式，让统计结果自然呈现。一份优秀的可比公司分析报告，即便非出自原作者之手，也应能立即被理解。

## ⚠️ 重要提示：优先使用公式而非硬编码值 + 分步验证

**必须使用公式，而非硬编码值：**
- 所有衍生数值（利润率、倍数、统计指标等）都必须是通过引用输入单元格的 Excel 公式计算得出——绝不能直接粘贴预先计算好的数值。
- 使用 Python/openpyxl 创建表格时，应写入 `cell.value = "=E7/C7"`（公式字符串），而非 `cell.value = 0.687`（计算结果）。
- 唯一可硬编码的值应是原始输入数据（如收入、EBITDA、股价等），且每项数据都应在对应单元格中添加说明其来源的注释。
- 原因在于：当输入数据发生变化时，模型必须能自动更新。而硬编码的利润率则可能成为日后难以发现的隐患。

**需与用户一起分步验证：**
- 在搭建好结构后 → 在填充数据前向用户展示标题布局。
- 在输入原始数据后 → 在编写公式前向用户展示输入内容，并确认数据来源及时间周期。
- 在编写运营指标公式后 → 在进入估值分析前，先向用户展示计算出的利润率并共同验证其合理性。
- 在计算出估值倍数后 → 在添加统计指标前，先向用户展示这些倍数并确认其合理性。
- **切勿一次性完成整个表格的构建后再呈现结果**——应通过逐环节确认的方式尽早发现错误。

## 第1部分：文档结构与设置

### 标题区域（第1-3行）
```
Row 1: [ANALYSIS TITLE] - COMPARABLE COMPANY ANALYSIS
Row 2: [List of Companies with Tickers] • [Company 1 (TICK1)] • [Company 2 (TICK2)] • [Company 3 (TICK3)]
Row 3: As of [Period] | All figures in [USD Millions/Billions] except per-share amounts and ratios
```

**为何如此重要：** 能立即明确背景信息。任何打开此文件的人都能立刻了解其内容、创建时间以及如何解读相关数据。

### 视觉规范标准（可选——用户偏好及上传的模板始终具有优先级）

**重要提示：** 以下仅为建议性默认设置。请始终以以下顺序为优先：
1. 用户明确的格式偏好
2. 任何上传的模板文件中的格式设定
3. 公司/团队的风格指南
4. 才采用这些默认设置（仅在无其他指导时使用）

**推荐的字体与排版：**
- **字体系列**：Times New Roman（专业、易读，为行业标准）
- **字体大小**：数据单元格为11磅，标题为12磅
- **加粗文本**：章节标题、公司名称、统计指标标签

**默认颜色与阴影——专业蓝/灰色调方案（简洁为佳）：**
- **保持简约**——仅使用蓝色和灰色。严禁使用绿色、橙色、红色或其他多种强调色。一份整洁的报表最多应使用3-4种颜色。
- **章节标题**（例如“运营统计数据与财务指标”）：
  - 深蓝色背景（`#1F4E79`或`#17365D`深蓝色）
  - 白色加粗文本
  - 所有列均应用全行阴影
- **列标题**（例如“公司”、“营收”、“利润率”）：
  - 浅蓝色背景（`#D9E1F2`或类似浅蓝色）
  - 黑色加粗文本
  - 居中对齐
- **数据行**：
  - 公司相关数据使用白色背景
  - 公式用黑色文字显示；硬编码输入值用蓝色文字显示
- **统计行**（最高值、第75百分位数等）：
  - 浅灰色背景（`#F2F2F2`）
  - 黑色文字，标签左对齐
- **完整配色方案即为此四色**：深蓝 + 浅蓝 + 浅灰 + 白色。除非用户模板另有规定，否则不得使用其他颜色。

**推荐的格式规范：**
- **小数精度**：
  - 百分比：保留1位小数（12.3%）
  - 数值倍数：保留1位小数（13.5x）
  - 美元金额：不显示小数，使用千位分隔符（69,632）
  - 以百分比表示的利润率：保留1位小数（68.7%）
- **边框**：无需添加边框（保持简洁外观）
- **对齐方式**：所有指标均居中对齐，以实现整洁统一的外观
- **单元格尺寸**：所有列宽应保持一致，所有行高也应统一（从而形成整洁专业的表格结构）

**注意：** 如果用户提供了模板文件或指定了其他格式，应以该设置为准。

## 第2部分：运营统计数据与财务指标

### 核心列（从这些列开始）
1. **公司**——采用统一格式的公司名称
2. **营收**——规模指标（根据具体情境可为过去12个月、季度或年度数据）
3. **营收增长率**——同比百分比变化率
4. **毛利润**——营收减去销售成本
5. **毛利率**——毛利润/营收（反映基本盈利能力）
6. **EBITDA**——息税折旧摊销前利润
7. **EBITDA利润率**——EBITDA/营收（体现运营效率）

### 可选添加列（根据行业或用途选择）
- **季度数据与过去12个月数据对比**——若存在季节性差异，可同时列出两者
- **自由现金流**——适用于资本密集型或SaaS企业
- **FCF利润率**——自由现金流/营收（反映现金生成效率）
- **净利润**——适用于已成熟且盈利良好的公司
- **营业利润**——适用于折旧摊销额不固定的企业
- **资本支出相关指标**——适用于资产密集型行业
- **40法则**——专为SaaS行业设计（增长率百分比 + 利润率百分比）
- **FCF转化率**——用于分析盈利质量（高级用法）

### 公式示例（以第7行为例）
```excel
// Core ratios - these are always calculated
Gross Margin (F7): =E7/C7
EBITDA Margin (H7): =G7/C7

// Optional ratios - include if relevant
FCF Margin: =[FCF]/[Revenue]
Net Margin: =[Net Income]/[Revenue]
Rule of 40: =[Growth %]+[FCF Margin %]
```

**核心原则：** 所有的比率都应表示为[某数值] / [营收]，或[某数值] / [本表格中的另一项数值]。设计时请力求简洁明了。

### 统计数据板块（公司数据之后）

**非常重要：** 需为所有可对比的指标（比率、利润率、增长率、倍数等）添加相应的统计计算公式。

```
[Leave one blank row for visual separation]
- Maximum: =MAX(B7:B9)
- 75th Percentile: =QUARTILE(B7:B9,3)
- Median: =MEDIAN(B7:B9)
- 25th Percentile: =QUARTILE(B7:B9,1)
- Minimum: =MIN(B7:B9)
```

**需要统计数据的列（可对比的指标）：**
- 营收增长率%、毛利率%、EBITDA利润率%、每股收益
- 市盈率倍数、EV/EBITDA倍数、市盈率、股息收益率%、贝塔值

**无需统计数据的列（规模类指标）：**
- 营收、EBITDA、净利润（具体数值因企业规模而异）
- 市值、企业价值（不同规模的企业之间不具备可比性）

**注意：** 为便于区分，应在公司数据行与统计数据行之间插入一空行。请勿添加“行业统计数据”或“估值统计指标”之类的标题行。

**为何分位数如此重要：** 它们反映的是数据分布情况，而不仅仅是平均值。75百分位倍数能帮助你了解企业相对于同行业的“溢价”水平。

## 第3节：估值倍数与投资指标

### 核心估值指标列（优先选用这些）
1. **公司名称**——顺序与运营数据部分相同
2. **市值**——当前市场估值
3. **企业价值**——市值±净债务/现金
4. **EV/营收倍数**——市场为每美元营收所支付的价格
5. **EV/EBITDA倍数**——市场为每美元盈利所支付的价格
6. **市盈率**——价格与净利润的比率

### 可选估值指标（根据实际情况选择）
- **自由现金流收益率**——自由现金流/市值（适用于以现金流为核心的分析）
- **PEG比率**——市盈率/增长率（适用于成长型企业）
- **市净率**——市场价值与账面价值的比率（适用于资产密集型企业）
- **净资产收益率/总资产收益率**——盈利能力指标（用于对比盈利水平）
- **营收/EBITDA复合年增长率**——历史增长速度（用于趋势分析）
- **资产周转率**——营收/资产总额（用于评估运营效率）
- **负债率**——杠杆水平（用于分析资本结构）

**核心原则：** 选择3-5个与你所在行业相关的核心估值倍数即可。不必因为能够获取所有指标就全部纳入。

### 公式示例
```excel
// Core multiples - always include these
EV/Revenue: =[Enterprise Value]/[LTM Revenue]
EV/EBITDA: =[Enterprise Value]/[LTM EBITDA]
P/E Ratio: =[Market Cap]/[Net Income]

// Optional multiples - include if data available
FCF Yield: =[LTM FCF]/[Market Cap]
PEG Ratio: =[P/E]/[Growth Rate %]
```

### 交叉引用规则
**至关重要：** 估值倍数必须引用“运营指标”部分。绝不可重复输入相同的原始数据。如果营收数据位于C7单元格，则EV/Revenue计算公式也应引用C7单元格。

### 统计数据区块
结构与运营指标部分相同：每项指标均需列出最大值、第75百分位数、中位数、第25百分位数和最小值。需添加一行空白行，以便在公司数据与统计数值之间进行视觉区分。**不得**添加“估值统计数据”这一标题行。

## 第4节：备注与方法论文档

### 必备组成部分

**数据来源与数据质量：**
- 数据来自何处？（S&P Kensho MCP、FactSet MCP、Daloopa MCP、彭博社、美国证券交易委员会备案文件）
- 数据覆盖的时间段是什么？（2024年第四季度，经审计的财务数据）
- 数据是如何核实的？（与10-K/10-Q文件进行交叉核对）
- 备注：如有可能，请优先使用MCP数据源（S&P Kensho、FactSet、Daloopa），以提高数据的准确性和可追溯性。

**关键定义：**
- EBITDA的计算方法（毛利润 + 折旧与摊销，或营业利润 + 折旧与摊销）
- 自由现金流的计算公式（营业现金流 - 资本支出）
- 特殊指标的说明（40法则、自由现金流转化率）
- 时间周期的定义（最近12个月数据、复合年增长率的计算周期）

**估值方法论：**
- 企业价值的计算方式是什么？（市值 + 净债务）
- 使用了哪些增长率？（历史复合年增长率、未来预测值）
- 是否进行了任何调整？（剔除一次性项目，对利润率进行标准化处理）

**分析框架：**
- 投资逻辑是什么？（云计算/软件即服务的效率优势）
- 哪些指标最为重要？（现金生成能力、资本使用效率）
- 阅读者应如何解读这些统计数据？（分位数有助于提供背景参考）

## 第5节：选择合适的指标（决策框架）

### 从“我要回答什么问题？”开始

**“哪家公司被低估了？”**
→ 重点关注：EV/Revenue、EV/EBITDA、P/E比率、市值
→ 可忽略：运营细节、增长指标

**“哪家公司的效率最高？”**
→ 重点关注：毛利率、EBITDA利润率、自由现金流利润率、资产周转率
→ 可忽略：规模相关指标、绝对金额数值

**“哪家公司的增长速度最快？”**
→ 重点关注：营收增长率、EBITDA复合年增长率、用户/客户数量增长率
→ 可忽略：利润率指标、杠杆比率

**“哪家公司的现金生成能力最强？”**
→ 重点关注：自由现金流、自由现金流利润率、自由现金流转化率、资本支出强度
→ 可忽略：EBITDA、P/E比率

### 不同行业的指标选择

**软件/软件即服务行业：**
必须包含的指标：营收增长率、毛利率、40法则
可选指标：年度经常性收入、净客户留存率、客户获取成本
可忽略的指标：资产周转率、库存相关指标

**制造业/工业行业：**
必须包含的指标：EBITDA利润率、资产周转率、资本支出与营收之比
可选指标：净资产收益率、库存周转率、未完成订单额
可忽略的指标：40法则、软件即服务相关指标

**金融服务行业：**
必须包含的指标：净资产收益率、总资产收益率、效率比率、P/E比率
可选指标：净利息边际、贷款损失准备金
可忽略的指标：毛利率、EBITDA（对银行而言该指标意义不大）

**零售/电子商务行业：**
必须包含的指标：营收增长率、毛利率、库存周转率
可选指标：同店销售额、客户获取成本
可忽略的指标：高额的研发费用或资本支出相关指标

### “5-10法则”

**5项运营指标**——营收、增长速度，以及2-3项利润率/效率指标
**5项估值指标**——市值、企业价值，以及3种不同的倍数指标
**总计10列数据**——数量足以清晰呈现分析内容，又不会过多导致信息混乱

如果指标数量超过15项，很可能其中包含无用信息。请进行严格筛选。

## 第6节：最佳实践与质量检查

### 开始之前
1. **明确同业群体**——所选公司必须真正具有可比性（业务模式、规模、地域均相似）
2. **选择合适的时间周期**——最近12个月的数据可平滑季节性波动，而季度数据则更便于观察趋势
3. **提前统一单位**——是使用百万单位还是十亿单位，这一决定会影响到所有数据的分析
4. **明确数据来源**——需清楚每项数值的出处

### 数据录入过程中
1. **先输入所有原始数据**——在编写公式之前，先填满蓝色标注的文本区域
2. **为所有硬编码的输入值添加单元格注释**——右键点击单元格 → 插入注释 → 说明数据来源或假设依据

   **对于来自外部数据源的数值，需准确注明出处：**
   - 示例：“彭博终端——微软股票DES数据，访问日期为2024年10月2日”
   - 示例：“2024年第四季度的10-K备案文件，第42页，‘总营收’这一行数据”
   - 示例：“截至2024年10月2日的FactSet机构共识预期值”
   - **如有可能，请添加超链接**：右键点击单元格 → 添加链接 → 粘贴美国证券交易委员会备案文件、数据源或报告的网址

   **对于假设值，需说明其推理逻辑：**
   - 示例：“由于该公司未公开相关数据，按同业公司的中位数水平，假设EBITDA利润率为15%”
   - 示例：“企业价值暂按市值加上5000万美元的净债务来估算（该数值取自第三季度的资产负债表，第四季度数据尚未公布）”
   - 示例：“预测P/E比率是基于市场普遍预期的3.45美元每股收益值（该值为12位分析师预测值的平均值）”

   **为何要这样做？** 这样做有助于建立审计追踪机制、便于数据核实、提高假设的透明度，并便于日后进行数据更新。

3. **逐行编写公式**——在继续下一步之前，先测试每项计算结果是否正确
4. **为标题行使用绝对引用**——使用$
```
Revenue Growth (YoY) % | EBITDA Margin | FCF Margin | Rule of 40
```

### 分位数分析的优势
与仅使用均值/中位数不同，分位数能够展现：
- **第75百分位**：代表“优质”企业所处的交易区间
- **中位数**：反映市场的典型估值水平
- **第25百分位**：属于“折价”交易区域

这有助于回答以下问题：“与同行相比，我们关注的目标企业的估值是偏高还是偏低？”

### 不同行业的调整要点

**软件/软件即服务行业：**
- 需补充的指标：年度经常性收入、净客户留存率、客户获取成本回收期
- 需重点关注的指标：40法则、自由现金流利润率、毛利率>70%

**医疗保健行业：**
- 需补充的指标：研发支出与营收之比、在研项目价值、监管状况
- 需重点关注的指标：EBITDA利润率、增长速度、医保报销风险

**工业行业：**
- 需补充的指标：未完成订单量、订单簿趋势、业务地域分布
- 需重点关注的指标：投资回报率、资产周转率、周期性调整因素

**消费品行业：**
- 需补充的指标：同店销售额、客户获取成本、品牌价值
- 需重点关注的指标：营收增长率、毛利率、库存周转率

## 第7节：工作流程与实用技巧

### 分步操作流程
1. **搭建框架**（30分钟）
   - 创建所有标题行
   - 设置单元格格式（输入数据用蓝色，公式用黑色）
   - 固定单位与日期引用格式

2. **收集数据**（60-90分钟）
   - 从原始数据源获取数据（如有条件可使用S&P Kensho MCP、FactSet MCP、Daloopa MCP；否则可使用Bloomberg、SEC数据库）
   - 将所有原始数值以蓝色填入对应单元格
   - 在备注栏中记录数据来源

3. **构建公式**（30分钟）
   - 先从简单的比率指标开始（如利润率）
   - 再逐步使用倍数指标（如企业价值/营收比率）
   - 添加交叉验证步骤，确认各项比率逻辑合理

4. **添加统计指标**（15分钟）
   - 复制适用于所有列的公式结构
   - 确认数据范围正确（例如B7:B9而非B7:B10）
   - 检查分位数计算逻辑是否正确

5. **质量管控**（30分钟）
   - 执行合理性检查
   - 核实公式引用是否正确
   - 检查是否存在#DIV/0!或#REF!错误
   - 与已知基准数据对比分析

6. **文档记录**（15分钟）
   - 完成备注栏的填写
   - 注明所有数据来源
   - 明确说明分析方法
   - 在文件中标注分析日期

- **保存模板**：一次性制作完成后可反复使用
- **对异常值进行颜色标记**：对偏离均值2个标准差以上的数值应用条件格式突出显示
- **链接到原始文件**：为Bloomberg截图或SEC备案文件添加超链接
- **版本控制**：采用“Comps_v1_2024-12-15”这类带明确日期的文件名保存

## 第10节：风险警示信号

### 数据质量问题
🚩 时间周期不一致（混用季度数据和年度数据）  
🚩 未说明原因即缺失数据  
🚩 不同数据源之间的差异过大（偏差超过10%）

### 估值风险信号
🚩 对EBITDA为负的公司仍采用EBITDA倍数进行估值（建议改用营收倍数）  
🚩 无高速成长故事支撑却存在超过100倍的市盈率  
🚩 利润率低于该行业正常水平

### 可比性问题
🚩 财年结算日不同（会导致时间匹配问题）  
🚩 将纯行业公司与综合企业混为一谈  
🚩 将业务模式存在显著差异的公司标为“可比对象”

**如有疑问，建议剔除该公司。** 3个完美的对比对象远胜于6个存疑的对象。


## 核心原则概要

1. **结构决定洞察力**——恰当的标题能引导正确的思考方向  
2. **少即是多**——5-10个关键指标远胜于20个无关指标  
3. **根据分析目标选择指标**——估值分析≠效率分析  
4. **数据揭示规律**——中位数/分位数比平均值更能反映真实情况  
5. **透明优于复杂**——简单易懂的公式更有效  
6. **可比性至关重要**——宁可排除某些公司，也不要强行进行不当对比  
7. **记录决策依据**——在备注部分说明所选指标及其原因

## 数据来源——优先使用MCP，网络检索作为备选

下文多处提到“使用S&P Kensho MCP / Daloopa MCP / FactSet MCP”。这些是源自原有Cowork插件平台的商业金融数据MCP服务。在Hermes系统中：  
- **如果您已配置任何结构化金融数据MCP**（Hermes支持MCP功能，参见`native-mcp`技能），建议优先使用它们来获取特定时间点的公司数据、历史交易案例及监管文件信息。  
- **否则**，可采取以下备选方案：  
  - 使用`web_search`/`web_extract`功能，从SEC EDGAR平台（`https://www.sec.gov/cgi-bin/browse-edgar`）获取美国公司的监管文件  
  - 查阅公司官网的投资者关系页面，获取新闻稿和财报材料  
  - 使用`browser_navigate`功能访问交互式数据门户  
  - 使用用户提供的数据（当现有数据不足时需明确询问用户补充）  
- **严禁编造数据**。如果无法找到某项倍数、历史案例或文件编号，请将该单元格标记为`[UNSOURCED]`，并向用户说明情况。
