## NeurIPS 论文检查清单

### 必填组成部分

所有提交给 NeurIPS 的论文都必须附上填写完整的检查清单。缺失此部分的论文将面临**直接拒收**的结果。该检查清单应置于参考文献和补充材料之后，且不计入页面限制范围内。

### 16项必填检查项目

#### 1. 研究主张一致性
作者需确保摘要与引言中的研究主张与理论结果及实验结果相一致，并明确阐述研究的贡献、假设及局限性。

**需核查内容：**
- [ ] 摘要中的主张与实际结果相符
- [ ] 引言未过度夸大研究成果
- [ ] 研究贡献具体且可验证

#### 2. 局限性分析
论文应设置专门的“局限性”章节，说明研究中的关键假设、对假设偏离的鲁棒性、研究范围的限制以及影响性能的因素。

**需包含内容：**
- [ ] 独立的局限性说明部分  
- [ ] 对研究范围的客观评估  
- [ ] 方法可能失效的条件  

#### 3. 理论与证明  
理论性研究成果需包含完整的假设陈述及严谨的证明过程（主论文中提供完整证明，或附录中给出便于理解的证明概要）。  

**需核查项：**  
- [ ] 所有假设均已明确表述  
- [ ] 提供了完整的证明内容（主文本或附录）  
- [ ] 主文本中包含有助于理解的证明概要  

#### 4. 可复现性  
作者必须通过代码发布、详细操作指南、模型访问方式，或根据研究类型所需的检查点等方式，说明确保结果可验证的步骤。  

**需提供内容：**  
- [ ] 明确的可复现性声明  
- [ ] 代码可用性信息  
- [ ] 如适用，需提供模型检查点  

#### 5. 数据与代码访问权限  
应提供用于复现主要实验结果的说明（补充材料或网址），包括具体的命令及环境配置要求。  

**需包含内容：**  
- [ ] 运行实验的精确命令  
- [ ] 环境配置要求（requirements.txt、conda env文件等）  
- [ ] 数据访问指南  

#### 6. 实验细节  
论文必须在主论文或补充材料中详细说明训练相关参数：数据划分方式、超参数设置及其选择方法。  

**需记录内容：**  
- [ ] 训练集/验证集/测试集的划分细节  
- [ ] 所使用的所有超参数  
- [ ] 超参数的选择方法
#### 7. 统计显著性
结果需附带误差棒、置信区间或统计检验，并明确说明计算方法及相关假设。

**需包含的内容：**
- [ ] 误差棒或置信区间
- [ ] 运行次数/种子数量
- [ ] 计算方法（标准差与标准误）

#### 8. 计算资源需求
所需规格包括：计算节点类型（CPU/GPU）、内存、存储空间、每次运行的执行时间，以及整个项目的总计算需求。

**需记录的内容：**
- [ ] GPU的类型及数量
- [ ] 每次运行的训练时间
- [ ] 总计算资源消耗量

#### 9. 道德规范遵守情况
作者需确认已遵循NeurIPS道德规范，并说明如有必要做出的任何偏离。

**需核实的事项：**
- [ ] 已阅读NeurIPS道德规范
- [ ] 确认已遵守该规范
- [ ] 如有偏离，需说明原因并加以记录

#### 10. 更广泛的影响
如适用，需探讨该技术可能带来的负面社会影响、公平性问题、隐私风险以及相应的缓解策略。

**需涉及的内容：**
- [ ] 潜在的负面应用
- [ ] 公平性考量
- [ ] 隐私方面的影响
- [ ] 缓解策略

#### 11. 安全保障措施
对于高风险模型（如语言模型、从互联网抓取的数据集），需制定相应的控制发布机制和使用指南。

**需考虑的因素：**
- [ ] 敏感模型的发布策略
- [ ] 是否需要制定使用指南
- [ ] 是否需要设置访问控制措施
#### 12. 许可证遵守
所有现有资产都必须注明创建者信息、许可证名称、网址、版本号以及服务条款的相关说明。

**需记录的内容：**
- [ ] 已标注的数据集许可证信息
- [ ] 已遵循的代码许可证要求
- [ ] 是否已标注版本号

#### 13. 资产文档说明
新发布的资产需要使用结构化模板，详细记录训练过程、功能限制、用户同意流程以及许可证信息。

**针对新的数据集/模型：**
- [ ] 数据表或模型简介文档
- [ ] 训练数据相关文档
- [ ] 已知的性能限制

#### 14. 受试者保护
基于众包的研究必须包含面向参与者的操作指南、截图、报酬明细，并符合最低工资标准要求。

**需包含的内容：**
- [ ] 任务操作说明
- [ ] 报酬详细信息
- [ ] 预计耗时

#### 15. 伦理委员会审批
涉及人类受试者的研究必须提供经正式批准的伦理委员会审批文件或同等证明，同时需披露相关风险信息（提交时需确保受试者身份匿名）。

**需核验的内容：**
- [ ] 是否已获得伦理委员会批准
- [ ] 是否已完成风险评估
- [ ] 提交时是否已对受试者信息进行匿名处理

#### 16. 大语言模型声明
若将大语言模型作为核心方法组件使用，则必须予以披露；仅用于写作或编辑任务则无需声明。

**需披露的内容：**
- [ ] 是否将大语言模型作为核心方法组件使用
- [ ] 具体使用方式
- [ ] （用于写作辅助的功能无需披露）

**重要提示：** 审稿人被明确要求不得因作者诚实地承认研究存在的局限性而对其评分降分。

## ICML 论文检查清单

### 更广泛影响声明

ICML 要求在论文末尾、参考文献之前提交一份更广泛影响声明。该内容不计入页面限制之内。

**必填要素：**
- 潜在的积极影响
- 潜在的消极影响
- 缓解策略
- 可能受到影响的人群

### ICML 特定要求

#### 可复现性检查清单

- [ ] 明确指定数据划分方式
- [ ] 列出超参数
- [ ] 说明搜索范围
- [ ] 解释数据选择方法
- [ ] 注明计算资源使用情况
- [ ] 说明代码是否可获取

#### 统计报告要求

- [ ] 所有图表均需标注误差棒
- [ ] 明确区分标准差与标准误
- [ ] 注明实验重复次数
- [ ] 若对比不同方法，需进行显著性检验

#### 匿名化要求

- [ ] 论文中不得出现作者姓名
- [ ] 不得包含致谢内容
- [ ] 不得标注资助项目编号
- [ ] 对先前研究需以第三人称提及
- [ ] 不得提供可识别代码仓库的网址

## ICLR 要求

### 大语言模型披露政策（2026年新要求）

ICML 有专门的大语言模型披露规定：

> “如果大语言模型在研究构思和/或写作过程中发挥了重要作用，甚至可被视为贡献者，作者必须在单独的附录章节中详细说明其具体作用。”

**需要披露的情况包括：**
- 使用大语言模型进行关键的研究构思
- 使用大语言模型完成大量写作工作
- 大语言模型可被视为研究的贡献者
**无需公开信息的情况：**
- 语法检查
- 轻微编辑协助
- 代码补全工具

**未公开信息的后果：**
- 直接被拒稿
- 可能出现论文发表后的问题

### ICLR特定要求

#### 可复现性声明（非强制但建议提供）

需添加以下内容的说明：
- 支持材料
- 代码的可用性
- 数据的可用性
- 模型检查点

#### 伦理声明（非强制）

在1页以内阐述潜在问题，该部分不计入页面限制。

#### 互审机制

- 发表过3篇及以上论文的作者必须担任至少6篇论文的审稿人
- 每篇投稿需至少有1名作者注册并负责审阅至少3篇论文

## ACL要求

### 局限性部分（强制要求）

ACL明确要求设置局限性部分：

**需包含的内容：**
- 所做的关键假设
- 研究范围的限制
- 方法可能失效的情况
- 泛化能力方面的问题

**重要提示：** 局限性部分不计入页面限制。

### ACL特定检查清单

#### 负责任的自然语言处理

- [ ] 已考虑偏见问题
- [ ] 如适用，已评估公平性
- [ ] 已探讨双重用途风险

#### 多语言处理考量

如适用：
- [ ] 已考虑语言多样性
- [ ] 是否包含非英语语言
- [ ] 是否验证了翻译质量

#### 人工评估

如适用：
- [ ] 已提供标注人员信息
- [ ] 已报告一致性指标
- [ ] 已记录相关补偿情况

## AAAI要求

### 格式规范（所有会议中最严格）

AAAI对格式要求的严格执行程度高于其他任何主流学术会议。不符合模板规范的论文将在初审阶段就被直接拒收。

- [ ] 必须原封不动地使用**完全符合**AAAI格式要求的样式文件——不得使用`\setlength`、`\vspace`等技巧，也不得更改字体设置
- [ ] 正文部分不得超过7页（若需包含作者信息，则为8页）
- [ ] 采用双栏排版，字体为Times（由模板指定）
- [ ] 参考文献和附录不计入页数限制范围内
- [ ] 摘要必须为单段文字
- [ ] 禁止更改页边距、列宽或字体大小

### 必需章节

- [ ] 摘要（单段，不得包含数学公式或参考文献）
- [ ] 需明确说明本文的贡献内容的引言部分
- [ ] 采用AAAI格式的参考文献列表（使用`aaai2026.bst`文件）
- [ ] 附录（可选，无页数限制）

### 伦理与可复现性要求

- [ ] 需撰写更详细的成果影响说明（虽非强制要求，但鼓励提交——请查阅当年的会议征稿简章）
- [ ] 需提供有关可复现性的详细信息，包括数据集及代码的获取方式
- [ ] 如使用了AI写作工具，需在文中注明

### 与其他会议的显著差异

- **无需单独设置限制说明部分**（与ACL不同），但建议仍对研究局限性进行阐述
- **格式审核最为严格**——格式检查工具会直接拒收不符合要求的PDF文件
- **没有像NeurIPS那样的论文检查清单**，但仍需遵循下方的通用检查清单
- **统一模板**：主论文内容与补充材料均需保存在同一个文件中

## COLM会议要求

### 概述

COLM（语言模型会议）专注于语言模型研究，因此投稿内容必须针对该领域受众进行阐述。

### 格式要求

- [ ] 正文9页（最终提交版本需10页）
- [ ] 使用COLM模板（基于ICLR模板并经过调整）
- [ ] 采用双盲评审机制
- [ ] 参考文献与附录数量不限

### 必备章节

- [ ] 摘要
- [ ] 面向语言模型研究社区的引言
- [ ] 结论
- [ ] 参考文献

### 内容要求

- [ ] 投稿内容必须与语言模型相关（涵盖范围广泛：训练、评估、应用、理论、对齐、安全性等）
- [ ] 若所提方法具有通用性，需通过语言模型实例进行说明
- [ ] 在适用情况下，基线对比应包含近期针对语言模型的方法

### 与其他会议的差异

- 相比NeurIPS/ICML，其**研究范围更为狭窄**——内容必须面向语言模型社区
- 模板源自ICLR，**格式规则类似**
- 作为较新的会议，**评审标准仍在形成中**，因此会更注重全面评估
- 不像NeurIPS那样有强制性的检查清单，但要求对研究的**更广泛影响**进行阐述
- **LLM披露要求**：若研究中使用了大语言模型（用于代码生成、数据标注或写作辅助等），必须予以说明

## 通用投稿前检查清单

### 每次投稿前均需检查

#### 论文内容

- [ ] 摘要字数符合限制要求（通常为250-300字）  
- [ ] 正文篇幅在页面限制范围内  
- [ ] 参考文献完整且经过核实  
- [ ] 包含局限性说明部分  
- [ ] 所有图表均配有标题  
- [ ] 图表标题内容完整独立  

#### 格式要求

- [ ] 使用了正确的模板（需注明会议名称及年份）  
- [ ] 页边距未作修改  
- [ ] 字体大小未作调整  
- [ ] 满足双盲评审要求  
- [ ] 包含页码（用于审稿）或无需页码（可直接用于印刷）  

#### 技术要求

- [ ] 所有论点均有证据支持  
- [ ] 图表中包含误差范围  
- [ ] 基线设置合理  
- [ ] 超参数已详细记录  
- [ ] 明确说明了所需的计算资源  

#### 可复现性要求

- [ ] 将提供代码（或给出相应说明）  
- [ ] 将提供数据（或给出相应说明）  
- [ ] 对实验环境有详细记录  
- [ ] 提供用于复现结果的命令  

#### 伦理要求

- [ ] 已考虑研究的更广泛影响  
- [ ] 如实说明存在的局限性  
- [ ] 遵守相关许可证规定  
- [ ] 如有必要，已获得机构审查委员会批准  

#### 最终检查项

- [ ] PDF文件能无错误地生成  
- [ ] 所有图表均能正确显示  
- [ ] 所有引用信息均可正常解析  
- [ ] 补充材料整理有序  
- [ ] 已完成会议提交清单填写

## 页数限制速查表

| 会议名称 | 主要内容页数 | 参考资料数量 | 附录数量 |
|----------|--------------|--------------|----------|
| NeurIPS 2025 | 9页 | 无限制 | 无限制（清单另存） |
| ICML 2026 | 8页（+1个摄像头相关内容） | 无限制 | 无限制 |
| ICLR 2026 | 9页（+1个摄像头相关内容） | 无限制 | 无限制 |
| ACL 2025 | 8页（长篇报告格式） | 无限制 | 无限制 |
| AAAI 2026 | 7页（+1个摄像头相关内容） | 无限制 | 无限制 |
| COLM 2025 | 9页（+1个摄像头相关内容） | 无限制 | 无限制 |

## 模板存放位置

所有会议模板均位于 `templates/` 目录中：

```
templates/
├── icml2026/       # ICML 2026 official
├── iclr2026/       # ICLR 2026 official
├── neurips2025/    # NeurIPS 2025
├── acl/            # ACL style files
├── aaai2026/       # AAAI 2026
└── colm2025/       # COLM 2025
```
