# ADMET参考指南

药物发现领域中关于吸收、分布、代谢、排泄和毒性（ADMET）分析的全面参考资料。

## 药物相似性规则集

### Lipinski五项规则（Ro5）

| 性质 | 阈值 |
|------|------|
| 分子量（MW） | ≤ 500 Da |
| 疏水性（LogP） | ≤ 5 |
| 氢键供体数（HBD） | ≤ 5 |
| 氢键受体数（HBA） | ≤ 10 |

参考文献：Lipinski等人，《Adv. Drug Deliv. Rev.》23, 3–25 (1997)。

### Veber口服生物利用度规则

| 性质 | 阈值 |
|------|------|
| 表面等离子体面积（TPSA） | ≤ 140 Å² |
| 可旋转键数 | ≤ 10 |

参考文献：Veber等人，《J. Med. Chem.》45, 2615–2623 (2002)。

### 中枢神经系统渗透性（血脑屏障穿透）

| 性质 | 最佳值 |
|------|--------|
| 分子量 | ≤ 400 Da |
| LogP值 | 1–3 |
| 表面等离子体面积 | < 90 Å² |
| 氢键供体数 | ≤ 3 |

## CYP450代谢途径

| 同工酶 | 所占药物比例 | 主要抑制剂 |
|------|------------|------------|
| CYP3A4 | 约50% | 葡萄柚、酮康唑 |
| CYP2D6 | 约25% | 氟西汀、帕罗西汀 |
| CYP2C9 | 约15% | 氟康唑、胺碘酮 |
| CYP2C19 | 约10% | 奥美拉唑、氟西汀 |
| CYP1A2 | 约5% | 氟伏沙明、环丙沙星 |

## hERG心脏毒性风险

结构警示特征：碱性氮原子（pKa 7–9）+ 芳香环 + 疏水基团，LogP值 > 3.5 + 碱性胺基。

降低风险的措施：降低物质碱性、引入极性基团、破坏分子平面结构。

## 常见生物等效替代基团

| 原始基团 | 生物等效替代基团 | 作用目的 |
|----------|----------------|----------|
| -COOH | -四唑、-SO₂NH₂ | 提高药物渗透性 |
| -OH（酚羟基） | -F、-CN | 减少葡萄糖醛酸化反应 |
| 苯环 | 吡啶、噻吩 | 降低LogP值 |
| 酯基 | -CONHR | 减少水解反应 |
