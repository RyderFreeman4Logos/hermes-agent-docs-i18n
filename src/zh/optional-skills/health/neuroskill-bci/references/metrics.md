# NeuroSkill指标定义与解读指南

> **⚠️ 仅限研究用途：** 所有指标均为实验性数据，基于消费级硬件（Muse 2/S）采集。这些设备尚未通过FDA/CE认证，不得用于医疗诊断或治疗。

---

## 硬件与信号采集

NeuroSkill已针对**Muse 2**和**Muse S**头带经过验证（桌面应用支持OpenBCI），数据采样率为**256 Hz**（脑电图）和**64 Hz**（光电容积脉搏波）。

### 电极位置（国际10-20系统）
| 通道 | 电极位置 | 位置描述 | 主要检测信号 |
|------|----------|----------|--------------|
| CH1 | TP9 | 左乳突 | 听觉皮层、语言记忆、咬肌活动伪迹 |
| CH2 | AF7 | 左前额叶 | 执行功能、行为动机、眨眼动作 |
| CH3 | AF8 | 右前额叶 | 情绪调节、警觉性、眨眼动作 |
| CH4 | TP10 | 右乳突 | 语调感知、空间听觉、非语言认知 |

### 预处理流程
1. **滤波处理**：高通滤波（0.5 Hz）、低通滤波（50/60 Hz）、带阻滤波
2. **频谱分析**：汉宁窗FFT分析（512个样本窗口）、韦尔奇周期图法
3. **GPU加速**：通过`gpu_fft`实现约125毫秒的延迟

## 脑电图频率带

各频率带的相对功率值（所有频率带之和≈1.0）：

| 频率带 | 频率范围（Hz） | 高功率状态含义 | 低功率状态含义 |
|--------|--------------|----------------|----------------|
| **Delta (δ)** | 1–4 | 深度睡眠（N3阶段）、高幅度伪迹 | 觉醒状态、警觉性高 |
| **Theta (θ)** | 4–8 | 困倦、REM睡眠开始、创造性思维、认知负荷高 | 警觉、专注状态 |
| **Alpha (α)** | 8–13 | 放松的清醒状态、努力时的“α波抑制”现象 | 积极思考、焦虑状态 |
| **Beta (β)** | 13–30 | 积极集中注意力、解决问题、高度警觉 | 放松、注意力不集中 |
| **Gamma (γ)** | 30–50 | 高阶信息处理、感知整合、记忆功能 | 基线水平 |

## 核心综合评分（0–1 分数制）

### 集中力
- **计算公式**：σ(β / (α + θ)) —— 贝塔波对慢波的支配程度，经过S型映射处理
- **> 0.70**：高度集中，处于心流状态，完全沉浸在任务中
- **0.40–0.69**：注意力中等，存在一定走神现象
- **< 0.40**：容易分心，感到疲劳，难以集中注意力

### 放松度
- **计算公式**：σ(α / (β + θ)) —— 阿尔法波占主导，经过S型映射处理
- **> 0.70**：心情平静，无压力，副交感神经处于主导状态
- **0.40–0.69**：存在轻微紧张感
- **< 0.30**：感到压力大、焦虑，交感神经处于主导状态

### 参与度
- **0–1 分数制**：反映主动的思维投入程度与动机水平
- **> 0.70**：思维高度专注，积极性高，处于主动处理信息状态
- **0.40–0.69**：被动参与
- **< 0.30**：感到无聊，缺乏参与感，处于自动驾驶模式

### 冥想状态
- **综合指标**：结合阿尔法波升高、身体静止状态（通过IMU检测）以及心率变异性一致性综合得出
- **> 0.70**：处于深度冥想状态
- **< 0.30**：处于活跃状态，未进入冥想

### 情绪状态
- **综合指标**：基于FAA、TAR和BAR三个指标计算得出
- **> 0.60**：情绪积极，具有主动寻求交流的动机
- **< 0.40**：情绪低落，倾向于退缩

### 认知负荷
- **计算公式**：(P_θ_frontal / P_α_temporal) · f(FAA, TBR) —— 反映工作记忆的使用程度
- **> 0.70**：工作记忆接近饱和，处于复杂信息处理状态
- **0.40–0.69**：思维负担中等
- **< 0.40**：任务简单或属于自动化操作
- **解读**：高负荷叠加高集中力 = 高效的艰难应对；高负荷叠加低集中力 = 感到不堪重负。

### 嗜睡程度
- **综合指标**：经过权重调整后的TAR、TBR值以及频谱质心下降幅度综合得出
- **> 0.60**：睡眠压力逐渐增加，存在微睡眠风险
- **0.30–0.59**：轻微疲劳
- **< 0.30**：保持清醒

## EEG比率与频谱指标

| 指标 | 计算公式 | 解读说明 |
|------|---------|----------|
| **FAA** | ln(P_α_AF8) − ln(P_α_AF7) | 额叶阿尔法波不对称性。正值表示积极/进取情绪；负值则表示退缩/抑郁倾向。 |
| **TAR** | P_θ / P_α | 希塔波与阿尔法波的比率。> 1.5 表示出现嗜睡或走神现象。 |
| **BAR** | P_β / P_α | 贝塔波与阿尔法波的比率。> 1.5 表示处于清醒、高度专注状态，也可能预示焦虑情绪。 |
| **TBR** | P_θ / P_β | 希塔波与贝塔波的比率，可作为多动症生物标志物。正常值约为1.0，升高超过1.5，临床值超过3.0。 |
| **APF** | 在[7.5, 12.5] Hz频段内函数PSD(f)的argmax_f值 | 阿尔法波峰值频率，通常在8–12 Hz之间。频率越高，认知处理速度越快；会随年龄增长或疲劳而下降。 |
| **SNR** | 10 · log₁₀(P_signal / P_noise) | 信噪比。> 10 dB表示信号质量良好，3–10 dB表示可用，< 3 dB表示信号不可靠。 |
| **Coherence** | 左右脑皮层之间的连接性（0–1范围） | 反映大脑两半球的皮质连接程度。 |
| **Mu Suppression** | 运动皮层抑制指数 | 在进行动作或运动想象时该值会降低。 |

## 复杂度与非线性指标

| 指标 | 描述 | 正常范围 |
|------|-------------|----------|
| **排列熵（PE）** | 衡量时间序列的复杂程度。接近1表示极度不规则，可作为意识状态的标志。 | 作为意识状态指标使用 |
| **Higuchi分形维数（HFD）** | 反映波形的自相似性。 | 觉醒状态下为1.3–1.8；数值越高，波形复杂度越高。 |
| **DFA指数** | 衡量长程相关性。 | 正常值为0.6–0.9。 |
| **PSE** | 功率谱熵。接近1.0表示为白噪声，数值越低表示大脑状态越有序。 | 越低表示大脑状态越有序。 |
| **PAC θ-γ** | 希塔波与伽马波的相位-振幅耦合度，是工作记忆的机制体现。 | 作为工作记忆的机制指标。 |
| **BPS** | 带功率斜率（1/f频谱指数），反映抑制作用占主导的程度。 | 斜率越陡表示抑制作用越强。 |

## 意识状态指标

由上述非线性指标衍生得出：

| 指标 | 分数范围 | 解读说明 |
|------|---------|----------|
| **LZC** | 0–100 | 基于Lempel-Ziv复杂度算法的代理指标（结合PE与HFD）。> 60表示处于清醒状态。 |
| **清醒度** | 0–100 | 嗜睡程度的反向综合指标。 |
| **整合度** | 0–100 | 反映大脑皮层的整合程度（由Coherence、PAC与频谱熵共同决定）。 |

状态阈值：≥ 50为绿色，25–50为黄色，< 25为红色。

## 心脏与自主神经指标（基于PPG数据）

| 指标 | 描述 | 正常/绿色范围 |
|------|-------------|---------------|
| **HR** | 心率（次/分钟） | 55–90为绿色，45–110为黄色，其余情况为红色 |
| **RMSSD** | 主要反映迷走神经张力的指标（毫秒单位） | > 50 ms表示状态正常，< 20 ms表示处于压力状态 |
| **SDNN** | 心率变异性在时间维度上的变化程度（毫秒单位），数值越高越好 | 数值越高表示状态越好 |
| **pNN50** | 反映副交感神经活性的指标（百分比） | 数值越高表示副交感神经活动越活跃 |
| **LF/HF比率** | 反映交感神经与迷走神经平衡状态的指标 | > 2.0表示处于压力状态，< 0.5表示处于放松状态 |
| **压力指数** | Baevsky SI公式：AMo / (2 × MxDMn × Mo)，为0–100分的综合指标。原始值> 200表示压力极大 | 为0–100分的综合指标，原始值> 200表示压力极大 |
| **SpO₂估计值** | 血氧饱和度（未经校准），仅用于研究目的 | 95–100%为正常范围 |
| **呼吸频率** | 每分钟的呼吸次数 | 12–20次/分为正常范围 |

## 动作与伪迹检测

| 指标 | 描述 |
|------|---------|
| **静止度** | 0–1（1表示完全静止），通过IMU的加速度计与陀螺仪检测得出。 |
| **眨眼次数** | 检测到的眼球眨动现象（在AF7/AF8频段会出现明显峰值），正常值为15–20次/分钟。 |
| **咬紧牙关次数** | 在TP9/TP10电极处检测到的高频肌电爆发信号（频率> 30 Hz）。 |
| **点头次数** | 通过IMU检测到头部点头动作。 |
| **摇头次数** | 通过IMU检测到头部摇头动作。 |
| **头部俯仰/滚动角度** | 通过IMU检测到的头部方向变化。 |

## 睡眠分期

基于5秒时间窗口内的相对频段功率比率以及AASM标准算法进行判定：

| 分期 | 代码 | EEG特征 | 功能作用 |
|------|------|---------|----------|
| 觉醒 | 0 | 阿尔法波占主导，BAR > 0.8 | 处于清醒意识状态 |
| N1期 | 1 | 阿尔法波向希塔波过渡 | 轻微入睡阶段 |
| N2期 | 2 | 出现睡眠纺锤波与K复合波 | 负责记忆巩固 |
| N3期（深度睡眠） | 3 | 波段δ波占比超过该时间窗口的20%，DTR值> 2 | 深度恢复性睡眠 |
| REM期 | 4 | EEG活动活跃，希塔波占比高，δ波占比低 | 负责情绪处理与梦境形成 |

### 成年人健康睡眠目标（约8小时睡眠）
- **N3期（深度睡眠）**：占总睡眠时间的15–25%
- **REM期**：占总睡眠时间的20–25%
- **睡眠效率**：> 85%
- **入睡潜伏期**：< 20分钟

## 综合状态模式

| 状态模式 | 关键指标 | 解读说明 |
|---------|---------|----------|
| **心流状态** | 集中力 > 0.75，参与度 > 0.70，认知负荷为0.50–0.70，心率稳定 | 处于最佳表现区间，应加以保护 |
| **精神疲劳** | 集中力 < 0.40，嗜睡程度 > 0.60，TBR > 1.5，希塔波升高 | 需要休息或暂停当前任务 |
| **焦虑状态** | 放松度 < 0.30，心率升高，贝塔波与BAR值均偏高，压力指数高 | 需要采取安抚措施 |
| **高度警觉状态** | 集中力 > 0.80，参与度 > 0.70，嗜睡程度 < 0.20 | 适合处理复杂任务的最佳时机 |
| **恢复状态** | 放松度 > 0.70，心率变异性（RMSSD）上升，阿尔法波占主导 | 大脑处于整合状态，仅适合处理简单任务 |
| **创意模式** | 希塔波与阿尔法波水平均较高，贝塔波较低，集中力适中 | 适合进行创意思考，无需强行追求结构化输出 |
| **退缩状态** | FAA值< 0，情绪低落，参与度低 | 需要激发主动寻求交流的动机 |

## ZUNA嵌入向量

NeuroSkill采用**ZUNA神经编码器**将5秒长的EEG数据段转换为**128维向量**，并存储在HNSW索引结构中：
- **搜索功能**：可实现亚毫秒级的近似最近邻查询
- **UMAP可视化**：通过GPU加速实现3D投影，便于直观对比不同状态
- **存储方式**：数据存储在`~/.skill/YYYYMMDD/`目录下的本地SQLite数据库与HNSW索引中 |
