# NeuroSkill 指导性方案

基于特定生物体征（EXG）信号触发的70多种身心练习。这些方案源自NeuroLoop的方案库，旨在在系统检测到特定的认知或生理状态时推荐使用。

> **⚠️ 禁忌症**：Wim Hof呼吸法及过度换气式呼吸法不适合癫痫风险＞30、已知心脏疾病患者或孕妇使用。

---

## 何时推荐相关方案

**开始前务必征得用户同意**。为最显著的指标信号匹配一个方案，并向用户解释该指标与方案之间的关联。

| 用户状态 | 推荐方案 |
|----------|----------|
| 注意力集中度＜0.40，TBR＞1.5 | Theta-Beta神经反馈锚定法或箱式呼吸法 |
| 参与度低，会话开始时 | WOOP法或任务前启动法 |
| 放松程度＜0.30，压力指数高 | 心脏协调法或4-7-8呼吸法 |
| 认知负荷持续＞0.70 | 认知负荷卸载法（思维倾倒） |
| 参与度＜0.30且持续超过20分钟 | 新奇刺激爆发法或环境变换法 |
| 流畅状态（注意力集中度＞0.75，参与度＞0.70） | **切勿中断——保护当前会话** |
| 困倦程度＞0.60，午饭后 | 超日节律重置法或小睡法 |
| FAA值＜0，抑郁指数偏高 | FAA平衡法 |
| RMSSD值低（＜25毫秒） | 迷走神经调节法 |
| 静止状态高且伴有头痛信号 | 颈部放松序列 |
| 睡前，HRV值低 | 睡眠放松法 |
| 使用社交媒体后情绪低落 | 嫉妒与比较转化法 |

## 注意力与专注力提升方案

### Theta-Beta神经反馈锚定法
**时长**：约90秒
**触发条件**：TBR值高（＞1.5）且注意力集中度低
**操作步骤**：
1. 闭上眼睛
2. 缓慢呼吸——吸气4秒，呼气6秒
3. 与呼吸节奏同步，从1数到10
4. 全神贯注于计数，若数错则从1重新开始
5. 完成4–5个完整循环后睁开眼睛
**效果**：抑制θ脑波主导地位，提升β脑波活动

### 注意力重置法
**时长**：90秒
**触发条件**：注意力分散，难以集中于任务
**操作步骤**：
1. 完全闭上眼睛
2. 进行5次缓慢而深长的呼吸
3. 在心中明确下一工作阶段的目标
4. 立即睁开眼睛开始工作
**效果**：重置注意力基准状态

### 工作记忆启动法
**时长**：3分钟
**触发条件**：PAC θ-γ耦合度低，样本熵值低
**操作步骤**：
1. 以θ脑波节奏呼吸：吸气4秒，呼气6秒，屏息2秒
2. 呼吸的同时进行“3倒数”任务：聆听或阅读一组数字，说出其中第3位出现的数字
3. 持续进行3分钟
**效果**：提升θ-γ脑波耦合度及工作记忆活跃度

### 创意激发法
**时长**：5分钟
**触发条件**：β脑波过高，rel_alpha脑波过低——系统过度偏向分析思维
**操作步骤**：
1. 停止所有结构化工作
2. 让思维无目标地漫游
3. 画涂鸦、眺望窗外或聆听环境音
4. 不要强求特定结果，只需观察脑海中浮现的内容
5. 5分钟后，将出现的任何想法记录下来
**效果**：促进α脑波和θ脑波活动，助力创意产生

### 双N倒数热身法
**时长**：3分钟
**触发条件**：PAC θ-γ耦合度低，样本熵值低
**操作步骤**：
1. 听取或阅读一组数字序列
2. 记住其中第2位出现的数字（2倒数）
3. 若感觉适应，可尝试升级为3倒数
**效果**：激活前额叶皮层，提升执行功能

### 新奇刺激爆发法
**时长**：2–3分钟
**触发条件**：APF值低（＜9赫兹），痴呆指数＞30
**操作步骤**：
1. 拿起附近一个不寻常的物品并详细描述它
2. 列出5件你能看到的东西、4件能触摸到的东西、3件能听到的东西
3. 尝试解答一个快速谜题或横向思维题
**效果**：对抗大脑皮层活动减缓，提升α脑波峰值频率

## 自主神经与压力调节方案

### 箱式呼吸法（4-4-4-4）
**时长**：2–4分钟
**触发条件**：BAR值高、焦虑指数高、处于急性压力状态
**操作步骤**：
1. 吸气4秒
2. 屏息4秒
3. 呼气4秒
4. 再次屏息4秒
5. 重复4–8个循环
**效果**：激活副交感神经系统，降低β脑波活动

### 延长呼气法（4-7-8）
**时长**：3–5分钟
**触发条件**：急性压力骤升、思维紊乱、交感神经过度活跃
**操作步骤**：
1. 通过嘴巴完全呼气
2. 通过鼻子吸气4秒
3. 屏息7秒
4. 通过嘴巴呼气8秒
5. 重复4个循环
**效果**：针对急性压力最快速的副交感神经激活方法

### 心脏协调法
**时长**：5分钟
**触发条件**：RMSSD值低（＜30毫秒）、压力指数高
**操作步骤**：
1. 均匀呼吸：吸气5秒，呼气5秒
2. 将注意力集中在心脏周围区域
3. 回忆一段美好的经历或心怀感激的情绪
4. 保持该状态5分钟
**效果**：最大化心率变异性，形成规律的心脏节律模式

### 生理性叹息法
**时长**：30秒（1–3个循环）
**触发条件**：突然感到不堪重负、急性恐慌
**操作步骤**：
1. 通过鼻子快速吸气两次（“吸——吸”）
2. 随后通过嘴巴缓慢呼气
3. 重复1–3次
**效果**：迅速激活副交感神经系统，立即起到镇静作用

### α脑波诱导法（开放式专注）
**时长**：5分钟
**触发条件**：β脑波过高且放松程度低——无法放松
**操作步骤**：
1. 放松目光——不要聚焦于任何单一物体
2. 注意观察物体之间及周围的空隙
3. 将注意力扩展到周边视野
4. 保持这种“开放式专注”状态5分钟
**效果**：促进α脑波产生，降低β脑波的主导地位

### 开放式觉察法
**时长**：5–10分钟
**触发条件**：LZC值低（0-100量表上＜40）——神经复杂度过低
**操作步骤**：
1. 舒适地坐着，闭眼或保持柔和的注视状态
2. 不要将注意力指向特定事物
3. 仅需观察任何浮现的意象——思维、声音、感觉等
4. 不加干预地让每一项观察自然流逝
**效果**：提升神经复杂度及意识相关指标

### 迷走神经调节法
**时长**：3分钟
**触发条件**：RMSSD值低（＜25毫秒）——迷走神经张力较弱
**操作步骤**：
1. 每次呼气时发出一个持续而稳定的长音，持续30秒
2. 或者：用冷水漱口30秒
3. 重复3–5次
**效果**：直接刺激迷走神经，增强副交感神经张力

## 情绪调节方案

### FAA平衡法
**时长**：5分钟
**触发条件**：负面FAA值（右脑半球占主导）、抑郁指数高
**操作步骤**：
1. 想想你真正期待的事情（接近动机）
2. 在心中想象自己成功完成一个有意义的目标
3. 用左手握拳10秒，然后松开
4. 重复该想象与握拳动作3–4次
**效果**：激活左前额叶皮层，使FAA值转为正面

### 慈悲心法（Metta）
**时长**：5–10分钟
**触发条件**：感到孤独、羞愧或情绪低落
**操作步骤**：
1. 闭上眼睛，想到你在意的人
2. 在心中默默重复：“愿你幸福。愿你健康。愿你安全。”
3. 将同样的祝福送给自己
4. 接着送给一个中性人物，最后逐渐转向关系复杂的人
**效果**：降低退缩动机，提升积极情绪

### 情绪释放法
**时长**：2分钟
**触发条件**：双相情感障碍指数高或FAA值出现剧烈波动
**操作步骤**：
1. 安全地进行30秒的快速深呼吸
2. 停下，进行3次缓慢而深长的呼吸
3. 进行60秒的身体扫描——注意身体哪些部位存在紧张感
4. 抖动双手和双臂15秒
**效果**：释放被滞留的交感神经能量，重新调整状态

### 安抚触碰法
**时长**：3–5分钟
**触发条件**：处于急性痛苦中、创伤记忆被激活或焦虑感极强
**操作步骤**：
1. 用掌心向下，从肩膀轻轻抚摸至肘部
2. 缓慢搓动双手掌心
3. 轻轻触摸额头和太阳穴
4. 在缓慢呼吸的同时持续进行3–5分钟
**效果**：打破杏仁核与大脑皮层的恶性循环，减轻痛苦感

### 焦虑冲浪法
**时长**：约8分钟
**触发条件**：无缘由地感到焦虑情绪上升
**操作步骤**：
1. 注意焦虑在身体中的位置——是胸部？腹部？喉咙？
2. 不加评判地描述那种感觉（紧绷？发热？嗡嗡作响？）
3. 向该部位呼吸3次
4. 观察：焦虑感是在变大、变小还是改变形态？
5. 继续观察5–8分钟——焦虑通常会在此时达到峰值然后消退

### 愤怒：掌心按压释放法
**时长**：2分钟
**触发条件**：出现愤怒信号，BAR值高且心率上升
**操作步骤**：
1. 双手掌心用力相压10秒
2. 松开双手，进行3次延长的呼气（吸气4秒，呼气8秒）
3. 重复3–4次

### 嫉妒与比较转化法
**时长**：3分钟
**触发条件**：使用社交媒体后出现嫉妒情绪
**操作步骤**：
1. 明确表达嫉妒：“我嫉妒___”
2. 自问：“这种嫉妒告诉我，我真正想要的是什么？”
3. 转化思路：“我实现该目标的下一步行动是___”
**效果**：将嫉妒情绪转化为能揭示个人价值观的欲望信号

### 惊叹感诱导法
**时长**：3–5分钟
**触发条件**：存在感缺失、参与度低、失去生活意义感
**操作步骤**：
1. 想象自己站在大峡谷边缘或星空之下
2. 允许自己感受那种渺小的震撼——这很美妙
3. 回忆过去某个令你真正感到惊叹的时刻
4. 注意观察身体有哪些变化
**效果**：对抗享乐适应现象，恢复生活意义感

## 睡眠与恢复方案

### 超日节律重置法
**时长**：20分钟
**触发条件**：90分钟专注时段结束，困倦感上升
**操作步骤**：
1. 设定20分钟的计时器
2. 不安排任何任务——只需休息（无需强制入睡）
3. 如有可能，调暗灯光并闭上眼睛
4. 让思维无序地漫游
**效果**：与90分钟的超日节律相契合，恢复认知资源

### 觉醒重置法
**时长**：5分钟
**触发条件**：嗜睡症指数＞40，极度困倦
**操作步骤**：
1. 用冷水泼脸和手腕
2. 进行20秒的卡帕拉巴蒂呼吸法（快速用鼻子呼气）
3. 暴露在明亮光线下2–3分钟
**效果**：引发即时觉醒反应，抑制困倦感

### 非睡眠深度休息法/瑜伽尼德拉法
**时长**：20–30分钟
**触发条件**：积累疲劳，需要深度恢复但不想入睡
**操作步骤**：
1. 平躺下来，手掌向上
2. 闭上眼睛，从脚趾开始逐步向上进行身体扫描
3. 在每个身体部位，仅观察感觉，无需做出任何改变
4. 若睡着了也没关系——设定闹钟即可
**效果**：在不产生睡眠惯性的前提下恢复多巴胺水平及认知资源

### 小睡法
**时长**：10–20分钟（务必设定闹钟！）
**触发条件**：困倦程度＞0.70、午饭后精力下降、θ脑波占主导
**操作步骤**：**1. 设置最长20分钟的闹钟（避免N3睡眠惯性）**  
**2. 躺下或半躺**  
**3. 即使无法进入深度睡眠，也请闭眼休息**  
**4. 醒来后：在继续工作前先进行30秒的伸展运动**  
**效果**：可恢复2–3小时的专注力与警觉性  

### 睡前放松流程  
**开始时间**：睡前60分钟  
**触发条件**：晚间时段、困意渐浓、即将入睡时  
**操作指南**：  
1. 将所有屏幕切换至夜间模式  
2. 停止学习新知识或处理复杂任务  
3. 将明日待办事项全部写在纸上  
4. 进行10分钟的渐进式放松训练或4-7-8呼吸法  
5. 保持房间温度在65–68华氏度/18–20摄氏度之间

## 躯体与物理调节方案  

### 渐进式肌肉放松（PMR）  
**时长**：10分钟  
**触发条件**：放松程度<0.25，且心率变异性在训练过程中持续下降  
**操作步骤**：  
1. 从脚部开始——肌肉绷紧5秒，然后放松8–10秒  
2. 逐节向上进行：小腿 → 大腿 → 腹部 → 手部 → 手臂 → 肩部 → 面部  
3. 每次绷紧肌肉5秒，放松8–10秒  
4. 最后做3次深呼吸  

### 现实回归法（5-4-3-2-1）  
**时长**：3分钟  
**触发条件**：出现恐慌、情绪脱离现实感或急性焦虑加剧  
**操作步骤**：  
1. 列出5件你能看到的东西  
2. 列出4件你能触摸到的东西  
3. 列出3件你能听到的声音  
4. 列出2种你能闻到的气味  
5. 列出1种你能尝到的味道  

### 20-20-20视觉恢复法  
**时长**：20秒  
**触发条件**：长时间使用屏幕导致眼睛疲劳  
**操作步骤**：  
1. 每使用屏幕20分钟后  
2. 看向20英尺远处的物体  
3. 保持注视20秒  

### 颈部放松序列  
**时长**：3分钟  
**触发条件**：静止状态指数过高（>0.85）且头痛指数上升  
**操作步骤**：  
1. 耳部向肩膀方向倾斜——每侧保持15秒  
2. 下巴内收——重复10次（将下巴尽量向后拉）  
3. 轻柔转动颈部——每个方向各5次  
4. 肩部耸动——重复10次（先向上耸肩，再放松）  

### 运动皮层激活法  
**时长**：2分钟  
**触发条件**：静止状态极高，且长时间保持静态坐姿  
**操作步骤**：  
1. 跨臂动作：右手触碰左膝，交替进行10次  
2. 手脚各抖动15秒  
3. 脚踝和手腕各向两侧转动5次  
**效果**：可重新激活本体感觉并促进运动皮层功能  

### 认知负荷卸载法（头脑倾倒法）  
**时长**：5分钟  
**触发条件**：认知负荷持续高于0.70，思绪纷乱，脑电波β波频率偏高  
**操作步骤**：  
1. 打开空白文档或拿一张纸  
2. 不加筛选、不加整理地写下脑海中所有念头  
3. 将担忧、待办事项、创意等一切占据工作记忆的内容全部写出来  
4. 关闭文档（如有需要可稍后查看）  
**效果**：将工作记忆外化可减少20–40%的认知负荷

## 数字设备与生活方式调节方案  

### 抑制刷手机冲动法  
**时长**：90秒  
**触发条件**：出现手机成瘾迹象，有查看社交媒体的冲动  
**操作步骤**：  
1. 注意到想要查看手机的冲动  
2. 不要立即行动，只需观察这种冲动90秒  
3. 观察：冲动是否会达到峰值后逐渐消失？  
4. 继续做原来的事情  
**效果**：可打破自动寻求多巴胺的循环  

### 重置多巴胺分泌机制法  
**时长**：持续进行  
**触发条件**：因大量观看短视频导致多巴胺分泌趋于平稳  
**操作步骤**：  
1. 找出能带来持续愉悦感的活动（如阅读、烹饪、散步）  
2. 用一项此类活动替代15分钟的刷屏时间  
3. 记录3天内情绪的变化情况  

### 数字设备使用截止时间法  
**开始时间**：睡前60–90分钟  
**触发条件**：晚间时段，即将入睡前的常规准备  
**操作指南**：  
1. 睡前60–90分钟彻底停止使用所有屏幕设备  
2. 转而进行非屏幕类活动：阅读、交谈、伸展运动等  
3. 若确实需要使用屏幕，至少将亮度调至夜间模式最低级别

## 饮食调节方案  

### 咖啡因摄入时间指南  
**触发条件**：早晨起床后，或焦虑指数偏高时  
**建议**：  
- 在醒来后90–120分钟再摄入咖啡因（此时皮质醇水平已达到峰值）  
- 下午2点之后不再摄入咖啡因（其半衰期约为6小时）  
- 若焦虑指数超过50，可搭配200毫克的L-茶氨酸一同摄入，以平缓咖啡因带来的刺激效应  

### 饭后能量崩溃缓解法  
**触发条件**：午餐后出现明显的困倦感  
**操作步骤**：  
1. 饭后立即进行5分钟的快走  
2. 暴露在阳光下10分钟  
**效果**：可有效缓解餐后困倦感

## 动机激发与计划制定方案  

### WOOP方法（愿望、结果、障碍、计划）  
**时长**：5分钟  
**触发条件**：面对任务时积极性较低  
**操作步骤**：  
1. **愿望**：你希望在这次任务中完成什么？  
2. **结果**：最理想的结果是什么？在心中将其可视化  
3. **障碍**：可能会出现的内部障碍有哪些？  
4. **计划**：“如果遇到[障碍]，我就采取[具体行动]。”  
**效果**：通过心理对比法，可提升任务完成率2–3倍  

### 任务前准备法  
**时长**：3分钟  
**触发条件**：开始任务时积极性低，且困意指数<0.50  
**操作步骤**：  
1. 为接下来的工作环节设定明确的目标  
2. 写下最关键的一项任务  
3. 做10个开合跳或20次深呼吸  
4. 从最简单的子任务开始，逐步积累动力
