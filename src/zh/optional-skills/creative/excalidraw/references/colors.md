# Excalidraw 颜色方案

在所有图表中统一使用这些颜色。

## 主色调（用于线条、箭头及强调元素）

| 名称 | 十六进制值 | 适用场景 |
|------|-----------|----------|
| 蓝色 | `#4a9eed` | 主要操作、链接、数据系列1 |
| 琥珀色 | `#f59e0b` | 警告提示、高亮显示、数据系列2 |
| 绿色 | `#22c55e` | 成功状态、积极含义、数据系列3 |
| 红色 | `#ef4444` | 错误状态、负面含义、数据系列4 |
| 紫色 | `#8b5cf6` | 强调元素、特殊项目、数据系列5 |
| 粉色 | `#ec4899` | 装饰性元素、数据系列6 |
| 青色 | `#06b6d4` | 信息展示、次要元素、数据系列7 |
| 黄绿色 | `#84cc16` | 其他用途、数据系列8 |

## 柔和填充色（用于形状背景）

| 颜色 | 十六进制值 | 适用场景 |
|------|-----------|----------|
| 浅蓝色 | `#a5d8ff` | 输入项、数据源、主要节点 |
| 浅绿色 | `#b2f2bb` | 成功状态、输出结果、已完成任务 |
| 浅橙色 | `#ffd8a8` | 警告提示、待处理状态、外部元素 |
| 浅紫色 | `#d0bfff` | 处理中状态、中间件、特殊元素 |
| 浅红色 | `#ffc9c9` | 错误状态、严重问题、警报信息 |
| 浅黄色 | `#fff3bf` | 备注、决策内容、规划事项 |
| 浅青色 | `#c3fae8` | 存储系统、数据、内存相关内容 |
| 浅粉色 | `#eebefa` | 分析结果、指标数据 |

## 背景区域色（用于分层图表，透明度建议设置为30-35）

| 颜色 | 十六进制值 | 适用场景 |
|------|-----------|----------|
| 蓝色区域 | `#dbe4ff` | UI/前端层 |
| 紫色区域 | `#e5dbff` | 逻辑/智能体层 |
| 绿色区域 | `#d3f9d8` | 数据/工具层 |

## 文本对比度规则

- **在白色背景上**：文本颜色最低要求为 `#757575`，推荐使用默认值 `#1e1e1e`。
- **在浅色背景上的彩色文本**：应选用深色调（如使用 `#15803d` 而非 `#22c55e`，使用 `#2563eb` 而非 `#4a9eed`）。
- **白色文本**：仅适用于深色背景（建议使用 `#9a5030` 而非 `#c4795b`）。
- **绝对禁止**在白色背景上使用浅灰色（如 `#b0b0b0`、`#999`），此类颜色难以辨认。
