请按照以下指南创建知识人物传记漫画页：

## 图像规格

- **类型**：包含多个分镜的连环画页面
- **方向**：纵向（竖屏）
- **宽高比**：2:3
- **风格**：具体视觉规范请参考对应风格指南

## 分镜结构

### 分镜边框
- 每个分镜周围保留1-2像素的清晰黑线
- 分镜之间设置8-12像素的白色间隔
- 分镜排列需保证阅读流畅性
- 不同尺寸的分镜可营造视觉节奏感

### 分镜内容构成
- 每个分镜都有明确的焦点
- 合理运用前景、中景和背景元素
- 摄影角度多样：平视、鸟瞰、低角度、特写、全景
- 分镜间的动作过渡需逻辑清晰
- 要有刻意设计的留白

## 文本元素

### 对话气泡
- **对话内容**：带尖尾的椭圆形气泡
- 内部为白色，边缘为细黑线
- 尾部需明确指向说话者
- 字体采用手写风格，而非电脑生成字体

### 叙述框
- **第四面墙/旁白**：矩形框
- 通常位于分镜边缘（顶部或底部）
- 填充颜色略有不同（奶油色或浅黄色）
- 用于添加评论、时间跳转或解释说明

### 心理活动气泡
- 形状类似云朵，带有通向思考者的气泡尾迹
- 边缘线条比对话气泡更柔和
- 用于表现角色的内心独白

### 字幕栏
- 位于分镜边缘的矩形条
- 显示时间与地点信息
- 可使用“与此同时……”“三年后……”这类过渡语
- 背景颜色较深，文字为白色，或反之

### 字体设计
- 全篇采用手绘风格字体
- 重要内容及关键词用粗体标注
- 字体大小保持一致
- 中文文本请使用全角标点符号""，。！
- 层级需清晰：标题 > 对话 > 字幕

在表现抽象概念时：

| 概念 | 视觉隐喻 |
|---------|----------|
| 神经网络 | 由线条连接的发光节点 |
| 数据流 | 沿简单路径移动的发光粒子 |
| 算法 | 几何图案与积木元素 |
| 逻辑/证明 | 互相扣合的拼图块 |
| 发现 | 光线穿透黑暗的场景 |
| 不确定性 | 分叉的道路与问号符号 |
| 时间 | 时钟图案与日历页面 |

- 将图表自然融入叙事分镜中
- 可通过插页或心理活动气泡形式进行解释
- 优先采用简化图标而非写实风格表现

## 第四面墙/旁白角色

在表现向读者讲述故事的旁白角色时：
- 该角色可直接看向画面之外
- 可出现在“现实场景”中
- 视觉呈现方式需与主线时间轴有所区分
- 通常位于页面边缘或专门的旁白分镜中
- 可对所展示的事件发表评论或提出疑问

## 历史真实性

- 需研究特定历史时期的细节：服饰、技术、建筑风格
- 不同时间段的角色外貌变化需自然呈现
- 具有标志性的物品与地点需保持可识别性
- 需在真实性与艺术化处理之间取得平衡
