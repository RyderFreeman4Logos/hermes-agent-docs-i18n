# ink-brush

水墨画风——兼具动态笔触的中国水墨美学风格

## 概述

专为漫画设计的传统中国水墨画风格。将书法般的笔触与水墨效果相结合，打造出源自东亚美学的富有氛围感与艺术性的视觉效果。

## 笔触设计

- 宽度不一的2-3像素动态笔触
- 具有传统水墨感的晕染效果
- 边缘清晰、有力且自信的笔触
- 用于表现布料与头发的流畅线条
- 基于压力感知的笔触变化

## 角色设计

- 符合现实比例的人物身材（头部高度为7.5-8单位）
- 以水墨风格呈现清晰的面部特征
- 能够展现动作动态的姿势设计
- 表现运动状态下的飘逸头发与衣物
- 提供传统服饰选项（长袍、汉服）
- 充满表现力且情绪饱满的面部表情

## 水墨技法

| 技法 | 用途 |
|------|------|
| 粗笔触 | 角色轮廓绘制 |
| 细线条 | 细节刻画与头发表现 |
| 水墨晕染 | 营造氛围与阴影效果 |
| 干刷技法 | 表现纹理与陈旧感 |
| 泼洒笔触 | 强化冲击力与戏剧效果 |

## 背景处理

- 壮观的风景元素：山脉、瀑布、寺庙
- 水墨风格的气候氛围渲染
- 朦胧的层次感深度
- 传统建筑元素
- 高对比度的剪影效果
- 将负空间作为设计元素

## 色彩方案

- 以水墨渐变为主色调
- 有限量的点缀色
- 传统中国色彩体系
- 具有氛围感的色彩晕染
- 高对比度构图
