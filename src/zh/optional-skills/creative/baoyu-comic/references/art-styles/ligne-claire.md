# 清线画风

清线画风——线条均匀、色彩扁平，承袭欧洲漫画传统。

## 概述

这种经典的欧洲漫画风格源自埃尔热创作的《丁丁历险记》。其特点在于线条简洁均匀，填充色为无渐变的扁平色彩，从而营造出一种经典且易于理解的视觉效果，非常适合用于教育类及叙事类内容。

## 线条处理

- 线条均匀、干净，粗细一致（2像素）
- 不使用阴影线或交叉阴影来表现明暗
- 所有元素的边缘都清晰锐利
- 所有人物和物体均以黑色墨线勾勒
- 通过扁平色块而非线条技巧来表现阴影

## 角色设计

- 角色略带卡通风格，但比例真实
- 面部特征鲜明，易于辨认
- 表情生动，情感表达清晰
- 服装符合所处时代特征，细节处理精致
- 不同分镜中角色的外观保持一致
- 身高与头部比例约为6-7倍

## 背景处理

- 背景细节丰富、真实，建筑细节准确
- 道具与技术符合特定时代背景
- 具有清晰的空间深度和透视感
- 通过细节展现环境故事
- 简化的角色与复杂的背景形成对比

## 色彩运用

- 采用无渐变的扁平色彩（遵循清线画风传统）
- 每页色彩种类有限，以保持整体协调性
- 色彩需服务于叙事氛围
- 场景内的光线逻辑保持一致

## 质量检查标准

- ✓ 全文线条粗细均匀、干净
- ✓ 为无渐变的扁平色彩
- ✓ 背景细节丰富，角色风格鲜明
- ✓ 分镜边界清晰，阅读流畅
- ✓ 文字采用手绘风格
- ✓ 环境中的透视关系正确
