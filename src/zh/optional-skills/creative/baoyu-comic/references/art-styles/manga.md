# 漫画风格

日式漫画风——兼具动漫特质与漫画美学，角色表现力十足

## 整体概述

日式漫画艺术风格以大而富有表现力的眼睛、动态的姿势以及直观的情绪表达元素为特色。这种风格应用极为广泛，适用于教育类、浪漫类到动作类等各类题材。

## 线条处理

- 清晰流畅的线条（1.5-2像素）
- 通过线条粗细变化强化表现力
- 流畅的曲线与富有动感的笔触
- 支持添加速度线与运动特效
- 可运用网点效果营造氛围

## 角色设计

- 动漫/漫画比例：大眼睛、富有表情的脸部
- 身高与头部比例通常为5-7倍（不同子风格有所差异）
- 直观的情绪表达符号（！、？、汗滴、闪光点）
- 动态的姿势与手势
- 细致到每一根发丝的头发设计
- 具有自然褶皱感的时尚服饰

## 眼睛样式

| 类型 | 描述 |
|------|------|
| 标准型 | 中等大小，2-3处高光点 |
| 教育向 | 友好亲切的眼神 |
| 戏剧型 | 细节丰富的强烈眼神 |
| 可爱型 | 非常大且带有闪光点的双眼 |

## 背景处理

- 对话或解释场景时采用简化处理
- 开场镜头则使用精细细节
- 通过网点渐变调节氛围
- 情感强烈的场景可使用抽象背景
- 技术图表可设计为显示屏样式

## 颜色方案

- 清新明亮的动漫色彩
- 皮肤颜色采用柔和渐变
- 多种鲜艳的配色选项
- 光影过渡自然柔和
- 通过颜色编码区分不同角色

## 视觉元素

- 对话框：圆形（普通情况）、尖形（兴奋时）
- 视觉化呈现的声音效果
- 情绪符号（汗滴、愤怒标记、心形）
- 速度线与运动模糊效果
- 闪光与发光效果

## 质量检查标准

- ✓ 角色面部表情富有表现力
- ✓ 线条清晰且风格统一
- ✓ 动作姿势与构图生动自然
- ✓ 合理运用漫画传统表现手法
- ✓ 分镜顺序清晰易读
- ✓ 角色设计风格一致
