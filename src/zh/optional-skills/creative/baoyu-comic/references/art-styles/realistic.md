# 写实风格

写实画风——采用数字绘画技术，呈现逼真的比例与光影效果。

## 概述

运用数字绘画技术打造的全彩写实漫画风格。其特点在于角色结构符合人体解剖学规律，拥有丰富的渐变效果以及精细的环境渲染，整体美学风格成熟，适合面向成年受众。

## 线条处理

- 线条干净精准，轮廓清晰
- 采用统一的线宽来凸显角色特征
- 不使用过多的阴影处理——依靠色彩层次来营造深度感
- 曲线流畅，角色结构线条真实自然
- 受“清晰线稿”风格影响：线条简洁但并非过度简化

## 角色设计

- 逼真的人体比例（头部高度为7-8单位）
- 特征与表情符合人体解剖学规律
- 面部结构细致，无夸张处理
- 动作与肢体语言自然
- 不同分镜中的角色形象保持一致
- 表情含蓄，而非典型的漫画式夸张表情

## 渲染风格

- 全彩数字绘画，搭配丰富的渐变效果
- 皮肤与布料上的阴影过渡柔和
- 材质纹理真实逼真（玻璃、液体、布料、木材等）
- 头发细节丰富，具有自然的光泽与蓬松感
- 环境光会影响所有元素
- 不采用扁平的赛璐珞风格——色彩过渡平滑自然

## 背景处理

- 环境细节极为丰富，极具写实感
- 透视与空间深度表现准确
- 具有氛围感的灯光效果（温暖的室内光、凉爽的室外光）
- 专业场景得以精准呈现
- 道具与物体的纹理真实自然

## 色彩方案

- 通过丰富的渐变来增强深度与立体感
- 光影效果真实，具有冷暖对比
- 根据不同材质进行个性化渲染
- 色温变化细腻自然
- 色彩搭配专业且富有层次感

## 质量标准

- ✓ 角色比例符合人体解剖学规律
- ✓ 颜色渐变平滑自然（非扁平填充）
- ✓ 材质纹理真实逼真
- ✓ 背景细节丰富，具有氛围感
- ✓ 光线自然，阴影柔和
- ✓ 表情富有表现力但不过于夸张
- ✓ 整体美学风格专业
- ✓ 对话框设计简洁清晰
