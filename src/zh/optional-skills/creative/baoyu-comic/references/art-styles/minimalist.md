# 极简风格

极简画风——采用干净的黑色线条，少量点缀色，以及简化的火柴人式角色设计。

## 概述

这种极简风格的卡通插画以白色背景上的干净黑色线条为特色，仅使用极少量的点缀色来突出重点。角色被简化为近乎火柴人的抽象形态，注重动作与概念的表达而非复杂的解剖结构。它非常适合用于商业寓言、便于快速阅读的教育内容以及概念性插图。

## 线条处理

- 干净且均匀的黑色线条（1.5-2像素）
- 不使用阴影、交叉阴影或渐变技巧
- 细节极简——每条线条都有其作用
- 角色轮廓较粗，道具/标签的线条则较细
- 无装饰性纹路或复杂线条

## 角色设计

- 非常简化的、类似火柴人的商业人物形象
- 头部为圆形或椭圆形，面部特征极简（点状眼睛、简单的线条嘴巴）
- 身体由简单的几何形状或线条构成
- 通过道具来区分不同角色（领带、帽子、公文包、眼镜）
- 无复杂的解剖结构——通过姿势和动作来表现情感
- 高度通常为4-5个头长，可呈现蹲姿或标志性姿态

## 背景处理

- 大多为空白/纯白色——负空间本身就是一种设计元素
- 环境元素极少（地面用一条线表示，简单的办公桌轮廓）
- 以概念标签和文字说明替代复杂的背景场景
- 优先使用图标和符号而非写实渲染
- 无透视效果或空间深度感

## 颜色方案

- 主要为黑白两色（占图像的90%以上）
- 使用1-2种点缀色来强调核心概念
- 点缀色使用谨慎：仅用于突出关键物体、文字标签及概念指示
- 背景无渐变、无阴影、无填充颜色
- 颜色用于引导视线，聚焦于每幅画面中最重要的元素

## 默认配色表

| 角色类型 | 颜色 | 十六进制值 |
|----------|------|------------|
| 主色 | 黑色墨水 | `#1A1A1A` |
| 背景色 | 纯白色 | `#FFFFFF` |
| 点缀色1 | 橙色 | `#FF6B35` |
| 点缀色2 | 蓝色（可选） | `#3182CE` |
| 文字标签色 | 深灰色 | `#4A4A4A` |
| 画面边框色 | 中灰色 | `#666666` |

## 视觉元素

- 对于关键术语，文字标签可搭配点缀色背景或下划线
- 简单的图标：箭头、圆形、对勾、叉号
- 使用点缀色的概念高亮框
- 对话气泡极少（简单的椭圆形或矩形，带有细黑色轮廓）
- 无音效、无运动线条、无屏幕提示音

## 质量标准

- ✓ 线条干净且富有目的性，无多余细节
- ✓ 90%以上为黑白色调，点缀色使用得当
- ✓ 即使缩小尺寸也能清晰辨认的简化角色
- ✓ 文字标签自然融入画面布局
- ✓ 负空间运用得当
- ✓ 每个元素都服务于叙事目的

## 兼容性

| 风格基调 | 适配度 | 备注 |
|----------|--------|------|
| 中性风格 | ✓✓ | 非常适合商业及教育类内容 |
| 温暖风格 | ✓ | 适用于轻松的故事，点缀色可增添温和感 |
| 活力风格 | ✓ | 适合充满活力、节奏明快的内容 |
| 戏剧风格 | ✗ | 风格过于简洁，无法体现强烈的戏剧效果 |
| 复古风格 | ✗ | 极简美学与复古/质感风格相冲突 |
| 浪漫风格 | ✗ | 无法容纳装饰性或柔和的元素 |
| 动作风格 | ✗ | 缺乏表现速度或冲击力的动态线条能力 |

## 最佳应用场景

商业寓言、管理类寓言故事、简短的概念插图、四格漫画、快速传递信息的教育内容、社交媒体素材
