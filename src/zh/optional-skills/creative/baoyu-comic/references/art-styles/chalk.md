# 粉笔画风格

具有手绘温润感的黑板美学风格

## 概述

采用经典的教室黑板风格，搭配手绘的粉笔图案。通过略显不完美的线条营造出怀旧的教育氛围，展现出传统教学方式的温暖质感。

## 线条设计

- 略显粗糙、不完美的手绘线条
- 所有线条均带有粉笔质感
- 根据粉笔按压力度呈现不同的线条粗细
- 边缘柔和，无生硬的数字线条
- 可见粉笔灰效果

## 角色设计

- 简约友好的角色形象
- 从简笔画到半细节风格不等
- 通过简单手势传达情感
- 质感亲和，不会令人产生压迫感
- 具有教育讲师风格的造型

## 背景设计

- 黑板黑色（#1A1A1A）或深绿黑色（#1C2B1C）
- 真实的黑板纹理
- 若干的划痕与粉笔灰颗粒
- 轻微的橡皮擦痕迹以增强真实感
- 可选木质边框

## 字体设计

- 手绘粉笔字体风格
- 文字上可见粉笔质感
- 不完美的基线增添真实感
- 可使用白色或亮色粉笔作为强调色

## 视觉元素

- 手绘的粉笔图案
- 元素周围环绕的粉笔灰效果
- 装饰性涂鸦：星星、箭头、下划线、圆圈
- 数学公式与图表
- 橡皮擦污渍与粉笔残留物
- 简笔画人物与简单图标
- 具有手绘感的连接线

## 风格规范

### 应该做到
- 所有元素均保持真实的粉笔质感
- 全程采用不完美、手绘风格
- 添加细微的粉笔灰与污渍效果
- 通过色彩变化构建视觉层次
- 加入有趣的涂鸦与注释

### 不应该做到
- 使用完美的几何形状
- 创造干净、类似数字线条的效果
- 添加超写实的元素
- 使用渐变或光泽效果

## 质量检查标准

- ✓ 所有元素均保持真实的粉笔质感
- ✓ 具有不完美、手绘风格的特征
- ✓ 即使是手绘风格也能保证文字清晰可读
- ✓ 具有怀旧的教室氛围
- ✓ 视觉层次分明
- ✓ 具有有趣的教育美学风格
