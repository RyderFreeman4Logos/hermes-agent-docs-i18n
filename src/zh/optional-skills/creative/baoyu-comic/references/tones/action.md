# 动作风格

动作基调——速度、冲击力与强大力量感

## 概述

这种高冲击力的动作风格以动态的运镜、激烈的战斗效果以及强烈的视觉冲击力为特点，能够打造出极具沉浸感与紧张感的场景。

## 氛围特征

- 速度与动态感
- 强大与冲击力
- 激烈的战斗氛围
- 身体力量感
- 强烈的情绪共鸣

## 颜色调整参数

适用于所有艺术风格：

| 调整项 | 方向 |
|--------|-------|
| 饱和度 | 高对比度 |
| 对比度 | 最大化 |
| 色温 | 根据不同效果灵活设定 |
| 亮度 | 动态范围处理 |

## 动作特效

**战斗/动态特效**（可大量使用）：

| 特效 | 用途 |
|------|------|
| 速度线 | 表现动作速度与动态感 |
| 冲击爆发效果 | 展现打击与碰撞瞬间 |
| 冲击波 | 强调强大的冲击力 |
| 飞散碎片 | 表现环境被破坏的场景 |
| 灰尘云 | 形象化地面受击后的景象 |
| 动态模糊 | 突出快速移动的效果 |
| 后像效果 | 象征超高速动作 |

## 动作姿势指导原则

- 动感十足的战士姿态
| 身体重量与动量清晰可见
| 肌肉紧张感得以展现
| 动作流畅性得以捕捉
| 冲击点需重点突出

## 最佳适用场景

- 武术格斗场景
- 动作场面
| 运动瞬间
| 身体对抗场景
| 战斗场面
| 高潮对决时刻

## 组合使用建议

与以下风格搭配效果最佳：
- 水墨笔触风格：武侠战斗场景
- 漫画风格：少年漫战斗场景

避免与以下风格搭配：
- 粉笔素描风格：风格不匹配
| 黑白线稿风格：风格不匹配（过于静态）
