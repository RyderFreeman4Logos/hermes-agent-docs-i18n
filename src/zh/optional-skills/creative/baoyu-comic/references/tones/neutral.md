# 中性基调

中性基调——平衡、理性且具教育性

## 概述

默认采用平衡的基调，非常适合用于教育类及信息传递类内容。既不会过于情绪化，也不会显得冷漠，从而营造出易于理解的专业氛围。

## 情绪特征

- 情感表达适度
- 表达清晰、理性
- 以教育为核心
- 专业且亲切
- 叙事客观

## 颜色调整参数

应用于任何艺术风格时：

| 调整项 | 方向 |
|--------|------|
| 饱和度 | 标准（无变化） |
| 对比度 | 平衡 |
| 色温 | 中性 |
| 亮度 | 略高 |

## 光线设置

- 光线均匀、清晰
- 几乎没有强烈的阴影
- 各画面元素的光线一致
- 采用自然光源
- 对比度适中

| 关切 | 若有所思的表情 |
| 惊讶 | 眼睛微微睁大 |

## 使用说明

中性基调为默认选项。可与任何艺术风格结合使用，以获得基础的专业级效果。这是最具通用性的基调选项。
