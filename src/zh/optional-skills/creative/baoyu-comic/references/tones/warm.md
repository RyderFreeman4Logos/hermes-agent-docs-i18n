# 温暖风格

温馨基调——充满怀旧感、个人色彩且令人舒适

## 概述

专为讲述个人故事与怀旧内容打造温馨宜人的氛围。通过舒适的审美风格与舒缓的视觉效果，建立情感共鸣。

## 氛围特征

- 怀旧情感
- 个人化且亲密的氛围
- 舒缓治愈的效果
- 唤起回忆与引发反思
- 温和的情感温暖感

## 颜色调整参数

适用于所有艺术风格：

| 调整项 | 调整方向 |
|--------|----------|
| 饱和度 | 稍微降低 |
| 对比度 | 降低柔和度 |
| 色温 | 向温暖色调偏移（+15%） |
| 亮度 | 采用柔和的金色调 |

## 色温设置

将色彩调色板向温暖色调倾斜：

| 原始颜色 | 温暖偏移后 |
|----------|------------|
| 冷蓝色 | 柔和青绿色 |
| 纯白色 | 奶油色 |
| 灰色 | 暖灰色 |
| 黑色 | 柔和炭黑色 |

## 强调色

- 金黄色（#D69E2E）
- 柔和橙色（#DD6B20）
- 暖棕色（#8B6F47）
- 日落色调

## 光线效果

- 黄金时刻光线
- 柔和的漫射光
- 室内温暖的灯光
- 蜡烛/台灯营造的温暖感
- 温和的阴影

## 情感表达范围

| 情感 | 表现方式 |
|------|----------|
| 快乐 | 真诚温暖的微笑 |
| 悲伤 | 温和的忧郁感 |
| 爱意 | 柔软温柔的表情 |
| 回忆 | 远望且若有所思的神情 |

## 构图要点

- 亲密的构图视角
- 舒适的背景环境
- 背景虚化处理
- 温馨的呈现空间
- 突出个人重要时刻

## 视觉元素

- 温暖的光线束
- 柔和的边缘处理
- 怀旧道具（老照片、纪念品）
- 舒缓物品（毛毯、茶杯）
- 自然元素（秋叶、日落景象）

## 最适合的应用场景

- 个人故事讲述
- 童年回忆分享
- 导师指导经历记录
- 家族历史传承
- 温和风格的传记创作
- 治愈类内容呈现

## 组合建议

与以下风格搭配效果尤为出色：
- 线条清晰风格：具有怀旧感的欧洲漫画风格
- 现实主义风格：感人至深的人物故事
- 漫画风格：充满生活气息的温暖画面
