# 浪漫风格

浪漫基调——柔和、优美，充满细腻的情感表达

## 概述

专为浪漫题材及情感细腻的内容打造柔和梦幻的氛围。通过装饰元素、闪光效果以及精美的构图，强化情感氛围与美感表现。

## 氛围特征

- 浪漫与爱情
- 优雅与美好
- 细腻的情感
- 梦想与希望
- 年轻与理想主义

## 颜色调整参数

适用于所有艺术风格：

| 调整项 | 方向 |
|--------|------|
| 饱和度 | 柔和的淡色调 |
| 对比度 | 低，柔和 |
| 色温 | 微暖的粉色调 |
| 亮度 | 柔和且带有光泽 |

## 光照效果

- 柔和的漫射光
- 光泽效果
- 后光环效应
- 闪光高光
- 梦幻氛围

## 装饰元素

**必备装饰元素**（可用于构图）：

| 元素 | 使用方式 |
|------|----------|
| 花瓣 | 漂浮状，用于构图框架 |
| 闪光点 | 强化情感表现的高光 |
| 气泡 | 营造梦幻感 |
| 羽毛 | 柔和飘动的效果 |
| 星星 | 适用于夜景，增添奇幻感 |
| 心形 | 强调爱情主题 |
| 光环 | 突出角色特征 |

## 情感表达范围

| 情感 | 表现方式 |
|------|----------|
| 爱情 | 柔和的目光、脸颊红晕 |
| 思念 | 远离现实般的美丽忧伤 |
| 快乐 | 容光焕发的笑容、闪光效果 |
| 害羞 | 低垂的双眼、脸颊红晕 |

## 构图技巧

- 优雅流畅的布局
- 柔和虚化的背景
- 由装饰元素环绕的角色
- 经典的3/4侧面视角
- 屏幕色调渐变
