# 复古风格

复古基调——具有历史感、陈旧感以及时代真实性。

## 概述

通过陈旧的纸张效果与符合时代审美的设计，营造出浓厚的历史氛围，赋予作品时间感、真实感以及历史纵深感。

## 氛围特征

- 历史真实性
- 历史距离感
- 档案质感
- 时间与记忆的联想
- 古典优雅气质

## 颜色调整参数

适用于所有艺术风格：

| 调整项 | 调整方向 |
|--------|-----------|
| 饱和度 | 降低，偏暗淡 |
| 对比度 | 中等，带陈旧感 |
| 色温 | 偏向棕褐色调 |
| 亮度 | 略显褪色 |

## 色彩方案

以陈旧色调为主：

| 颜色角色 | 颜色名称 | 十六进制值 |
|------|-------|-----|
| 主色 | 棕褐色 | #8B7355 |
| 背景色 | 陈旧纸张色 | #F5E6D3 |
| 强调色1 | 褪色青绿色 | #6B8E8E |
| 强调色2 | 淡紫红色 | #7B3F3F |
| 字体色 | 陈旧黑色 | #3D3D3D |
| 黄变色 | 纸张黄褐色 | #F5DEB3 |

## 视觉效果

**陈旧化处理**（适度应用）：

| 效果 | 应用方式 |
|--------|-----------|
| 纸张老化效果 | 背景纹理 |
| 边缘褪色效果 | 边缘暗角处理 |
| 灰尘斑点 | 微妙叠加层 |
| 黄变效果 | 颜色偏移 |
| 磨损痕迹 | 角落/边缘细节处理 |

## 历史元素

- 历史风格字体
- 符合时代的细节设计
- 档案式呈现方式
- 古典构图风格
- 正式装帧形式

## 光线设置

- 自然光，符合时代特征
- 烛光/油灯带来的温暖感
- 柔和的散射光
- 室内历史场景光线
- 电影级画质

## 情感表达范围

| 情感 | 表现方式 |
|---------|-----------|
| 尊严感 | 正式、沉稳的姿态 |
| 悲伤感 | 克制而优雅的表达 |
| 自豪感 | 古典式的仪态 |
| 智慧感 | 透着岁月的从容 |

## 构图原则

- 古典式构图
- 正式严谨的布局
- 符合时代的场景布置
- 纪录片风格
- 优先保证历史真实性

## 最佳适用场景

- 1950年代之前的故事
- 古典科学史题材
- 历史传记
- 时代背景作品
- 纪录片风格漫画
- 档案叙事类内容

## 风格搭配建议

与以下风格搭配效果最佳：
- 真实主义风格：历史剧
- 线条清晰风格：历史冒险题材
- 笔墨风格：古典亚洲故事

避免与以下风格混用：
- 漫画风格：风格冲突（过于现代）
| 粉笔风格：风格冲突（现代教育风格） |
