# 活力基调

充满活力、明亮且富有动感——营造令人兴奋的视觉氛围。

## 总体特点

通过明亮的色彩、动态的构图以及流畅的动效，为内容增添激情，非常适合面向年轻受众的创意表达。

## 情绪特征

- 兴奋与好奇
- 探索与学习
- 活力与热情
- 动感与行动力
- 年轻化风格

## 颜色调整参数

适用于所有艺术风格：

| 调整项 | 方向 |
|--------|------|
| 饱和度 | 高（鲜艳） |
| 对比度 | 中高 |
| 色温 | 可变，富有冲击力 |
| 亮度 | 明亮且干净 |

## 色彩方案

偏向鲜艳的色调：

| 角色 | 颜色 | 十六进制值 |
|------|------|-----------|
| 主红色 | 鲜艳红色 | #F56565 |
| 主黄色 | 阳光黄 | #F6E05E |
| 主蓝色 | 天空蓝 | #63B3ED |
| 强调色1 | 紫红色 | #D53F8C |
| 强调色2 | 酸橙绿 | #68D391 |
| 背景色 | 干净的白色 | #FFFFFF |
| 备用背景色 | 明亮淡色调 | 多种选择 |

## 光照效果

- 明亮清晰的照明
- 整洁的阴影
- 强烈的视觉冲击力
- 用于突出重点的聚光灯效果
- 动态的光源变化

## 动态元素

**活力特效**（可用于增强构图表现力）：

| 元素 | 用途 |
|------|------|
| 速度线 | 表现动作感与兴奋情绪 |
| 闪光点 | 象征新发现 |
| 爆发效果 | 强调“顿悟”时刻 |
| 动态模糊 | 表现快速动作 |
| 星光爆发 | 增强视觉焦点 |
| 汗珠 | 表现努力或惊讶情绪 |

## 情感表达

| 情感 | 表现方式 |
|------|----------|
| 兴奋 | 眼神放大、笑容灿烂 |
| 惊讶 | 戏剧性的反应 |
| 坚定 | 凝聚专注的眼神 |
| 好奇 | 闪烁的眼神 |

## 构图原则

- 动态视角
- 以动作为导向的布局
- 强调动态感
- 简洁有力的设计风格
- 色彩与元素的流畅过渡

## 视觉风格

- 具有表现力的动画角色
| 大眼睛、夸张的表情 |
| 动态姿势 |
| 以动作为核心的表现手法 |
| 为突出活力而简化的背景 |

## 最佳适用场景

- 科学知识讲解
- “顿悟”时刻的呈现
- 面向年轻受众的内容
- 探索主题的叙事
- 学习类冒险故事
- 动作操作教程

## 组合建议

**非常适合搭配的风格：**
- 漫画风格：充满少年感的活力
- 粉笔画风：趣味十足的教育内容

**避免搭配的风格：**
- 现实主义风格：风格冲突
- 笔墨画风：风格不匹配
