# 四格漫画预设——极简风格的四格商业寓言漫画

## 基础配置

| 参数 | 值 |
|------|-----|
| 艺术风格 | 极简风格 |
| 情绪基调 | 中性 |
| 布局类型 | 四格（默认） |
| 宽高比例 | 4:3（横向） |

对应参数为：art=minimalist, tone=neutral, layout=four-panel, aspect=4:3

## 特殊规则

该预设除了包含艺术风格与情绪基调的组合外，还有额外的特殊规则。一旦选择“四格漫画”预设，以下所有规则都必须严格执行。

### 起承转合叙事结构（至关重要）

每幅漫画必须遵循四格的起承转合结构：

| 格子 | 角色功能 | 要求 |
|------|----------|------|
| 1（起）：铺垫 | 介绍情境 | 展示处于可识别场景中的角色，明确“正常”状态或存在的问题 |
| 2（承）：发展 | 在铺垫基础上延伸 | 增加复杂情节，展示尝试行为或引入核心概念，让故事冲突更加清晰 |
| 3（转）：转折点 | 关键转折或顿悟时刻 | **最为重要的格子**。需展现出出乎意料的反转、对比或让人“恍然大悟”的瞬间，这是使寓言成立的关键 |
| 4（合）：结局 | 结局与启示 | 展示最终结果、后果或所得教训，可用视觉上的笑点或总结语句呈现 |

**重要提示**：严格遵循恰好4格的要求，不得出现第5格，图像内也不允许有标题栏或页脚栏。

### 单页故事规则（至关重要）

- 整个故事需在仅含4格的**单页**内讲完
- 页面总数始终为1页（可选择性添加封面）
- 不允许使用多页形式的四格故事——如果内容需要更多篇幅，应分别创建多幅独立的四格漫画
- 分镜结构：封面（可选）+ 1页正文

### 强调色系统

- 图像主体为黑白线条画风格
- 每幅漫画最多使用1-2种点缀色（默认为橙色 `#FF6B35`）
- 规则如下：
  - 核心概念标签或相关物体：用强调色填充或用该颜色描边
  - 第3格（转折点）需有最强烈的色彩突出效果
  - 角色仍保持黑白风格——颜色仅用于概念、物体和标签
  - 四个格子中的强调色必须保持一致，不得在不同格子间切换颜色

### 角色设计规则

- 采用简化的火柴人式角色设计
- 通过简单的道具区分不同角色：领带、眼镜、帽子、公文包、围裙等
- 面部细节不宜复杂，最多仅用圆点表示眼睛、线条表示嘴巴
- 角色设计应足够通用，能够代表不同的典型形象（如经理、员工、客户）
- 每幅漫画的角色数量最多为2-3个

### 格子内的文字

- 对话和标签需使用中文（也可与原文语言保持一致）
- 文字量应尽量精简，每个格子最多1-2行简短文字
- 核心概念词汇可用强调色背景进行突出显示
- 不允许出现旁白框，仅保留对话和标签
- 对话气泡：采用简单的矩形或椭圆形，搭配细黑边框

### 可选标题与旁白

- 四格漫画上方可添加简短的描述性标题
- 格子下方可添加可选的简短旁白或寓意总结
- 这些内容属于页面构成的一部分，不属于独立的格子

### 角色原型（灵活设定）

可根据故事内容创建简单的火柴人式角色，没有固定默认模板：

| 角色类型 | 典型原型 | 视觉特征 |
|----------|----------|----------|
| 主角 | 面对特定情境的工作者/员工 | 简单的造型，仅有少量区分特征（如眼镜、领带） |
| 权威角色 | 上司/经理/专家 | 体型稍大，或手持指示棒、剪贴板等道具 |
| 核心概念载体 | 所要表达的概念本身 | 带有标签的物体、图标，或用强调色突出显示的文字 |

### 提示词模板

在为四格漫画生成图像提示词时，请包含以下关键词：

> 一幅采用极简风格、线条清晰的数字漫画，采用2×2网格布局的四格结构。整体为简化版的卡通插画风格，具有清晰的黑色轮廓，色彩方案以黑白为主，核心概念会用特定的点缀色[强调色]突出显示。

对于每个格子的描述，需明确说明：
- 格子位置（左上/右上/左下/右下）
- 角色的姿势与动作（简单火柴人风格）
- 中文对话文字（手写风格）
- 所有带有强调色的元素（概念标签、关键物体）

## 质量检查标准

- ✓ 严格遵循2×2网格结构，恰好4格
- ✓ 清晰呈现起承转合的叙事脉络
- ✓ 图像90%以上为黑白色调，仅在关键位置使用点缀色
- ✓ 角色为简化的火柴人风格
- ✓ 核心概念通过强调色进行视觉突出
- ✓ 文字量极少，且为中文（或原文语言）
- ✓ 整个故事完整地呈现在单页内
- ✓ 第3格能清晰呈现转折点或关键洞察

## 适用场景

商业寓言、管理类寓言故事、简短观点阐述、职场相关寓言、概念对比展示、社交媒体教育内容、便于快速阅读的漫画等。
