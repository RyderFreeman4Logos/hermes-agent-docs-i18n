# 少女风格

少女主题预设——兼具浪漫美学的经典少女漫画风格

## 基础配置

| 维度 | 值 |
|------|-----|
| 艺术风格 | 漫画 |
| 情感基调 | 浪漫 |
| 布局 | 标准（默认） |

对应参数：art=manga, tone=romantic

## 独特规则

该预设除了包含艺术风格与情感基调的组合外，还设有特殊规则。选择“少女”预设时，必须应用以下所有规则。

### 装饰元素（必选）

每个情感场景都必须加入装饰元素：

| 情感类型 | 必需装饰元素 |
|---------|--------------|
| 爱情 | 飘浮的心形、闪光点、玫瑰花瓣 |
| 怀念 | 羽毛、气泡、远处的闪光点 |
| 快乐 | 盛开的花朵、光束、星星 |
| 悲伤 | 落下的花瓣、逐渐消失的闪光点 |
| 害羞 | 柔和的闪光点、漂浮的气泡 |
| 醒悟 | 带有闪光点的放射状线条 |

### 眼部细节要求

在少女风格中，眼睛至关重要：

| 维度 | 处理方式 |
|------|----------|
| 眼睛大小 | 比普通漫画更大（1.2倍） |
| 高光 | 多个高光点（3-5个），根据情感变化调整位置 |
| 反射效果 | 在充满情感的场景中加入场景反射 |
| 闪光效果 | 内置闪光特效 |
| 眼泪 | 晶莹剔透、细节丰富的泪滴形状 |

### 角色美感标准

| 特征 | 处理方式 |
|------|----------|
| 头发 | 流畅的线条、细腻的发丝、带有光泽的高光 |
| 肤质 | 如瓷器般光滑，脸颊带有柔和的红晕 |
| 嘴唇 | 柔和且略带光泽 |
| 手部 | 优雅的手势表现 |
| 姿态 | 优美端庄的姿势 |

### 背景效果

用于强化情感氛围的**抽象背景**：

| 场景类型 | 背景设计 |
|-----------|----------|
| 表白场景 | 柔和渐变背景 + 飘浮的花朵 |
| 震惊场景 | 屏幕色调速度线 + 闪光点 |
| 回忆场景 | 梦幻模糊效果 + 散落的花瓣 |
| 醒悟场景 | 径向线条 + 光束爆发 |
| 私密场景 | 柔和虚化背景 + 飘浮的装饰元素 |

### 分镜设计

- 在亲密场景中使用重叠分镜
- 打破分镜边框以增强情感冲击力
- 在分镜之间添加漂浮的装饰元素
- 使用屏幕色调渐变来营造氛围
- 采用不规则的分镜形状以增强戏剧性

### 情感节奏控制

通过放慢节奏来强化情感表达：

| 场景类型 | 分镜处理方式 |
|---------|--------------|
| 表白 | 多个小分镜，最后用大分镜呈现高潮 |
| 对视 | 连续的特写分镜 |
| 接触 | 慢动作的分镜拆解 |
| 醒悟 | 先通过逐步铺垫的分镜，最后达到情感高潮 |

### 色彩方案应用

| 场景类型 | 色彩搭配 |
|---------|----------|
| 浪漫场景 | 粉色、薰衣草色、玫瑰金 |
| 快乐场景 | 柔和的黄色、桃色、天蓝色 |
| 悲伤场景 | 淡蓝色、银色、灰紫色 |
| 戏剧性场景 | 深玫瑰红、紫色，对比强烈 |

### 屏幕色调运用

| 氛围类型 | 色调模式 |
|------|----------|
| 中性氛围 | 简洁、极简风格 |
| 浪漫氛围 | 柔和的渐变叠加效果 |
| 戏剧性氛围 | 对比强烈的色调 |
| 梦幻氛围 | 柔和的点状图案 |

## 质量标准

- ✓ 大而闪亮的精致眼睛
- ✓ 情感场景中包含装饰元素
- ✓ 流畅且美观的角色设计
- ✓ 柔和的淡彩色调
- ✓ 优雅的分镜构图
- ✓ 屏幕色调带来的氛围效果
- ✓ 全篇贯穿的浪漫氛围
- ✓ 美观且富有表现力的姿势

## 最适合的应用场景

爱情故事、成长题材、友情叙事、校园生活、情感剧、爱情小说
