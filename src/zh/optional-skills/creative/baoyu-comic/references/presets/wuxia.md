# 武侠

武侠预设——香港式武术漫画风格

## 基础配置

| 维度 | 值 |
|------|-----|
| 艺术风格 | 水墨笔触 |
| 情节基调 | 动作场面 |
| 布局方式 | 引人入胜的封面式布局（默认） |

相当于：art=ink-brush, tone=action

## 特有规则

该预设除了艺术风格与情节基调的组合外，还包含其他特殊规则。选择“武侠”预设时，必须应用以下所有规则。

### 气/能量效果（必选）

武术力量需通过气的效果展现出来：

| 效果类型 | 视觉呈现方式 |
|----------|--------------|
| 内力 | 角色周围散发出的光环 |
| 外力 | 可见的气体喷射效果 |
| 气的碰撞 | 散发的冲击波 |
| 气的吸收 | 朝角色方向流动的粒子 |
| 隐藏实力 | 眼睛或拳头处隐约的光芒 |

### 能量颜色

| 气的类型 | 颜色 |
|----------|------|
| 正义之气 | 蓝色（#4299E1）、金色（#FFD700） |
| 凶猛之气 | 红色（#DC2626）、橙色（#EA580C） |
| 邪恶之气 | 紫色（#7C3AED）、绿色（#16A34A） |
| 纯净之气 | 白色、银色 |
| 古老之气 | 带有粒子的金色 |

### 战斗视觉表现

**战斗关键时刻**必须包含以下元素：

1. 从碰撞点向外辐射的速度线
2. 飞散的碎片（石头、木块、布料）
3. 冲击波环
4. 灰尘/能量云
5. 被吹动的头发与衣物

### 动作表现方式

| 速度等级 | 视觉呈现方式 |
|----------|--------------|
| 普通速度 | 标准姿势 |
| 快速移动 | 动态模糊效果、速度线 |
| 闪电般速度 | 剩影、多角度视角 |
| 传送移动 | 淡出效果、粒子轨迹 |

### 环境融合

背景需能够衬托战斗场景：

| 环境类型 | 战斗场景增强元素 |
|----------|------------------|
| 山脉 | 战斗造成的山峰崩塌 |
| 森林 | 树木断裂、树叶飞散 |
| 水域 | 壮观的溅水效果、水上行走场景 |
| 寺庙 | 柱子倒塌、瓦片飞溅 |
| 悬崖 | 高空坠落场景、风效表现 |

### 角色姿势指南

- 具有重量分布感的动态战斗姿势
- 能体现动作流畅度的飘动服饰与头发
- 动作中可见的肌肉张力
- 稳立站立或处于动态移动中的双脚
- 传统武术姿势

### 武器效果

| 武器类型 | 视觉呈现方式 |
|----------|--------------|
| 剑 | 追随的光弧、剑身发光效果 |
| 掌法 | 气体喷射效果、风效 |
| 杖 | 旋转的模糊效果、冲击涟漪 |
| 鞭子 | 流动的能量轨迹 |

### 氛围元素

必须包含以下元素：
- 漂浮的粒子（树叶、花瓣、灰尘）
- 增加深度的水墨雾气
- 风向指示器
| 适当情况下的震撼天空/天气效果 |

## 质量检查标准

- ✓ 具有动态感且富有动作张力的姿势
- ✓ 符合水墨笔触风格的角色线条
- ✓ 可见的気/能量效果
- ✓ 对比度高的戏剧性光线效果
- ✓ 具有中国元素的氛围背景
- ✓ 服饰与头发的流畅动态表现
- ✓ 强烈的战斗关键时刻
- ✓ 速度线与冲击效果

## 最适合的应用场景

武术故事、中国历史小说、武侠/仙侠作品改编、动作场面密集的叙事作品
