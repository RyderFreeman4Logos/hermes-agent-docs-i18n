# concept-story

概念故事预设——通过角色驱动的故事来可视化抽象概念的叙事漫画

## 基础配置

| 维度 | 值 |
|------|-------|
| 艺术风格 | 漫画风格 |
| 氛围基调 | 温暖风格 |
| 布局方式 | 标准布局（默认值） |

对应参数为：art=manga, tone=warm

## 独特规则

该预设除了包含艺术风格与氛围基调的组合外，还设有特殊规则。一旦选择 `concept-story` 预设，以下所有规则都必须严格执行。

### 概念可视化系统（至关重要）

每个核心抽象概念都应拥有一个反复出现的视觉符号/隐喻：

| 概念类型 | 可视化方法 |
|-----------|--------------|
| 心理需求 | 角色持有或发现的实体物品（例如：发光的能量球象征能力） |
| 管理原则 | 角色在其中穿行的环境隐喻（例如：船舵象征自主权） |
| 成长/发展 | 会不断变化的有机生命体符号（例如：种子→开花植物象征人际联结） |
| 抽象框架 | 角色可以进入或观察的空间结构 |
| 情绪状态 | 场景氛围中的色彩/光线变化 |

**与 ohmsha 不同之处**：此处允许并期望使用对话框。其目标是将视觉隐喻与对话相结合，而非完全取代对话。

**典型叙事流程**：“对话引入概念”→“视觉隐喻加以阐释”→“角色作出反应或应用所学”

### 视觉符号的连贯性

符号必须在整个故事中保持一致：

| 阶段 | 处理方式 |
|------|----------|
| 引入阶段 | 当首次提及该概念时，符号会以柔和的发光效果出现 |
| 反复出现阶段 | 每当再次提及该概念时，相同的符号会出现在背景或角色互动场景中 |
| 结局阶段 | 所有符号会在最终画面中汇聚，体现所学概念的融会贯通 |

**分镜脚本要求**：在详细绘制分镜之前，需先制作一份“符号映射表”，明确概念与视觉符号之间的对应关系。

### 角色原型（灵活设定）

可根据内容领域创建原创角色，没有固定的默认模板：

| 角色职能 | 原型类型 | 视觉特征 |
|----------|----------|----------|
| 主角 | 面临挑战的学习者或工作者 | 现代职业人士或学生形象，具有共鸣感，初始姿态较为拘谨 |
| 导师 | 通过自身经验进行指导的资深引导者 | 年龄稍长，举止沉稳，画面中带有温暖的色彩点缀 |
| 推动者 | 引发角色转变的人或事件 | 可以是同事、某种情境、挑战或机遇 |

**重要提示**：角色会根据源内容所属领域（如商业、心理学、教育等）每次重新创建，不存在固定的角色库。

### 叙事弧线结构

必须遵循五阶段的成长弧线结构：

| 阶段 | 结构特点 | 视觉氛围 |
|-----|----------|----------|
| 开篇 | 主角陷入日常routine，面临种种挫折 | 柔和的暖色调，紧凑的构图，受限的画面空间 |
| 引发事件 | 导师出现或机遇降临 | 画面亮度提升，构图更加开阔 |
| 学习阶段 | 通过视觉隐喻引入各种概念 | 丰富的暖色调，符号逐一呈现 |
| 转折点 | 主角运用所学知识，面临考验 | 对比度增强，构图更具动态感 |
| 转变阶段 | 展现成长成果，新的理解清晰可见 | 全面的暖色调，广阔的构图，所有符号均出现 |

### 对话与动作的平衡

- 鼓励并期望使用对话（这与 ohmsha 的“禁止出现对话框”规则不同）
- 每一页都应至少包含一个对话框以及一个视觉/动作画面
- 应避免出现角色连续4格以上进行单纯讲解的“说教式”页面
- 当角色用语言解释某个概念时，下一格画面必须对其进行可视化呈现

**错误示例**：连续四格由导师向主角灌输知识
**正确示例**：导师引入概念 → 视觉隐喻画面 → 主角作出反应 → 主角应用所学知识

### 场景氛围规则

| 场景类型 | 氛围特点 |
|----------|----------|
| 问题/挫折场景 | 在暖色调基础上叠加冷调，构图紧凑，环境显得杂乱 |
| 导师指导场景 | 黄金时刻光线效果，构图开阔，室内充满温暖的光芒 |
| 概念可视化场景 | 柔和的发光效果，背景简洁简化，突出符号本身 |
| 成长/转变场景 | 温暖的光线由内向外扩散，角色的姿态也更加舒展 |
| 结局场景 | 全面的暖色调，广阔的构图，所有视觉符号均清晰可见 |

### 结尾要求

最后一页必须包含以下元素：

1. 主角展现出经过转化后的新理解（而非仅被告知结果）
2. 通过视觉对比展现与开篇状态的差异（例如：枯萎的植物→茁壮成长的植物）
3. 所有概念符号共同出现在画面中
4. 包含体现持续成长的前瞻性元素，避免封闭式的结局

### 页面标题规范

每一页都必须有一个叙事性标题：

**错误示例**：“第3章：自我决定理论”
**正确示例**：“小明找到属于自己的动力源泉那天”

## 质量检查标准

- ✓ 每个核心概念都有反复出现的视觉符号
- ✓ 对话与视觉隐喻相互配合，而非互相替代
- ✓ 从问题到转变的叙事弧线清晰可见
- ✓ 角色为内容领域量身打造，具有原创性
- ✓ 整体氛围温暖且专业
- ✓ 视觉符号在故事中不断重复出现并逐渐累积
- ✓ 最后一页将所有概念符号与转变后的成果相结合

## 适用场景

心理学概念、商业/管理原则、动机理论、个人发展、自助类内容、领导力框架、辅导叙事、软技能培训，以及通过角色驱动的故事来解释抽象概念。
