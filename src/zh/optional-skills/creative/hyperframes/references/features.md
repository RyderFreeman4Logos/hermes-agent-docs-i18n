# HyperFrames 功能参考手册

当合成内容需要字幕、文本转语音 narration、随音频变化的视觉效果、标记式文字高亮或场景切换功能时，即可加载此文件。此处所有的处理规则均为确定性逻辑（不使用 `Math.random()`、`Date.now()`，也不进行运行时的音频分析），并且会与合成内容的其余部分一同存在于同一个 GSAP 时间轴上。

## 字幕功能

### 语言规则（不可违反）

**除非确认音频为英语，否则绝不要使用 `.en` 类型的低语模型。** `.en` 模型会将非英语音频翻译成英语，而非直接进行转录。

- 用户指定语言 → `npx hyperframes transcribe audio.mp3 --model small --language <code>`（不使用 `.en`）
- 用户确认为英语 → `--model small.en`
- 语言未知 → `--model small`（系统自动检测）

### 风格识别

如果用户未指定字幕风格，系统会根据文本转录后的语调来自动判断：

| 语调类型         | 字体风格                | 动画效果                          | 颜色方案               | 字号    |
| -------------- | ------------------------ | ---------------------------------- | ----------------------- | ------- |
| 推广/发布类     | 粗体紧凑型，800-900       | 缩放弹出效果，`back.out(1.7)` 动画，持续 0.1-0.2 秒 | 深色背景上使用亮色       | 72-96px |
| 商务正式类     | 简洁无衬线字体，600-700    | 淡入滑动效果，`power3.out` 动画，持续 0.3 秒 | 白色/中性色搭配柔和点缀色 | 56-72px |
| 教程指导类     | 单行字体/简洁无衬线字体，500-600 | 打字机效果或淡入效果，持续 0.4-0.5 秒 | 高对比度，极简设计       | 48-64px |
| 叙事类         | 衬线字体/优雅风格，400-500   | 缓慢淡入效果，`power2.out` 动画，持续 0.5-0.6 秒 | 温和的柔和色调           | 44-56px |
| 社交媒体类     | 圆角无衬线字体，700-800    | 弹跳效果，`elastic.out` 动画，逐字显示   | 鲜艳色彩，趣味十足的设计   | 56-80px |

### 单词分组规则

- 高能量风格：2-3 个单词，快速切换。
- 对话式风格：3-5 个单词，使用自然短语。
- 冷静沉稳风格：4-6 个单词。

需在句子边界处断开显示，添加至少 150 毫秒的停顿时间，或控制单行单词数量。

### 定位方式

- 横屏格式（1920x1080）：位于底部 80-120 像素处，居中显示。
- 竖屏格式（1080x1920）：距离底部约 600-700 像素处，居中显示。
- 绝对不能遮挡主体的面部。必须使用 `position: absolute` 定位（严禁使用相对定位）。同一时间仅显示一组字幕。

### 防止文字溢出

可使用运行时辅助工具，确保字幕永远不会溢出显示区域：

```js
const result = window.__hyperframes.fitTextFontSize(group.text.toUpperCase(), {
  fontFamily: "Outfit",
  fontWeight: 900,
  maxWidth: 1600, // 1600 landscape, 900 portrait
});
el.style.fontSize = result.fontSize + "px";
```

当按单词应用样式时若使用 `scale > 1.0`，需通过计算 `maxWidth = safeWidth / maxScale` 来预留足够空间。容器应设置为 `overflow: visible`（而非 `hidden`，因为隐藏模式会裁剪掉经过缩放的强调文字及发光效果）。

### 字幕退出保障机制

每个组在完成退出动画后都必须有强制终止机制——否则这些组的内容会渗入后续的组中：

```js
tl.to(groupEl, { opacity: 0, scale: 0.95, duration: 0.12, ease: "power2.in" }, group.end - 0.12);
tl.set(groupEl, { opacity: 0, visibility: "hidden" }, group.end); // deterministic kill
```

### 单词级样式设置

在文本转录结果中筛选出需要特殊处理的单词：

- 品牌/产品名称 —— 放大字体并使用独特颜色。
- 全大写文本 —— 调整大小、添加闪光效果及强调色。
- 数字/统计数据 —— 设置粗体并使用强调色。
- 情感类关键词 —— 添加夸张的动画效果（如超出原位移动、弹跳）。
- 行动号召语句 —— 高亮显示、添加下划线并突出颜色。

## TTS（Kokoro-82M）

本地运行，无需API密钥，基于CPU处理。首次使用时会下载模型文件（约311 MB，另含约27 MB的语音文件），这些文件会缓存于`~/.cache/hyperframes/tts/`目录中。

### 语音选择

| 内容类型       | 推荐语音          | 选择原因                     |
| -------------- | ------------------- | ---------------------------- |
| 产品演示       | `af_heart` / `af_nova` | 温暖且专业的语气             |
| 教程指导       | `am_adam` / `bf_emma` | 中性语气，易于理解           |
| 营销宣传       | `af_sky` / `am_michael` | 充满活力或权威感的语气       |
| 文档说明       | `bf_emma` / `bm_george` | 清晰的英式英语发音           |
| 非正式场景     | `af_heart` / `af_sky` | 轻松自然，贴近日常交流       |

如需查看8种语言共54种语音选项，可运行命令 `npx hyperframes tts --list`。

### 多语言音素转换

语音标识的首字母用于表示语言类型：`a`=美式英语，`b`=英式英语，`e`=西班牙语，`f`=法语，`h`=印地语，`i`=意大利语，`j`=日语，`p`=巴西葡萄牙语，`z`=普通话。当语音与文本语言一致时，CLI会自动根据该前缀推断音素转换器的区域设置，无需额外使用`--lang`参数。

```bash
npx hyperframes tts "La reunión empieza a las nueve" --voice ef_dora --output es.wav
npx hyperframes tts "今日はいい天気ですね"            --voice jf_alpha --output ja.wav
```

仅当需要覆盖自动检测结果时（例如特殊符号的显示格式），才需使用 `--lang` 参数。

```bash
npx hyperframes tts "Hello there" --voice af_heart --lang fr-fr --output accented.wav
```

有效的 `--lang` 代码包括：`en-us`、`en-gb`、`es`、`fr-fr`、`hi`、`it`、`pt-br`、`ja`、`zh`。如需非英语语音合成，需在系统中全局安装 `espeak-ng`（可通过 `apt-get install espeak-ng` 或 `brew install espeak-ng` 安装）。

### 语速

- `0.7-0.8` — 教程类、复杂内容
- `1.0` — 自然语速（默认值）
- `1.1-1.2` — 简短介绍、轻松愉快的内容
- `1.5+` — 几乎不推荐使用

### 文字转语音 + 字幕生成工作流程

```bash
npx hyperframes tts script.txt --voice af_heart --output narration.wav
npx hyperframes transcribe narration.wav   # → transcript.json (word-level)
```

## 基于音频的动态视觉效果

让视觉效果随音乐、人声或各类声音变化。任何可通过 GSAP 进行动画处理的属性，都能对预先提取的音频数据做出响应。

### 数据格式

```js
const AUDIO_DATA = {
  fps: 30,
  totalFrames: 900,
  frames: [{ bands: [0.82, 0.45, 0.31, /* ... */] }, /* ... */],
};
```

`frames[i].bands[]`表示各频段的振幅值，范围在0到1之间。索引0对应低音，数值越大则代表高音。每个频段都会在整个音频轨道中独立进行归一化处理。

### 将音频映射为视觉效果

| 音频信号           | 视觉属性                   | 效果                     |
| ---------------------- | --------------------------------- | -------------------------- |
| 低音（`bands[0]`）      | `scale`                           | 随节奏脉动                 |
| 高音（`bands[12-14]`）| `textShadow`、`boxShadow`         | 萤光强度变化               |
| 整体振幅             | `opacity`、`y`、`backgroundColor` | 呼吸效果、上下移动、颜色变换 |
| 中音频段（`bands[4-8]`）| `borderRadius`、`width`          | 形状动态变化               |

任何可通过GSAP实现动画过渡的属性均可使用——包括`clipPath`、`filter`、SVG属性以及CSS自定义属性。让内容主导视觉呈现，同时让音频控制其动态行为。**切勿添加**均衡器条、频谱分析仪、波形显示、彩虹色循环效果或通用的粒子系统——这类元素会显得很廉价。

### 取样模式（必填）

要实现音频响应效果，需通过`tl.call()`的`for`循环对每一帧进行采样，而非仅使用单个动画过渡。单一的长时间动画过渡无法对音频做出响应：

```js
for (let f = 0; f < AUDIO_DATA.totalFrames; f++) {
  tl.call(
    ((frame) => () => draw(frame))(AUDIO_DATA.frames[f]),
    [],
    f / AUDIO_DATA.fps,
  );
}
```

### 常见注意事项

- **包含半透明子元素的容器**使用`textShadow`效果时（例如透明度为`rgba(255,255,255,0.3)`的未激活字幕文本），会在每个子元素后方生成可见的光晕矩形。建议将光晕效果单独应用于激活状态的字词，而非整个容器。
- **文本的视觉效果控制**：缩放幅度宜控制在3%-6%，并搭配柔和的光晕效果。过强的脉冲动画会导致文本难以辨认。
- **非文本元素的显示调整**：背景和形状元素的缩放幅度可达到10%-30%。
- **仅支持确定性渲染**：该功能基于预提取的音频数据，不使用Web Audio API，也不会在运行时进行动态分析。

## 标记风格高亮功能

通过确定性的CSS技术结合GSAP库，实现经典的“高亮/圆形/爆裂/涂鸦/草图”等文本强调动画效果。该功能完全支持搜索功能——无需使用带动画的SVG滤镜，也不依赖JS计时器。

### 高亮效果（黄色标记扫描）

```html
<span class="mh-highlight-wrap">
  <span class="mh-highlight-bar" id="hl-1"></span>
  <span class="mh-highlight-text">highlighted text</span>
</span>
```

```css
.mh-highlight-wrap { position: relative; display: inline; }
.mh-highlight-bar {
  position: absolute; inset: 0 -6px;
  background: #fdd835; opacity: 0.35;
  transform: scaleX(0); transform-origin: left center;
  border-radius: 3px; z-index: 0;
}
.mh-highlight-text { position: relative; z-index: 1; }
```

```js
tl.to("#hl-1", { scaleX: 1, duration: 0.5, ease: "power2.out" }, 0.6);
```

多行模式：适用于`.mh-highlight-bar`，可设置`stagger: 0.3`。

### 圆形

在单词周围绘制手绘风格的椭圆。通过使用定位的`::before`元素，并结合`border-radius: 50%`、轻微旋转以及`clip-path`属性，可避免覆盖字母内容。对于内联SVG圆形，可通过动画改变`clip-path`或`stroke-dashoffset`来实现效果。

### 爆发式

在单词周围呈现放射状的短线条。生成6到12个以辐射状排列的小`<span>`元素，然后让它们的`scaleY`值从0开始动画变化。

### 涂鸦风格

通过为内联SVG的`<path>`元素设置`d`属性来定义之字形路径，再利用`stroke-dashoffset`属性进行动画，从而形成混乱的叠加效果。应使用固定种子值，严禁使用`Math.random()`函数。

### 草图风格

呈现粗略的矩形轮廓。使用两个带有轻微`transform`偏移的`<rect>`元素，通过`stroke-dashoffset`属性实现动画效果。

上述五种模式均仅通过CSS变换或`stroke-dashoffset`属性来实现动画——这两种方式都能实现流畅的动画效果，且具有确定性，同时能准确达到预期的视觉效果。

### CSS过渡与着色器过渡

- **CSS过渡**通过透明度、变换、`clip-path`以及滤镜来为场景容器添加动画效果，设置更为简单。  
- **着色器过渡**则会在WebGL画布上对每个像素的场景纹理进行合成处理——能够实现CSS无法实现的变形、溶解及形态变化效果。用户可直接从`@hyperframes/shader-transitions`库中导入相关功能，无需手动编写原始GLSL代码。

请勿在同一个合成作品中同时使用CSS过渡与着色器过渡——一旦某合成作品启用了着色器过渡，所有动画效果都将由WebGL画布来处理，而非基于DOM的场景切换机制。

### 兼容着色器的CSS规则

着色器过渡会通过html2canvas将DOM中的场景转换为WebGL纹理，但Canvas的2D渲染管线与CSS标准并不完全一致，因此需遵循以下规则：

1. 渐变中不可使用`transparent`关键字——应使用透明度为0的目标颜色，即`rgba(200,117,51,0)`，而非`transparent`。（Canvas会将`transparent`自动解释为`rgba(0,0,0,0)`，从而导致边缘出现暗色痕迹。）
2. 宽度小于4px的元素不可设置渐变背景——此类细线条应使用纯色`background-color`。
3. 在捕获过程中可见的元素不可使用CSS变量（`var()`）——html2canvas无法可靠解析自定义属性，需直接使用具体的颜色值。
4. 对于无法被捕获的装饰性元素，可添加`data-no-capture`属性——这类元素会保留在真实的DOM中，但不会出现在着色器纹理中。
5. 渐变的透明度不得低于0.15——否则在Canvas与CSS中的渲染效果会有差异。
6. 每个`.scene`容器都必须明确指定`background-color`，且该颜色值需与`init()`配置中的`bgColor`一致。若缺少其中任意一项，生成的纹理将显示为黑色。

以上规则仅适用于使用着色器过渡的合成作品。仅使用CSS的合成作品则无需遵守这些限制。

### 不建议的做法

- 不要在同一个合成作品中同时混合使用CSS过渡与着色器过渡。  
- 除最终场景外，其他场景均不可设置退出动画——因为过渡效果本身即视为退出动画。  
- 每个场景都不要使用全新的过渡类型——建议选择1种主要过渡效果，再搭配1-2种辅助效果即可。  
- 避免使用会生成明显几何重复图案（如网格、六边形单元格或均匀分布的点）的过渡效果——无论其背后的数学原理如何，这类效果都会显得刻意且不自然。建议优先选择自然随机的效果（如分形布朗运动、域变形等）。
