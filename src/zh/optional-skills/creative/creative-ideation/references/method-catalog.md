# 方法目录

每一种方法都配有简短总结及适用场景，并可参照 `heuristics.md` 与 `SKILL.md` 中的路由表进行关联查询。

## 随机刺激法

| 方法 | 适用场景 |
|---|---|
| `methods/oblique-strategies.md` | 在项目进行中陷入僵局；已有素材但需打破思维循环。原生领域为音乐，但也适用于各类创作。 |
| `methods/lateral-provocations.md` | 思路过于保守，需要通过“PO运算符”或随机词汇来打破思维定式。 |
| `methods/chance-and-remix.md` | 现有素材已用尽，且有媒体素材可供混搭重组（如凯奇的随机运算、伯勒斯的拼贴技法、超现实主义的“精美尸体”手法以及情境主义的“挪用”技巧）。 |

## 约束驱动法

| 方法 | 适用场景 |
|---|---|
| `methods/oulipo.md` | 写作，尤其是诗歌与小说创作。适用于禁字写作、S+7规则、滚雪球式创作、回文创作等。 |
| `methods/scamper.md` | 已有基础创意，希望以低成本获得7种系统化的变体。 |
| `full-prompt-library.md` | 适用于从空白页面开始创作的场景。提供类似 wttdotm 风格的项目约束条件，按领域分类（通用/软件/物理/社会/列表）——仅需从对应类别中选择方法，无需遍历整个库。 |

## 理论导向法

| 方法 | 适用场景 |
|---|---|
| `methods/compression-progress.md` | 在选择研究课题或决定开展哪个项目时使用。根据施密德胡伯的观点：有价值的项目能够简化你对世界的认知模型。 |
| `methods/analogy-and-blending.md` | 陷入某种思维框架无法自拔时，需要从其他领域引入结构（如关联思维、联觉思维、概念融合等）。 |
| `methods/pataphysics.md**> 当常规逻辑已无法适用时，可详细描述那些看似不可能的事物。 |

## 工程/系统设计法

| 方法 | 适用场景 |
|---|---|
| `methods/triz-principles.md` | 面对技术上的矛盾现象（改善A反而会降低B的性能）。基于阿尔特舒勒提出的40条原则及矛盾矩阵进行解决。 |
| `methods/leverage-points.md**> 用于推动社会、组织或制度层面的变革。参考梅多斯提出的12个干预点。 |
| `methods/pattern-languages.md**> 基于既有的设计实践进行创作（如建筑、用户体验、产品设计）。源自克里斯托弗·亚历山大的理论。 |
| `methods/first-principles.md**> 当怀疑现有惯例中隐藏着已不再适用的假设时使用。 |
| `methods/polya.md**> 适用于数学、物理、算法、调试及形式化问题求解。 |
| `methods/biomimicry.md**> 面对物理设计难题时，可寻找自然界中的类似解决方案。 |

## 创意生成/学科特定法

| 方法 | 适用场景 |
|---|---|
| `methods/volume-generation.md**> 需要快速产生大量创意时使用（如“疯狂8字法”、集体头脑风暴、詹姆斯·韦伯·杨的创意方法）。 |
| `methods/creative-discipline.md**> 需要长期坚持的创作练习（如萨普、勒威特、克里斯、卡梅隆等人的实践方法），并非单次会议就能完成。 |

## 选择/优化法

| 方法 | 适用场景 |
|---|---|
| `methods/premortem-and-inversion.md**> 对计划进行压力测试，以便在多个候选方案中做出抉择（克莱因与芒格提出的方法）。 |
| `methods/defamiliarization.md**> 当某个对象过于常见以至于你已忽略其特性时使用（施克洛夫斯基、布莱希特的理论）。 |

## 映射/探索法

| 方法 | 适用场景 |
|---|---|
| `methods/derive-and-mapping.md**> 在陌生领域展开探索，或面临人生决策、需要针对特定场所进行创作时使用（德波尔、林奇、巴什拉的理论）。 |
| `methods/affinity-diagrams.md**> 当有一堆定性信息需要整理结构时使用（川北嘉彦的KJ法）。 |

## 领域专用法

| 方法 | 适用场景 |
|---|---|
| `methods/story-skeletons.md**> 叙事写作。包括科茨的“皮克斯22要素”、桑德斯的情节递进法则、勒吉恩的“手提包结构”，刻意避免使用“英雄之旅”模式。 |
| `methods/jobs-to-be-done.md**> 产品、服务及商业设计领域。基于克里斯滕森的理论。 |

## 如何在相似方法间做出选择

| 倾向于使用的方法 | 还可考虑的方法 | 原因 |
|---|---|---|
| 斜向策略法 | 横向激发法 | 斜向策略法侧重于诗意的随机性，而横向激发法则更偏向程序化的触发机制。 |
| OuLiPo规则法 | 随机混搭法 | OuLiPo基于固定规则，而随机混搭法则不设任何规则限制。 |
| TRIZ理论 | 第一性原理法 | TRIZ依赖模式库，而第一性原理法则拒绝依赖现有模式。 |
| 支撑点分析法 | 模式语言法 | 梅多斯的方法指出干预点，而亚历山大的方法则指导具体设计内容。 |
| 压缩进展法 | 波利亚技巧法 | 施密德胡伯的方法帮助确定研究问题，而波利亚技巧法则指导如何解决这些问题。 |
| 陌生化处理法 | 关联思维法 | 陌生化法旨在打破固有认知，而关联思维法则是在现有认知基础上进行重构。 |
| 前置死亡分析法 | 超现实物理法 | 前置死亡分析法用于规避极端结果，而超现实物理法则鼓励探索极端可能性。 |
| “疯狂8字法” | SCAMPER技巧法 | “疯狂8字法”从空白页面开始创造，而SCAMPER法则则基于现有基础进行改进。 |
| 探索性漫游法 | KJ亲和图法 | 探索性漫游法用于深入探索，而KJ法则在探索之后对信息进行整合。 |

## 故意未收录在目录中的方法

- **“英雄之旅”“拯救猫咪法则”“三幕结构”“故事圈模型”**：这些是故事写作框架，而非创意生成方法，它们会将创作过程简化为陈腐的模式。`methods/story-skeletons.md` 中提供了其他替代方案。
- **“设计思维”这一概念**：其下的实际方法（访谈、亲和图绘制、创意构思、原型设计等）均以真实名称收录在此目录中。
- **思维导图、六顶思考帽、鱼骨图**：这些属于创意整理工具，而非创意生成工具，本目录中的方法均为真正的创意生成手段。
- **“颠覆X”“蓝海战略”“精益创业”**：这些都是定位策略框架，而非创意生成方法。
- **通用的LLM头脑风暴方式**：这类方法正是该技能旨在替代的。
