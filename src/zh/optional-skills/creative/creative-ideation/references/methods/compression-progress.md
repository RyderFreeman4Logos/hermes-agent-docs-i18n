# 压缩进度

尤尔根·施密德胡伯，《创造力的形式理论》（1990–2010）。美 = 在具备先验知识条件下的可压缩性；有趣性 = 随着学习进程而产生的可压缩性变化。一个有价值的项目，其完成之后应当能够压缩你对世界的认知模型。

## 核心公式

```
I(D, O(t)) = B(D, O(t)) − B(D, O(t−1))
```

**趣味性 = 美感随时间变化的一阶导数。纯粹的噪声（无可学习的模式）与完全已知的模式（已被充分压缩）都会令人感到乏味，真正的美感存在于二者之间。**

## 适用场景

- 确定研究课题  
- 在多个候选项目间做选择（“哪个能让我学到最多？”）  
- 诊断审美上的不满（“还行，但缺乏趣味”）  
- 决定阅读内容  

## 不适用场景

- 需要快速生成内容的场景（此工具侧重反思而非创造）  
- 参与者观点差异较大的群体决策（属于单观察者模型）  

## 操作步骤

### 确定研究课题
1. 列出你在所在领域中目前**无法准确预测**的5–10件事。要具体明确：不要写“人工智能的未来”，而应写成“为何采用技术A训练的X 7B模型在基准测试Z上的表现不如采用技术B训练的Y 1.3B模型”。  
2. 对每一项进行分析：理解它是否能仅压缩这一事实，还是能重新组织更广泛的领域知识？优先选择后者。  
3. 再判断：从你目前的认知水平出发，能否学到相关答案？（不能是噪声，也不能远远超出你的现有知识范围。）  
4. 选择具备最高可学习性及压缩潜力的选项。  

### 评估创意想法
针对每个候选方案，提出以下问题：  
- 如果这个想法得以实现，我的理解会有何不同？  
- 这种新的理解是能覆盖整个领域，还是仅针对该想法本身？  
- 从我目前的认知水平来看，能否学到相关内容？  
三个问题中得分最高的方案即为值得深入探索的方向。  

### 进行审美批判
某项作品是完全可预测的（过于已知），还是完全不可预测的（过于随机）？它又处于“可学习但尚未被掌握”的区域吗？优秀的作品通常更偏向于后者。  

## 实例分析

用户面临三个选择：  
- A. 开发一个习惯追踪工具。  
- B. 开发一个工具，通过在`git rebase --interactive`操作过程中重建提交图，来解释冲突产生的原因。  
- C. 阅读拉康的著作。  

分析过程：  
- A：没有可学习的压缩空间，用户已具备习惯追踪工具的相关认知，故予以排除。  
- B：具有很高潜力。用户目前对rebase如何构建中间状态缺乏深入理解，开发此工具需要填补这一知识空白，而最终形成的模型将彻底改变用户对所有版本控制系统内部机制的认知方式。  
- C：确实存在可学习的压缩空间，但由于用户缺乏相关基础，实现路径较长。如果用户已具备相关预备知识，则值得尝试；否则建议先阅读齐泽克或布鲁斯·芬克的著作作为铺垫。  

最终推荐选择B。  

## 避免流于表面化的注意事项

- 将“可学习性压缩”作为口号并不等同于真正进行了分析，需明确指出具体需要填补的知识缺口。  
- 不要声称所有创意都具有高可学习性压缩潜力，实际上大多数并非如此。该框架的价值在于能够帮助我们进行区分。  
- 在应用于艺术作品时，切勿忽视其局限性，强行套用这一评判标准。
