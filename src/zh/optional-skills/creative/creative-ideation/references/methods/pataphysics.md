# 奇想物理学  

阿尔弗雷德·贾里所著的《奇想物理学家福斯特罗尔博士的言行录》（1898/1911）。这是一门研究虚构解决方案与特例的科学。  

如果说物理学是将普遍规律应用于常见情形，那么**奇想物理学则专注于研究特例与虚构解决方案**——那些独一无二的情况、例外现象，以及那些其“虚拟性”（潜在存在）能够像真实物体一样被合理描述的想象实体。  

“乌利波”组织最初是作为“奇想物理学学院”的下属委员会而成立的。马塞尔·杜尚、欧仁·尤内斯库、鲍里斯·维安、伊塔洛·卡尔维诺、翁贝托·埃科都是该组织的成员。从某种意义上说，博尔赫斯、勒姆、卡尔维诺和鲁塞尔也属于奇想物理学领域的作家。  

## 适用场景  

- 超越现实合理性限制，详细描述那些不可能存在的事物；  
- 需要严谨形式结构的戏仿或讽刺作品；  
- 创作虚构的物品或内容（如关于不存在文明的百科全书、不存在的设备的使用手册、对不存在的书籍的评论）；  
- 当常规解决方案已用尽，而你希望尝试某种不可能的解决方案时；  
- 强调某种“自然”的叙事框架其实是一种人为选择。  

## 不适用场景  

- 当你需要一次就提出真正可实施的方案时；  
- 当受众期望真诚的表达（此时使用此方法会显得带有讽刺意味）；  
- 为逃避深入分析而使用（这属于低质量的奇想物理学式逃避手段）；  
- 当你实际上并无内容可说时（形式需要内容作为支撑）。  

## 操作步骤  

### 明确指定一个想象物体  
1. 选择物体。可以是某种设备、生物、机构、地点、作品或人物——即那些根本不可能存在的事物。  
2. 用具体的细节描述它的**特征**。它由什么构成？如何运作？其组成部分有哪些？  
3. 确定它的规则——即内部一致性准则。它能做什么？不能做什么？  
4. 描述如果它真的存在会产生的后果。  
5. **切勿去探讨它是否可能存在**。这个问题不属于奇想物理学的范畴。  

### 寻找例外情况  
1. 首先阐述你所研究领域内的普遍规则。  
2. 找出那些不符合该规则的真实存在案例。  
3. 用该案例本身的特征来描述它——而非将其视为偏离规则的现象，而应如实呈现其本质。  
4. 避免将其归纳为某种修正后的新规则。  
5. 这个特例本身便是最终结果。  

### 奇想物理学式虚构创作  
1. 采用严肃体裁的形式（如百科全书、手册、技术论文、博物馆目录、书评等）。  
2. 将这种形式严格应用于一个并不存在的主题上。  
3. 不要打破叙事框架，也不要暗含暗示。  

## 实例分析  

**问题**：文件同步软件。所有现实的解决方案都必须在冲突解决机制上做出某种妥协。  

**奇想物理学式的设计方案**：设计一种文件系统，在该系统中，对同一文件同时进行的两次编辑会生成一个*第三个文件*，其中包含两次编辑的“副本”——这些副本对读者可见且可编辑，但直到达到一定数量的读者阅读并选定其中一个版本后，才会被正式确认。在有人观察之前，这个文件一直处于叠加状态。  

**该系统的特征**：这些“副本文件”具有“观察次数”计数器；当观察次数未达到阈值时，它们仍处于交互状态但未被正式确认；一旦超过阈值，它们就会坍缩为被选定的版本。  

**产生的后果**：编辑热门文件的速度很快（因为很快就能达到所需读者数量）；而编辑冷门文件则速度很慢（因为难以凑齐足够数量的读者）。这种文件系统具有*依赖受众数量的确认机制*。  

虽然这个设计方案在现实中无法实现，但通过奇想物理学式的思考方式所揭示的“依赖受众数量的确认机制”，实际上是一个具有实用价值且可找到合理实现方式的概念。  

## 避免低质量创作的注意事项  

- 荒诞无逻辑的内容并非奇想物理学。“如果牛会飞会怎样？”这类问题，若不考虑牛的翼载荷和升力系数等实际因素，就只是低质量的幻想罢了。  
- 不要试图模仿博尔赫斯或卡尔维诺的风格来创作作品。他们的作品都建立在极其细致的具体细节之上，仅做表面模仿只是装饰性的行为。  
- 严谨、认真的表达方式至关重要。喜剧风格的科幻作品不属于奇想物理学范畴。  
- 最后也不要再说“当然这只是一个思想实验”。这样的说法会破坏整个思考过程的有效性。  

参考文献：贾里，《奇想物理学家福斯特罗尔博士的言行录》（Fasquelle出版社，1911年）；博尔赫斯，《虚构集》（1944年）；勒姆，《完美真空》（1971年）。
