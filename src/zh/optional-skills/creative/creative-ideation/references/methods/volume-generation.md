# 思想量产方法

三种能够快速产生大量创意的传统方法：
- **疯狂8格法**——源自谷歌风投的冲刺工作法，其理论框架记载于《冲刺》（Knapp等人，2016年）一书中。
- **6-3-5头脑书写法**——由伯恩德·罗尔巴赫于1968年在德国设计方法相关文献中提出。
- **詹姆斯·韦伯·扬的方法**——记载于其1940年出版的《一种创意生成技巧》一书，这本共60页的手册堪称广告文案写作的经典指南。

## 适用场景

- 面临时间压力且需快速产出成果
- 团队集体创意讨论（事实证明，头脑书写法的效率远高于口头头脑风暴）
- 需优先追求数量而非质量的阶段
- 需通过大量尝试才能筛选出少数优质方案时

## 不建议使用的场景

- 尚未收集到相关素材时（符合扬方法的第一阶段：先收集资料）
- 正确答案极为罕见且出现时能立即识别时（大量产出反而可能遗漏正确答案）
- 无时间压力的个人独立工作（此时应采用更为深思熟虑的创意方法）

## 疯狂8格法

1. 将一张纸折叠成8个格子（或使用预先打印好的网格）。
2. 设置**8分钟**的计时器。
3. 在每个格子里草拟一个创意——总共8个创意，每个格子分配1分钟。
4. 仅进行草图绘制，无需书写。视觉化形式有助于将想法具体化。
5. 计时结束后，挑选出1–3个最出色的创意格子。
6. 团队成员共同分享这些创意。

通常前4–5个格子里的内容质量较低；而最后3–4个格子里往往会出现惊喜之作（因为简单的创意早已被挖掘殆尽）。

## 6-3-5头脑书写法

多项学术创意研究均表明，该方法的效率远高于口头头脑风暴（Diehl与Stroebe，1987年及后续大量重复实验）。口头头脑风暴存在明显的创作阻碍、评估恐惧以及社会懈怠现象，而头脑书写法则能避免这些问题。

1. **6名参与者**，每人持一张纸。
2. 每人在**5分钟**内，在纸张顶部连续写下**3个创意**。
3. 纸张依次传递，每位参与者看到前人写下的3个创意后，需再写下3个**新的**创意——可以是基于前人的延伸，也可以是全新创意。
4. 重复此过程，直到每张纸都被6人各看一遍。
5. 最终结果：30分钟内可产生6 × 6 × 3 = 108个创意。

## 詹姆斯·韦伯·扬的5阶段法

该方法客观描述了创意形成的**时间流程**。大多数方法都假设创意是按需产生的，但扬认为实际上创意往往并非如此产生，其形成过程需要在前期就做好准备。

1. **收集素材**：包括具体素材和通用素材。绝大多数创意生成工具都在这一环节失败。“再多想一个关于产品的点子，再多收集一点事实资料——很多时候这些细节就能决定成败。”
2. **在脑海中消化素材**：反复思考这些素材，尝试建立初步的关联，但暂不必急于形成最终创意。
3. **暂停创作**：停止当前工作，去睡觉、散步或看电影。让潜意识继续处理这些素材。
4. **创意出现**：往往在洗澡或散步时灵感涌现。“它会在你最意想不到的时候出现。”
5. **完善与发展**：初步形成的创意仍不完整，需经过进一步细致审视和打磨。

“暂停创作”阶段是不可或缺的。若试图压缩流程，直接从收集素材跳到形成创意，最终得到的只会是不完整的创意。

## 不同方法的适用场景

| 可用时间 | 团队规模 | 推荐方法 |
|---|---|---|
| 8分钟 | 个人独立 | 疯狂8格法 |
| 8分钟 | 团队合作 | 疯狂8格法 + 共享讨论 |
| 30分钟 | 个人独立 | 疯狂8格法 + 22分钟完善时间 |
| 30分钟 | 4–8人团队 | 6-3-5头脑书写法 |
| 1小时 | 团队合作 | 头脑书写法 + 30分钟亲和图分析 |
| 1天 | 个人独立 | 扬方法的1–3阶段 |
| 1周 | 个人或小团队 | 完整的扬方法5个阶段 |

## 避免内容空洞的建议

- **数量不等≠真正有价值**。8个结构相同的格子仅相当于同一个创意被重复了8次。应通过为不同格子应用不同的创意生成方法，来促进创意的多样性。
- 不要为了凑整数而强行填充内容。如果8个格子里只有5个产生了有价值的创意，那就只展示这5个即可。
- 向用户展示1–3个最佳创意即可，无需全部8个或108个。
- 不要将数量与质量混为一谈。数量体现的是广度，而深度则需要通过后续的完善方法才能实现。
- 尊重扬方法中的“暂停创作”阶段。试图在单次会议中直接从收集素材跳到形成创意，通常难以取得成功。

参考资料：扬，《一种创意生成技巧》（Advertising Publications，1940年）；罗尔巴赫，“635法”（《广告经济》第12期，1968年）；Knapp等人，《冲刺》（Simon & Schuster，2016年）。
