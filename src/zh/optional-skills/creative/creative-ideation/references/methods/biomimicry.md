# 模仿自然设计

珍妮·本尤斯所著《模仿自然设计》（1997年）。进化在绝大多数物理设计问题上已积累了38亿年的研发经验。我们可以将生物策略视为一个机制库——应借鉴其“运作原理”，而非仅使用表面比喻。

## 适用场景

- 具有进化生物类似特征的物理设计问题（如运动、感知、附着、结构、能量捕获、水分管理、温度调节、物质输送等）
- 材料科学领域的问题
- 存在生物先例的分布式系统问题（如黏菌、蚁群、免疫系统）
- 面临可持续性或材料效率约束的场景

## 不适用场景

- 软件、社会或表达类问题，若将生物类比仅作为装饰，则毫无意义。例如将初创企业比作“蚁群”不过是空洞的比喻。
- 试图用“自然”答案来解决规范性问题（自然本身并无道德属性）。
- 当尚未真正理解相关生物机制时（你需要的是机制本身，而非华丽的标题）。
- 制造环境无法匹配生物界依靠常温水进行组装的特性。

## 典型成功案例

**尼龙搭扣** ← 蒲公英的冠毛。由无数小型带刺机械钩组成。*运作原理：依靠大量微小互锁结构，而非强黏性胶水。*

**新干线500系列列车车头** ← 鹭鸟的喙部。其渐变形状能让列车以最小水花从空中俯冲入水。*运作原理：通过密度渐变减少介质界面处的冲击力。*

**荷叶效应** ← 莲叶表面的微结构蜡层。可实现自清洁功能。*运作原理：分层微纳结构结合低能量表面，从而形成超疏水性。*

**壁虎黏附力** ← 壁虎的脚垫。数百万根刚毛通过范德华力实现附着。*运作原理：大量微小接触点加上柔性基底，可产生强大的可逆黏附力。*

**白蚁丘恒温系统** ← *Macrotermes*种白蚁通过被动对流，在萨赫勒地区多变的气候条件下维持内部温度恒定。1996年哈拉雷的伊斯特盖特中心即采用了这一设计。*运作原理：通过精心设计的几何结构实现被动对流。*

**鲸鱼鳍上的突起** ← 鲸鱼鳍前缘的凸起结构可延缓气流分离，降低阻力。WhalePower公司的风力涡轮机叶片也采用了类似设计。*运作原理：前缘结构扰动可改变边界层流动状态。*

**黏菌路径规划** ← *Physarum polycephalum*黏菌能找到最短路径。Tero等人2010年在《科学》杂志上通过实验重现了东京铁路网络的结构。*运作原理：对高流量路径进行强化，同时淘汰未被使用的路径。*

**鲨鱼皮抗菌特性** ← 鲨鱼皮表面的微小棱状鳞片可防止细菌附着。医院墙面材料“Sharklet”即采用了这一原理。*运作原理：表面微拓扑结构可干扰细菌生长。*

**蜘蛛丝** ← 蜘蛛属物种的丝线。其比强度高于钢铁，韧性则超过凯夫拉尔纤维。Spiber和Bolt Threads公司均将其用于产品制造。*运作原理：在剪切流控制下实现分层蛋白质组装。*

**贻贝黏附剂** ← *Mytilus*贻贝所含的富含多巴胺的蛋白质可附着在潮湿岩石上。这类物质也被用于外科手术粘合剂。*运作原理：儿茶酚化学结构在水中依然具有黏附效果。*

**菌丝结构** ← 真菌可通过菌丝将颗粒粘结成坚固结构。Ecovative公司推出的MycoComposite包装即为此例。*运作原理：通过生物酶实现纤维素间的结合，从而形成可降解的坚固结构。*

## 实施步骤

1. **将问题转化为函数形式**。例如：“我需要一种可逆固定的方式，能承受50公斤的重量。”“我需要从沙漠空气中提取水分。”“我需要实现无需中心协调的数据包传输。”
2. **查找生物策略**。AskNature.org是一个按功能分类的优质数据库。
3. **提炼运作原理**。将相关生物策略简化为其核心机制。不要只说“壁虎能贴在墙上”，而应明确表述为“通过柔性刚毛形成的大量微小范德华力接触，可实现强大的可逆黏附”。
4. **与自身问题匹配**。诚实地分析现有条件的不足——生物系统之所以有效，往往是因为其存在特定的环境条件（如水、适宜温度），而这些条件在你的工程环境中可能并不存在。
5. **基于原理而非比喻进行原型设计**。不要试图制造“机器壁虎”，而应运用相应原理，结合自身的形态和材料条件进行设计。

## 避免空洞比喻的建议

- 仅宣称“受自然启发”却未具体说明来源，纯属营销手段。真正的模仿自然设计会明确指出对应的生物种类、机制及运作原理。
- 对于非物理问题，避免使用“像蚁群/蜂群/生态系统一样”之类的表述，这类说法只会让设计显得空洞无物。
- 不要认为“自然”的就一定“好”。寄生、欺骗、掠夺等行为同样是经过精密设计的。
- 避免采用过于玄学的表达方式。模仿自然设计属于工程学范畴，而那些空洞的比喻则更像是贺卡上的文字。

资料来源：本尤斯，《模仿自然设计》（Morrow出版社，1997年）。AskNature.org网站。
