# 波利亚的启发式方法

乔治·波利亚，《如何解题》（普林斯顿大学出版社，1945年）。该书提出了一个四阶段问题解决框架，并附有一份启发式策略手册。虽然最初是为数学问题而写，但同样适用于任何结构清晰的“找到满足……条件的X”类问题。

## 适用场景

- 数学、物理及理论问题
- 算法设计与调试
- 任何具有明确目标的问题（即“找到满足……条件的X”）
- 问题解决教学

## 不适用场景

- 没有明确目标的开放式创造性问题
- 难点在于*理解问题本身*，而非在已知条件下求解（此类情况应优先使用“发散法”或“压缩-推进法”）
- 解决方案更多依赖主观偏好而非逻辑分析
- 数据不完整、条件模糊的现实世界问题

## 四个阶段

### 1. 理解问题
- **未知量**是什么？
- **已知数据**有哪些？
- 连接它们的是什么**条件**？
- 该条件是充分的？不足的？多余的？还是矛盾的？
- 用自己的话表述问题。
- 画出示意图，并引入相应符号。

这一阶段最常被跳过。**大多数问题解决失败都源于方法之前**——即未能准确理解问题本身。

### 2. 制定计划
找出已知数据与未知量之间的关联。可采用的启发式策略包括：
- **你以前见过这个问题吗？** 或是以略有不同的形式出现过？
- **你知道类似的题目吗？**
- **仔细观察未知量**——寻找具有相同或类似未知量的熟悉问题。
- **能否运用相关问题的结果或方法？**
- **重新表述问题。**
- 如果无法解决当前问题，可尝试解决以下类型的关联问题：
  - 更一般的版本
  - 更具体的版本
  - 类似的版本
  - 当前问题的某个子问题
  - 条件有所放宽的版本
- **你是否用到了所有数据及所有条件？**

### 3. 执行计划
- 能清楚地看出每一步都是正确的吗？
- 能证明其正确性吗？

### 4. 回顾总结
- 检查结果与推理过程。
- 能用其他方法推导出相同结果吗？能否一目了然地理解它？
- 能将该结果或方法应用到其他问题中吗？

回顾阶段正是*学习*的环节——这也正是波利亚的方法之所以能成为一种*教育性*方法，而不仅仅是一种问题解决工具的原因。

## 手册中的核心启发式策略

- **分解与重组**：将问题拆解为若干部分，分别解决后再组合起来。
- **泛化**：有时处理一般情况比处理特殊情况更简单，因为这能帮助人们识别问题的本质结构。
- **特殊化**：尝试最简单的情形、参数为零的情形，以此寻找规律。
- **类比**：寻找结构相同但表面形式不同的相关问题。
- **辅助问题法**：先解决一个相关问题，再利用其结果。
- **逆向思考**：从未知量出发反向推导。正向思考往往分支过多，而逆向思考则约束更多。
- **建立方程式**：大多数文字题的失败原因在于表述转换，而非代数运算。
- **归谬法**：假设结论为假，进而推导出矛盾。
- **模式识别**：通过处理小规模案例→提出猜想→最终证明。
- **对称性**：问题中存在对称性的地方，其解决方案通常也具有对称性。

## 避免流于形式的注意事项

- 仅照搬四个阶段而不实际执行 = 流于形式。框架本身固然重要，但真正价值在于切实执行每一个阶段。
- 若尚未真正理解问题，切勿假装已懂。需明确说明未知量、已知数据及相关条件。
- 未参考具体的启发式策略，切勿声称自己已运用了波利亚的方法。
- 不要将其应用于模糊不清的问题。波利亚的方法假设问题描述是清晰明确的。

资料来源：波利亚，《如何解题》（普林斯顿大学出版社，1945年；2014年为最新版本）。
