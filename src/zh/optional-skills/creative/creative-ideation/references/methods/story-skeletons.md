# 故事骨架

以下是三种叙事结构传统，它们彼此差异显著（甚至对“何为故事”也存在分歧）：
- **艾玛·科茨**——皮克斯的《22个故事基础》（推特，2011年5月）。源自皮克斯故事创作室的创作原则。
- **乔治·桑德斯**——《雨中池塘里的游泳》（兰登书屋，2021年）。他认为故事是风险不断升级的驱动机制，这一观点源于他对俄罗斯短篇小说的深入研读。
- **厄休拉·K·勒古恩**——“小说的容器袋理论”（1986年）。她反对以冲突为驱动的故事结构，主张将小说视为一种“容器”。

本文档刻意未提及**英雄之旅/拯救猫咪法则/故事圆环/三幕结构**。尽管这些都是真正的叙事传统，但在剧本创作及类似自我提升类的写作中已被过度模板化，使用它们往往会导致内容空洞乏味。

## 适用场景

| 场景 | 建议采用的方法 |
|---|---|
| 故事缺乏框架，需要快速搭建核心结构 | 科茨的第4条 |
| 写作陷入初稿阶段 | 科茨的第9、11、12条 |
| 初稿进展不顺，原因不明 | 参考桑德斯关于“故事现在想要什么”的思考 |
| 冲突发展导致内容显得生硬或肤浅 | 勒古恩的容器袋理论 |
| 描写群体、地点或时间跨度而非英雄人物 | 勒古恩的容器袋理论 |
| 撰写文学性短篇小说 | 桑德斯的方法 |
| 商业长篇叙事作品 | 科茨的方法 |

## 不适用场景

- 纯抒情或说明性作品（无叙事元素）
- 面向需要固定模板的市场创作（英雄之旅或许适用，但桑德斯和勒古恩的理论会被视为另类）
- 尚无素材时——这些方法用于构建框架，而非凭空创造内容

## 科茨的22条核心原则（真正起关键作用的部分）

完整列表已被广泛传播，其中最常被引用的包括：

**#4 — 皮克斯故事大纲（核心骨架）：**
> *从前有___。每天，___。有一天，___。因此，___。又因此，___。最终___。*

这个由六句话构成的框架涵盖了：稳定的日常状态 → 颠覆性事件 → 连锁反应 → 解决方案，适用于大多数叙事作品。

**#6** — 你的角色擅长什么？对什么感到舒适？给他们设置完全相反的挑战。

**#7** — 在构思中间部分之前先确定结局。结局往往是最难设计的部分。

**#9** — 写作陷入僵局时，列出接下来不会发生的事情。很多时候，突破困境的灵感就会由此出现。

**#12** — 先排除最先想到的方案，再排除第二、第三、第四、第五个方案——先把显而易见的选项排除掉。

**#13** — 给角色赋予明确的观点。被动或易被塑造的角色虽然看似容易描写，但对读者而言却毫无吸引力。

**#14** — 你为何一定要讲这个故事？你内心深处怀有怎样的信念？这才是故事的核心。

**#16** — 风险是什么？如果角色失败会怎样？尽量增加失败的难度。

**#19** — 用巧合让角色陷入困境很棒，但用巧合让他们脱困则属于作弊行为。

**#20** — 拿出一部你不喜欢的电影的基本元素，思考如何重新组合它们，打造出你真正喜欢的故事。

**#22** — 你的故事本质是什么？最简洁的表达方式是什么？从那里开始扩展内容。

## 桑德斯——三种核心创作原则

**故事就是风险的不断升级。** 每个场景都必须提升情感、道德或情境层面的风险，停滞不前就会导致故事死亡。即便是安静的故事也需要有风险递增的元素。

**具体性是故事的驱动引擎。** 通用动词、通用名词和通用形容词会导致故事无法发展，因为没有具体的事件发生在特定的人物身上。

**故事比作者更了解自身。** 强劲的故事是通过“响应式创作”构建的：先写初稿，再阅读自己写的内容，问“故事现在想要什么？”，然后写出满足这一需求的下一句内容。作者是服务于故事的。

这与依赖固定模板的写作方式截然不同。

## 勒古恩——容器袋理论

人类学长期以来一直将*长矛*和*刀刃*视为定义叙事结构的早期人类发明——即关于猎人战士的故事。但实际上更重要的发明是*容器*：袋子、篮子、吊带等。人类的生存主要依赖于采集，而非狩猎。狩猎故事有逐步升级的情节和高潮，而采集故事则强调内容的不断积累。

> *小说最自然、最恰当的形态或许就是袋子或容器……小说就像一个药包，将各种元素以特定的方式相互关联，同时也与我们建立联系。*

在构思时，如果冲突发展迫使你把故事写得过于平面化，可以运用勒古恩的理论。这种“容器袋式”小说并非以英雄在旅程中面对障碍为主线，而是将许多具体元素以特定关系收纳在一起。厄休拉·K·勒古恩的《总是回家》（1985年）就是典范——它通过口述历史、食谱、歌曲、地图等多种形式，对一个虚构的民族进行多维度呈现，这些内容与传统叙事并行而非从属。

适合使用该理论的场景包括：
- 具有散文性、人类学特征或多元声音的作品
- 描写某个地方、群体、时间段或生活方式的作品
- 当“英雄面对障碍”的框架会削弱作品独特性的时候

## 操作步骤

### 为已有素材构建故事框架
1. 尝试使用科茨的第4条核心骨架。你能填满六个空白吗？如果不能，说明你尚未确定故事的核心结构。
2. 运用桑德斯的思维方式。逐句阅读，每次过渡时都问“故事现在想要什么？”
3. 思考勒古恩的问题：当前的冲突发展是否真的适合这些素材，还是我强行加入了冲突？

### 诊断陷入僵局的初稿
- 参考科茨的第16条：风险是什么？如果缺失，就需要明确这些风险。
- 按照桑德斯的思路：能量从何处开始消失？找出“死区”。
- 查看科茨的第13条：角色是否过于被动？如果是，那就是问题所在。
- 用勒古恩的理论思考：这个故事是否试图遵循英雄之旅的框架，但实际上并不想如此？

## 避免内容空洞的建议

- 不要默认使用英雄之旅结构。它已被过度使用，会导致所有故事都变成约瑟夫·坎贝尔式的模式。
- 不要编造所谓的“科茨风格”技巧，应严格使用他提出的22条原则。
- 桑德斯的作品风格与自我提升类内容截然不同，写作时不要陷入“作者的旅程”式的腔调。
- 不要肤浅地套用勒古恩的容器袋理论。这是一个具有深刻思想内涵的理论，若只是简单地将故事比作“装满东西的袋子”，而不理解其背后的理念，就会削弱其意义。

参考资料：科茨，皮克斯故事规则推文（2011年5月）；桑德斯，《雨中池塘里的游泳》（兰登书屋，2021年）；勒古恩，《小说的容器袋理论》，载于《在世界边缘起舞》（格罗夫出版社，1989年）。
