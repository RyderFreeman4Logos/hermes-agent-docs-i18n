# SCAMPER 方法

该方法由 Bob Eberle 于 1971 年提出，是在 Alex Osborn 1953 年提出的头脑风暴检查表基础上的发展。它通过七种系统化的转换方式，对现有事物进行创新改造。

## 适用场景

- 已有初步想法，希望低成本地获取多种变体
- 组织由不同专业背景人员参与的集体头脑风暴
- 克服第一直觉的局限，拓展思维广度
- 教授创意构思方法

## 不适用场景

- 白纸状态——SCAMPER 需要基于现有基础进行扩展，无法凭空创造新想法
- 需要深入挖掘某一特定方向的内容（SCAMPER 主要用于拓展思路）
- 任务是分析现有系统而非对其进行修改

## 七种转换技巧

**S — 替换。** 更换某个组件、材料、人物、地点或流程。*例如：用铝替代钢铁，用异步文档替代定时会议，用人形模型替代真人，替换食谱中的食材。*

**C — 组合。** 将两样事物合并在一起。可以是功能、部件、目标受众或呈现形式。*例如：将电话、摄像头和 GPS 结合成智能手机；将回忆录与烹饪书结合成美食回忆录；将程序员与语言学家结合成编译器设计师。*

**A — 适配。** 借鉴其他领域的元素。*例如：从苍耳中发明尼龙粘扣；丰田的准时制生产理念源自超市的补货方式；图像小说则借鉴了电影制作技术。*

**M — 修改（或放大/缩小）。** 改变某项属性——如规模、频率、强度、颜色、重量或形状。*例如：每年仅发布一次推文；将小说写成单页形式；用漫画、歌曲或雕塑呈现相同内容。*

**P — 开辟新用途。** 为现有事物找到不同的应用方式。*例如：阿司匹林从止痛药变为预防中风的药物；区块链从加密货币应用扩展到供应链管理；毛衣从服装变成窑炉隔热垫。*

**E — 删除。** 移除某个组件。*这通常是能带来最大创新效果的步骤。*例如：去掉用户界面，仅保留命令行界面或 API 作为产品形式；取消菜单设计，采用“厨师精选”或单菜餐厅模式；省略说明文字，如 Eno 的《机场音乐》专辑。*

**R — 反转/重新排序。** 打乱原有关系，改变顺序，彻底颠覆原有结构。*例如：Priceline 反转了卖方与买方的角色；维基百科打破了专家与业余爱好者的界限；电影《记忆碎片》则颠覆了时间顺序。*

## 操作步骤

1. 用一句话准确描述初始想法。
2. 对这七种转换技巧全部应用一遍。**不要跳过任何一步**——那些你选择不尝试的技巧往往蕴藏着最惊喜的创意。
3. 查看所有产生的想法。大多数可能比较平淡，一两个会有一定价值，或许还有一个会令人眼前一亮。
4. 选取那个最令人感兴趣的想法并进一步深化发展。
5. 抛弃其余想法。

## 实例解析

**初始想法**：一款用于追踪各类书籍阅读进度的网页应用。

- **S**：追踪用户的“无聊感”而非阅读进度——记录用户何时停止阅读以及原因。
- **C**：将阅读追踪器与书店功能结合（此方案已存在，效果不佳）。
- **A**：借鉴健身应用的习惯追踪功能（不合适，因为阅读与健身无关）。
- **M**：仅详细追踪某一本书的每一段内容及所有边注。
- **P**：不再追踪用户的阅读进度，而是追踪书籍本身的阅读情况——哪些段落最容易让读者停下阅读。
- **E**：去掉追踪功能，保留段落数据库，作为记录“我曾在此处落泪”之类的备注层。
- **R**：不是用户追踪书籍，而是让书籍反过来追踪用户——根据用户的阅读节奏分批推送内容。

**最具创意的方案**：S、P、R。进一步深化 P 的想法：打造一个以“段落”为关注单位的平台，面向所有读者，而非针对单本书籍。其余方案则予以舍弃。

## 避免产生平庸创意的建议

- 最常见的平庸方案：“将 X 与人工智能/机器学习/区块链/增强现实结合”。应直接摒弃。
- 第二常见的平庸方案：“将其改为订阅制”（这属于商业模式调整，而非产品功能创新）。
- 只向用户展示 1–3 个结果即可，无需全部七个。这七种技巧只是内部辅助工具。
- “删除”和“反转”两种技巧最容易产生高质量创意，应投入最多精力在此处探索。

参考资料：Eberle，《Scamper: Games for Imagination Development》（DOK，1971）；Osborn，《Applied Imagination》（Scribner's，1953）。
