# 模式语言

克里斯托弗·亚历山大等人所著的《模式语言》（1977年）提出了253种用于设计建筑、城镇及房间的模式，这些模式以生成语法的形式组织，并包含明确的交叉引用。该书后来催生了“四人组”软件设计模式（1994年）以及众多针对不同领域的衍生模式。

## 模式结构

一个模式由三部分组成：
1. **背景**——该模式适用的具体情境；
2. **问题**——该情境中反复出现的矛盾或挑战；
3. **解决方案**——一种*生成性*原则（而非具体设计方案，可衍生出多种实例）。

所谓“模式语言”，则是不同层级之间相互关联的模式网络：有些模式*包含*其他模式，有些则能*补充*其他模式。

## 适用场景

- 设计物理环境（建筑、房间、花园、社区）；
- 设计交互式环境（用户体验设计、软件架构）；
- 与团队共同建立统一的设计术语体系；
- 记录设计思路以便传承；
- 社区/公共空间设计。

## 不宜使用的场景

- 当你需要打破传统时（模式语言具有保守性，旨在总结已被验证有效的设计方法）；
- 当某个领域尚未形成成熟惯例、无法提取出模式时；
- 用于纯粹的概念性或艺术性创作；
- 当你试图机械地套用模式时（这会削弱模式的生成性，使其变成僵化的规则）。

## 亚历山大提出的253种模式中的精选示例

以下内容仅作示例参考，如需实际应用，建议购买或借阅原书。
- **8. 子文化马赛克**——一个区域应包含具有各自独特生态特征的子文化，这些子文化之间通过闲置区域隔开，避免同质化。
- **53. 主入口**——为每个入口设置明显的门槛。
- **60. 可进入的绿地**——确保居民步行3分钟内即可到达户外绿地。
- **105. 朝南的户外空间**——将最常使用的户外空间设置在建筑物的南侧。
- **111. 半隐蔽式花园**——位于街道旁的花园过于公开，而房屋后面的花园则未被利用，因此可将花园设计为半隐蔽状态。
- **159. 每个房间两侧都有光源**——房间至少应有两面有窗户。单面的房间会让人感到不适，也很少被使用。
- **179. 隐蔽空间**——没有可供休息的空间的房间会让人不安，应设置壁龛、凹室或窗边座位。
- **188. 床位隐蔽空间**——露天的床铺容易暴露在外，应至少设置部分遮蔽结构。
- **191. 室内空间的形状**——尽量保持简洁且以正交结构为主，仅在有明确理由时才进行改动。
- **230. 辐射式供暖**——辐射式供暖（如壁炉、散热器）与强制对流式供暖在效果上有本质区别。

这些模式有时被视为正确，有时则被质疑；但重要的是其*形式*本身。

## 实施步骤

### 使用现有的模式语言
1. 确定相应的尺度范围（区域/社区/建筑/房间/细节）；
2. 阅读与该尺度及以上相关的模式，找出适用的模式；
3. 进行组合设计：先应用更高层级的模式，再让它们约束更低层级的模式；
4. 根据具体需求进行调整。模式是生成性的，而非机械套用的规则。

### 创建属于自己的模式语言（更适用于软件、组织管理或教学领域）
1. 识别所在领域中反复出现的问题，需结合多个案例进行分析；
2. 为每个问题起一个简短易记的名字，该名字应能体现*解决方案的形态*——例如用“两侧有光源”而非“日照不足”来命名；
3. 为每个问题完整描述背景、问题、解决方案，进而总结出*生成性原则*，并注明相关的其他模式；
4. 明确各模式之间的包含关系；
5. 将模式应用于新问题中进行测试，并根据反馈进行修改。

## 实例分析（以软件领域为例，采用亚历山大的表述方式）

**迭代器模式**（“四人组”，1994年）

*背景*：客户端代码需要能够遍历某个对象集合。
*问题*：客户端无需了解集合的内部结构（是数组、树结构还是链表）；同时，集合的遍历逻辑也不应分散在各个客户端代码中。
*解决方案*：提供一个包含`next()`、`hasNext()`、`current()`方法的迭代器对象，用于封装遍历状态。集合在接收到请求时即可生成相应的迭代器。
*因此*：应将“被遍历的对象”与“遍历方式”分开处理。
*相关模式*：复合模式（用于树结构遍历）、访问者模式（用于在遍历过程中执行操作）、工厂方法模式（用于创建合适的迭代器）。

## 避免常见误区

- 以项目符号形式列出的“设计技巧”并非真正的模式。真正的模式包含背景、问题、生成性解决方案，以及其在模式网络中的位置。
- 不要为了显得内容全面而强行生成模式。真正的模式源自大量实际案例。
- 不要机械地将亚历山大的住宅设计模式直接应用于非住宅领域。
- 模式语言既具有保守性，又具备生成性。它们并非阻碍创新，反而能引导创新的方向。

参考文献：亚历山大等人所著《模式语言》（牛津大学出版社，1977年）；《永恒的建筑之道》（牛津大学出版社，1979年）。软件领域相关著作：伽马等人所著《设计模式》（Addison-Wesley出版社，1994年）。
