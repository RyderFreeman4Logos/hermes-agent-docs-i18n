# 完整提示词库

在 SKILL.md 中的核心约束之外，这里还提供了更多扩展约束。当用户需要更多创意或特定主题的内容时，可加载这些约束。

## 沟通与连接

**创建一种传递方式：**
只要能够利用自己创造的工具将某物传递给他人，这个项目就能实现其功能。

**设计一种交流手段：**
利用所创造的工具与他人进行对话，让项目发挥作用。不一定是聊天，可以是更奇特的形式。

**写一封情书：**
献给某个人、某种编程语言、某款游戏、某个地方或某件工具。可以用纸笔、代码、音乐或光影来表达，然后寄出去。

**邮件版国际象棋/异步游戏：**
一种无时间限制的回合制游戏，无需同时在线，游戏可以在碎片化时间里进行。

**Twitch 上一起玩 X 游戏：**
多人共同操控某个事物，通过集体输入产生新的行为模式。

## 屏幕与界面

**为你的桌面增添趣味：**
你花费大量时间在桌面上，让它变得更精彩吧。比如自定义时钟、终端里的“宠物”、会根据你的 Git 活动变化的壁纸。

**同一屏幕，双屏显示，旧屏新用：**
将原本只适用于某一种屏幕的内容放到完全不同的屏幕上。比如在智能冰箱上玩《毁灭战士》，在手表上查看电子表格，或在画作中嵌入终端界面。

**打造一面镜子：**
能将观看者反射回自身的事物。比如展示你浏览历史的网站，或打印出你 Git 使用错误的 CLI 工具。

## 哲学与概念

**代码即公案，公案即代码：**
“一只手拍打的声音是什么？”这样的问题，以及能够回答一个并未被提出问题的程序；在调用之前就返回结果的函数。

**无用之树：**
创造一些毫无实用价值的东西。刻意地、彻底地、完美地做到无用。没有功能，没有目的，也没有意义——这才是关键所在。

**人造愚笨：**
通过展现人工智能的缺陷来嘲笑它。错误训练它，对它说谎，打造与人工智能擅长之事完全相反的东西。

**“我使用技术，只为能更好地厌恶它”：**
基于对工具既喜爱又厌恶的矛盾心理创作出相关作品。

**变化越多，事物越相似：**
反思时间、差异与共性。

## 转换

**翻译：**
将原本为某一群体设计的内容转化为另一群体能够理解的形式。比如把研究论文改写成儿童读物，把 API 设计成棋盘游戏，把歌曲转化成架构图。

**我的意思是，我想你可以用那种方式存储数据：**
只要能够保存并读取数据，这个项目就能实现。比如将数据存储在 DNS 缓存中，用表情符号编码小说，或在非文件系统之上构建文件系统。

**我的意思是，我想那些应该是像素吧：**
只要能够显示图像，这个项目就能实现。在任何原本并非用于渲染的媒介上呈现视觉内容。

## 身份与反思

**绘制自画像：**
做真实的自己？还是伪装？或是虚幻的存在？可以用代码、数据、声音或目录结构来表现。

**创作双关语：**
越愚蠢越好。无论是物理的、数字的、语言的还是视觉的，项目本身就应该成为笑话。

**门、墙、边界、障碍物：**
连接两个空间的事物：开启、关闭、渗透、排斥或结合。

## 规模与重复

**列表！：**
条目化、分类法、详尽列举、迭代。就是这个，一层又一层的列表。

**你是想说*递归*吗？**
你指的是递归吗？

**动物：**
狮子、老虎和熊。螃蟹形状的逻辑门。鱼在炒股。

**猫咪：**
如果没有它们，互联网会变成什么样？

## 起点

**源自书籍的灵感：**
阅读某本书，然后受其启发创作出作品。

**去博物馆看看：**
由此诞生项目灵感。

**NPC 战利品：**
死亡时会掉落什么？旅程中会携带什么？那就去创造这些物品吧。

**神话中的物品与实体：**
潘多拉的盒子、时光之笛、帕兰提尔。去打造这些神器吧。

**69：**
不错，就用数字 69 作为笑点来创作作品。

**《办公室》里的打印机场景：**
捕捉那种氛围，释放摧毁令你烦恼之事后的畅快感。

**博尔赫斯周：**
受这位阿根廷作家启发的作品。巴别图书馆，地图即领土。

**灯光！：**
LED 发光手环、灯光装置，让任何东西都发光。创造一些会发亮的作品吧。
