# 定时练习

按时长分类的具体练习任务。适用于用户希望亲自动手完成练习、而非仅获取灵感的情况。每项练习包含：父方法及预期输出。

## 5分钟

**单一斜向策略** *（`methods/oblique-strategies.md`）* — 随机抽取一张卡片，将其内容直接应用于下一个决策，并据此采取行动。输出：一个具体行动步骤。

**随机词汇激发法** *（`methods/lateral-provocations.md`）* — 随机选取一个名词；强制为该问题建立五个关联点，并选择其中最有力的一个。输出：一个新的思考角度。

**逆向检验法** *（`methods/premortem-and-inversion.md`）* — 将目标反向表述，列出五件能确保实现该反向目标的事，检查自己是否正在做这些事。输出：失败路径的自我检测结果。

**段落S+7变换法** *（`methods/oulipo.md`）* — 将段落中的每个名词替换为词典中其后出现的第7个名词。输出：经过陌生化处理的文本版本。

## 30分钟

**约束条件发散法** *（`full-prompt-library.md`）* — 选择一项约束条件；每构思一个方案耗时5分钟，共生成3个方案；剔除显而易见的方案后，再生成第4个方案；最终输出最强的3个方案。输出：3个候选项目方案。

**SCAMPER创意拓展法** *（`methods/scamper.md`）* — 用一句话概括核心想法；运用所有7种创意转换工具；找出其中最出人意料的结果并加以扩展。输出：7个原始创意 + 1个扩展后的完整方案。

**事前失败分析** *（`methods/premortem-and-inversion.md`）* — 想象项目彻底失败的场景；用10分钟撰写失败经过，再用10分钟找出可解决的根源，最后用10分钟制定应对计划。输出：失败故事 + 缓解方案。

**疯狂8格法** *（`methods/volume-generation.md`）* — 将纸张折叠成8个格子；总耗时8分钟；每个格子写一个想法，仅作草图无需书写；选出最有力的2个想法。输出：8个原始创意 + 2个最终选定的方案。

**段落陌生化法** *（`methods/defamiliarization.md`）* — 从主题中挑选一个极其熟悉的事物；像初次见到它一样用200字描述它，且不得使用专业术语。输出：经过陌生化处理的描述 + 新发现的特征列表。

## 1小时

**TRIZ矛盾分析法** *（`methods/triz-principles.md`）* — 将问题表述为某种矛盾（改善X会降低Y的性能）；查找2–3条相关的TRIZ原则；针对每条原则，在具体问题上设计一种解决方案，并选出最有效的方案。输出：矛盾陈述 + 1个详细设计的解决方案。

**詹姆斯·韦伯·杨快速构思法** *（`methods/volume-generation.md`）* — 收集相关素材（15分钟）→ 深入分析并建立关联（15分钟）→ 离开片刻让思维沉淀（10分钟）→ 偶然产生灵感（时间不定）→ 对灵感进行完善（20分钟）。输出：经过充分酝酿后的书面创意。

**亲和图法** *（`methods/affinity-diagrams.md`）* — 将每条笔记或引文写在单独的卡片上；将它们摊开；静默地将其归类；为每个类别命名；同时标注出孤立项和空白区域。输出：自下而上的分类体系 + 空白区域列表。

**索尔·勒维特指令法** *（`methods/creative-discipline.md`）* — 将作品定义为一种指令而非实体；用一句话将其写下来，该语句本身即为作品。可选择执行一次该指令。输出：以指令形式存在的作品。

## 1天

**萨普的盒子法** *（`methods/creative-discipline.md`）* — 准备一个真实的盒子；用一整天的时间收集与项目相关的所有内容（剪报、参考资料、草图、来源信息、实物等）；给盒子贴上标签；在整个项目周期内持续补充内容。输出：实体档案库 + 培养“物归原处”习惯的实践。

**单日漫游法** *（`methods/derive-and-mapping.md`）* — 选择一处自己不太熟悉的区域；全天无固定计划地闲逛，跟随兴趣点前行；最后绘制一幅类似林奇风格的地图（包括路径、边界、区域、节点和地标），并记录下意外发现。输出：地图 + 意外发现 + 可能形成的项目构思。

**严格约束写作日** *（`methods/oulipo.md`）* — 选择一种约束规则（禁字法、单音节词限制、滚雪球式规则、囚徒规则等），在约束下撰写1000字内容；在遇到困难时也不放弃。输出：1000字内的受限写作成果。

**高概念低努力法** *（`full-prompt-library.md`）* — 选择一个出色的创意；以最轻松的方式将其实现；在当天结束前完成作品。输出：一个实际存在的成品。

## 1周

**压缩进展研究周** *（`methods/compression-progress.md`）* — 第1–2天：找出自己在某个领域预测能力较弱的方面。第3–5天：深入阅读相关资料。第6天：总结出自己能够预测的新规律。第7天：挑选出那个其答案最有助于进一步压缩模型的问题。输出：基于当前模型提出的研究问题。

**模式语言构建周** *（`methods/pattern-languages.md`）* — 第1–2天：找出10个反复出现的问题。第3–4天：将每个问题转化为一个模式（包括背景、问题描述和生成性解决方案）。第5天：按某种顺序对这些建模进行排序。第6天：以这些模式作为词汇库来设计作品。第7天：进行总结回顾。输出：一套简化的模式语言以及基于该语言设计的作品。

**克里斯开放模式周** *（`methods/creative-discipline.md`）* — 每天设定90分钟的“空白时间”，在这段时间内不进行任何有用的工作，不查看消息，也不完成任何任务。核心目标是避免进入“封闭思维模式”。输出：并非一个创意本身，而是产生创意的条件。

## 多周

**卡梅伦的《艺术家的道路》（12周）** *（`methods/creative-discipline.md`）* — 每天写晨间笔记（3页手写内容，采用意识流写作方式，8周内不得重读）。每周安排一次个人创作时间（2小时，做自己感兴趣的事）。输出：与艺术创作建立不同的关系。

**琳达·巴里的图像沉浸法** *（`methods/creative-discipline.md`）* — 连续数周，每天列出当天看到的10件事物；从中挑选一件进行绘制（画得不好也没关系）；然后根据该事物的记忆写一段话。输出：一系列被重新挖掘出的具体细节的档案。

## 当用户想要练习但未明确指定时

| 情境 | 默认推荐练习 |
|---|---|
| “想创作点什么，但还不确定做什么” | 30分钟：约束条件发散法 + 生成3个方案 |
| “陷入瓶颈” | 5分钟：单一斜向策略 |
| “有灵感但难以抉择” | 30分钟：对每个灵感分别进行事前失败分析 |
| “想更深入了解X” | 1小时：詹姆斯·韦伯·杨快速构思法，或1天：单日漫游法 |
| “需要长期练习” | 多周：晨间笔记、图像沉浸法、萨普的盒子法 |

首次使用时不要同时进行多项练习。先选择一项，执行后看看会有什么结果。
