# 样式参考

## 核心样式

为快速选择准备的简化样式层级：

| 核心样式 | 对应样式 | 最佳适用场景 |
|----------|---------|--------------|
| `vector` | vector-illustration | 知识文章、教程、技术内容 |
| `minimal-flat` | notion | 通用内容、知识分享、SaaS产品 |
| `sci-fi` | blueprint | AI、前沿技术、系统设计 |
| `hand-drawn` | sketch/warm | 轻松、反思类、休闲内容 |
| `editorial` | editorial | 流程说明、数据呈现、新闻报道 |
| `scene` | warm/watercolor | 叙事性内容、情感表达、生活方式主题 |
| `poster` | screen-print | 观点阐述、社论、文化内容、电影相关主题 |

在大多数情况下可直接使用核心样式。如需更精细的控制，可查看下方的完整样式库。

## 各类型风格的特色

### 信息图 + vector-illustration
- 简洁的扁平化矢量图形，几何轮廓鲜明
- 鲜艳且和谐的色彩搭配
- 通过图标和标签构建清晰的视觉层次
- 现代专业，可读性极高
- 非常适合知识文章和教程

### 流程图 + vector-illustration
- 醒目的箭头和连接线
- 带有图标的独立步骤区域
- 清晰的流程走向
- 高对比度设计，便于阅读

### 对比分析 + vector-illustration
- 分割式布局，视觉分隔清晰
- 每一侧都有醒目的图标
- 通过颜色区分不同内容
- 一目了然的对比效果

### 框架展示 + vector-illustration
- 几何节点表示法
- 清晰的层级结构
- 醒目的连接线
- 现代化的系统图风格

### 信息图 + blueprint
- 具备技术精确度的示意图线条
- 基于网格的布局，区域划分清晰
- 单行字体标签，以数据为核心
- 蓝白配色方案

### 信息图 + notion
- 具有手绘感，风格亲切
- 柔和的图标，圆润的元素设计
- 中性色调，背景简洁
- 非常适合SaaS产品和效率工具相关内容

### 叙事场景 + warm
- 黄金时刻的光线效果，营造舒适氛围
- 柔和的渐变与自然纹理
- 具有亲和力，富有个人情感色彩
- 非常适合故事讲述

### 叙事场景 + watercolor
- 艺术感强的绘画风格
- 边缘柔和，颜色相互渗透
- 梦幻且富有创意的氛围
- 最适合生活方式和旅行主题内容

### 流程图 + notion
- 清晰的步骤指示标识
- 简单的箭头连接方式
- 最小化的装饰元素
- 重点突出流程的清晰性

### 流程图 + blueprint
- 具备技术精确度
- 详细的连接点设计
- 工程领域的美学风格
- 适合展示复杂系统

### 对比分析 + elegant
- 精致的分隔线设计
- 均衡的排版风格
- 专业感强的外观
- 适用于商业领域的对比分析

### 框架展示 + blueprint
- 精确的节点连接设计
- 清晰的层级结构
- 具有系统架构的感觉
- 适合技术框架相关内容

### 时间轴 + elegant
- 精致的设计标记
- 精心设计的排版
- 具有历史厚重感
- 适合专业演示文稿

### 时间轴 + warm
- 友好的进展呈现方式
- 自然的流程过渡
- 具有个人成长叙事的感觉
- 适合讲述成长历程的内容

### 叙事场景 + screen-print
- 醒目的轮廓线条，象征性构图
- 2-5种扁平色彩搭配半色调纹理
- 通过负空间反转呈现次要故事（图形与背景角色互换）
- 复古海报风格，侧重概念表达而非写实描绘
- 非常适合观点文章和文化评论

### 对比分析 + screen-print
- 分割式的双色构图（每侧一种颜色）
- 醒目的几何分隔线
- 用象征性图标替代复杂细节渲染
- 高对比度，视觉冲击力强

### 框架展示 + screen-print
- 带有模板切割边缘的几何节点设计
- 有限的色彩编码（每个概念层级一种颜色）
- 基于简洁轮廓的图标设计
- 以海报风格呈现层级结构，搭配醒目的字体

## 色彩方案库

色彩方案可覆盖样式的默认颜色。任何样式均可与任何色彩方案搭配使用（例如：`style=vector-illustration, palette=macaron`）。

| 色彩方案 | 描述 | 最佳适用场景 |
|----------|-------|--------------|
| `macaron` | 柔和的淡彩色块（蓝色、薄荷绿、薰衣草色、桃色），搭配温暖的奶油色背景 | 教育、知识分享、教程类内容 |
| `warm` | 温暖的大地色系（橙色、赤陶色、金色），搭配柔和的桃色背景，无冷色调 | 品牌宣传、产品展示、生活方式相关内容 |
| `neon` | 鲜艳的霓虹色系（粉色、青色、黄色），搭配深紫色背景 | 游戏、复古风格、流行文化相关内容 |
| `mono-ink` | 纯白背景上搭配黑色墨水，少量点缀性颜色（珊瑚红、淡青色、灰褐色） | 专业视觉笔记、“前后对比”类文章、技术宣言 |

完整规范文档：`references/palettes/<palette>.md`

如果未指定色彩方案，则使用该样式的默认色彩方案。

## 色彩方案覆盖规则

1. 先读取样式文件 → 渲染规则（视觉元素、样式规则）
2. 再读取色彩方案文件 → 颜色与背景设置
3. 色彩方案中的颜色将**替换**样式的默认色彩方案
4. 色彩方案中的背景色将**替换**样式的默认背景色
5. 样式的纹理描述保持不变
