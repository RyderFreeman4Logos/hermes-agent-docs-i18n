# 使用方式

该技能可通过 Hermes 中的自然语言触发，无需使用斜杠命令或 CLI 参数。

## 触发语句

- “为这篇文章配图” / “Illustrate this article”
- “给这篇帖子添加图片”
- “为 [path/to/article.md] 生成插图”

## 输入模式

| 模式 | 触发方式 | 输出目录 |
|------|----------|----------|
| 文件路径 | 提及文章路径（如 `path/to/article.md`） | `{article-dir}/imgs/`（默认值） |
| 粘贴内容 | 在对话中粘贴文章文本 | `illustrations/{topic-slug}/`（当前工作目录） |

## 用自然语言指定选项

用户可直接在请求中指定以下任意选项。若未指定，该技能会通过 `clarify` 工具进行询问。

| 选项 | 示例表述 |
|------|----------|
| 图片类型 | “以信息图形式呈现”，“制作流程图”，“以场景图形式展示” |
| 风格 | “采用蓝图风格”，“使用 Notion 风格”，“用水彩风格” |
| 预设模板 | “使用技术解析预设模板”，“故事讲述预设模板” |
| 色彩方案 | “使用马卡龙色系”，“仅使用暖色调” |
| 图片密度 | “少量图片”，“每部分一张图”，“丰富插图” |
| 语言 | “图片文字用英文” / “图片文字用中文” |
| 输出位置 | “将图片保存在文章旁边” / “把图片放入 `illustrations/` 目录” |

## 实际示例

**包含数据的技术文章**：
> 帮我为 api-design.md 配图，要求用信息图形式且采用蓝图风格。

**使用预设模板快捷指令**：
> 用技术解析预设模板为 api-design.md 生成插图。

**个人故事类文章**：
> 使用故事讲述预设模板为 journey.md 添加插图。

**包含大量插图的教程文章**：
> 为 how-to-deploy.md 生成插图，使用教程预设模板并设置较高的图片密度。

**观点类文章**：
> 用观点文章预设模板为 opinion.md 制作插图。

**自定义风格的应用**：
> 对 article.md 使用技术解析预设模板，但将风格改为 Notion 风格。
