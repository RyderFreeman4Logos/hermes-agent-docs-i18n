# unbroker

这是一项基于智能体的原生技能，能够跨各类数据经纪商和人物查询网站查找已公开的个人敏感信息，并将其删除。该技能会在条件允许的情况下自动运行；仅当遇到网站要求输入其无法通过的验证码、政府身份证明、电话验证或传真验证时，才会交由人工处理。

## 功能简介

目前有数百家数据经纪商公开存储着人们的姓名、当前及历史住址、电话号码、电子邮箱、亲属关系以及房产记录等隐私信息。这些信息的泄露往往会引发人肉搜索、跟踪骚扰和身份盗窃等问题。虽然删除这些数据是已有的解决方案，但这项工作量巨大，且存在诸多隐蔽的套路，同时处理后的信息也可能很快被再次发布（因为经纪商会重新上架这些数据）。EasyOptOuts、Incogni和DeleteMe等商业服务可以有偿提供此类服务，但它们属于封闭系统，用户还需将想要删除的具体信息交给不熟悉的第三方公司处理。

unbroker则整合了这些服务的核心功能——包括EasyOptOuts的自动化能力、Incogni的法律请求处理机制以及DeleteMe的验证与报告功能——打造出一项透明、可审计且可自主托管的技能，由用户自己的智能体来运行。它支持**多租户模式**（可分别管理自己、家人或客户的数据，且彼此相互隔离），采用**基于用户同意的原则**运作，并以**最大程度的自动化处理为首要目标，同时保留人工干预机制**。目前该技能主要针对美国市场，未来计划扩展至欧盟/英国（遵循GDPR法规）及全球其他地区。

其设计完全遵循Hermes框架的理念：一个轻量级的确定性Python命令行工具（`scripts/pdd.py`）负责管理所有状态数据（配置信息、档案记录、经纪商数据库、分级处理计划、记录台账、草稿文件和报告），而智能体则利用原生工具（如`web_extract`、`browser_*`、邮件发送功能、`cronjob`和`delegate_task`）来执行扫描和提交操作。[`SKILL.md`](SKILL.md)是该技能的官方参考文档。

## 安装指南

```bash
hermes skills install official/security/unbroker
```

接着启动一个新的 Hermes 会话并对其进行驱动（见下文）。该技能无需任何配置即可使用；通过设置一些可选的环境变量，可实现更高级的自动化功能（相关说明均记载于 `SKILL.md` 的“前提条件”部分）：

- `BROWSERBASE_API_KEY`：推荐的默认浏览器。这是一种具备真实家庭 IP 的云浏览器，能够正常处理软性/托管型验证码（如 Turnstile、hCaptcha/reCAPTCHA），从而使相关数据经纪机构仍能保持自动化处理状态。它并非验证码破解工具，也无法绕过高强度的验证挑战。
- 邮件处理采用两种无人干预模式：**浏览器模式**（使用 `pdd.py setup --email-mode browser`，无需存储密码；代理会通过您已登录的网页邮件发送退出请求并打开验证链接），或使用 **`EMAIL_ADDRESS` + `EMAIL_PASSWORD`** 进行 SMTP 发送及 IMAP 验证。若未提供这两种信息，则会退而为您生成待发送的邮件草稿。
- `age` 工具：对档案和记录进行静态加密。
- `google-workspace` 技能：用于共享 Google Sheets 状态跟踪表。

## 使用方法

通过 Hermes 会话对其进行驱动：

> “请使用该无人干预型技能将我的数据从各类数据经纪机构中移除。这是我的同意书。请以无人干预方式运行，并在最后向我展示需人工处理的任务汇总。”

代理会自动完成配置（若存在 `EMAIL_*` 类凭据，则选择程序化邮件发送；若有可用云浏览器则使用该浏览器；若安装了 `age` 则启用加密功能），记录下您的同意信息，随后开始执行自动化队列中的任务：扫描数据、优先处理家长相关数据、发送并验证邮件、安排再次检查。您将收到两次反馈：一次是在任务开始时，另一次则是关于所有需人工处理的任务的汇总信息。

其底层的 CLI 命令可通过 `terminal` 运行，格式为 `python3 scripts/pdd.py <cmd>`：

| 命令 | 用途 |
|---|---|
| `pdd.py setup --auto` / `doctor` | 自动配置（选择最能实现自动化的有效配置）并检查就绪状态 |
| `pdd.py intake` | 创建已同意处理的对象（收集别名、多个邮箱/电话号码及历史地址信息） |
| `pdd.py next` | 循环驱动工具：显示当前代理需执行的有序任务、人工处理任务汇总以及下一次启动时间 |
| `pdd.py brokers` / `refresh-brokers` | 列出人员搜索类数据经纪机构，或获取最新的 BADBOOL 清单及证书颁发机构注册列表 |
| `pdd.py registry` | 显示数据经纪机构注册列表的覆盖范围（目前约 545 家已纳入覆盖范围；还包括佛蒙特州、俄勒冈州和德克萨斯州的查询端口）；使用 `--search` 可查找特定机构 |
| `pdd.py drop` | CA DROP 一次性处理功能：通过单次请求将数据从所有已注册的经纪机构中删除 |
| `pdd.py plan` | 显示每个经纪机构的处理等级、方法、搜索维度以及需披露的具体字段 |
| `pdd.py fanout` | 将多个经纪机构分批分配给多个并行运行的 `delegate_task` 子代理 |
| `pdd.py record` | 更新记录本（基于经过验证的状态机）；自动标记再次检查的日期 |
| `pdd.py send-email` | 生成并发送退出请求、CCPA 或 GDPR 相关申请（收件地址固定为该经纪机构自身的地址） |
| `pdd.py poll-verification` / `verify-link` | 处理邮件验证链接（通过 IMAP 查询，或通过粘贴的文本在浏览器模式下进行验证） |
| `pdd.py render-email` | 仅作为草稿使用的备用方案（披露信息最少） |
| `pdd.py due` / `tasks` | 查看按计划需再次检查的任务队列，以及人工处理任务的汇总信息 |
| `pdd.py status` / `report` | 显示每个对象的当前状态，还可选择在 Google Sheets 中添加相应行 |

## 工作原理

- **默认为自动化处理**。在完成一次人工对话（包括信息收集和同意确认）后，代理会按既定顺序执行任务队列中的操作（通过 `pdd.py next` 执行）：扫描数据、优先处理家长相关数据、发送并验证邮件、按计划再次检查，整个过程无需暂停等待用户指令。所有需人工完成的任务（如政府身份验证网站、电话回访、高强度验证码网站的处理）会默默地汇总到运行结束时的汇总报告中（通过 `pdd.py tasks` 查看）。
- **分级自动化处理（T0 到 T3 级别）**。每项从数据经纪机构获取数据的操作都会被分为不同级别：从完全自动化处理，到需人工验证的自动化处理，再到需人工确认的处理，最后是仅需人工处理的操作。代理会始终选择最高可行级别的处理方式，只有在确实无法继续时才会升级为人工任务。
- **优先处理关联的家长数据**。许多数据经纪机构实际上都是从少数家长的原始数据衍生而来的，因此删除一个家长的数据即可清除其名下众多子账户的数据。计划引擎会优先处理这些关联的家长数据，而非独立的账户信息，并为每个家长生成经过字段验证的处理方案。通常情况下，这类方案会更倾向于使用“删除权”途径，而非单纯的屏蔽措施（例如 Whitepages 的隐私邮件功能，可避免电话回访），当然也有特定经纪机构的情况例外（如 PeopleConnect：删除您的用户数据虽会清除屏蔽设置，但无法阻止公共记录的重新列出，因此需采用屏蔽并持续维护的处理方式）。
- **基于多标识符的批量处理**。一个人的信息会以所有姓名/别名、电话号码、邮箱地址和住址的形式被索引。计划引擎会利用每个经纪机构支持的功能对所有这些标识符进行扩展，从而找到使用曾用名或旧地址注册的账户信息，而不仅仅是“主姓名加当前所在城市”的信息。
- **先验证再披露**。在确认存在真实的数据记录、确定匹配对象就是您本人而非同名者或亲属之前，不会提交任何信息。而且只会发送该经纪机构所要求的必要字段信息（遵循最小化披露原则；身份证号和社保号码绝不会主动提供）。
- **考虑司法管辖区差异**。请求会依据目标对象所在地区的适用法律进行提交：加利福尼亚州适用 CCPA/CPRA 法规，欧盟/英国适用 GDPR 法规，其他地区则适用一般的删除权请求规定。该工具绝不会提及目标对象无法行使的任何权利。
- **覆盖范围与商业服务相当甚至更优**。该工具提供两种处理途径：(1) 具有各站点独立退出功能的个人搜索网站（已整理出 19 个此类网站，包括 FamilyTreeNow、Radaris 和 Nuwber，同时还会从 [BADBOOL](https://github.com/yaelwrites/Big-Ass-Data-Broker-Opt-Out-List) 获取实时列表）；(2) **州级数据经纪机构注册列表**，作为另一独立的法律覆盖途径：目前已纳入加利福尼亚州数据经纪机构注册列表的机构约有 545 家，这是商业服务所依赖的权威数据来源；此外，佛蒙特州、俄勒冈州和德克萨斯州的查询端口也已纳入覆盖范围。
- **DROP 一次性处理功能**。加利福尼亚州的“删除请求与退出平台”现已正式启用：对于加利福尼亚州居民而言，只需提交一份经过验证的请求，即可一次性将其数据从**所有已注册的经纪机构中删除**，而 `pdd.py next` 会将该操作标记为最具效的处理方式。
- **记录本管理、审计与重新扫描**。每个案件都遵循经过验证的状态机流程，每一次个人身份信息の披露都会被记录下来（仅记录字段名称），已确认删除的数据也会按计划被重新扫描，以便及时发现数据被重新列出并再次进行处理。记录本的写入操作会通过文件锁定机制确保在多任务并行运行时数据安全。
- **默认采用隐私保护设计**。对象编号采用匿名化处理（编号、路径和日志中均不包含姓名信息），可选择使用 `age` 对档案进行静态加密，所有数据处理均在本地完成。该技能仅提供占位数据。

## 安全与伦理准则

- **需授权方可操作。** 该引擎在未获得明确授权记录的情况下，不会对任何目标进行扫描或采取行动。它属于数据删除工具，而非信息搜集平台。
- **仅限官方浏览器使用，禁止使用批量解算服务。** 默认的云端浏览器会像普通浏览器一样自动破解简单或受管理的验证码，但系统不提供任何验证码破解服务，也不支持指纹伪装功能。对于复杂的交互式验证挑战，则会转由人工处理。
- **最小化信息披露，如实报告结果。** 该工具仅提交经纪人所需的信息。“在免费搜索中不可见”的数据不会被标记为“已删除”，而那些仍可能被查询到的数据（如公共记录、付费服务保留的数据）则会如实披露。
- **个人身份信息处理方式。** 所有相关数据都存储在Hermes系统的主目录下（权限设置为`0600`，并可选择使用`age`算法进行加密），且每个数据条目都有匿名标识。
