# 导航/Markdown 活动检测功能

如需了解现行的纯 Markdown 检测工具及相关命令，请参阅 [markdown-README.md](markdown-README.md)。该功能会在隔离的 Chromium 环境中加载生产环境版本的桌面级 Markdown 组件与 CSS，检测硬断行/软断行以及高亮显示的代码内容，并在读取浏览器剪贴板内容之前，实际点击代码卡上的“复制”控件。这属于组件级的实时渲染验证，而非对原生 Electron 框架、导航功能、后端传输机制或 macOS 系统本身的检测，且不会发起任何后端请求或模型调用。

早期整合型的通知测试用例仍保存在 git 历史记录中的 `07a4da338bc` 版本中；而异步报告相关的代码变更则属于另一个分支。
