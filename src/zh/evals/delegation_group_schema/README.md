# 委派分组模式下的指标统计

`probe.py TREE OUTPUT [--independent]` 会在一个全新的、无凭证且禁止网络连接的临时环境中，整合真实的即时 CLI 工具定义。需在独立的解释器中分别针对基础配置和修复后的配置运行该命令，并使用相同的参数。此功能依赖 `tiktoken`（`o200k_base`），并基于压缩后的 OpenAI 函数 JSON 进行统计。该指标用于衡量架构的占用空间，而非模型质量或节省的费用。

基础配置哈希值：`b2aa855b626ff8688eb34b95c60ee8b6a4af3679`。

| 策略 | 基础配置的委托令牌数 | 修复后配置的委托令牌数 | 变化量 |
| --- | ---: | ---: | ---: |
| 默认关闭 | 927 | 826 | -101 |
| 显式开启 | 927 | 913 | -14 |

在相同配置的对比中，仅有 `delegate_task` 发生变化。整体即时 CLI 架构数量分别为：关闭状态为 7586 → 7485，开启状态为 7586 → 7572。该字段在开启状态下依然可用，其参数架构保持不变。重复整合操作后的数据在字节级上是稳定的。这两项约束机制还会检测静态/历史架构的不可变性、旧任务的标准化处理，以及分组/非分组交付方式的划分。在实现之前，基于基础配置的默认关闭状态下的暴露性验证已失败。

## 真实模型 N=1 子任务测试

已固定使用配置好的 Nous 模型 `google/gemini-3.7-flash`，不会回退到其他提供方。系统中还有一个独立的临时目录，仅用于存储复制的 Nous 认证信息以及最少的显式配置参数（不包含个人技能或记忆数据）。由于强制使用了默认的注册表架构，导致生成的请求为仅包含单个任务且无 `group` 字段的数组。随后的实际委托处理机制会构建并运行一个真实的 AIAgent 子进程，该子进程通过一次 API 调用即可完成任务，并返回 `GROUP_GATE_OK` 状态码。在整个子进程执行过程中，父工具的参数保持不变。此测试仅用于验证架构兼容性与执行流程，而非用于进行性能对比或验证异步处理的时间延迟。

在推理开始前，系统会读取实时目录，并为两次调用估算约 0.016 美元的预算（20k 字节的输入数据 + 1024 字节的输出限制）。

| 推理类型 | 输入数据量 | 输出数据量 | 推理过程（包含在输出中） | API 报告的 `usage.cost` |
| --- | ---: | ---: | ---: | ---: |
| 父进程架构调用 | 796 | 104 | 75 | 0.000987 美元 |
| 子进程推理 | 708 | 42 | 37 | 0.0006885 美元 |
| 总计 | 1504 | 146 | 112 | 0.0016755 美元 |

父进程请求编号：`gen-1788889571-fBLF8eStu3UAevfGtvgD`。原始提供方使用的费用数据与 `upstream_inference_cost` 的数值一致；这些均为 API 报告的费用，而非经过独立核实的门户系统账单。而子进程的本地估算工具则显示费用为 0.000551 美元，状态标记为“估算值”，不可将其视为正式费用凭证。完整的本地费用记录文件位于：`/tmp/delegation-group-live-receipt.json`。
